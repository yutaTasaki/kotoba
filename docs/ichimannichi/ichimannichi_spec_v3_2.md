# 一万日 v3.2 仕様書 — 一括入力・今月の言葉から引く・小修正

既存の index.html（v3.1 ＋コスト削減版）に追加する。同期・自動関連づけ・朝の流れは変えない。

## 1. 一括入力

### 目的
名言集のページや読書メモ、動画の文字起こしをまとめて貼ると、AI が「言葉・出典・タグ」に分解して下書きを作る。
「自分の言葉での一言」は AI が書かず、本人が書いた札だけ保存できる。

### 入口
- 「言葉」画面の右上「＋ 追加」の隣に「一括」ボタン

### 画面（一括入力）
1. 上部で種類を選ぶ：「本・名言集」「自分の話（文字起こし）」
2. 出典欄（本・名言集のとき必須。既存の出典候補チップから選べる）。文字起こしのときは動画タイトル欄（任意）。
   文字起こしの出典は自動で「自分（動画: タイトル）」、タイトル空なら「自分（動画）」
3. テキスト貼り付け欄（大きめ、上限 20,000 字。超えたら分割を促す）
4. 「分解する」ボタン → API を1回呼ぶ（Sonnet。設定の「朝の言葉・相談のモデル」を使う）
   - 本・名言集：「独立した言葉・一節・格言として意味が完結する単位に分ける。1つ 200 字以内。前後の解説文や見出しは含めない。
     各項目に既存タグ（一覧を渡す）から最大3つ選ぶ。既存で合わなければ新しいタグを1つだけ提案してよい。JSON のみ」
   - 文字起こし：「話し言葉の中から、本人の考え・気づき・言い切りとして独立して残す価値のある文を抜き出す。
     相槌、繰り返し、言い直し、本の引用そのもの（本人の言葉ではない部分）は除く。1つ 150 字以内に整えるが、意味と言い回しは変えない。
     最大 15 件。各項目にタグ最大3つ。JSON のみ」
   - 返答形式：`[{"text":"...","tags":["..."]}]`。壊れた JSON への対処は自動関連づけと同じ
5. 分解結果は「下書き」として保存される（data.json に `drafts` 配列。ノートと同じくエントリ単位でマージ、削除は tombstone）
   ```json
   "drafts": [{"id":"d_...","text":"...","source":"...","tags":[...],"createdAt":"..."}]
   ```

### 下書きの処理
- 「言葉」画面の上部に「下書き N 件」の帯を出す（0 件なら非表示）。タップで下書き一覧へ
- 下書き一覧：1件ずつカード表示。text と source、タグ（編集可）、その下に「自分の言葉での一言」の入力欄（空）
- 一言を書いて「保存」を押すと、通常のノートとして保存され（自動関連づけも走る）、下書きから消える
- 「捨てる」で下書きを削除。「あとで」で次のカードへ（順番の最後に回る）
- カードは1枚ずつ、スワイプまたは「次へ」で進む。残り件数を表示
- 一言が空のままでは保存できない（v1 からの原則を守る）

### 費用の目安
- 分解は1回の呼び出し（貼り付け 5,000 字で数円）。下書きの保存時に自動関連づけが1回ずつ走る（Haiku、キャッシュあり）

## 2. 引く：「今月の言葉から引く」モード
- 引く画面の最初（タップ前）に、小さく切替を置く：「すべてから」「今月よく届いた言葉から」
- 「今月よく届いた言葉から」：直近30日の journal（kind: morning と consult）の picks に出たノートを、回数の多い順に上位10枚まで集め、その中からシャッフルして1枚に止まる。
  10枚に満たなければあるだけで。0枚なら「まだ今月の言葉がありません」と出して「すべてから」に戻す
- 止まった後の演出・つながり表示・journal への記録は既存と同じ
- 選んだモードは端末に記憶する

## 3. 小修正
- 網の可視化：スマホで球をドラッグしたとき、画面全体が動いてしまう不具合を修正。球のタッチはドラッグ、空白のタッチはパン、2本指でズーム、と分ける
- 引くの記録：辿った先はすべて記録する現状のまま。ただし記録タブの「引く」では、同じ日の連続した引きは1つのカードにまとめて表示する（最初の1枚を大きく、辿った先を小さく並べる）
