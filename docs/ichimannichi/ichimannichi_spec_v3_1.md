# 一万日 v3.1 仕様書 — 名前・アイコン、X 投稿、引く画面、網の可視化

既存の kotoba v3.0（C:\kotoba\index.html）に追加する。同期・自動関連づけ・朝の流れは変えない。

## 1. 名前とアイコン
- アプリ名を「一万日」に変更。ページタイトル、manifest の name / short_name、ヘッダー表示、README
- アイコンは walk10000 の投稿画像と同じ緑のグリッド（黒背景・ネオングリーンの正方形グリッド）。
  walk10000 の描画コードを流用して 180px / 512px の PNG を生成する。文字は入れない
- リポジトリ名と URL は当面そのまま（yutaTasaki/kotoba）。ホーム画面のアイコンは削除して追加し直せば名前とアイコンが変わる
- 画面内の「kotoba」表記をすべて「一万日」に置き換える。データファイルやリポジトリ名は変えない

## 2. X 投稿

### 2-a. 朝の投稿にテキストを添える
- 朝タブの「Xで投稿」で共有シートを開くとき、画像に加えてテキストを渡す（Web Share API の text）
- テキストの初期値：
  ```
  【N日目 / 10000】

  今朝の言葉
  「（今朝受け取った1枚目の text）」
  — （source）
  ```
- 今朝の言葉を受け取っていない日は、1行目のみ
- 共有直前に編集できるよう、ボタンの上に同じテキストの編集欄を置く（編集内容はその日だけ保持）
- 画像には何も追加しない（walk10000 と完全に同一のまま）

### 2-b. ノート単体を画像で投稿
- ノート詳細に「この言葉を投稿」ボタン
- 正方形（1080×1080）の画像を canvas で生成し、共有シートへ（画像のみ。テキストは渡さない）
- デザイン：一万日（旧 kotoba）の配色。背景は濃色、text を大きく中央（長さに応じて自動で文字サイズを調整、最大12行程度）、
  下に source、さらに下に myWords を小さく。右下に小さく「一万日」。タグは載せない
- 出典が「自分」のときは source を「（自分の言葉）」と表示
- 文字サイズ調整と改行は日本語向け（句読点で優先的に折り返す）

## 3. 引く画面（YouTube 用の演出）
- 下部タブは増やさず、「言葉」画面の右上に「引く」ボタンを置く。押すと全画面表示に切り替わる
- 全画面：黒背景、上部と下部のナビを隠す。画面をタップするとシャッフル開始
- シャッフル：0.1秒間隔でノートの text がランダムに切り替わり、約2秒でだんだん遅くなって1枚に止まる。
  止まった瞬間に軽く拡大する。止まるノートは、直近30日で「引く」に出ていないものから選ぶ
- 止まった後：text を大きく、source、myWords の順に表示。2秒後に「つながり」が1枚ずつ0.5秒間隔で下に現れる（関係ラベル付き、最大5枚）
- つながりの1枚をタップすると、それを中心にして同じ演出（シャッフルなし、拡大→つながり表示）が始まる。これで網を辿れる
- 右上に小さく「×」（閉じる）と「もう一度」。長押しで詳細画面へ
- 「引く」で出たノートは journal に kind: draw で記録（date, picks: [{id}]）。記録タブの「朝の言葉」に「引く」の欄を追加するのではなく、
  「相談」の隣に「引く」タブを追加して日付順に表示
- 画面収録を想定し、アニメーション中に同期バーやトーストが出ないようにする

## 4. 網の可視化
- 「言葉」画面の右上に「網」ボタン。押すと全画面のグラフ表示
- d3-force（cdnjs から読み込み）で、ノード＝ノート、線＝リンク。線の色は関係ラベルと同じ（似ている＝アクセント、対立＝赤系、補足＝青系、手動＝グレー）
- ノードの大きさはリンク数に比例。ノードの色は出典ごとに自動で割り当て（凡例を右下に）
- ノードをタップするとその text と source がポップアップし、もう一度タップで詳細へ。ドラッグで動かせる。ピンチでズーム
- 上部に「出典」「タグ」の絞り込み。絞り込むと該当ノードと、それに繋がる線だけ残し、他は薄くする
- 孤立ノード（リンク0）は端に薄く表示
- 100枚を超えても動くよう、ノードのラベルはズームインしたときだけ表示する
- 「引く」画面の中からも開けるようにし、止まったノートを中心にした状態で表示する
