# kotoba — 言葉と考えのノート 仕様書 v1

## 目的
本や名言集で出会った言葉、偉人・著者の考え、自分自身の考えを1枚ずつ保存し、
関連するものを手動で紐づけて、忘れないように再会できるようにする個人用アプリ。

## 技術・公開
- 静的サイト（HTML / CSS / JavaScript、フレームワークなし。walk10000 と同じ構成）
- GitHub Pages で公開。リポジトリ: yutaTasaki/kotoba（public）
- iPhone のホーム画面に追加して使う（PWA: manifest.json、アイコン、standalone 表示、viewport-fit）
- データは localStorage に保存し、さらに private リポジトリ yutaTasaki/kotoba-data の data.json に
  GitHub API で自動同期する（walk10000 → walk10000-data と同じ仕組みを流用。
  Fine-grained token は設定画面で入力して localStorage に保存）
- 起動時: リモートの data.json を取得し、ローカルより新しければ取り込む。
  保存・削除のたびにリモートへ書き込む。失敗時は画面上部に小さく「未同期」表示し、次回保存時に再試行

## データ構造
```json
{
  "version": 1,
  "updatedAt": "2026-09-07T08:00:00+09:00",
  "notes": [
    {
      "id": "n_20260907_001",
      "text": "言葉本体（引用文、または自分の考え）",
      "source": "出典。本のタイトル／人名。自分の考えなら「自分」",
      "myWords": "自分の言葉での一言（必須）",
      "tags": ["無常", "執着"],
      "links": ["n_20260901_003"],
      "createdAt": "2026-09-07T08:00:00+09:00",
      "updatedAt": "2026-09-07T08:00:00+09:00"
    }
  ]
}
```
- `myWords` は必須。空のままでは保存できない（保存ボタンを無効にし、理由を表示）
- `links` は双方向。A から B を追加したら B の links にも A を入れる。削除も同様
- タグは自由入力。入力時に既存タグを候補表示（先頭一致）

## 画面

### 1. ホーム（起動画面）
- ランダムに1枚のノートを大きく表示（text → source → myWords の順、タグは小さく下に）
- 「次の1枚」ボタン。タップでカードを開ける（詳細画面へ）
- 右上に「＋ 追加」、下部に「一覧」「設定」

### 2. 追加／編集
- 項目: 言葉（複数行）、出典、自分の言葉での一言（複数行、必須）、タグ、関連ノート
- 出典は既存の出典を候補表示（同じ本を何度も入力しないため）
- 関連ノート: 検索窓に入力すると既存ノートが絞り込まれ、タップで追加。追加済みはチップで表示し ×で外せる
- 保存すると詳細画面へ

### 3. 一覧
- 新しい順。1行に text の冒頭＋出典
- 上部: キーワード検索（text / source / myWords を対象）、タグで絞り込み（複数選択可）
- タップで詳細へ

### 4. 詳細
- text、source、myWords、タグを全文表示
- 「関連ノート」欄: リンク先を一覧表示、タップでそのノートの詳細へ移動（連鎖して辿れる）
- 「編集」「削除（確認あり）」

### 5. 設定
- GitHub token 入力／同期先リポジトリ名
- 「今すぐ同期」「data.json をエクスポート（ダウンロード）」「インポート（読み込み）」
- ノート総数、タグ数、最終同期時刻の表示

## デザイン
- 読むためのアプリなので読みやすさ最優先。文字は大きめ（本文 17〜18px 相当）、行間広め
- 背景は黒に近い濃色、文字は明るいオフホワイト。アクセント色は1色のみ（落ち着いた色。蛍光緑は使わない）
- 装飾は最小限。ホームのカードだけ少し余白を多く取り、1枚の言葉が主役に見えるようにする
- 日本語フォントは端末標準（system-ui）でよい

## v1 に含めないもの（v2 以降）
- 意味的に近いノートの自動提案（埋め込み／Claude API）
- ノートと対話する機能
- 間隔反復（忘却曲線に合わせた再表示）
- 画像添付、複数ユーザー
