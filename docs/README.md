# docs の歩き方

**探しているものから引く。**

| 知りたいこと | 行き先 |
|---|---|
| 「あの作業、どうなった？」 | **`sekai/houkoku/`**（実行結果の報告書） |
| 「あれ、前に測ったっけ？」 | **`sekai/chousa/`**（調査の記録） |
| 「どう作る約束だったか」 | **`sekai/spec/`**（仕様書） |
| 「何を頼んだんだっけ」 | `sekai/shiji/`（指示書。**非公開**なので手元にだけある） |

## フォルダの中身

| フォルダ | 何が入るか | 公開 |
|---|---|---|
| `sekai/houkoku/` | 実行結果の報告書。**指示書1本＝報告書1本** | 公開 |
| `sekai/chousa/` | 調査の記録。測った事実そのもの（直しと結びついていないもの） | 公開 |
| `sekai/spec/` | 仕様書。これからどう作るか | 公開 |
| `sekai/shiji/` | 指示書・回答書 | **非公開**（`.gitignore`） |
| `sekai/data/` | 取り込んだ生データ | **非公開** |
| `toru/` | 撮るの指示書 | **非公開** |
| `kotoba/` `ichimannichi/` | 言葉・一万日の古い仕様書 | 公開 |

非公開のものは GitHub に送られないので、**お手元の `C:\kotoba` にしかありません**。

## 3つの違い（迷ったとき）

- **報告書**：頼まれた作業を1回やった記録。「何をして、どうなったか」。日付つき。
- **調査**：作業とは別に、事実を確かめた記録。「どのサイトが開けるか」など。あとで何度も引く。
- **仕様書**：作り方の取り決め。作業が終わっても残り、更新されていく。

## 書き方の約束

報告書は**使う側から見て何が変わったか**を先に書く。どの関数を直したかは書かない。
詳しい決まりは `sekai/houkoku/README.md` に。
