## 4. プロンプトの選ぶ作り

朝の取り込みのプロンプト（app/index.html の組み立て）を読んだ。

### 4.1 何件取れと言っているか

- 「12件を目安に返す（確認できたものだけ）」「件数を埋めるために出来事を作らない。12件は目安」（WORLD_PROMPT_COUNT=12）
- 初期投入は「12件まで」
- 「毎回必ず見るもの」の7件は「札にできてもできなくても checked に報告」「大きな動きが無ければ picked 0」
- 今日見るべき件は 0〜3件、「数を合わせるために選ばない」

実際の朝の回は2〜10枚（平均6.1枚）で、12件に届いていない。**「目安12件」を上限でなく目標として読んでいるかは、この数からは言えない。** ただし9/12（UTC）は1日に8回流して42枚になり、1日の量は「1回の件数 × 回数」で決まっている。

### 4.2 選ぶ基準の文面

| 節 | 文面 | 甲・乙との関係 |
|---|---|---|
| 冒頭 | 「これから効き続ける動き」だけを返す | 持続を言っている。**向きの変化（乙）でも根（甲）でもない** |
| 期間 | 直近7日間に動いたもの。ただし「その日のニュース」ではなく、これから数ヶ月〜数年にわたって効き続ける動きを選ぶ。発表そのものより、発表が示している力学を選ぶ | 「力学」は甲に近いが、何を力学と呼ぶかの基準が無い |
| 選び方（下限） | 返す札のうち、flow を書けるものを半分以上。届かないときは件数を減らしてでも守る。主体が書けない札は返さない | **量を書けるか**の基準。重要さの基準ではない。日次・週次の数字の札（枝葉）が通りやすい |
| 選び方 | 同じくらい重要なら、金額が出典に書かれている方を選ぶ | 「重要」の中身は書いていない |
| 探し方 | お金が動いた記録、残高の変化、主体の行動の3つを探す | 何を探すかであって、どれを先に選ぶかではない |
| 並べ方 | 重要だと思う順に並べる。上から読まれる | 並べる基準は書いていない（上3枚の核41%、以降23%で少し効く） |
| same（v20.48） | すでにある札と同じ出来事なら札にしない | 重複には効くはず。重要さとは別 |
| 今日見るべき件 | 金融や世界情勢に詳しくない人が、今日まず見るべきもの。型は詰まり・逃げ・囲い込み・無理・つぎ込み | 型は「何の動きか」で、**多くを説明するか・向きが変わるかは問うていない** |

**評価：**
- **「重要なものを先に選ぶ」作りになっていない。** 集める → 形を整える、の順で、選ぶ基準は「効き続ける」「お金が書ける」。本人が選んだ甲（多くを説明する）・乙（向きが変わる）の言葉は、どの節にも無い
- **「すでにある根」をチャットに渡していない。** 既知の概念・アクター・地層・最近のお金の動き・（v20.48 から）すでにある札は渡すが、「どの根がもう立っているか」は無い。だから、新しい札が「既存の根の枝」なのか「新しい根」なのかを、チャットは判断できない
- **「毎回必ず見るもの」の7件が枝葉を呼ぶ。** 週・日の数字から「大きな動きが無ければ0」と書いてあるが、実際は週次の口座の揺れ（4・21）や1日の払い出し（25）が札になっている
- **「flow を半分以上」は、根の札を落とす方向に働きうる。** 根の札のうち flow が無いものは11枚（115 ホルムズ1日7隻、116 米 CPI、30 FRB、53 長期金利など）。半分の下限を守るために、件数を減らすときに flow の無い根の札から落とされるおそれがある（推測。落とした札は記録されないので測れない）

## 5. 減らすなら何枚まで

### 5.1 今ある132枚

| 絞り方 | 残る枚数 | 失うもの |
|---|---|---|
| 重複・続報を畳む | 100 | ほぼ無い（29 輸入禁止、99 イランの追加支援など、続報の新しい事実は開けば見える形にする必要） |
| 核だけ | **43** | 枝葉57枚。1国ずつの IMF 融資（H の中身）、AI の1社ずつ、防衛費の1国ずつ。**H・J はほぼ空になる** |
| 迷いの無い核だけ | 21 | **E（関税）・H・I（円安）の根が全部消える**（核が全部迷いのため） |
| 根ごとに代表2〜3枚＋迷いの無い核 | **約25** | 根の中の細部。A は 115・19・82・92、C は 78・53・87・88 のように残る |

**見込み：画面の核として置くなら約25〜43枚。** 25枚にするなら、迷いの核（22枚）は人が1回ずつ見て決める必要がある（こちらの読みは揺れるため）。

### 5.2 これから入る分（推測）

- 実測では、朝の回の核は1回あたり0〜4枚、B13 以降は0〜3枚。9/13〜14 の3回では核1枚
- **1回の件数を12件目安から3〜5件にしても、核はほぼ落ちない見込み**（推測：これまでの回で核が5枚を超えた回は無い）
- ただし「多くの札から核を選ぶ」のと「最初から3〜5件だけ探す」のでは、チャットの探し方が変わる。件数を減らしたとき核が同じだけ入るかは、流して数えないと分からない
- 根が大体立った後は、**新しい札の多くは既存の根の枝か続報になる**（9/12 以降（UTC）の53枚のうち核13枚、うち新しい根を立てた札は0枚。全部 A〜I のどれかに掛かる）

## 測れないこと

- 振り分けの揺れ：1人の読み。迷い48枚（核の半分）
- 今日の3件の傾向：記録が1回分だけ
- プロンプトで落とされた札（flow 下限や12件目安で落ちたもの）：保存されていない
- 件数を減らしたときに核が同じだけ入るか：流して数える必要
- 札が4日間（9/11〜14）で作られていて、根が「長い目で本当に根か」は時間を置かないと分からない
