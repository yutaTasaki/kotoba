## 結果（先に）

1. **心配は当たっている。このままだと持たない。** 早いものは**あと約1か月（10月末）**で症状が出る（撮るの一覧から古い動画が消える）。重くなって使えなくなるものは**半年〜2年**で出てくる
2. **ただし、データベースに移せば直るわけではない。** 困っている所はどれも「置き場所」ではなく「使い方」の問題：
   - 起動のたび・画面を開くたびに**全部を読む**
   - 1件直すたびに**ファイル丸ごとを書き直す**
   - チャットへの依頼文に**全部を入れる**
   データベースにしても、この3つの作りのままなら同じように重くなる。端末の中はもう小さなデータベース（IndexedDB）を使っていて、そこには問題は無い。**9/14 の「GitHub のまま、読み方と分け方を直す」という結論は変わらない**
3. **9/14 に決めた直しは第1段（変わらないファイルは書かない）しか入っていない。** 第2段以降が止まったまま世界と撮るを作ったので、同じ型の問題が増えた。**一番大きく増えているのは「調べたこと」（note の記事・語り・幹の記録）で、1日約80KB。9/14 には無かった**
4. **勧めること：新しい機能を足す前に、下の「直す順」の1〜5を先にやる。** どれも今のデータを移し替えずにできる。GitHub の履歴・無料・自分のサーバー無しは全部守れる

## 2. 困る順（いつ・何が起きるか）

| 順 | いつ | 何が起きるか | 原因 |
|---|---|---|---|
| **1** | **10/31 ごろから** | **撮るの一覧・前の動画との比べ・これまでの動画の結果から、9月の動画が消えて見える**（データは残っている。端末に開いているのは「今日と30日前を含む月」だけ） | 撮るの画面は、端末に開いている月の記録しか見ていない。古い月を読みに行かない。**不具合で、量の問題ではない** |
| **2** | 今〜数か月 | 「幹の立て直し・割り振り」を押すと依頼文が大きすぎて使えない | 依頼文に**全部の札**を入れる（札1枚約150字）。今186枚で約2.8万字、1,000枚（約5か月後）で約15万字 |
| **3** | 半年〜1年 | 取り込む・読む画面と**設定**を開くたびに遅くなり、いずれ開けない | 世界の札の**全部の月**を読み込み、しかも**月ごとに GitHub へ取りに行く**（端末にあっても）。9/14 の「約200日で困る」はまだ直っていない。**しかも v20.49 から設定を開くだけでも同じことが起きる** |
| **4** | 1〜2年 | 起動が遅くなる、iPhone で落ちる | **調べたことを起動のたびに全部の月読む**。1日約80KB なので1年で約30MB、3年で約90MB |
| **5** | 2〜5年 | 言葉を保存するたび（見た印・使った回数の記録でも）に固まる | 保存のたびに、全部の言葉を全部の月に分け直して比べている。PC で測って：5,000枚で0.04秒、2万枚で0.3秒、5万枚で1.1秒。iPhone はこの数倍 |
| **6** | 数年 | 概念・主体のファイルが1回の同期で数MB | 札に出てきた番号の一覧を、v20.92 から上限なしにした。札10万枚で10〜15MB。これを丸ごと書き直す |
| **7** | 5〜10年 | 起動のたびに全部の言葉をメモリに置くのが重い | 5万枚で約180MB（うち7割がつながりの理由文） |
| **8** | 約9年 | リポジトリが1GB を超える | 書き込みの回数。9/14 の案（年ごとに新しいリポジトリ）は未着手で、リポジトリ名はまだ固定 |

**ほかに、少しずつ増えるもの（すぐには困らない）**
- **撮るの学びの依頼文**：口調・足すこと・避けることを上限なしで全部入れる。動画1本で3〜8件増えるので、100本を超えたころから重い
- **朝の取り込みの依頼文**：地層・よく使う出典・閉じていない幹を全部入れる（ほかの欄には上限がある）
- **消した印**（どのファイルにもある）、**消した言葉の全文（ごみ箱）**、下書きを言葉にしたときの印：どれも消さない。data.json は同期のたびに丸ごと読む
- **記録の索引**：月ごと×言葉ごとの数を1ファイルに持つ。27年で数MB
- **数字**：端末では全部の月を1つにまとめて持ち、保存のたびに丸ごと書く。27年で約10MB
- **言葉を1枚開く**と、その言葉が引かれた月を全部 GitHub から取りに行く。27年で数百回になりうる

## 3. 守りの穴（量とは別に）

| 穴 | 今どうなっているか | 困るとき |
|---|---|---|
| **書き出し（手元に控える）が一部だけ** | 「言葉と記録を書き出す」は言葉は全部、記録は開いている月だけ。筋トレ・瞑想・世界・調べたこと・撮るは入らない | GitHub の鍵が切れた・アカウントに入れない、が重なったとき。GitHub 以外に全部の控えが無い |
| **大きさの知らせが無い** | 設定に端末の大きさは出る。GitHub 側の大きさ、1GB 近い、ファイルが50MB を超えそう、の知らせは無い（9/14 に「段3」として決めて未着手） | 気づいたときには超えている |
| **ホーム画面から通信なしで開けない** | Service Worker が無い。開いた後に切れても端末のデータで使える | 電波の無い所で開いたとき |
| **世界の1ファイル物は、2台で同時に書くとその回の同期が止まる** | 次の同期で直る（消えはしない） | 2台で同時に使うとき。低 |

端末のデータが勝手に消されないようにする設定（永続化）は、v20.94 から入っている。

## 4. 直す順（勧め）

**どれも、今のデータの形を移し替えずにできる。** 上ほど早く困り、直しも小さい。

| 順 | 直すこと | 効くもの | 大きさ |
|---|---|---|---|
| **1** | **撮るの画面が、古い月の動画も読みに行く**（一覧は索引から、開いたら読む） | 困る順1（10/31 ごろから消える） | 小。**10月中に** |
| **2** | **端末にある月は、索引の日時が同じなら GitHub に取りに行かない**（9/14 の案 B1）。先に「札・記録を直したら索引の日時も必ず変わる」ようにする（今は枚数が変わらないと日時が変わらないので、このまま B1 を入れると**2台目に直しが届かなくなる**） | 困る順3の通信 | 中 |
| **3** | **取り込む・読む画面と設定で、全部の月を読まない**。読む枠は索引に「未読のある月」を持って、その月だけ読む。設定の世界の欄は索引の数だけ出す | 困る順3のメモリ | 中 |
| **4** | **全部の札を入れる依頼文に上限**（幹の立て直し・割り振り、撮るの学び、朝の地層・出典・幹） | 困る順2、撮るの学び | 小〜中 |
| **5** | **言葉の保存で、変わった月だけ書く**（全部を分け直さない） | 困る順5 | 小 |
| 6 | 調べたことを、起動時は今月・先月だけ読む（記事と語りは開いたとき読む） | 困る順4 | 中 |
| 7 | 撮るの動画を記録の月ファイルから出して、1本1ファイルに（`toru/<番号>.json`） | 記録の月ファイルの書き直し（601回×200KB）、困る順1の根 | 中 |
| 8 | 全部を書き出すボタン（GitHub の全ファイルを1つの zip か JSON に） | 守りの穴 | 小 |
| 9 | 大きさの知らせ（9/14 の段3：リポジトリ 800MB・1GB、1ファイル50MB、同期3日なし） | 困る順8の予告 | 小 |
| 10 | 概念・主体の番号の一覧を札の側から数え直す／言葉のつながりを開いたときに読む（9/14 の B3）／リポジトリ名を設定に（9/14 の段4） | 困る順6・7・8 | 大。**数年のうちに** |

**やらないほうがよいこと**
- **データベース（Supabase など）への引っ越し**：9/14 の理由のまま（履歴が残らない、無料の枠は1万日で超える、1週間使わないと止まる、上の作りを直さないと同じく重い）
- **履歴を詰め直す**：戻せなくなる。1GB が近づいたら、年ごとの新しいリポジトリに分けるほうが安全

## 5. 決めてほしいこと

1. **新しい機能の前に、直す順1〜5を先にやってよいか。**（1は10月中に入れないと、10月末に9月の動画が一覧から消えて見える）
2. **撮るの動画を1本1ファイルに分けるか（直す順7）。** 分けると記録の月ファイルが小さくなり、動画ごとの履歴が GitHub で追いやすくなる。代わりに移し替えが1回要る（戻すボタン付き）
3. **全部を書き出すボタンを作るか（直す順8）。** GitHub 以外に控えが無い状態をなくす

## 付録：測り方

- kotoba-data を手元（作業用の一時フォルダ）に写し、各日の最後の版のファイルの大きさ・中身の内訳・書き込みの回数を数えた。中身は変えていない
- 言葉の保存の重さは、本物の言葉を5,000・2万・5万枚に増やして PC で測った（iPhone はこの数倍と見る）
- コードは v20.105 を読んだ。9/14 の案 B1〜B7 のうち入っているのは B6（変わらないファイルは書かない）と、B5 の半分（数字を月ごと）だけ
