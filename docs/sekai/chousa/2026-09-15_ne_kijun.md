## 気づいたこと

### 1. K3（ずれ）に偏る
- 当たり27回のうち14回が K3。K3 は取り込み時に書かれた zure 欄にほぼそのまま引っ張られる（根Aの29枚で zure は5枚、C 5/15、D 6/19、F 8/21）。
- 同じ型のずれの繰り返し（「大きく言って小さく打つ」#63→#112→#119、「約束だけで金が動かない」#14→#40→#121）を 0 にしないと、③は毎回書き直しになる。**「前のずれと別の型か」を判定させる文面が要る**。
- 根の主体でない札のずれ（#103 中国の資本注入、#47 IMF、#50 ドイツの断定）で③が書き換わる危険。「この根の主な主体の」と限る必要がある。

### 2. K1（得る側・払う側）は厳しすぎ、「足す」が行き場を失う
- 厳しめでは K1 は4回だけ。一方、答えに無い得る側・払う側・主体が増えるだけの札が20枚あった。
- 「今の答えと違う」を字義どおりに読むと、答えは最初の2枚の薄さのまま育たない。ゆるく読むと毎回書き直しになる。
- **5つ目の出口として「足す（書き直しではなく付け加え）」を分けるのを勧める**。履歴の重さも「書き直し」とは分けられる。

### 3. K2 と K4 の区別がつきにくい例
- #115 米軍がタンカーを沈めた：#62 の読み「沈めずに見せしめだけ」と矛盾（K2）とも、米国が封鎖から撃沈へ強めた（K4）とも読める。
- #3 モカ制圧：#71「紅海は戻る」の逆（K4）とも、読みの矛盾（K2）とも。
- #98・#87：米財務省・FRB が買い手に回る。K4 だが、どちらが先に来るかで片方だけが K4 になる。
- 分け方の案（推測）：**K2 は主体の「読み（狙い）」が外れたとき、K4 はお金・物の流れの向きか増減の符号が変わったとき**、と流れの欄に結びつけると揺れが減りそう。

### 4. 基準が作る見かけの書き直し
- **週・日の数字の札に意図を読むと、読み同士が矛盾する**：#21「口座を積んで FRB に迫る」と #4「FOMC 前に資金を厚くする」（C の K2 はこれ1回だけ）。枝葉の札の読みは K2 の相手にしない方がよい。
- **eventDate と数字の月のずれ**：#71（6月までの年度の数字、eventDate 8/11）が「紅海は戻る」を作り、#120（7月の数字、eventDate 9/11）が #55（8月に減った）と逆に見えた。
- **最初の答えが周辺から始まる**：A は #18・#69、F は #13（米国がイスラエルに払う）から始まり、根の中心の札（#19 生産停止、#115 ホルムズ）はどの基準にも当たらないまま通り過ぎた。出発点の札（指示書3.6）か核の札から答えを始めないと、4基準では中心へ寄っていかない。

### 5. 4つ以外に要りそうな基準
1. **足す**（上の2）
2. **事実の食い違い**：#82（フーシ派が攻撃）と #90・#128（イラクからのドローン、日付も 9/8・9/10・9/11 と揺れる）。②の「サウジは誰に向けて止めたか」が変わるのに、4基準のどれにも入らない。
3. **予告の結果**：根の欄に「予告と結果」があるのに、3.4 の基準に予告の当たり外れが無い。いまは forecasts.json の33本のうち待ち32本・確かめられない1本（#110 の「9/14 に大手銀行」）で、答えを動かせる結果はまだ0本。
4. **根の中心の差し替え**（上の4の3点目）。

### 6. 1枚が2本の根にかかるとき
- 2本の根にかかる札8枚のうち3枚が片方だけ変わった：#55（A：K1 K2／D：0）、#62（A：K1／D：0）、#48（A：K1△／D：0）。どれも A が変わり D は変わらない。
- 逆に、表の割り当てに無い根が変わるべき例：#110 の「EU は歓迎しただけで費用なく乗った」は F（欧州が埋める）にも効くが、F に付いていない。**割り当ての漏れが書き直しの漏れになる**。

### 7. 札の中身で答えが書けたか
- ①は flow（from→to）と detail で大体書けた。ただ flow は「動いたもの」で「誰が損を負うか」ではない（カタールの失った240億ドルは detail、サウジの石油部門25%縮小も detail）。flow が無い札は A 6枚、C 2枚、D 8枚、F 7枚。
- ②は actors の read が頼り。wants は報じ手の狙いが混ざり（「読者に伝えたい」「調査会社について」）、②には使いにくかった。
- ③は zure 欄にほぼ頼った。said はあるのに zure が空の札（#6 OPEC「完全な遵守」なのに出せない）は拾えない。
- **足りなかったもの**：根の前提そのものの札（A「なぜ海峡が詰まったか」、F「米国の支援が止まった」）。F は前提が無いので、#125 で「米国は得る側」と出たとき、根の名前ごと揺れた。

### 8. 60字で切れた read の影響
- 4本の根にかかる札の read で、ちょうど60字のもの：A 29（21枚）、C 16（12枚）、D 19（14枚）、F 18（16枚）。
- 切れる位置は文末の「〜のため」「〜に向けて」の手前が多く、**②の「誰に向けた手か」の相手が落ちる**：#3・#123「…ホルム」、#120 インド「…と見せて」、#119「…自主的な取引」、#125「…先」、#126「…ユーロ」。
- 判定そのものは、why と readWas（前の短い読み、切れていない）で補えたので、当たり外れが変わった札は無かったと見ている（推測）。ただ #115 の K2 は #62 の切れた読み「…中間選挙まで新たな戦」に頼っており、#63 の why が無ければ判定できなかった。
- 読む回に渡すときに切れた読みしか無いと、②を書き直すための「前に読んだ手」が欠ける。論点6（データの傷を先に直す）を先にやる理由になる。

## 3.5 の小さな試し：30枚を2回割る（1人の揺れの目安、推測扱い）

- 選択肢：A／C／D／F／なし（2本まで）。30枚は根の端や「なし」を混ぜて選んだ。
- 1回目：番号順で割った。**ただし直前に振り分け表を読んでいたので、表と30枚すべて一致した（表の写しに近く、独立していない）**。
- 2回目：並びを変え、fact と why の頭90字だけを見て割った。
