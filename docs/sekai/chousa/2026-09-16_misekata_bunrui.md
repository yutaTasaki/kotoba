## 軸の意味（使った定義）

| 軸 | この札で効くもの |
|---|---|
| 場所 | どこからどこへ動いたか。距離・通り道・隣かどうかが意味を持つ |
| 大きさ | 額や量が、何か（前の額・他の主体・全体）と比べて大きいか小さいか |
| 構図 | 誰と誰がどちら側に並んだか（賛否・加盟・味方） |
| 時間 | 前の値から今の値への移り |
| 順序 | 前の動き → この札 → 次の動き の鎖 |
| 無 | 文だけで足りる |

「全体の中の割合」（内訳）は大きさに入れた。図にすると同じ形（比べる横棒）になるため。
