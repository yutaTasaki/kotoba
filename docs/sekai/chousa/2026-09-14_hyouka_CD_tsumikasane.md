## 2. 主体・概念・地層は「育つ」か

### 判定

| もの | 仕組み | 実際 | 判定 |
|---|---|---|---|
| **主体** | 新しい札が来ると、札の番号を足し、日時を進める。国が空なら入れる。**欲しがるもの（stance）は手書きだけ**。生成が書く欄は無い | 更新日時が作った日時と違う主体 43/93。**中身が書かれた主体 0**。欲しがるもの 0/93 | **育たない（札の束が伸びるだけ）** |

| **概念** | 説明は**空のときだけ**書く。つながりは同じ札に出た回数を足すだけ。「この概念を厚くする」はコピーして Claude に聞くだけで、答えを概念に戻す欄は無い | 説明の長さ 26〜51字の1文、書き直しの跡なし。概念に聞いた記録 0件 | **育たない** |

### 根拠の要点

- 「札が増えるほど主体の像が濃くなる」は、**主体の画面で時系列に述べた／推定が縦に並ぶ**ことでだけ実現している。まとめ（この主体はふだん何を欲しがっているか、読みがどう変わったか）はどこにも蓄積しない
- 自分で調べた記録（4件、見つけたこと合わせて93項目、うち流れのあるもの多数）は**主体・概念に一切足されない**。どの札とも番号でつながっていない（見つけたことの札番号 0/93）。深く追った話ほど、積み重なりの外に置かれている

### 3-3 まとめ

- 「主体を核に広げる」道は**ある**（札→主体→時系列→札）

- 「概念を核に広げる」道は、概念が広すぎ・関係の文が概念側に無い・札の3分の2から概念に行けない、の3つで**働いていない**

- **良い点**：1つ1つの説明は正確で短く、お金の動きを読むのに要る語が選ばれている（実質金利・財政支配・財政余地・期間プレミアム・準備預金・政府の現金残高・域外適用・資産凍結・コンディショナリティ・比較可能な待遇 など）。札の前提として「AとBの関係」を1行で書かせる作りは、体系の芽になっている

- 判定：**「理解の体系」ではなく「札に付いたタグの定義集＋共起の回数」**。ただし中身の質は良いので、材料としては使える

### 5-2 根拠が流れ・思惑に結びついているか

- **結びついている（良い）。** 33本すべてが元の札を指し（33/33 が今ある札）、**元の札の主体の推定を「元の推定」として写し持つ**（33/33、今の札の推定と一致）。主体は33本とも主体の置き場にいる（19主体）。元の札の26/33（79%）にお金・ものの流れがある
- 動詞が「止める／貸す／買う／動かす」の4つに絞られ、「当たりの印」（どこで確かめるか：FRB H.4.1、日銀営業毎旬報告、米財務省プレスリリース など）が付く。**思惑を「次にこう動くはず」という確かめられる形に落とす作りとして、よくできている**
- 例：FRB「保有証券の圧縮を止め、残高を6.4兆ドル台で横ばいに」← 元の推定「総額を絞りながら中身を短期国債へ寄せ…停止を求められても後戻りできる余地を確保している」
- 弱い点：印が報道（Axios・CNN・FXStreet／icrypex の市場レポート）の予告がある。「日銀が1.25%に上げる」と「1.25%後は据え置く」のように**同じ読みから両側の予告**が出ているものがある（両方当たり得るので、読みの確かめとしては弱い。推測）

| 予告の画面から元の札へ行けるか | **行けない** |
| 札・主体の画面に、その読みから出た予告と結果が出るか | **出ない** |
| 当たりの時に「読みの筋で当たったのか、たまたまか」を残す欄 | **無い** |
| 読み違いの中身（どこを読み違えたか）を書く欄 | **無い**（3択だけ） |
| 率 | 当たり・外れが揃うまで割合を出さない。確かめられないが溜まったら「印の立て方を見直す時期」と出す |

- 判定：**仕組みの芯（読み→確かめられる行動→印→一次ソースでの確認→本人の判定→読み違いの印）は揃っている。** ただ、
  1. 判定が0件で、まだ一度も回っていない
  2. 押す画面に「何を読んでいたか」が出ないので、読み違いかを選ぶ時に元の札を探しに行く必要がある（推測：押されにくい）
  3. 結果が主体・札に戻らないので、「この主体の読みは何回当たったか」が積み重ならない
  4. 「当たったが筋は違った」を残せない
- → 今は「当たり外れを付ける仕組み」で、「理解を確かめる仕組み」になりきっていない
