| today（今日の3件） | 型：詰まり・逃げ・囲い込み・無理・つぎ込み | △ | − | − | 地図の見方としては良い。思惑の3つとは別の軸 |
| 選び方・分野 | 「どちらが正しいかを書かない。誰が何に縛られているかを書く」「発表そのものより、発表が示している力学を選ぶ」 | ○ | ○ | − | 方向は合っている |

朝のまとめ：①は why で半分、②はほぼ問うていない、③は said で土台だけ。「相手」「得る側・払う側」「表の説明とのずれ」を問う文は朝には無い。

### 3-3 読むプロンプト（worldReadPromptText）

| 項目 | 文面 | 評価 |
|---|---|---|
| read の問い方 | 「損を承知でやっているなら、何を犠牲にしたかを書く（儲かることをするのは当たり前で、思惑は読めない）」「なぜその時期に、その相手に、その額なのかまで書く」 | **①と②に一番効いている文**。実際、サウジ生産の札の read「当面の輸出収入を捨てて設備の残存を優先」や、トルコ銀行の read「規模ではなく機能」のように、犠牲・時期・相手まで書けている |
| 「同じ主体には違う読みを書いてください」 | 同じ文の繰り返しを防ぐ意図 | **主体ごとの一貫した狙いを積み上げるのとは逆向き**。前の札での読みを見せずに「違う読み」を求めるので、米財務省の読みは「予告で自主的に降ろさせる」系が5枚で言い換えられている（w_20260910_14、w_20260911_9 など）。まとめた戦略にはならない |
| 材料 | fact・why・detail・source・actors・flow・concepts・つながる札2枚（概念が重なる札の fact だけ）。**wants と premise は渡していない** | 札の外が見えないので、②を札をまたいで読むことができない。つながる札の選び方が「概念の共有」だけ。チョークポイントのような広い概念はイラン・サウジ・半導体をまたぐので、話の筋にならない（推測） |
| zure | 「said と did がずれている札は、そのずれの中身を1文で」 | ③に直結して良い。ただ said が必要なので半分の札で立たない。said と detail の数字、wants と detail のずれ、前の said と今の did のずれは対象外 |
| fork / forecast | 「3か月ほどで決着する分かれ目」「その思惑が本当なら、次に起きるはずの行動を1つ」 | **思惑を確かめられる形にしていて、とても良い**。33本すべて waiting か unverifiable で、まだ1本も確かめていない。同じ札から2本出た重複が3組ある（w_20260904_4、w_20260907_2、w_20260911_1） |
| 60字切れ | 「必ず書き直す（rewrite を true）」 | 仕組みはある。枠（cut の割り当て）で少しずつしか回らず、102枚が残っている |

読むのまとめ：①は「犠牲」の問いで○、②は主体ごとに閉じていて相手の欄が無いので△、③は zure で○だが said に依存。

### 3-4 ②に一番近い構造は、札の外にある

- **聞く（worldAskPromptText）** は主体ごとに want・fear・bound を書かせる。さらに「他の主体と食い違う点が分かるように」「誰と誰の望みがぶつかっているかが見える形に」「誰が、何と引き換えに、何を得ているか」と頼んでいる。**①②をそのまま問う文面**だが、asks は2件だけで、札とも主体台帳ともつながっていない。
- **自分で調べたこと（dig）** は、問い・主体ごとの did/said/read（出典つき）・分からないこと（open）という形。**思惑を調べる型として一番良い**。ただ found の read は札の actors.read に戻らない（札の候補として新しい札になるだけ）。
- **主体の画面** には「ふだん欲しがるもの（手書き・任意）」と「この半年の動きを読む」（時系列を貼って、述べた理由と動かした金額のズレを聞くコピー）がある。前者は0件で、後者は答えを保存しない。

## 4. 「お金の流れ → なぜ → 誰の思惑」は札1枚で閉じるか、札をまたいで組み上がるか

**札1枚：閉じる作りになっている（実際に書けている）。**
- flow（誰から誰へいくら）→ why（なぜ今）→ actors.read（主体ごとの思惑）→ zure（言っていることとのずれ）→ fork/forecast（確かめ方）が1枚にそろう。
- 良い例は w_20260904_4 トルコ銀行。flow「中国の製油業者 → イラン政府 石油代金をトルコ経由で金と現金に替えて渡す 数千万ドル」、why「金に替える出口が残ると制裁が抜ける」、read「出口を一点だけ潰し…他行に次は自分だと思わせる」、zure「小銀行にとどまる」、予告「金への換金に関わる金融機関を1行以上追加で制裁指定」。
- ただし1枚で閉じるので、思惑も「その週の、その主体の、その一手」の範囲に止まる。

**札をまたいで：組み上がる仕組みは、部品はあるがつながっていない。**

| 仕組み | 状態（実測） | 筋を組むのに使えるか |
|---|---|---|
| flow.after | 6/132、うち時間が逆2本・同一出来事2本 | 実質使えていない |
| related | 0/132 | 使われていない |
| follows / same（v20.48） | 実装済み、取り込みの記録は0件 | これから。ただ理由の欄が無く、札に残らない |
| 概念の共起リンク（concepts.links） | 45概念、自動で共起を記録 | 「同じ見方の札」は集まるが、「同じ話の札」にはならない（チョークポイントは3つの話すべてに出る） |
| 主体の eventIds と主体の画面 | 93主体、出来事一覧と動かしたお金 | 並べるだけ。stance は0件、読みの要約・一貫性の欄が無い |
| 読む回のつながる札 | 概念が重なる2枚の fact だけ | 同じ主体・同じお金の流れの札は選ばれない |
| 予告（forecasts） | 33本、確かめ済み0本 | 思惑を時間で確かめる唯一の糸。ただし結果がまだ無い |
| dig / asks | dig 4本・asks 2件 | 一番深い。ただ札・主体・話に戻らない |

欠けているのは **「話（筋）」という単位の器**。核になる問い、それに属する札、主体ごとの得る物・失う物・相手、表の説明と実際のずれの一覧、予告を、1か所にまとめて更新していく場所。今は、本人が頭の中で札を並べて組み立てる前提になっている（推測：本人がそれを dig と聞くで補っているように見える）。

## 5. 良いところ

1. **事実と推定をきっちり分けている。** did（出典の行動）／said（出典の主張）／read（推定）が別の欄で、朝は read を書かない。書き直すと readWas に元の文が残る（132件）。思惑を扱うときに一番大事な土台ができている。
2. **read の問い方が鋭い。** 「儲かることをするのは当たり前で、思惑は読めない」「なぜその時期に、その相手に、その額なのか」。実際の読みも「規模ではなく機能」（トルコ銀行）、「放出ではなく交換の形を取り続けているのは、買い戻しの予算措置を議会に通さずに在庫を回せるから」（w_20260910_10 米戦略備蓄）のように、金融に詳しくない人でも筋が追える具体性がある。
3. **zure 欄がある。** ③を独立した欄にしていて、埋まった41枚は「言いながら〜にとどまる」「述べたが〜だけ」と具体的な食い違いになっている。
4. **お金の欄が正直。** total/share で「追えなかった分を消さない」、pledge で「約束と実行を分ける」、「推定しない・合計しない」。①を数字で支える下地になっている。
5. **思惑を確かめる仕組み（forecast）がある。** 「その思惑が本当なら次に起きるはずの行動」を期限・印つきで書かせる。「自分の判断に使える」に直結する、他ではあまり見ない設計。
6. **dig と聞くの型が①②に合っている。** 主体ごとの want/fear/bound、問い・found・open。本人の深掘りは実際にこの型で質の高い答えになっている（EA の「四半期開示からの解放という利点は…経営陣個人の利点に近い」、Micron の「資金では生産能力を前倒しできないため、長期契約で順番待ちの列に先に並んでいる」）。
7. 確度が低い札（フーシ派の噂系は確度2〜3）を捨てずに印を付けて残している。

## 6. 足りない仕組み（方向だけ。設計は別途）

1. **「話」の器**：核の問いと、属する札・主体・お金の流れ・予告を束ね、①②③の現時点の答えを1か所で更新する。follows と dig がここに流れ込む形が自然（推測）。
2. **①のための欄**：flow の受け手を具体名にする。「得る側／費用を払う側（最後に負担する人）」を札か話の単位で書かせる。
3. **②のための欄**：read に「誰に向けた手か（相手）」を足す。または話の単位で、聞くと同じ want/fear/bound の主体表を持つ。
4. **読む回に、同じ主体の他の札での読みを渡す**。「違う読みを」ではなく「前の読みと合っているか・変わったか」を問う。
5. **③を広げる**：wants を読む回に渡す。said と数字（detail）のずれ、前の said と後の did のずれ（予告の答え合わせ）も zure の対象にする。
6. **データの傷を先に直す**：60字で切れた read が残る102枚、同じ出来事で主体や日付が食い違う札（パイプライン停止3枚）、flow が fact と違う札（サウジ協調融資）、時間が逆の after。
7. **dig / 聞くの結果を札と主体に戻す道**（found の read を actors.read や主体の stance の候補にする、など）。
