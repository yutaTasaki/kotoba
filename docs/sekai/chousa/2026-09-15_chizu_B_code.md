## 1. 枝の札を開いたときの画面

### 札の画面は「一覧の中で開く」形しかない

- 札を1枚だけ出す専用の画面はありません。**札はいつも「札の一覧」の中の1行で、押すとその行の下に中身が開く**（開けるのは一覧の中で1枚だけ。別の行を押すと前の札は閉じる）
- 「札を開く」には2つの入り口がある
  - **その札を開く**：いま出ている一覧にその札が入っていれば、一覧はそのままでその札を開き、そこまで流す。入っていなければ「日付 の札」という1枚だけの一覧を作って開く
  - **一覧を開く**：題・札の並び・最初に開く札を渡して、札の一覧の画面を出す（幹の画面の枝の行・続報・お金の一覧の「同じ動きの札」などはこちら）
- 葉・根も、同じ札の画面です（葉・根のための別の画面は無い）

### 上から並ぶもの（札を1枚開いたとき）

一覧の行（閉じていても見える）：
1. 日付
2. **何が起きたか**（見出し）
3. 右端の印：★／地層の短い名／前提のタグ（2回目以降は回数）／「自分で作った」／「調べた」／「確度N」

行を押すと、その下に開く中身（この順）：

| 順 | 中身 | 出るとき |
|---|---|---|
| 1 | 「自分で調べて作った札（元の札：…）」と「自分で入れた値：…」 | 自分で作った札だけ |
| 2 | **続報**：「続報の前の札：日付 見出し ▸」／「この後の続報 N枚 ▸」 | 続報があるときだけ |
| 3 | **幹の行**：「幹：〇〇 ▸」（最大2本）。葉なら「葉（まだどの幹にも付いていない）」（押せない1行） | 幹があるとき |
| 4 | **なぜ**（なぜ今動いたか。用語は押せる） | いつも（無ければ「なぜ今動いたかが書かれていません」） |
| 5 | **動かした側**：名前＋したことの1行ずつ。押すと「述べた」「ずれ」「推定」「前の読み」「途中で切れていた読み」「まだ読んでいません／いま読む ▸」「この主体の動きを見る」 | 主体があるとき |
| 6 | **ドル換算の1行**：「30億ユーロ ≒ 約34億ドル（推定・ECB 6/25）」 | 換算済みで、ドル建てでない金額のときだけ |
| 7 | **前提**の箱（前提の名前・1行・「N回目・前は…」・「この概念を見る」） | いつも（無ければ「（前提なし）」） |
| 8 | 用語・地層のボタンの行、用語の説明 | あるとき |
| 9 | **つながる札**（最大3件＋「ほか N件」） | あるとき |
| 10 | 確度の理由「確度 N/5：…」 | 理由があるとき |
| 11 | ボタンの行：☆／**詳しく**／Claude に聞く／調べたことを戻す／非表示 | いつも |
| 12 | 聞く型のボタン・戻す欄・コピーの結果 | 押したときだけ開く |
| 13 | **「詳しく」の中身**（既定で閉じている）：本文の詳しい文／選んだ理由／**お金の動き**／出典／確度（理由なし）／この出典が欲しいもの／url | 「詳しく」を押したときだけ |
| 14 | **自分で調べたこと（N回）** | 記録があるとき |
| 15 | 分かれ目：… | あるとき |

**お金の動きの欄の文言（そのまま）**：見出しは「お金の動き：」「物の動き：」「人の動き：」の3つ（動きの種類で変わる）。中身は
「［物］」「［人］」の印（お金は印なし）＋「出す側 → 受け取る側　何 額（期間：…）／〇〇のうち△△（N%）の行き先が分かった」＋「約N億ドル（推定・ECB 6/25）」＋自分で入れた欄があれば「（出す側・額：自分で入力）」。
例：「お金の動き：カナダ → 米国 酒と乳製品 500億ドル」

**大事な点**：**「誰から誰へ」は、既定では札の画面のどこにも見えていません。** 「詳しく」を押して初めて出ます。押さなくても見えるお金の情報は、6番のドル換算の1行（額とドルだけで、出す側・受け取る側は書かない）だけです。
「動かした先」という文言はコードにありません（手で札を作る画面の欄の名前は「出す側」「受け取る側」「何」「額」）。

### 枝を次々に開く道

- 幹の画面の「枝 N枚」の行（新しい順に10行まで、同じ出来事の組は1行にまとめる）を押す → **その幹の枝を全部並べた札の一覧**（題は幹の名前、新しい順、同じ出来事の組もまとめずに全部）が開き、押した枝が開いた状態で、そこまで流れる
- 「次の札」のボタンはありません。**次の枝は、開いた札の中身の下にある次の行を押す**（押すと今の札は閉じ、次の札が開く。流す位置は動かさないので、上の札が閉じたぶん画面がずれる）
- 札の中の「続報」「つながる札」を押したとき、その札が同じ一覧の中にあれば、一覧のまま開いて流す。無ければ1枚だけの一覧に移る（戻るで幹の一覧に戻れる）
- 「ほか N枚 ▸」は、同じ枝の一覧を、どれも開いていない状態で出す

### 地図を置く候補の位置

札の中身の高さは札ごとに違うので、押し下げの量は地図の高さそのもの（前回の見積もり：世界地図 約175px＋下の枠 約68px＝**約240px**。いまの小さな地図は 178px）。

| 候補 | その位置の前後 | 置いたときに押し下げられるもの | 読むときの様子 |
|---|---|---|---|
| **A 文の上**（幹の行のすぐ下、なぜの前） | 前：見出し（行）・続報・幹の行　後：なぜ | なぜ・動かした側・ドル換算・前提・用語・つながる札・ボタンの行・詳しく・調べたこと・分かれ目＝**札の中身の全部** | 見出しのすぐ次に地図。なぜ（一番読む文）が 240px 下がる。iPhone では、札を開いた直後に文が画面の外に出ることがある。**その下に並ぶ次の枝の行も 240px 下がる** |
| **B 文の下**（ドル換算の1行のすぐ下、前提の箱の前） | 前：なぜ・動かした側・ドル換算の1行　後：前提の箱 | 前提・用語・地層・つながる札・確度の理由・ボタンの行（★・詳しく・聞く・戻す・非表示）・詳しく・調べたこと・分かれ目・次の枝の行 | 「なぜ → 誰が動かした → いくら（ドル）→ 地図」と読む順に並ぶ。ドル換算の1行が地図の見出しの代わりになる。**ボタンの行が 240px 下がる**（★や「詳しく」を押すまでに流す量が増える） |
| **C お金の動きの欄の中**（詳しくの中、「お金の動き：」の行のすぐ下） | 前：本文の詳しい文・選んだ理由・お金の動き　後：出典・確度・この出典が欲しいもの・url | 出典・url・自分で調べたこと・分かれ目・次の枝の行（詳しくを開いたときだけ） | 「誰から誰へ」の文と地図が隣になる。ただし**「詳しく」を押さないと出ない**（押す回数1）。閉じているあいだは何も押し下げない |

補足：
- A・B は「動きの無い札」（前回の実測で枝112枚のうち33枚）でも位置を取るかどうかを決める必要がある。描けないときは地図を出さず1行にするなら、押し下げは起きない
- どの位置でも、札の一覧の中なので、**開いている札の下にある「次の枝」の行が押し下げられる**。枝を次々に開く読み方では、毎回その分流すことになる
- 同じ画面で開ける札は1枚だけなので、地図が2つ同時に出ることは、札の一覧の中では起きない（幹の画面の地図と、札の中の地図は、別の画面）

### ドル換算：地図タブ以外で動く場所は無い

- **レートを取りに行って札に書き込む処理を呼んでいるのは、大きな地図を開いたとき（地図タブ）の1か所だけです。今もそうです。** 小さな地図・国の網・札の画面・取り込み・同期のどれからも呼んでいません
- 書き込んだ値は札そのものに入る（月のファイルに保存され、同期で他の端末にも行く）。だから**読む側は地図タブ以外にもたくさんある**
- 同じ処理の中で「金額の書き方が直された札の古い換算を消す」もしている。これも地図タブを開いたときだけ

**地図タブをなくすと、そのままでは壊れるもの**（新しく入った札・金額を直した札から順に）：

| 壊れるもの | 様子 |
|---|---|
| 札の画面の「≒ 約N億ドル」の1行、詳しくの中のお金の動きのドル | 出なくなる |
| お金の鎖・単発・お金の一覧・地層の画面のお金・主体の「この主体が動かしたお金」の行の「約N億ドル（推定…）」 | 出なくなる |
| Claude に聞くでコピーする文の中のドル | 入らなくなる |
| 線の太さ（小さな地図・国の網の矢印・これから作る画面ごとの地図） | 換算の無い線は「換算できない点線」になる。杭も一番細い形になる |
| 金額を直した札 | 古い換算が残り続ける…ではなく、読む側が「書き方が違う換算は使わない」ので、ドルが消えたままになる |

## 3. 地図タブの入口と出口

### 入口（コードで数えた全部）

| 入口 | どこ | 備考 |
|---|---|---|
| 「地図」ボタン | 世界の画面の「お金の動き（単発）」（鎖が無い日は「お金の流れ」）の見出しの右、「お金の一覧（N）」の隣 | **お金の動きが1件も無い日は、見出しごと出ない**（ボタンも出ない） |
| 小さな地図 | 世界の画面。上から「幹 N本 ▸」→今日動いた幹／今日見るべき件→「予告 ▸」→「調べたこと ▸」→**小さな地図**→今日の地層→お金の鎖・単発 | どこを押しても大きな地図へ。描けなかったとき（読み込み失敗）も押せば大きな地図へ。中の文「押すと大きな地図（90日）」「確度3以下で外した線 N本（押すと大きな地図で一覧）」 |
| 網から戻る | 国の網・市場の網の「地図に戻る」ボタン、上の「← 戻る」 | 網の入口は地図の中だけなので、網から戻ると必ず地図 |
| 地図から開いた札の一覧から戻る | 一覧の「戻る」、上の「← 戻る」 | |
| アプリを開き直したとき | 4時間以内に開き直すと、最後に見ていた世界の画面に戻す決まりに「地図」が入っている | |

**入口が無いところ**：ホーム（朝）・設定・札の画面・幹の画面・主体の画面・お金の一覧からは、地図へのリンクはありません。国の点は地図の中の物で、地図の外には国の点はありません（主体の画面の「国」の1行は地図の部品で国名を出すだけで、押しても地図には行かない）。

| 押す物 | 行き先 |

| 線1本 | その動きの札の一覧（1枚ならその札を開いた一覧）。戻ると地図 |
| 国の点 | その国の網 |
| 「市場」の枠 | 市場の網 |
| 「国際機関」「地域」の枠 | その枠が絡む動きの札の一覧 |

## 4. 地図の描き方は使い回せるか

### 部品の読み込みとキャッシュ

- 世界地図の部品は、アプリの中の assets に置いた5つ（d3-array・d3-geo・topojson-client の3つのスクリプトと、国の形 countries-110m.json、国の表 world_countries.json）
- **初めて地図の部品が要ったときに1回だけ読み、読み終わった結果（国の形の一覧・国名の表・国の点の位置）をアプリが開いているあいだ覚えておく**。読み込みに失敗したら覚えを捨て、次にもう一度読む
- 使っている所：大きな地図・小さな地図・国の網・主体の画面の「国」の1行（4か所とも同じ覚えを使う）
- **覚えているのは「国の形のデータ」まで。画面に描く形（177か国の輪郭の線）は、毎回作り直している**（幅と寄せ方で変わるため）。前回の実測で、描く時間の大半（PCで約50ms）はここ

### 2つの描く関数

| | 小さな地図 | 大きな地図 |
|---|---|---|
| 受け取るもの | 描く箱・部品・組み立てた動き | 部品・組み立てた動き・地域 |
| 描く箱 | **渡された箱に描く**（どこにでも置ける） | **地図タブの決まった箱に描く**。数の行・選ぶ一覧・点検の一覧・説明・地域と種類のボタンも、地図タブの決まった場所に書く |
| 画面の状態 | 使わない | 地域・種類の選択、押した判定の控え（試験用）を世界の状態に書く |
| 描く物 | 国をまたぐ線だけ（枠・枠への線・国内の印・国名・約束の見分け・杭は無い）。押しても線は選べない | 全部 |
| 大きさ | 高さ178px 固定、世界全体 | 幅に合わせる。世界全体か、決まった4地域の四角 |
| 矢印の部品の名前 | 決まった名前が1つ | 決まった名前が2つ（普通・白抜き）＋杭の濃さの名前 |

**同じ画面に2つ以上の地図を置くと、矢印の部品の名前がぶつかります**（大きな地図の描き方を2か所で使うとき）。形は同じなので見た目は同じになることが多いが、先に描いた方が隠れる（閉じた札の中など）と、後の地図の矢印が出なくなるブラウザがある（推測）。いまは小さな地図と大きな地図が別の画面なので起きていない。

### 札の集合だけで描けるか

- **動きを組み立てる関数は「札の一覧」を受け取りません。** 受け取るのは「いつから」の日付だけで、中で**端末に読み込んでいる全部の札**から、日付・確度3以下・同じ動きのまとめ、を通して組み立てる
- **90日は組み立ての中には固定されていない**。大きな地図・国の網が「今日から90日前」、小さな地図が「7日前」を、呼ぶ側で渡している
- 札1枚ずつの「両端の場所を決める」「外国の持ち主への支払いを市場に寄せる」は別の関数に分かれているので、**「札の一覧を受け取って組み立てる」形は、今の組み立ての最初の絞りを差し替えるだけで作れる**（新しく書く量は小さい）。ただし「同じ動きを1行にまとめる」は、渡した札の中だけでまとめることになる（前回の実測では、幹の札だけで組み立てると PC で 5ms）
- 絞り込みの結果（地域・種類で絞ったもの）には、点検の一覧用の欄が入っていない。点検の件数を出すなら、絞る前の組み立てを使う

### 「ある線だけ濃く・ほかを薄く」

- 今の線の見分け（大きな地図）：
  - 普通の線：濃さ85%
  - 物・人・換算できない：細い点線
  - 累計・期間あたり：破線
  - **約束：濃さ40%＋白抜きの矢印**
  - 太さ：ドル換算の5段
- 線は1本ずつ別の形として描いていて、動き（札）ごとに見分けの印を付けている。**「この札の線」に印を足すことは、今の描き方のまま簡単にできる**
- ただし**「ほかを薄く」を濃さで表すと、約束の40%とぶつかる**（薄い線が「約束」なのか「ほかの枝」なのか分からない）。約束は白抜きの矢印でも見分けているが、細い線では矢印が小さい
- ぶつからない表し方の候補（どれも今の描き方に入る）：
  - 濃くする線だけ色を変える（今は全部同じ色）／ほかの線を灰色にする
  - 濃くする線を太くしない（太さは額の意味なので使えない）
  - 濃くする線だけ最後に描いて上に重ねる
- **気をつける点**：同じ国の組は太い順に5本までで、6本目から「ほかN本」。濃くしたい枝の線が細い（額が小さい）と、隠れる側に入る。「濃くする線は必ず描く」の決まりが別に要る
- 小さな地図は約束の見分け（薄さ・白抜き）を持っていない

<small>コードの場所：部品の読み込み＝worldLoadMapLib()（覚え＝worldMapLibP）→ worldBuildMapLib(d3, topojson, atlas, table)（features・byName・nameOf・anchors、あとから _countryAliases・shortNames）。組み立て＝worldMapModel(lib, from)（中で worldLiveEvents() を絞る。札1枚の場所＝worldFlowPlacesHow ＋ worldApplyForeignHolder、まとめ＝worldMergeFlows）。大きな地図＝worldDrawMap(lib, model0, region)（#worldMapBox・#worldMapStatus・#worldMapChooser・#worldMapUnknown・#worldMapGuide 決め打ち、marker id 'wmArrow'／'wmArrowOpen'／'wmRootFade0..'、worldState.mapHits／mapView）。小さな地図＝worldDrawMiniMap(box, lib, model)（marker id 'wmMiniArrow'、WORLD_MINI_H=178）。90日＝WORLD_MAP_DAYS を renderWorldMap／renderWorldNet が渡す、7日＝WORLD_MINI_DAYS。線の印＝class 'wmL' ＋ ' dot'／' dash'／' pledge'、CSS .wmL{opacity:.85} .wmL.pledge{opacity:.4}、5本＝WORLD_MAP_LINES_PER_PAIR。</small>

## 5. 幹の画面の並び

上から（幹を1本開いたとき）：

1. 題：幹の名前
2. 一言（誰が得をし、誰が払う話か）
3. **今の答え**（答えが無ければ「答えはまだ（…）」の1行。あれば ①②③ の3欄、それぞれ文と「履歴 N回」）
4. **まだ分からないこと**（あれば。「分かった N件」の折りたたみ）
5. **根**（「まだ（朝の取り込みで1本ずつ探します）」／「見つからなかった：…」／根の札の行「日付　見出し」。押すとその札）
6. 主な主体（多い順に5つ、押すと主体の画面）
7. 見る地層
8. 予告 N本
9. **枝 N枚**（新しい順に10行、同じ出来事の組は「同じ出来事 ほかN枚」、自分で調べた札に印、「ほか N枚 ▸」）
10. この幹を外す
11. 戻る

前回の名前の「出発点」は、v20.55 で「**根**」になっています（欄の名前も「根」）。前回勧めた「出発点のすぐ下、主な主体の前」は、**今のコードでは 5「根」の欄と 6「主な主体」の間**です。答え・分からないこと・根の3つは1つの関数でまとめて並べていて、その後に主な主体以下を並べる作りなので、**その切れ目にちょうど1つ差し込める**。

気をつける点：
- 枝の月を読み込む処理は、根の欄を並べた直後に始まる（読み込み終わると幹の画面を描き直す）。地図をここに置くと、**読み込み中は枝が足りない地図**になり、読み込み後に描き直される
- 根の札は、いまは幹の画面の「根」の行と、札の画面の幹の行（根の札も幹に付く）でしか見分けがつかない。**札の画面には「この幹の根」という印は無い**

<small>コードの場所：renderWorldMiki()。1〜5＝worldMikiAnswerEls(t, body)（根の欄＝sec('根')、A.starts）、その直後に need（月の読み込み）→ 主な主体（WORLD_MIKI_ACTORS_SHOW=5）→ 見る地層 → 予告 → 枝（WORLD_MIKI_BRANCH_SHOW=10）→ worldMikiCloseEl。差し込み位置＝worldMikiAnswerEls の呼び出しの直後。</small>

### いま：枝の札を読んでいて「どこで起きたか」を地図で見る

| 3 | 「← 戻る」（幹の一覧 → 世界の画面） | 3 |
