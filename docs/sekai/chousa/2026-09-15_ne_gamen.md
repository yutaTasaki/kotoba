## 14. 根の一覧をどこに置くか。既定画面を変えるか

### いまの既定画面（世界の画面）の並び（コードから）

上から：古い未読の帯 → 今日見るべき件（最大3） → 予告 ▸ → 調べたこと ▸ → 小さな地図 → 地層の1行 → 「確度3以下は外しています」 → お金の鎖（最大3本）・お金の動き（単発3）・地図・お金の一覧 → 今日動いた主体（5） → 背景の札 → 知りたいことから引く（問い） → 探す

→ すでに**12種類の塊**がある。概念の一覧はここに無い（設定 → 整理、か探すで打ったときだけ）。

## 16. 論点3「札の画面に流れの前後を出す」は根で要らなくなるか

**答え：要る。ただし根があると作り方が軽くなる。**（反対：根で代わりになる、とは言えない）

実測（仮の割り当て）：

| | 数 |
|---|---|
| いまの明示の前後（お金の動きの「前の動き」） | 6本・札11枚（8%） |
| その6本が同じ根の中か | **6本とも同じ根の中** |
| 根に入る札 | 120枚（根なし12） |
| 根の中を日付順に並べたときの隣どうし | 124組。**そのうち主体かお金の相手が共通なのは33組（27%）** |

- 根の画面で札を日付順に並べれば「同じ話の中の前と後」は見える。明示の鎖はどれも同じ根に収まったので、**鎖を根の画面の中に描ける**
- でも日付の隣の73%は、主体もお金の相手も共通しない（同じ根の別の枝）。**日付順は「流れ」ではない。** 前の動き→次の動きをたどるには、明示の前後（前の動き・続報）が要る
- 根をまたぐ流れ（評価の「中東の戦争 → エネルギー高 → 物価 → 利上げ → 国債」＝A・B・C の鎖）も、根の中の並びでは見えない

推奨：札の画面に出すのは
1. **明示の前後**（前の動き・続報。いま画面に出ていない「前の動き」を出す）
2. **同じ根の札（新しい順3枚）**を、いまの「つながる札（概念で結ぶ）」の位置に

失うもの：札の画面が長くなる。「同じ根の札」は流れの前後ではないので、見出しで「同じ根（日付順）」と分ける必要がある。
なお、札の中の**お金の動きは「詳しく」を押さないと出ない**（ドル換算の1行だけ外に出ている）。お金から見る狙いに対して、札の画面の並び自体が「なぜ → 動かした側 → （詳しく）お金」になっている点も論点3で一緒に見るべき（足りない論点）。

## 20. 根は動線のどこに入るか（図）

### 今の実際の流れ（v20.48、コードから）

```
朝タブ
 ├ 待っている予告 N本 ▸ ───────────→ [予告の画面]（答え合わせ）
 │                                     元の札・元の推定へは行けない（袋小路）
 ├ 世界・動いた主体 N（畳んだ行。開くと今日動いた主体）
 └ 今日の取り込み（N件）
        │ 押す1（数秒後にコピー）
        ▼
 [取り込む画面]  コピー → (チャット) → 貼る → 取り込む
        │ 結果の1行：入れた件数・同じ・続報・今日見るべき件
        │
        │ 同じ画面の下の欄「読む」：コピー → (チャット) → 貼る → 取り込む
        │   → 札に 推定・ずれ・分かれ目、予告が入る（結果の1行だけ。見に行くのは別）
        │ 戻る
        ▼
 [世界の画面]
   今日見るべき件 ──────────────┐           ← 着火点
   予告 ▸ ／ 調べたこと ▸ ／ 小さな地図 ／ 地層 │
   お金の鎖（3本）・お金の動き（単発3） ────┤           ← お金の動き
   今日動いた主体（5） ─────────┐  │
   問い ▸ ／ 探す                  │  │ 押す1
                                 │  ▼
                         押す1   │ [札]（その場で開く）
                                 │  なぜ → 動かした側（行動）→押す→ 述べた／推定（意思）
                                 │  つながる札（概念で3枚）・地層・用語・詳しく（お金）
                                 │  前の動き・後の動き：出ない
                                 ▼    │ 押す2
                          [主体の画面] ◀┘
                           時系列に 述べた／推定（意思が縦に並ぶ）
                           ＝線の終わり。ここで止まり、次の朝に何も戻らない

 横の部屋：設定 → 整理 → [概念]／探す → [概念]
```

線は「着火点 → お金 → 行動 → 意思」の順に**画面の上から下へは並んでいる**。ただし
- 意思（推定）を書く「読む」は取り込む画面の下の欄にあり、書いた結果は札に散る
- **意思で線が終わり、翌朝の取り込みに何も戻らない**（評価の「札が根に組み上がらない」）

### 根を入れた後（推奨）

**根は線の途中の部屋でも、横の部屋でもなく、線の終点に置き、翌朝の着火点に戻す（輪にする）。** 画面では、その終点（根の今の答え）を世界の画面の一番上＝着火点の位置に出す。

```
 着火点 ──→ お金の動き ──→ 行動 ──→ 主体の意思 ──→ 根：今の答え①②③
(朝の取り込み)  (札のお金)   (動かした側)  (読む回の推定)   (読む回が書き直す／「変えなかった」)
   ▲   取り込みで「どの根の枝か」を付ける                               │
   └────────── 翌朝のプロンプトに 根の一覧（と核の札）を渡す ─────────────┘
```

```

 └ 今日の取り込み ─押す1→ [取り込む画面]
        コピー（根の一覧入り）→ (チャット) → 貼る → 取り込む
        結果の1行 ＋「根に付いた枝：ホルムズ +2・AI +1／どの根にも入らない 2枚

        │ 戻る
        ▼

   今日動いた根（0〜数行） ──押す1──→ [根の画面]
```

### 根が概念と同じ道をたどらない条件（推奨）

1. **中身の書き手が毎日の回にいる。** 読む回が答えを書き直す。概念は「空のときだけ書く」だった
2. **「変えなかった」を必ず返させ、結果の1行に出す。** 回ったことが見える。概念は黙って止まっていた
3. **人に頼むのは「根を立てる」だけ。** 統合・名前直し・親子のような整理を人に頼まない（概念ではこの操作が0回）
4. **根を立てる入口を、取り込みの結果の1行に置く**（候補が出たその場で押せる）。根の一覧の見出しにも「候補 N件」
5. **入口が毎日通る場所にある**：取り込みの結果・読む回の結果・世界の画面の一番上・札の画面（札の画面は実際に一番手を動かしている場所）
6. **本数を10本前後に抑え、3本目のサインで切り方の粗さを見せる。** 概念は「チョークポイント」30枚で広がりすぎた（仮の割り当てで、チョークポイントの札は根 A 23・D 5・E 2・G 2…の8か所にまたがる）
7. **止まったら見える**：根の一覧に答えの更新日を出す（催促の印は出さない）

### それでも残る穴（推測）

- **答えは読む回に乗っているので、読む回が止まれば根も止まる。** 読む回は今は取り込みの直後に回っている（9/14 は9分後）。ただ、読む回に誘う朝タブの1行は「読んでいない札が8枚以上」のときだけ出る。論点2で取り込みを1回3〜5件に減らすと、8枚に届かず1行が出ない日が増える（推測）。**根の答えを読む回に乗せるなら、この8枚の境目も一緒に見直す必要がある**
- 札が来ない根（静かな根）は読む回に載らないので、答えは書き直されない。数ヶ月〜数年の話なので止まっていてよいが、「止まっている」と「変わっていない」を分けて見せる必要がある

## 24. 根が育つと朝・読む回が楽になるか

**答え：押す回数は楽にならない（増えもしない）。楽になるのは「読む回に渡すもの」と「どこから見るか」。根だけでは読む回の回数は減らず、論点2（取り込みを根に効くものに絞る）と組んだときに初めて回数が減る。** 世話は小さいが、読む量は増える。

| 場面 | 楽になるか | 具体的に | 実測／推測 |

## 足りない論点（足した）

1. **「根」という名前がもう使われている。** 地図の「自分に使う」で、主体の国の点から下へ伸びる線を「根」と呼んでいる（v20.30〜v20.32、点か根を押すと「網」と「根」を並べて選ぶ画面もある）。同じ世界タブで「根」が2つの意味になる。どちらかの名前を変えるか決めてほしい（地図の方は画面の文言に出ているので、変えると v20.31 の説明文も直すことになる）
2. **札の画面で、お金の動きが「詳しく」の中にある。** 動線の2番目（お金）が札の中では畳まれている。根を足す前後で、札の画面の並び（なぜ → 動かした側 → お金）を見直すか
3. **取り込む画面に「取り込み・初期投入・読む」が縦に並んでいる。** 根の候補を新しい欄にするとさらに長くなる。候補は結果の1行から開く形にし、欄は足さない方がよい
4. **根 A が大きい**（仮の割り当てで29枚、2番目の F の約1.4倍）。10本でも1本に偏る。根の画面は核と枝を分けて畳む前提にするか、A を「ホルムズ」と「紅海」に割るか（割り直しのときの論点）
5. **読む回に誘う1行の境目（8枚）** は、根の答えを読む回に乗せるなら一緒に見直す（22 章）
6. **根の行の並び順**（枝が付いた日か、答えの更新日か）。静かな根を沈めるか、止まっている根を見せるかで逆になる
