# 調査の記録

**仕様書（`../spec/`）とは分ける。** 仕様書は「これからどう作るか」、ここは「何を測って、何が分かったか」。

## 何をここに書くか

- 実際に開いて・叩いて・数えた結果（URL が開けたか、何字だったか、いくらかかったか）
- 分かったことだけでなく、**分からなかったこと・外れた見立ても残す**（同じ道を二度調べないため）
- 測った日。ウェブ側の事情は変わるので、日付の無い調査結果は使えない

## 書かないこと

- 実装の手順（仕様書へ）
- 推測だけのもの。測っていないなら「未測定」と書く

## 名前の付け方

`YYYY-MM-DD_<題>.md`（例：`2026-09-12_iriguchi_torikata.md`）
