## 1. 第3段で何ができるようになるか

1. 地図の種類の絞りで「**自分に使う**」を押すと、**主体の国の点から真下に根**が伸びる（先は⊥、矢印なし、いつも実線、線と同じ色）
2. 相手の場所が分からない自分に使う金（今は TSMC の2本）も、**主体の国が分かれば根で描ける**。「自分に使う」のボタンは **18 → 20**
3. 自分に使う金のうち、**相手が別の国にある6本は横の線のまま**残る。「根14本・線6本」の形で、自分の将来に賭けた金のうち国の外へ出ている分がそのまま見える
4. 国の網で、国の中の「自分に使う」矢印の先が **⊥** になる（今のデータで9本）
5. 根を出す／出さないは**1か所**で切り替えられる。出さない側に戻すと、v20.29.1 と同じ画面になる

**札のデータは変えない。** 根にするかどうかは描くときに毎回決める。

## 2. 場所不明の「自分に使う」2本（TSMC）

### 2.1 根の意味

- TSMC の2本は主体の国（台湾）が分かっているので、相手の場所が分からなくても根を引く
- 根の意味は「**その国の中で使った**」ではなく「**主体が自分の側に積んだ（持ち主はその国の主体）**」。TSMC の「先端工程と海外工場」も、海外工場の分まで台湾に描かれる
- 「自分に使う金には相手がいない」は20本のうち14本にだけ当てはまる。残り6本は行き先が別の国にあるので線で描く（判断2）

## 3. 根の形と長さ

### 3.1 形

**【第4版】先の形は「下へ消える」（太さそのまま、点の下の濃さ0.85から先で0.15へ薄くなる）、長さ11px。** 先の形・長さ・押す範囲は同じ1か所の値で切り替える（`下へ消える`／`棒`／`くさび`／`⊥`）。形を変えると、描き方と「ほかの点に触れるか」の範囲が一緒に変わる。網の矢印の先は⊥のまま。以下は v20.30 の記録。


- 主体の国の点から**真下**へ、まっすぐ
- 先は **⊥**（横棒）。矢印は付けない
- いつも実線（期間つきでも破線にしない）。色は線と同じ
- 太さは線と同じ**ドル換算の5段**（1・2・3.5・5・7px）。換算できないものは線の点線と同じ細さ（1.2px）

### 3.2 細かい決め方

| 所 | 決め方 | 理由 |
|---|---|---|
| 1つの国に何本もあるとき | **1つの国に根は1本。** 太さはその中で**いちばん額の大きい1本**の段 | 本数だけ根を並べると日本（4本）・米国（4本）が横に広がり、隣の点に触れる。**太さを足さない**（合計しない決まり） |
| 何本分の根か | 根を押すと、その国の根の動きの一覧（見出しに本数） | 点の横の「（国内N）」は今のまま |
| ⊥の横棒 | **幅＝根の太さ＋4px、線の太さ1.5px** | 根より横棒が狭いと⊥に見えない。1.5pxなら太い根でも横棒が塊にならない |
| 約束の金の根 | **線と同じ薄さ（不透明度0.4）**（判断4。今のデータで1本：モントリオール銀行 700億ドル・10年） | 「薄い＝約束」を根でも崩さない |
| 根の長さ | **いつも9px**（点の**中心**から⊥の横棒まで）。全体図も地域の図も、拡大しても同じ | 3.5 |

### 3.3 描くたびに測り、触れる国は出さない（判断3）

根を描く前に、その画面の根について次を決める。

1. 長さは **9px**（固定。1か所の値）
2. 根（縦棒と⊥の横棒）が、**その画面に描かれているほかの点**に触れるかを測る
3. 触れるなら、**その画面ではその国の根を出さない**。数には入れ、4.2 の行に「〇〇の図で見られる根 N（国名）」と出す

- 触れるかの幅（何を含めて測るか）：ほかの点の**半径3.5px＋縁の線0.5px**に、根の**縦棒の太さの半分**、または⊥の**横棒の太さの半分（0.75px）**を足した距離より近ければ触れる。横棒の幅（根の太さ＋4px）も含める。**線と字は含めない**
- 拡大して描き直すたびに測る（拡大すると点の間が広がるので、隠れていた根が出ることがある）
- **国名で決め打ちしない**

### 3.4 9px固定にした理由（第2版からの変更）

第2版は「14pxから始めて、触れる国があれば画面の根を全部同じだけ短くする」だった。承認書の案で、**いつも9px**にした。

| | 第2版（揃えて短くする） | 第3版（9px固定） |
|---|---|---|
| 端末によって | 9〜14px で変わる | 変わらない |
| 同じ端末で日によって | 近くに点が出る日は全部短くなり、**額が減ったように見える** | 変わらない |
| 拡大したとき | 14px に戻っていく | 変わらない |
| 地域の図 | 20px から | 9px |
| 根を出さない国 | 9pxまで短くしても触れる国 | 9pxで触れる国（**第2版と同じ条件**。固定にしても、出さない国は増えない） |
| 仕組み | 国ごとに14→9pxまで1pxずつ測り、一番短い長さを探す | 国ごとに1回測るだけ |

**失うもの：** 広い地図で14pxにできた根が9pxのまま。長さは額を表さないので、読む中身は失わない。**根らしさ**は短いぶん弱い（実機で見る）。

### 3.5 9pxで触れる国（実測）

「自分に使う」の画面で描く点（根の6か国＋線の端のベネズエラ・サウジ・シリア）で測った。**地図の幅＝画面の幅から左右の余白16pxずつを引いた幅**（例：画面390pt → 地図358px）。

| 地図の幅（画面の幅） | 全体図 | 米州・中東・アジアの図 |
|---|---|---|
| 288（320・初代 iPhone SE） | **日本→台湾の点に0.7px食い込む → 日本の根を出さない** | 触れない |
| 320（352） | 触れない（日本→台湾 すき間0.8px） | 触れない |
| 343（375・iPhone SE 第2・3世代など） | 触れない | 触れない |
| 358（390）・361（393） | 触れない | 触れない |
| 398（430・Pro Max など） | 触れない | 触れない |

- 今の iPhone の地図の幅（343〜398px）では、**どの国も9pxで触れない**
- 第2版までの表の「幅320／360／390」は、**地図の幅**の数字だった（画面の幅ではない）。画面320ptの端末の地図は288pxで、そこでは9pxでも日本が触れる

**固定の値を上げたとき（実機で9pxが短すぎた場合）に、全体図で日本の根が出なくなる地図の幅：**

| 固定の値 | 日本の根を出さない地図の幅 |
|---|---|
| 9px | 288 |
| 10px | 288・320 |
| 11px | 288・320（343 はすき間0.3px） |
| 12px | 288・320・343（358・361 はすき間0.3〜0.4px） |
| 13px | 288・320・343・358・361（375 はすき間0.4px） |
| 14px | 390未満のすべて |

日本の根を出さないときは、地図の下に「アジアの図で見られる根 1（日本）」が出る（アジアの図では触れない）。

### 4.4 押す

**【第4版】根の上を押したら、ほかに近いものがあっても、その国の根の一覧を直接開く。** 根の上＝根の形の左右と先の下に4px（画面の px。1か所の値）、上は国の点の下の縁より下。**根を出している画面では、国の点の上（点の半径＋同じ4px）を押したら、その国の網を直接開く。** どちらでもなければ今までどおり（22px の中を集めて、2つ以上なら一覧）。失うもの：点のすぐ下を押すと根が開く、根の上を通る線は根の上では選べない。押す範囲を8pxに広げると、台湾の点を押しても日本の根が開く（試した）。


- 根（縦棒と⊥）は、今の線と同じく**描いた形で押した所を判定**する（22px の中）。1つならその国の根の一覧、2つ以上なら今の「この辺りの線・国」に「〇〇の根（N本）」として並ぶ

### 4.5 国の網
