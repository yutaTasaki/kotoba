## 1. 第3段で何ができるようになるか

1. 地図の種類の絞りで「**自分に使う**」を押すと、**主体の国の点から真下に根**が伸びる（先は⊥、矢印なし、いつも実線、線と同じ色）
2. 相手の場所が分からない自分に使う金（今は TSMC の2本）も、**主体の国が分かれば根で描ける**。「自分に使う」のボタンは **18 → 20**
3. 自分に使う金のうち、**相手が別の国にある6本は横の線のまま**残る。「根14本・線6本」の形で、自分の将来に賭けた金のうち国の外へ出ている分がそのまま見える
4. 国の網で、国の中の「自分に使う」矢印の先が **⊥** になる（今のデータで9本）
5. 根を出す／出さないは**1か所**で切り替えられる。出さない側に戻すと、v20.29 と同じ画面になる

**札のデータは変えない。** 根にするかどうかは描くときに毎回決める。

## 2. 場所不明の「自分に使う」2本（TSMC）

### 2.1 根の意味

- TSMC の2本は主体の国（台湾）が分かっているので、相手の場所が分からなくても根を引く
- 根の意味は「**その国の中で使った**」ではなく「**主体が自分の側に積んだ（持ち主はその国の主体）**」。TSMC の「先端工程と海外工場」も、海外工場の分まで台湾に描かれる
- 「自分に使う金には相手がいない」は20本のうち14本にだけ当てはまる。残り6本は行き先が別の国にあるので線で描く（判断2）

### 2.2 今のデータで何本か

| | 本数 |
|---|---|

| うち自分に使う金 | **2**（TSMC → 先端工程と海外工場 600億ドル・期間 2026年、TSMC → 先端工程の製造装置・工場 157億ドル・期間 2026年4〜6月期） |
| そのうち主体の国が分かる＝根にできる | **2**（台湾） |
| 主体の国も分からない自分に使う金 | **0** |

残りの場所不明2本（世界の石油在庫→石油市場、日本→原油の輸出国）は自分に使う金ではないので、そのまま。

## 3. 根の形と長さ

### 3.1 形

- 主体の国の点から**真下**へ、まっすぐ
- 先は **⊥**（横棒）。矢印は付けない
- いつも実線（期間つきでも破線にしない）。色は線と同じ
- 太さは線と同じ**ドル換算の5段**（1・2・3.5・5・7px）。換算できないものは線の点線と同じ細さ（1.2px）

### 3.2 細かい決め方

| 所 | 決め方 | 理由 |
|---|---|---|
| 1つの国に何本もあるとき | **1つの国に根は1本。** 太さはその中で**いちばん額の大きい1本**の段 | 本数だけ根を並べると日本（4本）・米国（4本）が横に広がり、隣の点に触れる。**太さを足さない**（合計しない決まり） |
| 何本分の根か | 根を押すと、その国の根の動きの一覧（見出しに本数） | 点の横の「（国内N）」は今のまま |
| ⊥の横棒 | **幅＝根の太さ＋4px、線の太さ1.5px** | 根より横棒が狭いと⊥に見えない。1.5pxなら太い根でも横棒が塊にならない |
| 約束の金の根 | **線と同じ薄さ（不透明度0.4）**（判断4。今のデータで1本：モントリオール銀行 700億ドル・10年） | 「薄い＝約束」を根でも崩さない |
| 根の長さの測り方 | 点の**中心**から⊥の横棒まで。全体図14px・地域の図20pxから始める | 前の報告と同じ測り方 |

### 3.3 描くたびに測り、触れるならまず短くする（判断3）

根を描く前に、その画面の根について次の順で決める。

1. 長さを、全体図は **14px**、地域の図は **20px** で置く
2. 根（縦棒と⊥の横棒）が、**その画面に描かれているほかの点**に触れるかを測る
3. 触れるなら **1pxずつ短くして**、触れなくなる長さを探す
4. **下限**まで短くしても触れるなら、**その画面ではその国の根を出さない**。数には入れ、4.2 の行に「〇〇の図で見られる根 N（国名）」と出す

- 触れるかの幅（何を含めて測るか）：ほかの点の**半径3.5px＋縁の線0.5px**に、根の**縦棒の太さの半分**、または⊥の**横棒の太さの半分（0.75px）**を足した距離より近ければ触れる。横棒の幅（根の太さ＋4px）も含める。**線と字は含めない**（線や字との重なりでは短くしない。7. で数だけ出す）
- 1px刻みにする理由：日本は幅360で12px、幅320で9pxで触れなくなる（3.4）。2px刻みだと幅360で必要以上に短くなる
- **国名で決め打ちしない**

### 3.4 下限と、日本の根

**下限は1か所の値にする。最初は 9px。**

実測（「自分に使う」の画面で描く点：根の6か国＋線の端のベネズエラ・サウジ・シリア。日本の根は5px、横棒は幅9px・太さ1.5px）：

| 地図の幅 | 14pxでのすき間 | 触れなくなる一番長い長さ | そのときのすき間 | 触れる相手 |
|---|---|---|---|---|
| 320 | −2.0px（食い込む） | **9px** | 0.8px | 台湾 |
| 360 | −0.8px | **12px** | 0.4px | 台湾 |
| 375 | −0.2px | 13px | 0.4px | 台湾 |
| 390 | 0.5px | 14px（短くしない） | 0.5px | 台湾 |

- 幅320では **10pxでも0.01px触れる**。下限を10pxにすると、幅320で日本の根が消える。だから最初の下限は **9px**
- 9pxの根は、点の縁の外に **5.5px** しか出ない（点の半径3.5px）。そこに⊥が付く。**根に見えるかは実機でしか分からない**。短すぎたら下限を上げる。上げると幅320では日本の根が消え、「アジアの図で見られる根 1（日本）」が出る
- ほかの国（米国・中国・台湾・カナダ・メキシコ）は、幅320〜390のどれでも14pxのまま触れない。米国→メキシコは幅320で0.7px（すれすれ）
- 地域の図（20px）では、どの国も触れない（短くしない）
- 計算は、アプリと同じ地図の部品で国の点の位置を出して行った。**画面の幅ではなく地図の幅**で決まる（画面の幅から左右の余白を引いたもの）

### 3.5 国ごとに長さが違うと読み違えるか（第2版で勧めること）

**恐れはある。** 見立ては次のとおり。

- 太さが額、という決まりはあるが、人は**長さのほうを量として読みやすい**。細長い棒が並ぶと、太さより長さの差が先に目に入る
- 幅320では、日本の根だけ9px、ほかは14px。日本（トヨタの自社株 232億ドル、5px）がカナダ（700億ドル、5px）より**小さい金**に見える恐れがある。同じ太さなので、長さで比べてしまう
- 米国（7px・14px）と日本（5px・9px）では、太さと長さの両方が小さい側に揃い、差が実際より大きく見える

**勧める形：同じ画面の根は、全部同じ長さに揃える。** 3.3 で国ごとに触れなくなる長さを出し、**その中で一番短い長さ**を画面のすべての根に使う（ただし下限を下回る国は、その国だけ出さず、ほかの国は下限で揃える）。

| 地図の幅 | 揃えた長さ |
|---|---|
| 320 | 9px（全部の根） |
| 360 | 12px |
| 375 | 13px |
| 390 | 14px |

**失うもの：** 1つの国のために、全部の根が短くなる。幅320では全部の根が9pxになり、根らしさが全体で弱まる。

**揃えない場合（回答書の形のまま）：** 国ごとに短くする。4.3 の「数字の見方」に「根の長さに意味は無い（点に触れないよう短くすることがある）。額は太さ」を書く。

## 8. 約束の線が増える見込み

**測った事実：**

- 直近90日の地図の動き68本のうち、約束は**2本**。国をまたぐ約束の線は0本
- 確度3以下で地図から外している8本のうち、理由が「**交渉・打診の段階**」なのは**2本**（国内外の債券投資家→サウジ政府、エジプト政府→LNGの供給企業）。v20.27 の指示で、これからはこういう札が約束として地図に入る

- 札の数は増えている（動きのある札：6月6枚・7月15枚・8月25枚・9月は13日までで36枚）
