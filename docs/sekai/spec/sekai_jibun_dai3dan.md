## 1. 第3段で何ができるようになるか

1. 地図の種類の絞りで「**自分に使う**」を押すと、**主体の国の点から真下に根**が伸びる（先は⊥、矢印なし、いつも実線、線と同じ色）
2. 相手の場所が分からない自分に使う金（今は TSMC の2本）も、**主体の国が分かれば根で描ける**。「自分に使う」のボタンは **18 → 20**
3. 国の網で、国の中の「自分に使う」矢印の先が **⊥** になる（今のデータで9本）
4. 根を出す／出さないは**1か所**で切り替えられる。出さない側に戻すと、v20.28 と同じ画面になる

**札のデータは変えない。** 根にするかどうかは描くときに毎回決める。

## 2. 場所不明の「自分に使う」2本（TSMC）── 質問1への答え

### 2.1 考えは正しいか

**根を引ける、は正しい。ただし前提の一部が違う。**

- 正しい所：TSMC の2本は主体の国（台湾）が分かっている。根は「主体の側に積んだ金」を表すので、相手の場所が分からなくても引ける
- 違う所：「自分に使う金は、そもそも相手がいない」は、**20本のうち14本にしか当てはまらない**。残り6本は行き先が別の国にある（変2）。そして TSMC の「先端工程と**海外工場**」も、金の一部は台湾の外（海外工場）で使われている
- だから根の意味は「**その国の中で使った**」ではなく「**主体が自分の側に積んだ（持ち主はその国の主体）**」になる。画面の説明もこの言い方にする（4.3）

### 2.2 今のデータで何本か

| | 本数 |
|---|---|
| 場所不明の動き（全部） | 4 |
| うち自分に使う金 | **2**（TSMC → 先端工程と海外工場 600億ドル、TSMC → 先端工程の製造装置・工場 157億ドル。どちらも設備・期間つき） |
| そのうち主体の国が分かる＝根にできる | **2**（台湾） |
| 主体の国も分からない自分に使う金 | **0** |

残りの場所不明2本（世界の石油在庫→石油市場、日本→原油の輸出国）は自分に使う金ではないので、そのまま。

### 2.3 主体の国も分からないもの

**場所不明に残す。** 地図の下の「場所不明 N件」にそのまま入り、根は描かない。「自分に使う」の画面では 4.2 の行に「主体の国も分からず描けないもの N本」として出す（今は0本なので出さない）。

### 2.4 ボタンの件数

**20 になる。** 件数は「押したら何本描かれるか」で数える決まり（押す前と押した後が合う）なので、根で描く2本も数える。

| 地域 | 今（v20.28） | 第3段（変2あり） | 第3段（変2なし＝全部を根） |
|---|---|---|---|
| 全体 | 18 | **20** | 20 |
| 米州 | 11 | 11 | 8 |
| 欧州 | 1 | 1 | **0**（押せなくなる） |
| 中東 | 2 | 2 | 2 |
| アジア | 8 | **10** | 10 |

- 根は**主体の国の地域**で数える。横の線は今と同じく**両端の地域**で数える
- 変2なしだと、日本政府→米国やシェブロン→ベネズエラが米州から消え、アル・ハラフィ建設→シリアが欧州から消える（欧州が0になる）
- 「全部」のボタン（68）と、「全部」の地図の下の「場所不明 4件」は**変わらない**（変1で「全部」には根を出さないため）

**数が変わる理由を画面に出す形：** 4.2。

## 3. 根の形と長さ

### 3.1 形（決まっているとおり）

- 主体の国の点の縁から**真下**へ、まっすぐ
- 先は **⊥**（横棒）。矢印は付けない
- いつも実線（期間つきでも破線にしない）。色は線と同じ
- 太さは線と同じ**ドル換算の5段**（1・2・3.5・5・7px）。換算できないものは線の点線と同じ細さ（1.2px）

### 3.2 決まっていなかったので決める所

| 所 | 決め方 | 理由 |
|---|---|---|
| 1つの国に何本もあるとき | **1つの国に根は1本。** 太さはその中で**いちばん額の大きい1本**の段 | 本数だけ根を並べると、日本（4本）・米国（4本）が横に広がり、隣の点に必ず触れる。**太さを足さない**（合計しない決まりのため） |
| 何本分の根か | 根を押すと、その国の根の動きの一覧（見出しに本数） | 点の横の「（国内N）」は今のまま |
| ⊥の横棒 | **幅＝根の太さ＋4px、線の太さ1.5px** | 根より横棒が狭いと⊥に見えない（根5pxに横棒6pxでは、左右0.5pxしか出ない）。太さ1.5pxなら、太い根でも横棒が塊にならない |
| 約束の金の根 | 線と同じく**薄く**（今のデータで1本：モントリオール銀行 700億ドル・10年） | 「薄い＝約束」の意味を根でも崩さない。「いつも実線」とは両立する |
| 根の長さの測り方 | 点の**中心**から⊥まで。全体図14px・地域の図20px | 前の報告と同じ測り方 |

### 3.3 描くときに毎回測る（変3）

根を描く前に、その国の根（縦棒と⊥）が**その画面に描かれているほかの点**に触れるかを測る。

- 触れるかの幅：ほかの点の半径3.5px＋縁0.5px＋根（横棒は1.5px）の太さの半分
- 触れるなら、**その画面ではその国の根を描かない**。数には入れ、4.2 の行に「〇〇の図で見られる根 N（国名）」と出す
- 地域の図でも同じ決まりを当てる（今のデータでは地域の図で触れる国は0）
- **国名で決め打ちしない。** サウジ・日本と決めておくと、データが変わったときに黙って外れたまま、または黙って重なる

### 3.4 日本の根（変3で失うもの・代わりの案）

**実測（「自分に使う」、変2あり）：** 日本の根は5px（トヨタの自社株 232億ドル）。台湾の点は日本の点の左下（幅360で左8.1px・下15.6px、幅320で左7.3px・下13.8px）。

| ⊥の横棒 | 幅360 | 幅320 |
|---|---|---|
| 横棒なし（縦棒だけ） | すき間1.8px | すき間0.8px |
| 横棒 幅9px・太さ1.5px（3.2の形） | 触れる（約0.8px食い込む） | 触れる（約1.9px食い込む） |
| 横棒 幅6px・太さ1.5px | すき間0.6px | 触れる（0.4px） |
| 横棒 幅4px・太さ1.5px | すき間1.6px | すき間0.6px（ただし根5pxより狭く、⊥に見えない） |

どの形でも、**日本の根を⊥として読める形で全体図に出すと台湾の点に触れる。**

| 案 | 失うもの |
|---|---|
| **a（推奨）** 3.3 のとおり、全体図では日本の根を出さず「アジアの図で見られる根 1（日本）」と出す | 全体図で日本の根が見えない。「自分に使う」を押して一番見たい国がアジアの図に切り替えないと見えない |
| b 日本だけ触れるのを認める（台湾の点の縁に1〜2px乗る） | 決まり（触れる国は出さない）に例外が1つできる。台湾の点が根に隠れて見えにくい |
| c TSMC を根にしない（2.を採らない） | 台湾に点が出ないので、日本の根は触れない。TSMC の757億ドルが地図に出ないまま |

**推奨は a。** 決まりを1つに保つほうが、データが変わったときに嘘をつきにくい。台湾に点が出るのは TSMC を根にしたからで、c との取り引きになる。**ここは実機で見て決めてください。**（地図の幅が390pxなら、計算では横棒9pxでも触れない。**地図の幅は画面の幅より左右の余白の分だけ狭い**ので、お使いの端末でいくつかは実機で見るのが確か）

## 8. 約束の線が増える見込み（質問3への答え）

**測った事実：**

- ただしこの2本は**どちらも場所不明**（相手の場所が決まらない）なので、今の決まりのままなら地図に線は増えない。場所不明が2件増える
- 札の数は増えている（動きのある札：6月6枚・7月15枚・8月25枚・9月は13日までで36枚）

**見込み（測っていない。今の割合を伸ばしただけ）：**

- 交渉・打診の札が9月の割合（13日で2本）のまま続くと、月4本前後。今の地図の動きの分け方（線になるのは約6割）を当てると、**90日の地図に約束の線が数本〜十本前後増える**
- 約束の線は薄く（不透明度0.4）描くので、太い破線ほどは目立たない。ただし押す判定と「この辺りの線」の一覧には同じ重さで入る
- **根との関係：** 変1を採れば、「全部」の画面では根と約束の線は同じ画面に出ない。「自分に使う」の画面に出る約束は、自分に使う金の約束だけ（今は1本、根で薄く描く）
- 増えたかどうかは、地図の下の件数と「約束（N）」のボタンで見られる。**30日ごとに約束のボタンの数を記録する**のが確か（この仕様書の範囲外。やるなら別に決める）
