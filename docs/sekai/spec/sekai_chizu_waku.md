- 版：v20.60
- 段2（場所の無い枠を、点のそばの言葉にする）と段3（EU の塗り）は、この仕様書に入れない

## 0. 決まり

- 本部の場所は、海峡と同じ**独立した場所の点**にする。**国コードには置き換えない**（米国 → 国連安保理 が「米国 → 米国」になって線が消えるため）
- 名前と丸ごと一致したときだけ当てる
- お金の線の本数が変わらないことを、数で確かめる（変わるものがあれば、報告に理由を書く）

- これらの名前は、今は国際機関・地域の枠に当たっている。**枠より先に場所の点に当てる**

## 2. 見た目（本部の点だと分かるようにする）

枝の地図には使い方の説明が無いので、**点の名前で分かるようにする**（指示書 2.2）。

| 種類 | 形 | 名前 |
|---|---|---|
| 国 | 丸（今のまま） | 書かない |
| 海峡・運河 | ひし形（v20.59 のまま） | 「ホルムズ海峡」 |
| **本部の点** | **四角** | **「IMF（本部）」「国連安保理（本部）」** |

- 「（本部）」を名前に付けるので、札を開いた人がその場で読める
- 地図タブの使い方の説明にも1行足す：「四角の点は、国際機関などの**本部の場所**。金や手が本部から出入りしたという意味ではない」
- 失うもの：名前が少し長くなる（地図の上の字が増える）

## 3. 大きな地図（地図タブ）

- 本部の点も線の端として地図の中に描く（下の3つの箱は今のまま）
- 箱の中身からは、点になった名前が消える（国際機関の箱はほぼ空になる見込み）
- 箱・絞り込み・点検の一覧の作りは変えない

## 4. 変えないもの

- 効かせた線の規則・確度3以下の決まり・1行の出し方
- 場所の無い枠（市場・株主・国の集まり）の扱い（段2で決める）
- お金の線の当て方の順（主体の国 → 名前の表 → …）。本部の点は、海峡と同じ「丸ごと一致」の段に入れる

## 5. 確かめ

### 手元
1. **お金の線の本数**（地図タブ・枝の地図・国内・場所不明）が、前の版と同じ。変わるものがあれば、1件ずつ理由を書く
2. 本部の点が絡む札（実データで14枚）で、線が地図の中で完結する。四角の点と「〇〇（本部）」が出る
3. 米国 → 国連安保理 が線として残る（国内にならない）
4. 地図タブ：国際機関・地域の箱の中身が減り、線が地図の中に移る。押しても壊れない
5. 145枚を全部開いてページのエラー0

### 公開の前に実機で確かめてほしいこと
1. 安保理・BRICS・EU が相手の札を開き、四角の点と「（本部）」が読めるか（BRICS は枠のまま）
2. 地図タブで、線が箱に伸びる代わりに地図の中に入っているか。箱を押しても壊れないか
3. 枝の地図で、本部の点と国の点が近いとき（EU＝ブリュッセルとベルギー）に読めるか
4. もう片方の端末で同期して同じに見えるか

## 6. 段2への答え（指示書 2.1。この段では作らない）

外向きの矢印が「北東へ動いた」と読まれないようにする案。

| 案 | 中身 | 失うもの |
|---|---|---|
| **A 矢印を描かず、点の横に文字だけ（推奨）** | 国の点のすぐ右に、小さい字で「→ 国債市場」。線は引かない | 形の目立ちは弱い。方角の誤読は原理的に起きない |
| B 点線の短い棒（6px ほど）＋名前 | 点から外へ点線の棒を出し、その先に名前 | 短くても向きはあるので、方角と読まれる余地が残る |
| C 地図の縁で止める矢印 | 点から地図の縁へ向かう矢印 | いちばん方角に見える。**反対** |

- 勧めは A。地図の中に「相手の名前」だけが増え、位置は主張しない
- A でも紛れるようなら、段2は入れず、今の下の箱のままにする
