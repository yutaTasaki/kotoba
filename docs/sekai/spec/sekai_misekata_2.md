## 0. 決まり（段2-1・段2-2 に共通）

- **棒の長さは線形**（長さ＝量そのもの）。対数にしない
- **比べる相手の名前と値を必ず横に書く**。棒だけにしない
- **相手は1つだけ**
- **100倍を超えたら棒をやめて言葉にする**
- 型は「**全体の中の一部**」と「**同じ主体の前の額**」の2つだけ。他者との比べ・稼ぎとの比べは出さない
- 位置は「なぜ」の直下（印が `size` の札には地図が出ないので、そこが空いている）
- 押す物にしない

## 1. 段2-1（v20.64）：全体の中の一部

### 1-1. 出す条件

**印が `size` で、欄に `total`（全体の額）と `share`（割合）の両方がある札だけ。**

- 新しいデータは足さない

### 1-2. 形

```
▓▓▓░░░░░░░░░░░░░░░░░░░░░░
143兆656億円 のうち 36兆6386億円（26%）
```

- 帯の高さ10px、塗りは `share`%（線形）
- 塗りは1%を下限、100%を上限にする（欄の値が壊れていても崩れないため）
- 下に1行：`全体 のうち 部分（N%）`。部分の字だけ明るくする

### 1-3. 1行から、同じ文を外す

いまの1行は「日本政府 → 国債の保有者 … 36兆6386億円（期間：2027年度）**／143兆656億円のうち36兆6386億円（26%）の行き先が分かった**」と出ていました。

**帯とまったく同じことを言っています。** 箱が1行と同じことを言うなら意味がない、という前の判断（v20.59 の相談）と同じ形です。

**帯を出す札では、1行から「◯◯のうち◯◯（N%）の行き先が分かった」を外します。** 帯が出ない札（6枚）では今までどおり出します。

### 1-4. 変えないもの

## 2. 段2-2（v20.65）：比べる相手（cmp）

### 2-1. 何を書かせるか

朝の取り込みの返事に、札ごとに1つだけ。

```json
"cmp":{"name":"前年同期の設備投資","value":"396億4300万ドル","rel":"prev","ratio":2.03}
```

- `rel` は2つだけ。`part`＝この札の額が全体の一部（name と value に全体）／`prev`＝同じ主体の前の額
- `ratio` は「**この札の額 ÷ 相手の額**」。数は1つだけ。単位をそろえてから割る。`part` なら1より小さい
- **比べる相手は、その出典の中にある数字だけ。外から探してこない**
- 相手は1つだけ。2つ以上は書かせない
- `flow` の `total` を書いたときは `cmp` を書かない（同じことになる）
- 無ければ `null`

記録は、調べた記録の月ファイルの新しい並び `cmps`（`views`・`aims` と同じ作り。足すだけ）。

### 2-2. 出し方

- 印が `size` の札だけ。`total` がある札は段2-1 の帯が優先し、`cmp` は出さない
- **棒2本**。長い方を枠いっぱいにし、もう1本を `ratio` の比で（線形）
  - 上＝この札の額（明るい色）／下＝相手の名前と値（暗い色）
  - 塗りの下限は1%（0pxにしない）
- **100倍を超えたら棒をやめて言葉にする**：`政府債務の総額 1000兆円 の 0.10%（差が大きいので棒にしていません）`

### 2-3. 「最近のお金の動き」の節を外す

- 節（実測2,053字）を丸ごと外す
- `after` の決まりを「**同じ JSON の中の #番号だけ**」に変える（w_ の id を渡さないので、書かせない）
- 外した札は「すでにある札」の節に回る（重複を見つける材料としては残る）

### 2-4. 埋め直さない

新しい札から効かせる。既存の145枚には `cmp` を足さない。
