# 仕様書：枠の線 段2（場所の無い枠は、点の横の文字にする）

- 元：相談 `houkoku/2026-09-16_chizu_waku.md`、回答 `shiji/sekai_chizu_waku_kaitou.md`、指示 `shiji/sekai_chizu_waku_1_koukai.md`
- 版：v20.61
- 段1（v20.60）で、本部のある機関は地図の点になった。ここで扱うのは**場所の無い枠**（市場・株主・国の集まり）

## 0. 決まり

- 地図の外に箱を置かない。**線も引かない**（方角の誤読を原理的に起こさない）
- 相手の名前は、**国の点のすぐ横に小さい字**で出す。「→」は文字の一部で、出る・入るの向きだけを表す
- お金の線（国どうし・国と場所の点）は変えない。数で確かめる
- 実機で紛らわしければ、今の箱に戻せるようにする（この段だけを取り消せば戻る）

## 1. 何を変えるか（枝の地図だけ）

| 札の形 | v20.60 | v20.61 |
|---|---|---|
| 国（または海峡・本部）→ 国（または海峡・本部） | 線 | **今のまま** |
| 国 → 枠（市場・国際機関・地域の集まり） | 地図の下に枠の箱を置き、そこへ線 | **箱も線も出さない。** 国の点の横に「→ 国債市場」 |
| 枠 → 国 | 同上 | 国の点の横に「国債市場 →」 |
| 枠 → 枠 | 箱1つ（同じ枠）／箱どうしの線 | 地図を出さない（1行だけ） |
| 効かせた線の相手が枠（BRICS など） | 枠の箱へ線 | 出す側の点の横に「→ BRICS」 |

- 地図を出すのは、線が1本でもあるか、点の横の文字が1つでもあるとき
- 下の枠の箱（市場・国際機関・地域）は、**枝の地図から無くす**。地図タブは今のまま

## 2. 文字の出し方

- 位置：国の点の右6px、上下は点の中心＋3px（「国内」の字と同じ置き方）
- 同じ点に2つ以上あるときは、下へ11pxずつずらす
- **右に出すと地図からはみ出すとき**（点が地図の右端から100px以内）は、点の左に出して右寄せにする
- 字は暗い縁取り付き（線や国の形に重なっても読める）。お金は今の線の色、効かせた相手は橙
- 名前は**12字まで**。長いときは次の順で短くする
  1. 「（」より前だけにする（「株主（市場での自社株買い付け先）」→「株主」、「中央政府（国債市場）」→「中央政府」）
  2. それでも12字を超えるときは、12字で切って「…」（「データセンターの買い手（書類では匿名）」→「データセンターの買い手」＝11字なのでそのまま）
- 全部の名前は、地図の下の1行（誰から誰へ）にそのまま出るので、切っても失われない

## 3. 変えないもの

- 地図タブ（大きな地図）・国の網・点検の一覧
- 1行（お金：／効かせた：）とその理由
- 確度3以下の決まり、杭、海峡・本部の点

## 4. 確かめ

### 手元
1. **お金の線の本数**：地図タブ（全期間51・直近90日47）と、枝の地図の「国どうしの線」の数が前の版と同じ。枠が相手の分は、線から文字に移った数を出す
2. 枠が相手の札（市場20・地域の集まり・BRICS）で、点の横に文字が出て、下の箱が消えている
3. 長い名前が短くなる（株主／中央政府／データセンターの買い手）
4. 右端に近い国（日本・オーストラリア）で、文字が左側に出る
5. 145枚を全部開いてページのエラー0。地図が出る札の数

### 公開の前に実機で確かめてほしいこと
1. 枠が相手の札で、点の横の文字が**線と読めないか**（方角に見えないか）
2. 文字が国の形や線に重なって読めなくならないか
3. 右端の国（日本）で、文字が画面の外に出ないか
4. 長い名前が切れても意味が分かるか（下の1行で全部読める）
5. もう片方の端末で同じに見えるか
