# 仕様書：まとめサイト対策（案A・案B）

- 元：質問への答え `houkoku/2026-09-17_matome.md`、背景 `spec/sekai_kosinya.md`
- 版：v20.69

## 0. 決まり

- **案B は「知らせるだけ」。確度は動かさない。** 「確度を自動で下げる」という元の案は採らない（理由は答えの報告のとおり）
- **案A は「天井」。下げるのではなく、天井を超えた申告だけ天井まで戻す**
- プロンプトへの新規の欄は無い（`url`・`confidenceWhy` という、すでにある欄をアプリ側で後から読むだけ）

## 1. 案A：まとめサイトの負のリスト

### 1-1. 置き場

出典一覧（`sources.json`）とは別の、**コードの中の固定配列**。

```js
const WORLD_MATOME_DOMAINS = ['hojyokin-portal.jp'];
const WORLD_MATOME_CONF_CAP = 5;
```

理由：出典一覧は「よく使う・信頼する場所」の一覧で、プロンプトの「よく使う出典」節に出る。負のリストを混ぜると、そこに要注意ドメインが紛れる。加えて出典一覧には人が押して「必ず見るもの」に昇格させる仕組みがあり、混ぜると誤って要注意ドメインを昇格させる道ができる。

### 1-2. 判定と天井

- `worldMatomeHost(url)`：url のホストが一覧のいずれかと一致するか、そのサブドメインなら、一致したドメイン名を返す。無ければ空
- `worldCappedConfidence(v, url)`：`v`（申告された確度）が一覧に該当し、かつ天井（5）を超えていたら、天井まで戻す。**天井以下ならそのまま**（下げない）
- 適用場所：`normalizeWorldEvent` の中、確度を正規化する1行

### 1-3. 重要な性質：読み込むたびに効く（実測で確認）

`normalizeWorldEvent` は**取り込みのときだけでなく、月ファイルを読み込むたびに毎回すべての札に対して呼ばれる**（`normalizeWorldMonthDoc` が `raw.events.map(normalizeWorldEvent)` をしているため）。

これは**新しい札に対してだけでなく、すでに保存されている過去の札にも効く**ということです。実際に確かめました。

> 保存済みの想定（確度9・まとめサイトの url）を読み込みの正規化にそのまま通すと、確度は **9 → 5** になった

**利点**：あとでドメインを一覧に足したとき、過去の該当する札にも自動で効きます。書き直しのスクリプトが要りません。

**留意点**：この天井にかかった札の月ファイルが何かの理由で書き戻されると、**元の申告値（9など）はもう戻せません**。ただし、これは `WORLD_FACT_MAX` など既存のどの正規化とも同じ性質で、この機能だけの特別な危うさではありません。

### 1-4. 画面

札の確度バッジのすぐ隣に、橙のバッジ。

```
確度4　[まとめサイトの可能性]
```

- `url` から**開くたびに判定**する（保存はしない）ので、**過去の札にも表示されます**
- 一覧に無いドメインには何も出ない

## 2. 案B：自己申告の見逃しを知らせる（確度は動かさない）

### 2-1. 判定

`confidenceWhy` に対して、揺れを拾う広い判定を使う。

```js
const WORLD_PRIMARY_GAP_RE = /一次資料.{0,6}(当たれず|確認でき|確かめ.{0,4}(ず|てい)|読めず)|(原文|原資料|発表文|公表文|本文).{0,8}(当たれず|確認でき|確かめ.{0,4}(ず|てい)|開けず|読めず)|報道(のみ|だけ)|(要約|集計|二次)(サイト|媒体|情報|的)/
```

理由：誤って多く拾っても、実害は「取り込みの結果に1行増える」だけ。狭い固定の言い回し（「一次資料に当たれず」）だと約半分しか拾えない（実測：114件中31件 vs 68件）。

### 2-2. 何もしない

**確度は変えない。** チャットの自己申告をそのまま尊重する。

### 2-3. 知らせ方

取り込みの結果（追加された札だけを数える）に、件数だけ出す。

```
※ 一次資料に届いていない可能性がある札 3件（確度はそのまま。理由は確度の隣に出ます）。
```

一覧やリンクは出さない（`staleNum` と同じ、数だけの軽い知らせ）。理由の中身は、もともと確度バッジの `title`（ホバーで見える）に出ている。

## 3. 変えないもの

地図・帯・棒・折れ線・1行・地図タブ・`validTo`・`checked` の保存。プロンプトの字数（0増、実測で確認）。

## 4. 確かめ

### 手元（実測）

1. 実際の事故の札（`w_20260909_597958`）で、`worldMatomeHost` が `hojyokin-portal.jp` を返す。確度は4のまま（天井5未満なので変わらない）。バッジが出る
2. 試し：まとめサイトから確度8 → **5に天井**／確度3 → 3のまま／ふつうの一次資料から確度9 → 9のまま（一覧に無いので何もしない）
3. 試し：「一次資料に当たれず報道のみ」→ 知らせの件数に入る。確度は変えていない（4のまま）。「数量は推定値で幅がある」（無関係な理由）→ 入らない
4. 保存済みの札（確度9・まとめサイト）を読み込みに通すと 9→5 になる（**読み込みのたびに効くことの実測**）
5. 既存145枚に変化なし（帯13・折れ線6・地図13・1行122/99/55・地図タブ51/28/9/47・エラー0）
6. プロンプトの字数：v20.68 と v20.69 で**完全に同じ**（26,572字。差0）
