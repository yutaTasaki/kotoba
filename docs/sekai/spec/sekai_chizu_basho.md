## 0. 決まり

- 地図は確かな物だけ（確度3以下は線にしない。1行は出す）を崩さない
- 場所の点に当てるのは、名前が表の呼び名と**丸ごと一致したときだけ**。お金の線の今の当て方は変えない（今の線の本数が変わらないことを確かめる）
- 記録は一度書いたら変えない。消すときは消した印を付ける

- 枝の地図では、**ひし形の点と、その名前の小さな字**で描く（国は丸い点で名前を書かない。場所の点は地図の上に名前が無いと何の点か分からないため）

- 地図タブの大きな地図では、線の端として置くだけ（点の印・絞り込みは変えない）

### 1.2 失うもの

- 呼び名が丸ごと一致しないもの（「紅海のヤンブー港」「ホルムズ海峡の通航」）は、今のまま場所不明
- 地図タブの絞り込み（地域）で、場所の点が入る地域が決まらない線は「全体」にだけ出る

## 3. 効かせた相手の規則の直し

朝の取り込みと、埋めるプロンプトの規則（同じ文）を次にする。

```
- 札ごとに、主体が「誰に向けて、何を効かせたか」を0〜2件書く。お金・物・人が動いていなくてよい（制裁・関税・攻撃・要求・合意・名指し・投票・訪問 など）。
- from と to は、国・国際機関・地域・海峡の名前（例：米国、ロシア、EU、国連安保理、ホルムズ海峡）。「第三国の銀行」「市場」「株主」のように場所が決まらない相手は書かない。
- how は、手を表す短い言葉1つ（10字まで）。
- 自分の国の中だけの手（利上げ・統計・保有高・自国の予算）は []。ただし、他の国から求められた手・他の国に向けた手は書く（例：米財務長官が日銀に利上げを求めた → 米国→日本「要求」）。
- なぜ に書いてある狙いの相手（制裁で資金を断とうとしている国など）は書く。なぜ に名前が出てくるだけの国は書かない。
- flow と同じ向きの同じ話は書かない。
```

- 字数は手元で数えて報告に書く
- 失うもの：揺れが今より増えるかもしれない（測れません）

## 4. 確度3以下

今のまま（効かせた線も描かない。1行は出す）。

## 5. 「出来事」への言い換え

別の出来事を指す言葉と、一覧の見出しを「出来事」にする。数える単位は「件」。

| 今 | これから |
|---|---|
| 一覧の見出し「9/14 の札（1）」 | 「9/14 の出来事（1件）」（一覧の見出しの数は全部「件」） |
| つながる札 | つながる出来事 |
| 続報の前の札： | 続報の前の出来事： |
| この後の続報 N枚 ▸ | この後の続報 N件 ▸ |
| 続報の札（N枚） | 続報の出来事 |
| 同じ動きの札N枚／同じ動きの札（N枚） | 同じ動きの出来事N件／同じ動きの出来事 |
| 同じと判断した札： | 同じと判断した出来事： |
| 自分で調べて作った札（元の札：…） | 自分で調べて作った札（元の出来事：…） |
| 「同じ」とされたが別の出来事として作った札（比べた札：…） | …（比べた出来事：…） |
| この国の札を一覧で見る／この市場の札を一覧で見る（網の説明の中も） | この国の出来事を一覧で見る／この市場の出来事を一覧で見る |
| 「〇〇」の札（探す・問い） | 「〇〇」の出来事 |
| この主体が動かした札（時系列） | この主体が動かした出来事（時系列） |
| 札を開く（主体の時系列） | 出来事を開く |

札を作る・読む・数える言葉（札にする・まだ読んでいない札 など）は変えない。

## 6. 国の中の動きの1行に国名

- 国の中の動き（両端が同じ国）の1行の頭に「日本の中：」を付け、後ろの「（国の中の動き）」は外す
- 効かせた相手もある札は「お金（日本の中）：」

## 7. 埋めた返事を残さない

- これから埋めるときは、返事2回分の記録を書かない。札ごとの記録にも返事の写しを書かない（線と控えだけ）
- **すでに埋めた返事の記録**は、v20.59 を開いたときに1回だけ次をしてから、消した印を付けて消す
  1. 2回の返事を、今の場所の表（1・2章を足した表）で比べ直す
  2. 線にする組が変わった札だけ、札ごとの記録を足す（控えから線になった組がある札）
  3. 比べた結果を足す（数を新しくする）
  4. 返事2件に消した印
- 札ごとの記録（今ある145件）は消さない
