## 0. 第2段Aで何ができるようになるか

期限が来た予告について、朝の回が**当たりらしさの候補と根拠1行**を持ってくる。
世界タブの新しい画面で、**あなたが押して結果を確定する**。

**取り込んだだけでは結果は変わらない。** 押して初めて変わる。

---

## 1. いちばん大事な境目（ここを緩めない）

**取り込みでは `state` を絶対に動かさない。**

生成が「当たり」と書いてきても、取り込みで入るのは次の2つだけ。

- `verdictNote`：生成が書いた根拠1行
- `verdictAt`：その判定を取り込んだ日時
- `evidence`：判定に使った数字（下の 3）

`state` は「まだ」のまま。**人が押して初めて変わる。**
ここが緩むと、見た目は「人が押している」のに中身は機械判定になる。

---

## 2. 予告に足す項目

第1段の入れ物に足す。**第1段で結果欄と押した日時は用意済み**なので、足すのは判定の材料だけ。

| 項目 | 中身 | 誰が書くか |
|---|---|---|
| `verdictNote` | 生成が書いた根拠1行（80字以内） | 取り込み |
| `verdictAt` | その判定を取り込んだ日時 | 取り込み |
| `evidence` | 判定に使った数字（下の 3）。無ければ空 | 取り込み |
| `verdictSuggest` | 生成が挙げた候補（`hit`／`miss`／`unverifiable`） | 取り込み |
| `unverifiableCount` | 「確かめられない」を押した回数 | 人が押すたび +1 |
| `foldedAt` | 畳んだ日時（3回で畳む） | 端末 |

既にある `state`・`stateAt`・`stateNote` は第1段のまま使う。

---

## 3. `evidence` は4つ組

```
"evidence": { "stratumId": "st_us_debt_total", "at": "2026-11-30",
              "value": "38.9", "readAt": "2026-12-01T09:00:00Z" }
```

**4つとも要る理由**：米国の政府債務は同じ日付の値が後から訂正される
（`worldAddLevel` は同じ日の API の値だけ新しい方で置き換える作り）。
基準日だけ残しても、後から見た値は変わっている。
**そのとき見えていた値**を写して初めて再現できる。

値が書けないときは `evidence` を空にし、候補は `unverifiable` になる。

## 4. 朝のプロンプトに足すもの

### 4.1 差し込む場所

**「並べ方」の後、「出力形式」の前。** 既知の概念・アクターの羅列より前に置く
（羅列は末尾に置く決まりで、規則を押しのけないため）。

### 4.2 出す中身（期限切れが1本以上あるときだけ）

```
■ 期限が来た予告（答え合わせ）
[fc_20260912_1] 日本銀行が「国債買い入れの減額を四半期4000億円で続ける」
  期限 2026-12-19 ／ 当たりの印：日本銀行の金融市場調節の公表
```

**1回5本まで。** 期限の古い順。

### 4.3 書かせること

- `verdict`：`hit`／`miss`／`unverifiable` のどれか
- `note`：そう判断した根拠を1行（80字以内）
- `evidence`：数字で確かめられたときだけ（系列id・基準日・値）。読み取った日時は端末が入れる
- **確かめる数字が無いときは `unverifiable`。「まだ」に倒さない**

### 4.4 期限切れが0本なら、この節ごと出さない

「期限が来た予告はありません」とも書かない。プロンプトが長くなるだけ。

### 4.5 字数

1本およそ90字。5本で450字。いまの朝のプロンプト（16,031字）に対して**約3%**。

---

## 5. 読む回のプロンプトに「印に使える系列」を示す

いまの `sign` の説明に足す。**「この3つしか使うな」とは書かない。**

```
- sign：何が見えたら当たりか。上の札に出ている出典の名前から選ぶ。
  - 数字で確かめられるのは、いまのところ次の3つだけ：
    米国の政府債務総額／米国 上位0.1%の富の割合／米国 下半分の富の割合
  - それ以外は「公表そのもの」を印にしてよい（「日本銀行の金融市場調節の公表」など）。
    公表を印にするのは有効。無理に数字の印を作らない。
```

**理由**：地層は実測で717点あるが、**厚いのは上の3系列だけ**で、残り17系列は1〜3点か0点。
いまのまま書かせると、照合できない印が立ち続ける。

## 6. 取り込み（貼り戻し）

第2段Aでは**朝の欄をそのまま使う**（貼る欄を1つにするのは第3段）。

朝の JSON に `verify` を同居させる。

```
{"events":[…],
 "verify":[{"id":"fc_20260912_1","verdict":"hit","note":"12月19日の公表で減額幅は据え置き",
            "evidence":{"stratumId":"st_us_debt_total","at":"2026-11-30","value":"38.9"}}]}
```

### 6.1 入れるときの決まり

- `id` が端末に無い予告は**無視して数える**
- `state` が「まだ」でない予告（既に押したもの）は**上書きしない**。数えて出す
- `verdict` が3つのどれでもなければ、その1本を落として数える
- `evidence` の `readAt` は**端末が入れる**（生成に書かせない）

### 6.2 画面に出す結果

朝の取り込みの結果の文に足す。

```
…　答え合わせの候補が3本つきました。
※ 端末に無い予告1本は無視しました。
※ すでに押してある予告1本は変えていません。
```

**落としたものは必ず数と理由を出す。**

## 7. 世界タブに「予告」の画面を足す

### 7.1 置き方

地図・網と同じ形で画面を1つ増やす（`worldState.view === 'forecast'`）。
入口は**世界タブの入り口に1行**。朝タブからの導線は**第2段B**。

### 7.2 並び

1. **期限が来たもの**（押せる）
2. 期限の近い順（まだ期限前。押せない）
3. **畳んだもの**（3回「確かめられない」を押したもの）

期限前のものも出すのは、**予告の全体が1か所で見えるようにする**ため。

### 7.3 1本の見え方

```
12/19まで　日本銀行が 国債買い入れの減額を四半期4000億円で続ける
　当たりの印：日本銀行の金融市場調節の公表
　生成の見立て：当たり
　　12月19日の公表で減額幅は据え置き
　［当たり］［外れ］［確かめられない］
```

- **根拠1行は、押すボタンより上に置く**（押す前に必ず読ませる）
- 押した後は結果の印が付き、**行は消えない**
- **ボタンは押した後も出たまま**。別のものを押せば変わる（「取り消し」は作らない）
- 期限前のものにはボタンを出さない（押しても何も起きないものを作らない）

### 7.4 押したときに起きること

- `state` を変える
- `stateAt` に押した日時
- 「確かめられない」なら `unverifiableCount` を +1
- **3回目の「確かめられない」で畳む**（`foldedAt` を入れ、押せる場所から外す）

### 7.5 畳んだものの扱い

- **消さない**
- 当たり率の分母に**入れない**
- 読む回に**戻さない**（札の思惑ではなく、印の立て方の問題だから）
- **5本を超えたら画面に1行**：「確かめられなかった予告が N本あります。印の立て方を見直す時期です」

---

## 8. 当たり率

**予告の画面の一番上。** 設定には出さない（毎日見る場所に置く）。

- 分母は **当たり＋外れ** だけ
- **10件未満は割合を出さず件数だけ**：「当たり3・外れ2・確かめられない1・まだ5」
- 10件以上で「当たり 12/20（60%）」

---

## 9. 消えないための決まり

| 危険 | 対策 |
|---|---|
| 取り込みで結果が動く | `state` は取り込みで**触らない**。押す経路だけが変える |
| 2台で別々に押す | `stateAt` の新しい方を採る（第1段で実装済み） |
| 判定の根拠が消える | `verdictNote`・`evidence` は押した後も残す |
| 生成の見立てと人の判断が混ざる | `verdictSuggest`（生成）と `state`（人）を**別の項目**にする |
| 新しい項目が保存で落ちる | `normalizeWorldForecast` に**明示的に足す**。第1段と同じ轍を踏まない |

## 11. 第2段Bに送るもの

- 外れたら読む回に戻す（札に `missAt` を足し、読む対象に加える）
- 朝タブを1行にし、押すと予告の画面へ
- **世界のデータを捨てるときに予告も捨てる（4か所）**

  | 場所 | いまの状態 |
  |---|---|
  | `worldResetLocal` が空にする器 | 予告が**無い** |
  | 保存庫へ書き戻す器の一覧 | 予告が**無い** |
  | 受け取った側の端末へ書く並び | 予告が**無い** |
  | `worldResetNow` が保存庫を上書きする並び | 予告が**無い** |

  4か所すべてに足さないと、**捨てた端末では消えるのに、もう一方で残って次の同期で復活する**。
  捨てる前に数えて「札 N枚・予告 N本を捨てます」と出す。
