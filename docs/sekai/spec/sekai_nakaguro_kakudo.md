## 0. この段で何ができるようになるか

1. **名前に国が2つ以上並ぶ相手・主体を、1つの国に決めつけない**（場所不明にする）。地図の下に件数を出す
2. 地域などの**枠に入れた名前に、別の国も並んでいるもの**を、枠のまま一覧に出す（「欧州の同盟国とカナダ」）
3. 「**ロシア軍**」「米軍」のような「国の呼び名＋軍」を、その国として読む
4. **確度3以下で地図から外した動き**を、地図の下に件数で出し、押すと一覧が開く
5. 生成に「国ごとに分ける」「まだ起きていないことは確度で表さない」と指示する
6. お金の一覧の注意書きに「一覧は確度3以下の札も出します（地図は外しています）」

**データは変えない。** 主体の表の国も書き換えない（使わないだけ）。

## 1. 名前に国が2つ以上並ぶとき（回答書の判断1）

### 1.1 決まり

名前の中に、**国の呼び名が2つ以上**入っていたら、その名前からは国を決めない（場所不明）。

- **区切りは問わない**（「・」「と」「、」でも、区切りが無くても）
- 国の呼び名は、国の表の**日本語の2字以上の呼び名**で数える。**長い呼び名から当てる**（「インドネシア」を「インド」と数えない）
- **いちばん先に当てる**：主体の国・「〜の」の前・「・」の前・枠の言葉より前。枠の言葉があっても、国が2つ以上なら場所不明
- **例外：** 名前がそのまま主体の表に当たり、その主体の国を**手で決めた印**があるときは、主体の国を使う（手で決めたものは疑わない）

**今のデータでの試算（本物のデータ、全期間の札121枚）：**

| | 結果 |
|---|---|
| 地図の払う側・受け取る側の名前 | **動く行は0**（直近90日も全期間も、v20.26 と全行を比べた） |
| 主体の表 | 「ロシア産原油を買うインド・中国の製油業者」（国が3つ：インド・中国・ロシア）が**国を使わない主体**になる。今は取り込みで生成が「中国」と書いた国で読まれている |
| 誤って引っかかる名前 | 210個の名前で**0** |

**限界（拾えないもの）：**

- **1字の呼び名（米・独・仏・豪）は数えない。** 「独立」「豪雨」「仏教」「米価」のような、国と関係ない言葉の一部に当たるため。だから「**日米の同盟国**」「**米中**」は拾えない（試算で「日米の同盟国」は地域の枠のまま）
- 英字の呼び名（US・UK など）も数えない。英単語の一部に当たるため

### 1.2 主体の表の国

- 上の決まりに当たる主体は、場所を読むときに**その主体の国を使わない**
- 主体の詳細の「国」の行に、次の1行を足す：

```
名前に国が2つ以上（インド・中国・ロシア）。取り込みで入った国は、地図では使っていません
```

- 国を「直す」で手で決めれば、その国を使う（1.1 の例外）
- 主体の表のデータ（国の欄）は**書き換えない**

### 1.3 画面に出す

地図の下の件数の並びに足す（0件でも押せない形で出す。地域では絞らない）：

| 名前 | 開いた一覧の頭の1行（26字以内） |
|---|---|
| **国が2つ以上並ぶ相手 N件** | 国が2つ以上並ぶので、1つに決めなかったもの |

「数字の見方 ▸」（地図）に、決まりと限界（1字の呼び名は数えない）を足す。

### 1.4 生成への指示（そのまま足す文）

毎朝のプロンプトの、お金の動きの説明（from／to の段落の最後）：

```
  1つの相手に国を並べない（「米国・日本の製油所」と書かない）。国が2つ以上なら、動きを国ごとに分けて書く。
```

主体（actors）の説明の country の段落の最後：

```
    国が2つ以上にまたがる集まり（インドと中国の製油業者など）は1つの主体にせず、国ごとに分ける。
```

**これからの札にしか効かない。** 今の主体（インド・中国の製油業者）は 1.2 で扱う。

## 2. 枠に入れた名前に、別の国も並ぶとき（回答書の判断2）

### 2.1 回答書の問い「決まりが複雑になりすぎないか」への答え

**反対しない。2つの決まりは別々の問いに答えているので、並べても読める。**

- 1 は「**1つの国に決めつけていないか**」（国が2つ以上 → 場所不明）
- 2 は「**枠に入れたとき、落ちた国は無いか**」（枠のまま → 一覧で知らせる）
- 当てる順は **1 が先**。国が2つ以上なら、枠の言葉があっても場所不明（「欧州の同盟国と米国・日本」なら 1）。国が1つだけ別に並ぶときだけ 2

**ただし、ただ「枠に入った名前に国の呼び名がある」で拾うと誤る。** 実測で、枠に入る名前のうち国の呼び名を含むのは2つ：

| 名前 | 枠 | 国の呼び名 | 国が別の相手として並んでいるか |
|---|---|---|---|
| 欧州の同盟国とカナダ | 地域 | カナダ | **並んでいる**（「と」の後ろ） |
| ロシア産原油の買い手 | 市場 | ロシア | **並んでいない**（ロシアは原油の産地。買い手はロシアではない） |

### 2.2 決まり

枠（市場・国際機関・地域）に入った名前を「**と**」「**・**」「**、**」で区切り、**2つ目以降の部分**が国の呼び名そのもの（または「国の呼び名＋後ろの決まった言葉」）なら、**枠のまま**、一覧に出す。

- 今のデータで当たるのは「欧州の同盟国とカナダ」の1つ（払う側。対ウクライナ支援700億ユーロの約束）
- 「ロシア産原油の買い手」は当たらない（確かめた）

### 2.3 画面に出す

| 名前 | 開いた一覧の頭の1行（26字以内） |
|---|---|
| **枠の名前に国も並ぶ相手 N件** | 地域などの枠に入れたが、名前に別の国も並ぶもの |

**失うもの：** カナダの分は、この一覧を開かないと分からない（地図ではカナダに線は描かない）。

## 3. 「国の呼び名＋軍」（回答書の判断3）

### 3.1 確かめた結果

**全期間の札で「軍」を含む名前は2つだけ：**

| 名前 | 今の読み | どこに出たか |
|---|---|---|
| ロシア軍・軍需産業 | 決まらない | 受け取る側1 |
| 米中央軍 | 米国（主体の表） | 札の主体・主体の表 |

札の本文には「米軍」「米海軍」「中国の軍」「フーシ派の軍」などが出ている（名前としてはまだ来ていない）。

**「国連軍」「多国籍軍」「有志連合軍」のような1国に定まらないものは、今のデータに無い。**

### 3.2 決まり

**「国の呼び名＋軍」の形だけを読む**（回答書の案のとおり）。

- 国の後ろの決まった言葉（政府・議会・国防省など）に「**海軍・空軍・陸軍・軍**」を足す。後ろの言葉を外した残りが**国の呼び名と丸ごと一致**したときだけ、その国
- 「〜の」「・」の**前**の部分にも、この後ろの言葉を外して当てる（「ロシア軍・軍需産業」の前は「ロシア軍」なので）

**試算：**

| 名前 | 結果 |
|---|---|
| ロシア軍・軍需産業 | ロシア |
| 米軍 | 米国 |
| 米海軍の艦船 | 米国 |
| イスラエル軍・北朝鮮軍 | イスラエル・北朝鮮 |
| **国連軍・多国籍軍・有志連合軍** | **決まらない**（前が国の呼び名ではない） |

- 地図の行は**分類が変わる行が0**（直近90日も全期間も）
- **ただし「ロシア政府予算 → ロシア軍・軍需産業」は場所不明のまま。** 受け取る側はロシアと読めるようになるが、**払う側の「ロシア政府予算」が決まらない**（「〜予算」を読む決まりが無い）。この段では「〜予算」は足さない
- 「〜の」「・」の前に後ろの言葉を当てるのを広げても、ほかに動いた行は無い（全期間で確かめた）

**失うもの：** 「フーシ派の軍」のような「国でない主体＋軍」は、今までどおり決まらない。

## 4. 確度3以下で地図から外した動き（回答書の判断4）

### 4.1 回答書の問い「押したら外した札の一覧が開く形にできるか」への答え

**できる。** 地図は描く前に確度3以下を外しているので、外した分を別に取っておけば、場所不明などと同じ形で一覧を開ける。

### 4.2 決まり

- 地図と同じ期間（直近90日）で、確度3以下で外した動きを取っておく（同じ動きは1行にまとめる）
- **地域・種類では絞らない**（場所不明と同じ。いつも全体の数）
- **今のデータ：8行**（まとめても8行）

### 4.3 画面に出す

| 名前 | 開いた一覧の頭の1行（26字以内） |
|---|---|
| **確度3以下で外した動き N件** | 確度3以下なので、地図に描かなかったもの |

- 開いた一覧で札を開くと、確度の理由が「詳しく」を押さずに見える（v20.26 の形）
- 「数字の見方 ▸」（地図）に「確度3以下の動きは地図・国の網・お金の鎖に描かない。お金の一覧には出す」を足す

### 4.4 ほかに確度で外している所

| 所 | この段で | 失うもの |
|---|---|---|
| 大きな地図・国の網 | 4.3 の件数で見せる | — |
| **小さな地図（7日）** | **【承認書で変更】出す。** SVG の外（小さな地図のすぐ下）にふつうの行で「確度3以下で外した線 N本（押すと大きな地図で一覧）」。数えるのは、小さな地図が描く国をまたぐ線だけ。0本なら出さない | 1行増える |
| **世界の画面のお金（鎖・単発）** | 見出しの上に1行「確度3以下の動きは外しています（一覧には出ます）」（**【実装時に短縮】** 幅320で1行に収めるため） | 1行増える |
| 朝の「背景の札 N件」 | **触らない**。主体の無い札と確度3以下が混ざった1つの数のまま | 確度で外した分だけの数は、朝の画面では分からない |

## 5. 「まだ起きていない」を確度から外す（回答書の判断4）

生成への指示に足す文（そのまま）。

毎朝のプロンプトの、confidence の説明の後：

```
  交渉・打診・約束の段階であることは confidence で表さない（出典の確かさだけで付ける）。まだ実体が動いていないなら pledge を true にする。
```

読む回のプロンプトの、confidence の説明の後：

```
  - まだ起きていない（交渉・打診・約束の段階）ことを理由に下げない。それは確かさではない。
```

- **これからの札にしか効かない。** 今の確度3の「交渉段階」「打診の段階」の札（エジプトの LNG、サウジの協調融資）は3のまま
- **失うもの：** 交渉・打診の札が、これからは今より高い確度で入り、地図に残る。約束の見分けに当たれば、地図の「約束」の絞りで薄い線として見える

## 6. お金の一覧（回答書の判断5）

**外さない。** 注意書き（「読み込んでいる月：…」の行）の後ろに1文足す：

```
一覧は確度3以下の札も出します（地図は外しています）。
```

「数字の見方 ▸」（お金の一覧）の「読み込んでいる月」の説明にも同じ文を足す。

## 7. 生成への指示が長くなる分

1.4 と 5 で、毎朝のプロンプトに約130字、読む回のプロンプトに約40字増える。**今の長さは測っていない**ので、実装のときに本物のデータで測る（v20.24 の実測では毎朝 19,631字、注意を出す線は 23,000字）。

## 8. 消えないため・嘘をつかないための決まり

| 危険 | 対策 |
|---|---|
| 主体の表の国を書き換えて、同期で広がる | 書き換えない。場所を読むときに使わないだけ |
| 手で決めた国まで疑う | 手で決めた印がある主体は、国が2つ以上の名前でも主体の国を使う |
| 「国の呼び名＋軍」で1国に定まらない軍を拾う | 後ろの「軍」を外した残りが国の呼び名と丸ごと一致したときだけ |
| 枠の名前の国を誤って知らせる（「ロシア産原油の買い手」） | 「と」「・」「、」の後ろに国が別の相手として並ぶときだけ |
| 確度で外した動きが黙って消える | 地図の下に件数、押すと一覧。世界の画面のお金にも1行 |
| 決まりの順番で結果が変わる | 国が2つ以上 → 主体の国（手で決めたもの）→ 今までの順、と決めて1か所に書く |
