## 1. 予告の時期を1つの決まりにする

### 1.1 決まり

今日（端末の日付）と期限・押した日時・見立ての日時から、予告1本の時期を1つの関数で決める。画面・件数・答え合わせは全部これを使い、**期限を直接比べる所を残さない**（今は 18040行と 22787行の2か所）。

| 時期 | 条件 | 押せるか | 答え合わせに載るか | 予告の画面の欄 |
|---|---|---|---|---|
| **待っている** | まだ押していない・畳んでいない、期限 ＞ 今日 | 押せない | 載らない | 待っている |
| **期限当日** | まだ押していない・畳んでいない、期限 ＝ 今日 | **押せる** | **載らない** | 期限が来た（押して確定してください） |
| **期限が来た** | まだ押していない・畳んでいない、期限 ＜ 今日 | 押せる | 載る | 期限が来た（押して確定してください） |
| **もう一度確かめる時期** | 結果が「確かめられない」・畳んでいない、**数えた日から7日** ≦ 今日 | 押せる | 載る | もう一度確かめる時期（押して確定してください） |
| 押したもの | 当たり・外れ、または 7日たっていない「確かめられない」 | 押し直せる | 載らない | 押したもの |
| 畳んだもの | 畳んだ | 押せない | 載らない | 畳んだもの（回数と理由を添える） |

- 「7日」は1か所の値にする（聞き直しまでの日数 7、打ち切る回数 3 は今の値の隣に置く）
- 日付は端末の日付で数える（「押した日」は押した日時を端末の日付にしたもの）。時刻の決まりは作らない（回答書「時間の扱い」）
- 「数えた日」は 3.1 の欄。無い予告（今ある予告・古い版の端末が整えた予告）は、押した日時で代わりに数える

### 1.2 変わる所

| 所 | 今 | v20.40 |
|---|---|---|
| 予告の画面「期限が来た」 | 期限 ≦ 今日 | 期限当日＋期限が来た（今と同じ本数） |
| 予告の画面「待っている」 | 期限 ＞ 今日（直接比べていた） | 待っている（決まりから） |
| 予告の画面「もう一度確かめる時期」 | 無い | 新しく出す（足3） |
| 予告の画面「押したもの」 | 押したもの全部 | 7日たった「確かめられない」を除く |
| 答え合わせの塊を出すか | 期限が来た予告があるとき | 押せる予告（期限当日・期限が来た・もう一度確かめる時期）があるとき |
| ホーム「待っている予告 N本・期限が来たもの N本」 | 期限 ≦ 今日 | 「期限が来たもの」＝期限当日＋期限が来た＋もう一度確かめる時期 |
| 世界の画面「予告 ・ 期限が来たもの N本」 | 同上 | 同上 |

**変わらない所：** 待っている予告の並び（期限の古い順）／同じ予告の見分け／読む回の切れた推定の枠の並び／当たり外れの割合の数え方。

### 1.3 もう一度確かめる時期の欄（足3）

```
もう一度確かめる時期（押して確定してください） 1本
09/14まで　米財務省が 9月14日に大手金融機関1行以上を制裁対象に指定
当たりの印：CNBC
生成の見立て：確かめられない …（前の見立て）
結果：確かめられない（1回目・9/14）
［当たり］［外れ］［確かめられない］
```

- 結果の行に、回数と数えた日を出す
- **結果は機械が変えない。** この欄に出ても「確かめられない」のまま（回答書 3）

**足3 の理由：** 載せ直した予告が「押したもの」の中に埋もれていると、答え合わせの返事を取り込んだ後にどれを押せばよいか見つけにくい。

## 2. 答え合わせ

### 2.1 塊の見出し

```
答え合わせ（期限が来た 3本・もう一度確かめる 1本・期限当日 1本は明日から載ります）
```

- 期限当日の予告は「明日から載ります」と数だけ出す（載らない理由が見える）
- 載せる予告が0本で、期限当日の予告だけあるときも塊は出す（押す欄があるため）。［答え合わせのプロンプトをコピー］を押すと「今は答え合わせに載せる予告がありません（期限当日の予告は明日から載ります）」

### 2.2 載せる予告と並び（足2）

次の順に、1回10本まで（今のまま）。

1. **期限が来た**予告で、**見立てがまだ無い**もの（期限の古い順）
2. **もう一度確かめる時期**の予告で、**7日たった後に見立てをまだ取り込んでいない**もの（数えた日の古い順）
3. **期限が来た**予告で、**見立てから7日たった**もの（見立ての古い順）＝回答書 5
4. もう一度確かめる時期の予告で、見立てを取り込み直してから7日たったもの（見立ての古い順）

- **載せないもの：** 期限当日／待っている／見立てを取り込んでから7日たっていない予告（押していなくても）
- 残りがあれば、今の「ほか N本は…」
- **足2 の理由：** v20.39 は「見立てがまだの予告が0本なら、見立てのある予告を全部聞き直す」だったので、取り込んだ直後にもう一度コピーすると、同じ予告をすぐに聞き直してしまう。7日の決まりにそろえる
- **失うもの：** 見立てを取り込んだ直後に、もう一度同じ予告を聞き直したいときは、7日待つ（自分で調べて押すことはできる）

プロンプトの中身は v20.39 のまま。聞き直しの予告には、元の予告の行の下に1行足す：

```
  前の答え合わせ：確かめられない（まだ発表されていない）9/14。今日あらためて確かめる。
```

### 2.3 取り込み（足4・足5）

| 予告の状態 | 取り込むか |
|---|---|
| まだ押していない・期限当日か期限が来た | 取り込む（今のまま） |
| まだ押していない・**期限前** | **取り込まない**（「※ 期限前の予告 N本は取り込んでいません」）足5 |
| 結果が「確かめられない」・畳んでいない | **取り込む（見立てだけ入れ直す。結果は変えない）** 足4 |
| 当たり・外れ | 取り込まない（今のまま「すでに押してある予告」） |
| 畳んだ | 取り込まない（今のまま） |

- url の決まり・組み合わせの決まりは v20.39 のまま
- 7日たつ前に貼られた「確かめられない」の予告の見立ても受け付ける（前にコピーしたプロンプトの返事かもしれないため。結果は変えない）

**足5 の理由：** 期限前の予告は答え合わせに載らないので、貼られたとしたら古いプロンプトか手で作った返事。期限前に見立てを入れると、期限が来たときに「見立てあり」として後回しになる。

## 3. 「確かめられない」の回数（回答書 4）

### 3.1 数える欄を足す（足1）

予告に「確かめられないを数えた日時」を1つ足す。

### 3.2 押したときの決まり

［確かめられない］を押したとき、次の**どれか**に当たるときだけ回数を1つ増やし、数えた日時を今にする。

1. 今までに1回も数えていない（回数0）
2. 前に数えた日時より**後に、見立てを取り込んでいる**（答え合わせで確かめ直した）
3. 前に数えた日から**7日たっている**（もう一度確かめる時期に入っている。自分で調べ直した）

どれにも当たらないとき（続けて押した・押し替えただけ）は、結果は「確かめられない」にするが**回数は増やさない**。回数が3になったら畳む（今のまま）。

- 数えた日時が無い予告（今ある予告）は、回数が1以上なら**押した日時**を数えた日時とみなす
- ［当たり］［外れ］を押したときは回数を変えない（今のまま）。畳んでいたら畳みを解く（今のまま）

**失うもの：** 7日たつ前に自分で調べ直して［確かめられない］を押しても、回数に数えない（見立ての取り込みが無いと、確かめ直したと分からないため）。

**足1 の理由：** 押した日時（stateAt）は［外れ］を押しても変わるので、それで数えると「確かめられない → 外れ → 確かめられない」と押し替えただけで回数が増える。

### 3.3 畳んだものの欄（回答書「守ること」）

```
畳んだもの 1本
09/14まで　米財務省が …
結果：確かめられない（3回で畳みました・最後の理由：まだ発表されていない）
```

- 回数と、最後の見立ての「確かめられなかった理由」（無ければ事実の種類、それも無ければ出さない）を添える
- 当たり外れの割合の行は今のまま（畳んだものが5本を超えたら「印の立て方を見直す時期です」も今のまま）

## 6. 確かめ方

日付を動かして確かめる（試しのページで端末の時計を差し替える）。

1. **期限当日の予告が画面から消えない**：期限を今日にした予告が「期限が来た（押して確定してください）」に出て、［当たり］［外れ］［確かめられない］を本当に押せる
2. **期限当日の予告がプロンプトに載らない**：その状態で［答え合わせのプロンプトをコピー］→ 載っていない。見出しに「期限当日 1本は明日から載ります」。翌日にすると載る
3. **続けて3回押しても畳まれない**：［確かめられない］を3回続けて押す → 回数1のまま、畳まれない。［外れ］→［確かめられない］と押し替えても増えない
4. **7日後に載り直す**：確かめられないを押した日から6日目は載らない、7日目に「もう一度確かめる時期」に出て、プロンプトに載る。その後に見立てを取り込んで押すと回数2。さらに7日後に3回目で畳まれ、「畳んだもの」に回数と理由が出る
5. **見立てを取り込んだが押していない予告**：見立てから6日目は載らない、7日目に載る
6. **米財務省の1本**：今の kotoba-data の予告をそのまま入れた試しのページで、端末の日付を 9/20 にすると「押したもの」、9/21 にすると「もう一度確かめる時期」に出てプロンプトに載る（書き込みなし）
7. **取り込み**：期限前の予告の答えは取り込まれず本数が出る。確かめられないの予告の答えは取り込まれ、結果は変わらない
8. **ホーム・世界の画面の件数**が新しい決まりと合う
9. **本物のデータ**：今の kotoba-data を整え直して v20.39 と比べ、違いは足した欄（空）だけ
10. **触る確かめ**：決まった8項目。予告の画面の貼る欄に2文字以上打って取り込む、コピー・当たり・外れ・確かめられない・読み違いを本当に押す
