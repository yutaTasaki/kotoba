# 仕様書：見せ方 段1（地図は、場所が効く札だけに出す）

- 元：相談 `houkoku/2026-09-16_misekata.md`、回答 `shiji/sekai_misekata_kaitou.md`、答え `houkoku/2026-09-16_misekata_kaitou.md`
- 版：v20.62

## 0. 決まり

- 地図を出す基準を「乗せられるか」から「**その札で場所が効くか**」に変える
- 印は**札ごとに1つ**（場所・大きさ・構図・時間・順序・無）。これから入る札はチャットが書く。今ある145枚は下書きを持たせる
- **印が分からない札には地図を出さない**（既定は出さない）
- 1行（お金：／効かせた：）は145枚とも今までどおり。**情報は何も失わない。消えるのは図だけ**
- 地図タブ（大きな地図）・国の網・点検の一覧は変えない

## 1. 見せ方の印（view）

### 1.1 値

| 値 | 意味 |
|---|---|
| `place` | どこからどこへ動いたかが効く |
| `size` | 額や量が、何かと比べて大きいか小さいかが効く |
| `line` | 誰と誰がどちら側に並んだかが効く |
| `time` | 前の値から今の値への移りが効く |
| `order` | 前の動き → この札 → 次の動き の鎖が効く |
| `none` | 文だけで足りる |

段1で使うのは `place` かどうかだけ。残り5つは段2・段3で使う（先に貯めておく）。

### 1.2 どこに持つか

- **これから入る札**：朝の取り込みの返事に `view` を足し、調べた記録（dig）の月ファイルの新しい並び `views` に1件ずつ記録する（`aims` と同じ作り。足すだけ・消さない・新しいものが勝つ）
- **今ある145枚**：コードの中の下書き表（`WORLD_VIEW_SEED`）から読む。**データには何も書かない**
- 読む順：`views` の記録 → 下書き表 → 空（空なら地図を出さない）

下書き表は、私が145枚を1枚ずつ読んで付けたものです（`chousa/2026-09-16_misekata_bunrui.md`）。コードの中にあるので、違うと思った札があれば直せます。

### 1.3 朝のプロンプト

出来事ごとの欄に `view` を足す（約250字）。今 27,303字 → 約 27,550字（上限3万字）。

比べる相手（`cmp`）は段2で足し、そのときに「最近のお金の動き」の節（2,053字）を外します。

## 2. 枝の地図

### 2.1 出す条件

| | v20.61 | v20.62 |
|---|---|---|
| 出す札 | お金の線・点の横の文字・効かせた線のどれかがある札 | **印が `place` で、かつ お金の線か効かせた線がある札** |
| 枚数（145枚中） | 75 | **13** |

### 2.2 効かせた線

**場所が効く札の中では、今までどおり地図に描く。**

回答では「地図から外す」でしたが、測ったところ、外すと地図が出る札が13枚→8枚になり、フーシ派の制圧・サウジのパイプライン停止など、場所がすべての札が消えます。地図を `place` の札だけに絞ることで、気にされていた25枚（米財務長官→日銀など）は**地図ごと自動的に消えます**。詳しくは `houkoku/2026-09-16_misekata_kaitou.md`。

### 2.3 点の横の文字（v20.61）は外す

- 相手が枠（市場・株主・BRICS）のときの、点の横の小さい文字を出さない
- 相手の名前は今までどおり下の1行に全部出る
- 片方が枠の札は、地図を出さない（`place` の札にほとんど無い。22枚中1枚）

外すもの：`worldEdaSideName`・`out.sides`・`.wmSideLabel`・`WORLD_EDA_SIDE_MAX`。

## 3. 変えないもの

- 地図タブ（大きな地図）・本部の点・海峡の点・国の網・点検の一覧
- 1行（お金：／効かせた：）とその理由
- 確度3以下は線にしない決まり
- 効かせた相手の欄（aims）の書き方・記録
- 幹・葉・根・芽・杭

## 4. 直さないもの（段1では）

- 動きの欄が空の4枚（モカ制圧など）は、地図が出ないまま。「起きた場所」の欄を足すかどうかは、実機で見てから
- 「紅海のヤンブー港」が場所の表に当たらない件。部分一致に緩めるのは反対（前に「ペルシャ湾→ペルー」の誤りを出した）
- 確度3以下の2枚

## 5. 確かめ

### 手元

1. **枝の地図が出る札が 75枚 → 13枚**。内訳は お金の線がある8枚＋効かせた線だけの5枚
2. **1行は145枚とも変わらない**（お金：／効かせた：の本数が前の版と同じ）
3. **地図タブの線の本数が変わらない**（全期間51・直近90日47・国内28・場所不明9）
4. 印が `place` でない札（トヨタ・安保理・ECB）で、地図が消えて1行だけになる
5. 点の横の文字がどこにも出ない
6. 145枚を全部開いてページのエラー0
7. 朝のプロンプトの字数（27,303 → 約27,550）

### 公開の前に実機で

1. **地図が消えた札（132枚）で、1行だけになって読めなくなっていないか**。特にトヨタ・ECB・IMF の札
2. 地図が残った13枚（フーシ派・海峡・原油の輸出先）で、地図が読む助けになっているか
3. 地図タブが今までどおりか
4. 次の朝の取り込みのあと、新しい札に地図が出るか出ないか（チャットが `view` を書けているか）
5. もう片方の端末で同じか
