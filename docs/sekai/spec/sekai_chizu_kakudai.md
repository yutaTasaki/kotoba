# 仕様書：枝の地図を、関わる場所に合わせて拡大する

- 元：指示 `shiji/sekai_chizu_kakudai_shiji.md`
- 版：v20.63
- 前提：v20.62 で地図が出る札は13枚に絞られた

## 0. 決まり

- 開いたときに、その札の分だけ**最初から拡大された状態**で出す。押して拡大する仕掛けは作らない
- 地図は押す物にしない（指でなぞればページが動く決まりは維持）
- **国の形は今までどおり幅ごとに1回だけ作り、拡大は SVG の transform でかける**（形を作り直さない）
- 1行・地図タブ・お金の線の本数は変えない

## 1. 決めたこと（聞かれた7つ）

### 1-1. 拡大の範囲

**関わる点（国・海峡・本部）を全部含む四角が、枠の6割を占める倍率**にする。残り4割が余白（上下左右に2割ずつ）。

「いちばん小さい四角＋余白」という案と同じ考えですが、余白を「px で何ぼ」ではなく**割合**にしました。px で決めると、点が近い札（サウジとイエメン）で余白ばかりになり、拡大が効かなくなるためです（試作で確かめ、倍率が 3.8 止まりでした）。

- 上限は **6倍**。これ以上寄せると、使っている地形データ（110m）の粗さが見えます
- **1.2倍に満たないときは拡大しない**（世界全体のまま）。わずかにずらすと、かえって読みにくくなります
- 地図の外の余白が見えないよう、世界の枠の中に収める（端の国でも黒い帯が出ない）

### 1-2. 関わる点が1つしかない札

**上限の6倍まで寄せて、その点を真ん中に置く。**

いまは `place` の印があり、かつ線か効かせた線がある札にしか地図が出ないので、点が1つになる札はありません（実データ13枚すべて2点以上）。作りとしてだけ備えます。

### 1-3. 端から端まで離れている札

**世界全体のままにします。** 1-1 の倍率が 1.2 に届かないので、自動的にそうなります。別の基準は作りません。

実データでは2枚が該当しました（中国のイラン産原油＝イラン・中国・米国、トルコの銀行への制裁＝中国・イラン・米国・トルコ）。どちらも太平洋をまたぐので、拡大のしようがありません。

### 1-4. 杭・海峡・本部の点

**全部、範囲に含めます。** 地図に描く点はすべて入れます。杭は国の点の下に立つので、その国が入っていれば収まります。

### 1-5. 実データ13枚の拡大

後述（3節）。

### 1-6. 国の形の使い回しと重さ

**影響しません。** 拡大は、作り置きした国の形（幅ごとに1つ）の複製に `transform` をかけるだけです。形を作り直さないので、キャッシュはそのまま効きます。

境界線は今までどおり細いまま（`vector-effect: non-scaling-stroke` が v20.1 から入っている）。点・線・文字の大きさも変わりません（画面の座標で描くため）。

実測は3節。

### 1-7. 地図タブ（大きな地図）

**今までどおり世界全体のまま。** あちらは90日分の札をまとめて見る場所で、関わる場所が世界中に散っています。拡大する意味がありません。

## 2. 作り

`worldEdaView(m, S, W, H)` を足す。

1. その札で描く点（`dots` ＋ `places`）を、世界全体の座標に直す
2. その四角の幅と高さを出す
3. `k = min(W×0.6 ÷ 幅, H×0.6 ÷ 高さ)`。点が1つ（長さ0）の側は上限を使う
4. `k` を 6 で頭打ちにし、1.2 未満なら 1（拡大しない）に落とす
5. 四角の真ん中が枠の真ん中に来るよう寄せ、世界の外が見えないよう端で止める

描くときは、国の形の複製を `translate(...) scale(k)` の中に入れ、点の座標は `点 × k + ずらし` で出す。

## 4. 公開の前に実機で確かめてほしいこと

**触ると壊れる形から**

1. **拡大の範囲が狭すぎて、国の形が読めなくなっていないか。** いちばん寄る2枚（サウジ＋イエメン、6倍）を先に
2. **広すぎて元と変わらないか。** いちばん寄らない2枚（ヒズボラ制裁1.8倍、インド＋ロシア2.2倍）
3. 線・矢印・文字（手の言葉・国内・海峡の名前）が、拡大しても正しい場所に出るか。大きさが変わっていないか
4. 指でなぞってページが動くか（地図が押す物になっていないか）
5. 拡大しない2枚（イラン・中国・米国／トルコの銀行）が、今までどおり世界全体か
6. 地図タブ（大きな地図）が今までどおり世界全体か
7. もう片方の端末で同じか
