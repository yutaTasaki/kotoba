## 0. 決まり

- **期間を切り取らない。** 持っている点を全部出す
- **縦軸は最小〜最大。両端の値を必ず数字で書く**（0から始めない。どちらを選んでも印象は作られるので、数字で打ち消す）
- **上下を色や記号で強調しない**（良い／悪いの判断を混ぜない）
- どの地層を使うかは**機械的に決める**（点がいちばん多いもの）。人もチャットも選ばない
- 位置は「なぜ」の直下

## 1. 段3-1（v20.66）：地層の折れ線

### 1-1. 出す条件

印が `time` の札で、その札の地層のうち、次を**すべて**満たすものがあるとき。

1. **すべての点が数にできる**（1点でも数にならない並びは出さない）
2. **点が3つ以上**
3. **いちばん古い点といちばん新しい点の間が90日以上**

複数当てはまるときは、**点がいちばん多い**地層。

実データ145枚のうち **6枚**。

### 1-2. なぜ2と3だけでは足りないか

- `日銀の資産の内訳` は3点あるが、1点が `国債:519.9...,貸付金:71.8...` という複合の文字列で数にならない。一部だけ使うと、抜けた点が無かったことになる
- `日本の長期金利` は4点あるが**10日間**しかない。この地層を使う札には「長期金利が30年ぶりに3.005％を付けた」があり、10日の線は「30年ぶり」を支えないどころか、ただの上下に見せてしまう

### 1-3. 形

- 幅いっぱい・高さ約52px。点は日付に比例して横に置く（間隔が不揃いなら、そのまま不揃いに出る）
- 線は1色。太さは拡大しても変わらない
- **その札が入れた値（`eventId` が一致する点）は丸で示す**
- 下に2行
  - `地層：米国の政府債務総額（兆ドル・403点）`
  - `1993年4月 4.25 → 2026年9月 40.05`

### 1-4. 変えないもの

地図（`place`）・帯と比べる棒（`size`）・1行・地図タブ・朝の取り込みのプロンプト。

## 2. 段3-2（返事のあと）：文の中の前の値

### 2-1. 新しい欄は足さない

段2-2 で作った `cmp` に `rel:"prev"`（前の額）がすでにある。時間の札で要るのも「前の値」なので、**同じ欄を使う**。

変えるのは2つだけ。

- 規則の1行：「札の**額**が」→「札の**数字**が」（額でない値＝%・隻数・バレルも書けるようにする）
- 出す条件：印が `size` だけ → `size` と `time`

**字数の追加はゼロ。**

### 2-2. 見せ方は棒ではない

金利 2.891% と 3.005% を0から伸ばす棒はほとんど同じ長さになり、札が言う「0.11ポイント上がった」が消える。

**数字2つと差だけを出す。**

```
2.891% → 3.005%（+0.114）
```

- 差は、単位が同じときだけ出す。単位が違う・割合のときは出さない
- 色は変えない

### 2-3. 埋め直さない

新しい札から効かせる。既存の27枚には書き足さない。
