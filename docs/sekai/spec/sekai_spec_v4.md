# 一万日 v13 仕様書 — 世界：既定を「主体の盤面」にする

v12.1 までの世界タブの**既定画面を入れ替える**。一覧を足すのではなく、既定を降ろして入れ替える。既存の言葉・引く・相談・問い・撮る・筋トレ・散歩には触らない。

## なぜ入れ替えるのか

世界タブを開くと、地層の1行 → 今日の3件 → `[出来事][概念][予測]` → 検索 → 17件の札の一覧が出る。概念タブに移ると概念16・用語51・アクター24 が回数順に並ぶ。

**これは在庫リストで、「情報が地面に転がっている」状態そのもの。**

原因ははっきりしている。**この機能は「情報を集める」から作り始めて、あとから「思惑を見る」を足した。** だから土台が札の一覧のままで、アクターは札の中に埋まっている。順番が逆だった。

目的をもう一度置く：

> すべての物事は人間の思惑で動いている。その思惑は、お金の動きや行動に現れる。それが分かる仕組みを作りたい。

この目的からすると、最初に見るべきは「今日どんな出来事があったか」ではなく、**「いま誰が何を動かそうとしているか」**。

## 1. 主体の盤面

### 1.1 形

```
（地層の1行）

今日の3件
  9/9  ホルムズ海峡の制約で…              [ホルムズ海峡 3]
  9/7  円買い介入で外貨準備が…            [外貨準備 2]
  9/9  BISがフロンティアAIの…             [フロンティアAI 3]

[主体] [出来事] [概念] [予測]

動いている主体                        述＝述べた理由がある／推＝推定がある ▸
  日本政府   イラン外相と電話会談し海峡の自由な航行の回復を求めた   9/8  3件  ・推
  NATO       アルテア作戦を支持し国連による任期更新への支持を表明   9/8  2件  述
  財務省     7月30日〜8月26日に円買い・ドル売り介入                9/7  1件  述推
  IMF        エルサルバドルとEFFの第2・3次レビューで職員級合意      9/3  1件  述
  ─────────────────────────────
  もっと見る（あと 6件）
```

- **1行 = 名前／直近の行動（`did`）／最終日／回数／印**
- 押すとアクター詳細（時系列）
- **行動が1件も無い主体は出さない**（種21件のうち、動いた主体だけ）

### 1.2 並び順 — 期間で切らない

**最終行動の新しい順。** 同じ日なら回数の多い順。

期間（直近30日など）で切らない。**「静かになったこと自体が情報」**だから——「あれだけ介入していた財務省が2か月動いていない」が消えるのは危ない。古い主体は自然に下がるので、切る必要がない。

### 1.3 右端の印 — この画面の核心

**行動だけ並べると「誰が何をしたか」の一覧（＝出来事一覧の主語版）になり、また在庫リストに戻る。** 盤面の核心は**思惑の有無**なので、そこを右端に出す。

| 印 | 意味 | 見え方 |
|---|---|---|
| `述` | その主体の記録のどれかに `said` がある | 通常色（`--text-dim`） |
| `推` | どれかに `read` がある | **琥珀（`--guess`）** |
| `・推` | **`said` が1件も無く、`read` だけがある** | **琥珀＋左に中黒。一番目立つ** |

**「述」が無く「推」だけの行が、この画面で一番重要。** 何も言わずに動いている主体が、探さずに見える形にする。中黒（`・`）を頭に付けて位置をずらし、色を琥珀にして、走査したときに引っかかるようにする。

**金額は出さない。** 出すと金額のある主体だけが目立ち、動いているが金を動かしていない主体（NATO・イラン政府）が沈む。盤面は「誰が動いているか」であって「誰が金を使ったか」ではない。金額が縦に並ぶ絵は**アクター詳細の時系列**にある（そこが正しい置き場所）。

### 1.4 凡例

見出しの右に薄く1行。`述＝述べた理由がある／推＝推定がある`。

**押すと畳める**（`WORLD_BOARD_LEGEND_KEY` に覚える）。2文字の印は最初は読めないが、数日で覚えるので、覚えたら消せる形にする。

### 1.5 件数

- 既定は**上位5件**（`WORLD_BOARD_FOLD`）
- 「もっと見る（あと N件）」で `WORLD_BOARD_MAX`（20）まで
- 20 を超えたら「一覧で見る」（アクター一覧へ）

「今日の3件」は畳まない。**読む行為の起点**なので、既定から外すと消費が止まる。盤面の側だけ畳む。

## 2. タブ

`[主体] [出来事] [概念] [予測]` の4つ。**既定は「主体」**（`worldState.tab` の初期値を `'board'`）。

- **出来事**：残す。探すときに要る。検索もそのまま
- **概念**：前に決めたとおり「たまに整理する場所」なので、既定から遠くてよい
- **予測**：そのまま

390px で4つ並ぶ。`tagFilterRow` は折り返すので、入らなければ2行になる（既存の挙動）。

## 3. 盤面へ戻る導線

既定が盤面になると、出来事タブに入ったあと戻れなくなる。**2か所から戻せるようにする。**

| どこから | いま | 足すもの |
|---|---|---|
| 出来事タブ（「入れた札を見る」「つながる札」から飛んだ後） | 「全部を見る」で出来事の全件に戻るだけ | タブの `[主体]` を押せば戻る（**タブが常に見えているので、これで足りる**） |
| アクター詳細（盤面の行から入った後） | `btnWorldConceptBack` が `worldState.view = 'main'` に戻る | `worldState.tab` を**盤面に戻す**（いまは直前のタブに戻るので、アクター一覧から入ったときは一覧に、盤面から入ったときは盤面に戻る形にする） |

**どこから来たかを覚える**：`worldState.entryFrom = 'board' | 'list'` を持ち、アクター詳細の「戻る」でそこへ返す。盤面から入ったのに一覧に落ちる、を防ぐ。

`btnWorldImportShow` と `openWorldEvent` は既に `worldState.tab = 'events'` を明示しているので壊れない（確認済み）。

## 4. データ

**新しい保存項目は無い。** 盤面は `worldActors()` と `worldLiveEvents()` から毎回組み立てる。

```js
// 動いた主体だけを、最終行動の新しい順に
function worldBoardRows() {
  return worldActors()
    .map((a) => {
      const rows = worldActorRows(a);           // 既存。時系列と同じ組み立て
      if (!rows.length) return null;            // 行動が無い主体は出さない
      const top = rows[0];                      // 既に新しい順
      return {
        actor: a,
        did: top.rec ? top.rec.did : top.event.fact,
        date: top.event.eventDate,
        count: rows.length,
        said: rows.some((r) => r.rec && r.rec.said),
        read: rows.some((r) => r.rec && r.rec.read),
      };
    })
    .filter(Boolean)
    .sort((x, y) => (x.date > y.date ? -1 : x.date < y.date ? 1 : y.count - x.count));
}
```

`worldActorRows()` は端末に読み込んでいる月だけを見る。**盤面も同じ**（読み込んでいない月の行動は数えない）。件数が実際より少なく見えることがあるので、盤面の下に1行出す：`端末に読み込んでいる月だけを数えています`。

## 6. 守ること

- **在庫リストを増やさない。** 一覧を足すのではなく、既定を入れ替える
- **期間で切らない。** 静かになったこと自体が情報
- **金額を盤面に出さない。** 金を動かさない主体が沈む
- 「今日の3件」は畳まない（読む行為の起点）
- 行動が1件も無い主体は出さない
- 既存のデータ（札・概念・用語・地層・アクター）は消さない
- 朝の流れは変えない
- 出来事タブ・概念タブは残す。降ろすだけ
- **網は保留。** ゲート15本に届いても、自動では着手しない

## 7. 実装後に見るところ

- **盤面の1行目が、いま一番動いている主体になっているか。** なっていなければ並び順（最終行動の新しい順）が目的と合っていない
- **`・推` の行がいくつあるか。** 0件なら生成が推定を書かなすぎ、半分以上なら書きすぎ
- **「もっと見る」を押す頻度。** 毎回押すなら `WORLD_BOARD_FOLD` を上げる
- 盤面 → アクター詳細 → 戻る、で盤面に返ってくるか
