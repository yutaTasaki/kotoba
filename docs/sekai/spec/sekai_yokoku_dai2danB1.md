## 0. B-1 で何ができるようになるか

1. 朝タブの予告が**1行**になり、押すと予告の画面へ飛ぶ（戻ると朝に返る）
2. 世界のデータを捨てるとき、**予告も一緒に捨てる**。捨てる前に**本数を出す**
3. 読む回の枠20枚が**種類ごとに配分**され、浅い読みが必ず回るようになる

**3 が今回いちばん効く。** 作ってあるのに一度も動いていなかった仕組みを動かす。

## 1. 読む枠の配分（実測で見つかった問題への対策）

### 1.1 いま起きていること

| | 枚数 |
|---|---|
| 札 | 115 |
| **未読** | **75** |
| 浅い読みが残る（書き直し候補） | 20 |

枠は1回20枚。いまの作りは「未読を優先し、余った枠に書き直し候補」なので、
**未読75枚だけで埋まり、書き直し候補は1枚も回らない**。未読が尽きるまで4回ぶん、当分先。

### 1.2 新しい配分

| 種類 | 枠 |
|---|---|
| 外れた札（B-2 で入る） | 最大 **3** |
| 浅い読み（書き直し候補） | 最大 **5** |
| 未読 | **残り全部** |

- その種類が足りなければ、**余りは未読に回す**
- 未読が足りなければ、余りは浅い読みに回す（枠を遊ばせない）
- 合計は必ず20枚以内

**B-1 の時点では外れた札は0枚**（B-2 で入る）。つまり当面は「浅い読み5＋未読15」になる。

### 1.3 取り込みの結果に内訳を出す

```
5枚に思惑が入りました（…）。　読んだ内訳：浅い読み5・未読15。
```

**何が回っているかが見えないと、また同じことが起きる。** 必ず出す。

## 2. 朝タブを1行にする

### 2.1 出す形

| 状態 | 出すもの |
|---|---|
| 期限切れあり | `待っている予告 5本・期限が来たもの 1本 ▸` |
| 期限切れ0本 | `待っている予告 5本 ▸` |
| 両方0本 | **行ごと出さない** |

### 2.2 押したときの動き

押すと**世界タブの予告の画面**へ飛ぶ。

### 2.3 戻り先（ここが要）

**朝から入ったときは、戻ると朝に返る。**

予告の画面の「世界に戻る」は、いまは世界タブの主画面へ行く。
朝から入ったのに世界タブに残ると迷子になるので、**どこから入ったかを覚えて返す**。
一覧や網が既に同じ形を採っているので、それに合わせる。

- 朝から入った → ボタンの文字は「朝に戻る」、押すと朝タブへ
- 世界タブから入った → いままで通り「世界に戻る」

### 2.4 第1段からの変更点

第1段では押せない `div` で5本並べていた。これを**押せる1行**に変える。
並びの登録（ホームの手順の一覧）は第1段で済んでいるので、**中身と押したときの動きだけ**を変える。

## 3. 捨てるときに予告も捨てる

### 3.1 足す順番（間違えると壊れる）

| 順 | 場所 | 足さないと何が起きるか |
|---|---|---|
| **1** | 保存庫を上書きする並び | 端末で消えても**保存庫に残り、次の同期で戻ってくる** |
| **2** | 空にする器 | そもそも端末で消えない |
| **3** | 書き戻す器の一覧（捨てた側） | 索引に日付が入らず、相手が気づかない |
| **4** | 受け取った側へ書く並び | もう一方の端末で消えない |

**必ず1から順に足す。** 2だけ先に足すと「消したのに次の同期で戻る」という、
いちばん切り分けの難しい壊れ方になる。

### 3.2 保存庫の上書きの位置

捨てる処理は**途中で止まると「もう一度押すと続きをやる」**作り。
予告の上書きは**地層の後・月ファイルの前**に置く（器を全部片付けてから月に入る形を保つ）。

### 3.3 捨てる前に本数を出す

**全部の月を読み込んでから数える。**

回答書の「い」への答え：**できます。しかも追加の重さはほぼありません。**

理由：捨てる手順は「1 バックアップを作る → 2 端末に保存 → 3 捨てる」で、
**1 の時点で全部の月を保存庫から読み直している**。3 を押す時点では既に全月が端末に載っている。
念のため、数える直前にも「まだ読んでいない月があれば読む」処理を通す
（既に読んだ月は何もしないので、二重には読まない）。

確認の文：

```
札 115枚・概念 42件・用語 18件・問い 3件・予告 5本を捨てます。
主体・地層の値・ソースは残します。
元に戻すにはバックアップを手で戻す必要があります。
捨てますか？
```

- 数えるのは**確認を出す直前**
- 全月を読み込めなかった月があれば、その数を添える：
  「※ 読み込めなかった月が N か月あります。実際はこれより多い可能性があります」
- **「端末が読み込んでいる分」だけを黙って出さない**

### 3.4 捨てたあとの結果

いまの結果の文に予告を足す。

```
札 115件・概念 42件・用語 18件・問い 3件・予告 5本を消しました。世代 4
```

### 3.5 押し間違えられない形

いまの「1 → 2 → 3」の並びは**変えない**。3 は 1・2 が済むまで押せない作りのまま。

## 4. 消えないための決まり

| 危険 | 対策 |
|---|---|
| 片側だけ消えて同期で復活 | 4か所を**1→2→3→4の順**に足す |
| 途中で止まって予告だけ残る | 予告の上書きは地層の後・月ファイルの前 |
| 実際より少ない本数を見せて捨てる | 全月を読み込んでから数える。読めない月があれば明記 |
| 朝から入って迷子になる | どこから入ったかを覚えて返す |
| 枠の配分で未読が止まる | 種類ごとの上限を決め、余りは他へ回す。合計20枚は超えない |
