# 仕様書：地図 直し②（効かせた線）

- 元：相談 `houkoku/2026-09-15_chizu_ugoki.md`、回答 `shiji/sekai_chizu_ugoki_kaitou.md`・`shiji/sekai_chizu_1_koukai_2.md`
- 前提：直し①（v20.57）で、地図は線が描ける札だけに出る（52枚）
- 版：v20.58（実装するかは、この仕様書を見て本人が決める）

## 0. 決まり

- 「誰が、誰に向けて、何を効かせたか」を、**チャットに札ごとに書かせる**。今の文から自動で拾わない（相談の実測：当たり15・誤り7・見落とし8）
- お金の線と効かせた線は、**色・先の形・手の言葉**の3つで分ける。**太さは変えない**
- 効かせた線は**枝の地図だけ**に出す（地図タブ・小さな地図・網には出さない）
- 点だけの地図は出さない（直し①のまま）
- 記録は捨てない（場所が決まらない相手・片方の回にしか出なかった組も、線にはしないが控えとして残す）

---

## 1. 朝の取り込みのプロンプトに足す欄

### 1.1 規則の節（幹の節の後ろに置く）

```
■ 効かせた相手（aims）
- 札ごとに、主体が「誰に向けて、何を効かせたか」を0〜2件書く。お金・物・人が動いていなくてよい（制裁・関税・攻撃・要求・合意・名指し・投票・訪問 など）。
- from と to は、国・国際機関・地域の名前（例：米国、ロシア、EU、国連安保理）。「第三国の銀行」「市場」「株主」のように場所が決まらない相手は書かない。
- how は、手を表す短い言葉1つ（10字まで）。
- 自分の国の中だけの手（利上げ・統計・保有高・自国の予算）は []。
- flow と同じ向きの同じ話は書かない。なぜ の背景に出てくるだけの国は書かない。
```

### 1.2 出力形式に足す行

- 札ごとの形式（follows・miki の後ろ）：`,"aims":[{"from":"...","to":"...","how":"..."}]`
- 形式の決まりの行：`効かせた相手が無いとき： "aims": []`

### 1.3 字数（実測。上の文をそのまま数えた）

| 足すもの | 字数 |
|---|---|
| 規則の節 | 285 |
| 札ごとの形式の行 | 50 |
| 形式の決まりの行 | 24 |
| **朝のプロンプトに足す合計** | **359** |
| 返事に増える字数（1件の例 `{"from":"米国","to":"ロシア","how":"制裁"}`） | 1件あたり約40字。1回の取り込み（札10枚前後、半分に1件と推測）で約200字 |

- 失うもの：朝のプロンプトが359字長くなる。チャットが背景の国を書く誤りは、規則で減らせても0にはならない（測れません）

### 1.4 取り込み

- 札ごとに aims を読む（0〜2件。3件目以降は控え）
- from・to の名前を、地図と同じ当て方で場所にする（国か、国際機関・地域の枠）
- 次のものは線にせず、控えに残して数える：
  - 場所が決まらない（from か to）
  - 両方が同じ国・同じ枠
  - how が空
  - 3件目以降
- 初期投入・問いから掘った札・候補から作った札には付けない（今の幹の欄と同じ）
- 結果の1行に足す：「効かせた線 N本（控え M件：場所が決まらない K・同じ国どうし L）」

## 2. 記録の置き場所

**調べた記録の月ファイルに、新しい並び `aims` を足す**（幹の記録 `miki` と同じ置き方）。
- 理由：札（world の月ファイル）の欄に足すと、古い版の端末が札を書き戻したときに知らない欄が消える。調べた記録の月ファイルの知らない並びは、v20.48 から残る
- 記録は一度書いたら変えない。札ごとに一番新しい記録を今の姿とする

| type | 中身 |
|---|---|
| `card` | card（札の番号）・aims（線にする組 0〜2：from・to・how・fromCode・toCode）・extra（控え：同じ形に理由 unknownPlace／same／noHow／over／oneRun）・src（import／fill）・batchId か fillId |
| `fill` | 埋めた回の記録：run（1・2）・order（asc／desc）・result（札ごとの返事そのもの）。2回分を2件 |
| `fillSum` | 比べた結果：札の数・2回とも同じ組の数・片方だけの組の数・揺れた札の数・fillId |

## 3. 今ある145枚を埋める（1回きり）

### 3.1 画面（設定 → 世界、幹の割り直しの下）

```
効かせた相手を埋める（今ある札 145枚・1回きり）
  1回目：［プロンプトをコピー］ 貼る欄 ［読む］
  2回目（並びを逆・別のチャットで）：［プロンプトをコピー］ 貼る欄 ［読む］
  比べた結果：2回とも同じ組 N ／ 片方だけ M（1回目だけ a・2回目だけ b）／ 揺れた札 K枚
    揺れた札の例 ▸
  ［この結果で入れる］
```

- 返事の無かった札があれば［返事の無かった札だけもう一度コピー］（割り直しと同じ）
- 途中の返事は端末に残す（割り直しと同じ。アプリを切り替えても消えない）
- 入れたあとは「埋めた（日付）：線 N本・控え M件」と出し、コピーのボタンは畳む
- 対象：まだ `card` の記録が無い札（朝の取り込みで欄が付いた札は除く）

### 3.2 プロンプト

```
あなたは、下に並ぶ出来事の札ごとに「誰が、誰に向けて、何を効かせたか」を書く係です。新しい出来事を探しません。web 検索も使いません。

■ 書き方
（1.1 の規則と同じ5行）
- 下の札は全部、aims に書く（無ければ []）。

■ 出力形式
{"aims":{"w_20260910_2":[{"from":"米国","to":"ロシア","how":"制裁"}],"w_20260911_1":[]}}
- JSON のみ。

■ 札（145枚）
[w_20260914_444584]　2026-09-14　米財務省がロシアのVTB銀行をイラン関連で制裁
  なぜ：…
  主体：米財務省（VTB銀行を大統領令13902に基づき制裁指定し、…）
  お金：…→…（動きがある札だけ）
```

- 字数（実測、本物の写し145枚）：**1回あたり 29,946字**（頭の説明 476字、札1枚あたり平均 203字）
  - なぜを60字・主体のしたことを40字までに切っても 27,982字で、ほとんど減らない（札の番号と何が起きたかが大半）ので、**切らない**
  - 割り直しの段B（139枚で約18,500字）より長い。返事が途中で切れたら、返事の無かった札だけをもう一度渡す
- 2回目は札の並びを逆にする（割り直しと同じ）
- 失うもの：チャットに約30,000字を2回貼る（1回きり）

### 3.3 比べ方

- 組は、**from と to を場所にした組**（例：USA>RUS、USA>INT）で比べる。名前の書き方（米国／米政権）や手の言葉の違いは、組が同じなら同じとみなす
- **2回とも同じ組 → 線にする**。from・to・how の書き方は1回目のもの
- **片方にしかない組 → 線にしない。控え（理由 oneRun、どちらの回か）に残す**
- 場所が決まらない・同じ国どうしなどは、1.4 と同じく控え
- 数えて出す：2回とも同じ組の数、片方だけの組の数（1回目だけ・2回目だけ）、揺れた札の数（2回で組の集まりが違う札）、揺れた札の例3枚
- 朝の取り込みは今までどおり1回（2回にしない）

## 4. 描き方（枝の地図）

### 4.1 効かせた線

| | お金・物・人の線（今のまま） | 効かせた線 |
|---|---|---|
| 色 | 緑（今の強調の色） | **橙**（新しい色を1つ足す） |
| 先の形 | 三角の矢印（約束は白抜き） | **「⊣」**（相手に押し当てる形） |
| 線 | 太さ＝ドル換算、点線＝物・人・換算できない、破線＝累計・期間、薄い＝約束 | **実線・太さ一定**（1.6px） |
| 言葉 | なし | 線の中ほどに **how**（例：制裁）。暗い下地の小さな字 |

- 両端が枠（国際機関・地域）なら、お金の線と同じく地図の下に枠の箱を置き、そこへ向かう
- 相手の国も、関わる国として少し明るく塗る
- 確度3以下の札は、効かせた線も描かない（お金の線と同じ決まり）。1行は出す

### 4.2 地図を出す札

- お金・物・人の線か、効かせた線が1本でも描ければ地図を出す（点だけの地図は出さない）
- 見込み：52枚 → 約75枚（動きの無い46枚のうち、1枚ずつ読んで線が引けると判定した23枚が戻ると推測。チャットが書くかは測れません）

### 4.3 お金の線と効かせた線が両方ある札

- 両方描く。同じ2つの場所の間なら、お金の線は今の向きに膨らませ、効かせた線は反対側へ膨らませる（重ならない）
- 下の1行を2行にする

```
お金：イラン → 中国　原油代金 …　約N億ドル（推定・ECB 9/1）
効かせた：米国 → 中国　制裁
```

- 効かせた線だけの札は「効かせた：…」の行だけ
- お金の線だけの札は、今のまま（「お金：」を付けない）
- 控えに残した組（場所が決まらない相手など）は、1行に「効かせた：米国 → 第三国の銀行　警告（場所が決まらない）」と出す（地図には描かない）
- 効かせた組が2件あれば2行（最大で3行）

## 5. 変えないもの

- 地図タブ・小さな地図・網・点検の一覧（効かせた線は出さない）
- お金の線の決まり・場所の当て方
- 読む回のプロンプト
- 幹の記録

## 6. ③（海峡などの場所の点）の見通し

②の次に、地図の部品に**海峡・運河などの「場所の点」を数か所足す**。候補は、ホルムズ海峡・バブエルマンデブ海峡・紅海・スエズ運河・マラッカ海峡・台湾海峡・黒海・パナマ運河の8つ（数は推測。今の145枚で文に出るのはホルムズ・紅海・バブエルマンデブ・スエズの4つ）。場所の点は国とも枠とも別の種類にし（国の塗りは無く、点の形を変える）、**効かせた線の相手にも、お金の線の両端にも使える**ようにする。効き方：効かせた線では「イラン → ホルムズ海峡：通航の管理」「フーシ派 → バブエルマンデブ海峡」が線になる（動きの無い46枚のうち3枚、145枚で文か主体のしたことに海峡が出るのは10枚）。お金の線では、場所の当て方の順（主体の国 → 名前の表 → 頭の国名 → 一般名 → 枠）のどこに入れるかで結果が変わる（例：「紅海のヤンブー港」は今は場所不明で、場所の点を頭の言葉に当てれば紅海になるが、本当はサウジの港）。そのため③では、**お金の線の当て方は変えず、場所の点に当たるのは名前が海峡・運河の名前と丸ごと一致したときだけ**から始め、今の52本の線が変わらないことを確かめる。幹「ホルムズが詰まる」「紅海の出口が握られる」の地図（地図の段2）は、③が入ってから作る方が中身が出る。

4. 描く：効かせた線だけの札・お金と効かせた線が両方の札（同じ組・違う組）・枠への効かせた線・確度3以下。色・⊣・言葉・膨らみの向き・2行の1行
