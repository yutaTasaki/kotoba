### 0.2 仕様にするとき解いたこと（確認の印つき。反対が無ければこのまま進める）

**確認1：候補の文は、今ある文をそのまま使う。朝の依頼文は変えない（段1）**
- 候補を「なぜ〜のか」の問いの形にするには、チャットに書かせる欄が要る。段1では足さない
- 今日見るべき件は「何が起きたか＋なぜ見るべきか」、ずれのある札は「何が起きたか＋ずれ」をそのまま出す
- 問いの形は、段2の語り方の依頼文で作らせる（選んだ1件だけなので、そこで丁寧に作れる）
- 失うもの：選ぶ画面の文が、問いの形より硬い

**確認2：「みんな同じことを言っていて面白くない」は、選ぶ前ではなく集めた後で見分ける**
- 選ぶ前に「語りが割れそうか」を当てさせると、朝の依頼文に規則が増えるうえ、当てずっぽうになる
- 代わりに、語り方の依頼文で**割れ方**（割れた・一部だけ・揃った）と**記事の芯になりそうか**を必ず返させる
- 揃っていても芯になる場合を、はっきり探させる
  - **みんなの語りと、お金・もの・人の動きがずれている**（「全員そう言うが、お金は逆に動いている」）
  - **みんなが書いていないことがある**（対立する国どうしが、同じ点に触れない）
  - **対立する国どうしが同じことを言う**（動かせない事実の印になる）
- どれも無ければ「芯になりにくい」と返し、画面に［選び直す］を出す。**その日の残りの候補から選び直せる**
- 失うもの：外れた日は1往復が無駄になり、選び直すともう1往復
- **試しの間は、候補の出どころ（今日見るべき件か・ずれか）ごとに割れ方を記録し、どちらが芯になりやすいかを数える**（段2を2週間使ったら報告）

**確認3：記録は「調べたこと」の月ファイルに相乗りする**
- 置き場所は `world/dig/YYYY-MM.json` に新しい並び `choices`（選んだ記録）と `katari`（語り方の記録）
- 調べたことの月ファイルは、v20.48 から「知らない並びでも id と日時があれば落とさず残す」作り。2台で版がずれても消えない
- 合わせ方は id ごとに足し合わせる（今の作りのまま）
- 失うもの：ファイル名が dig（掘った）なのに、中身がさらに増える

## 1. 段1：毎日選ぶ（v20.71）

### 1.1 候補

| 出どころ | 条件 | 出す文 |
|---|---|---|
| 今日見るべき件 | いちばん新しい記録（7日以内）。札が取り込まれなかった件は除く | 何が起きたか／なぜ：理由 |
| ずれのある札 | ずれが空でない。出来事の日付が14日以内 | 何が起きたか／ずれ：ずれの文 |

- 並べる数：**最大4つ＋「今日はなし」**。今日見るべき件から最大2、ずれから最大2。片方が足りなければ、もう片方で埋める
- ずれの中の順：出来事の新しい順
- 除くもの：**前に選んだ札・「芯になりにくい」と返った札**（同じものを毎日出さない）。「今日はなし」を押した日の候補は、次の日も出してよい
- 同じ札が両方に入るときは1つにまとめ、「今日見るべき件・ずれあり」と両方の印を付ける
- 候補が0なら、この枠ごと出さない

### 1.2 画面

世界の画面の一番上、「今日動いた幹」の上に：

```
今日、深く見るなら（1つ選ぶ）
 ┌───────────────────────────────
 │ ［ずれあり］メキシコが2027年のペメックス支援を811億ペソに縮小
 │   ずれ：2027年から自立すると言いながら、上半期だけで1,004億ペソを注入
 ├───────────────────────────────
 │ ［今日見るべき件］ホルムズ海峡を通る船が1日7隻に減った
 │   なぜ：…
 ├───────────────────────────────
 │ …
 └───────────────────────────────
  今日はなし
```

- 1つを押すと選んだことになる（押し直しの確認は出さない）
- 選んだ後の枠：

```
今日深く見る：メキシコが2027年のペメックス支援を811億ペソに縮小
［語り方を集める依頼文をコピー］［札を開く］［選び直す］
```

- ［語り方を集める依頼文をコピー］は段2で出る。段1では［札を開く］［選び直す］だけ
- ［選び直す］：今日の選んだ記録に「取り消した」の印を付け、候補に戻る
- 「今日はなし」を押した日：「今日は選ばない（戻す）」の1行だけ出す
- 日付が変わったら、新しい日の候補を出す。前の日に選んだものは、その札の画面に残る（1.4）

### 1.3 記録（`choices`）

| 欄 | 中身 |
|---|---|
| id | `ch_YYYYMMDD_` ＋ 乱数6桁 |
| date | 選んだ日（端末の日付） |
| at・updatedAt | 日時 |
| cardId | 選んだ札。「今日はなし」は空 |
| none | 「今日はなし」なら true |
| from | `today`・`zure`・両方なら `both` |
| shown | その時に並んでいた候補の札の番号（あとで「何を選ばなかったか」を数えるため） |
| fact・note | 選んだ時の文（札が後で直っても、選んだ時に何を見ていたかが残る） |
| canceled | ［選び直す］を押したら true（消さない） |

### 1.4 札の画面

選んだことのある札の上に、小さな1行「9/17 に深く見るものとして選んだ」を出す。

### 1.5 失うもの

- 世界の画面の一番上が1枠増える
- 毎日1回押す手間（押さなくても何も壊れない）

## 2. 段2：語り方を集める（v20.72）

### 2.1 流れ

1. 選んだ枠の［語り方を集める依頼文をコピー］
2. Claude のチャット（新しいチャット）に貼る。チャットが検索して JSON を返す
3. 選んだ枠の［語り方を戻す］の欄に貼って［取り込む］
4. 札の画面と選んだ枠に、立場ごとの表・割れ方・思惑の候補が出る

- 1日1往復増える（決まり7）
- 貼った文章は、取り込むまで端末の中に持っておく（調べたことを戻す欄と同じ。同期で描き直しても消えない）

### 2.2 依頼文の中身

**渡すもの**
- 札に元から書いてあったこと（調べたことを戻す依頼文と同じ組み立て：何が起きたか・なぜ・動かした側と述べた理由・推定・お金の動き・詳細・出典）
- ずれ（あれば）
- 仕組みの1行（札の premise）
- その札が付いている幹の名前と1行（あれば）
- 同じ主体の、ほかの札での読み（最大3つ・新しい順）

**頼むこと**

```
この出来事を、立場の違う媒体がどう語っているかを調べ、思惑を推測する材料にまとめてください。

■ 集める媒体
- 立場を最低3つ、できれば5つ。次の中から、この出来事に合うものを選ぶ。
  当事者の国／それと対立する国／第三国（近くの国・影響を受ける国）／国際機関・市場の専門媒体
- 当事者の国と対立する国は、できるだけその国の媒体（国営・政府寄りを含む）を探す。英語版があれば英語版でよい。
- 媒体ごとに、国と持ち主の種類（国営・政府寄り・民間・当事者本人）を書く。右寄り・左寄りは書かない。
- 開けなかった媒体は opened:false で残す。見出しと検索結果の要約しか読めなかったものは headlineOnly:true。
- 開けていないページの中身を想像で書かない。

■ 媒体ごとに書くこと
- 何を強調したか／何を書かなかったか／誰のせいにしたか（誰の手柄にしたか）／使った言葉（「制圧」と「解放」のような、立場が出る言葉）
- 言い分は必ず「誰がそう言ったか」を付ける。宣伝をそのまま事実として書かない。

■ 動き
- 語りとは別に、お金・もの・人が実際にどう動いたかを、出典つきで書く。語りの中の数字と、一次資料の数字を混ぜない。

■ 割れ方
- 割れた・一部だけ・揃った のどれかと、1文。
- 揃っていても、次のどれかがあれば芯になる。必ず探す。
  みんなの語りと、実際の動きがずれている／みんなが書いていないことがある／対立する立場どうしが同じことを言う

■ 思惑（推測）
- 主体ごとに1〜3件。1件1文。推測と分かる書き方にする。
- 根拠：どの語り・どの動きから読んだか。
- 崩れる条件：何が起きたら、この推測は外れていたことになるか（1文）。
- 裏づける条件：何が起きたら、この推測が強まるか（1文）。

■ 読者に残す
- 問い：記事の入口になる「なぜ〜のか」を1つ（40字以内）。
- 仕組み：この出来事で分かる、ほかの出来事にも使える仕組みを1文。
- 疑い：本人が「本当にそうか」と考えるための候補を3つ（1件1文）。

■ 芯になりそうか
- なる・なりにくい と、理由1文。なりにくいときは、何が足りないか。
```

- 最後に JSON の形（2.3）。「中身は架空、形だけ使う」の注意を付ける（調べたことの依頼文と同じ）
- 字数は実装で本物のデータから測って報告する

### 2.3 返す JSON と記録（`katari`）

```
{"eventId":"w_…",
 "media":[{"name":"","country":"","owner":"国営|政府寄り|民間|当事者","url":"","date":"",
           "opened":true,"headlineOnly":false,
           "stress":"","omit":"","blame":"","words":[""]}],
 "moves":[{"text":"","flow":{"from":"","to":"","what":"","amount":""},"source":"","url":""}],
 "split":{"kind":"割れた|一部だけ|揃った","line":"","core":"語りと動きのずれ|誰も書かないこと|対立どうしの一致|"},
 "omowaku":[{"actor":"","text":"","basis":"","breaks":"","backs":""}],
 "toi":"","shikumi":"","utagai":["","",""],
 "fit":{"ok":true,"why":""}}
```

- 記録には、上の中身に id・choiceId・eventId・at・updatedAt を足す
- 読めない欄は捨てずに数え、結果の1行に出す（調べたことを戻すときと同じ書き方：「長くて切った欄 N か所」「url の形が正しくない N件」など）
- 同じ中身の二度貼りは断る
- `fit.ok` が false：選んだ枠に「芯になりにくい：理由」と［選び直す］を出す（確認2）
- 札・地図・朝の依頼文には入れない（記録のファイルにだけ残す。調べたことと同じ決まり）

### 2.4 画面

札の画面の「調べたこと」の上に、語り方の欄：

```
語り方（9/17 に集めた・推測を含む）
問い：なぜメキシコは「自立する」と言いながら、注ぎ足すのか
割れ方：一部だけ ─ …
┌ 媒体 ─────── 国・持ち主 ── 強調 ── 書かなかった ── 誰のせい ┐
│ …                                                              │
└────────────────────────────────────────┘
動き：…（出典）
思惑（推測）
 ・メキシコ政府：… 　崩れる条件：… 　裏づける条件：…
仕組み：…
疑いの候補：① … ② … ③ …
```

- 表は phone 幅で横にはみ出す。表だけ横に動かせる枠に入れる（ページ全体は横に動かない）
- 開けなかった媒体は薄い字で「開けなかった」、見出しだけは「見出しだけ」
- 思惑の欄は推定の色（今の黄色）

### 2.5 失うもの

- 1日1往復（コピー → 貼る → 待つ → 貼り戻す）
- Pro の使用量：検索が多い依頼なので、1回が朝の取り込みに近い重さになる見込み（推測。2週間の使用量で報告）
- 対立する国の国営媒体の言い分が画面に並ぶ。必ず「誰が言ったか」付きで、事実の欄とは分けて出す

## 3. この後（仕様は段2を使ってから足す）

### 段3：疑う・答えの一文
- 語り方の「疑いの候補」3つから選ぶ＋自分の1行（空でもよい）
- 答えの一文（自分の仮説）を1つ書く
- ここで初めて「本人の視点」がデータに入る。記事の核になる

### 段4：続報
- 記録した思惑ごとに「崩れる条件・裏づける条件」を持っている（段2で返させる）
- 新しい札が来たら、同じ幹・同じ主体の思惑と照らし、関わる動きに印を付ける（照らすのはチャット。読む回に乗せるか、別の依頼文にするかは段2を使ってから決める）
- 印が2〜3回たまった日、または幹の答えが書き直された日に、毎日の候補に「続報」として出す
- 続報の出口：裏づけた・崩した・別の見方が出た

### その後：記事の束・どのように届けるか
- 選んだ1件＋語り方＋疑い＋答えの一文＋仕組み＋関わる札2〜4枚＋数字1つ、を記事の材料の束にする
- note への出し方（下書きまで自動か・どこから人が書くか・note に公式の投稿の口があるか）は、ここで相談する
