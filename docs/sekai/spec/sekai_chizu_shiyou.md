# 一万日 v20 仕様書 — 世界：お金の流れを地図で見る

回答書 `sekai_chizu_kaitousho.md` で確定した方針の仕様書です。**まだ実装していません。** 見てもらってから実装に入ります。

地図の部品・世界地図のデータ・換算レートの API は、2026-09-11 に実際に取って確かめました。Yuta さんの実データの数字は、回答書1章の内訳（お金つき13件：国をまたぐ4・国内6・場所が定まらない3）を使っています。

## 0. 全体の形

```
世界の画面の一番上：小さな地図（直近7日の線）……押すと大きな地図の画面へ（M5）
大きな地図の画面：直近90日の線。国の点を押すと、その国の網へ（M1・M4）
  線の太さ＝ドル換算（推定）の5段（M3）。物・人・換算できないものは細い点線
  地図の下に3つの枠：市場／国際機関／地域（場所の無い相手の置き場）
国の網：その国の主体を円に並べ、お金の動きを矢印で結ぶ（M4）
初期投入：地域ごとに4回のプロンプト。今の取り込みの形のまま（M2）
```

**段階と削る順**：M1 → M2 → M3 → M4 → M5。間に合わないときは M5 → M4 → M3 の順に削ります。**M1 と M2 は削りません**（国をまたぐ線は今4本しかなく、うち3本がウクライナ支援に集中しているため。回答書1章）。

**変わらない原則**：元の金額（`amount`）は書き換えない。ドル換算は推定として別の欄に持ち、線の太さにだけ使い、合計には使わない。データは追記のみ。url の無い値は取り込まない。中継サーバーを作らない。自動実行しない。

## 1. M1：主体に国を付け、大きな地図を描く（v20.0）

### 1.1 データ：主体に `country`

主体（`actors.json` の各主体）に1つ欄を足します。

```
country: 'JPN'    // 3文字の国コード（ISO 3166-1）
                  // または 'MKT'（市場）・'INT'（国際機関）・'REG'（地域・集まり）
                  // 空は「まだ分からない」
countrySetAt: ''  // 一度でも決めた印（周期の cadenceSetAt と同じ考え方。自分で直したものを既定で上書きしない）
```

### 1.2 国の付け方（上から順に当てる）

| 順 | 相手 | 付け方 |
|---|---|---|
| 1 | 種の主体21件 | 決まった表で付ける（下の表）。起動時、`countrySetAt` が空のものだけ |
| 2 | これから入る主体 | 取り込みのプロンプトの actors に `country` を足して、生成に書かせる（分からなければ空） |
| 3 | 国が空の既存の主体 | **別名の表（付録A）に載っている呼び名と、名前が丸ごと一致したときだけ**、その国。頭の一致では当てない（「中東の産油国」が「中」で中国に当たる、を防ぐ）。外れたら空のまま（指示書 sekai_chizu_jisso_shiji.md 2-B） |
| 4 | お金の出す側・受ける側が、主体ではなく国名そのもの（「米国」「カナダ」） | 同じく、別名の表と丸ごと一致したときだけ |
| 5 | どれにも当たらない | 「場所不明」。地図に出さず、地図の下に「場所不明 N件」と出して、押すと一覧。**間違った国に当てるより、空のままの方がよい** |

順3・順4は、表示のたびに当てるだけで、主体には書き込みません（書き込むのは、種の主体の表と、手で直したときだけ）。

**種の主体21件の割り当て**

| 国 | 主体 |
|---|---|
| JPN | 財務省・日本銀行・日本政府 |
| USA | FRB・米財務省・米政権・米議会 |
| CHN | 中国人民銀行・中国政府 |
| IRN・RUS・UKR・PRK | イラン政府・ロシア政府・ウクライナ政府・北朝鮮 |
| REG（地域：EU） | 欧州委員会・ECB |
| INT（国際機関） | IMF・BIS・WTO・NATO・国連・OPEC＋ |

**手で直す**：主体の詳細の画面に「国：日本（直す）」の1行を足します。押すと国名を打つ欄が開き、辞書で引いて決めます（`countrySetAt` を入れる）。

### 1.3 国の表（アプリの中に持つ）

- **番号と3文字コードの対応表**（250行）：世界地図のデータは国を数字の番号（日本は392）で持っているので、3文字コード（JPN）との対応が要ります。公開データ（i18n-iso-countries の codes.json）から作ります。
- **日本語の国名**：同じ公開データの日本語名を使います。ただし**正式名で入っている**ので（アメリカ合衆国・中華人民共和国・ロシア連邦・イラン・イスラム共和国）、**報道の呼び方の別名を手で足します**（米国・米・アメリカ／中国／ロシア／イラン／英国・イギリス／韓国／北朝鮮／台湾／ドイツ・独／フランス・仏 など40ほど）。
- 合わせて約18KB。`assets/world_countries.json` に置きます。
- 揉めている境界・国名（台湾・コソボ・西サハラなど）は、**世界地図のデータの形のまま使い、名前は中立に書きます**（回答書 10章-8）。

### 1.4 場所の無い相手の置き場

地図の下に、3つの枠を固定で置きます（本部の場所には置かない）。

| 枠 | 入るもの |
|---|---|
| 市場（MKT） | 為替市場・金市場・世界の石油市場・国債の保有者 など |
| 国際機関（INT） | IMF・世界銀行・BIS・WTO・NATO・国連・OPEC＋ |
| 地域（REG） | EU（欧州委員会・ECB）・「欧州の同盟国とカナダ」・「中東の産油国」などの国の集まり |

市場・国際機関・地域の判定は、1.2 の表と、付録B の名前の決め方で決めます。当たらなければ「場所不明」です（例：「TSMC → 先端工程と海外工場」の受ける側。指示書 1-1 のとおり、M1 では from／to に国を書かせない）。

- **EU は「地域」の枠**（指示書 1-2。ブリュッセルの点に置くとベルギーの動きと混ざるため）。
- **「欧州の同盟国とカナダ」などの国の集まりも「地域」の枠**（指示書 1-3）。

### 1.5 地図の部品（リポジトリに置く）

| ファイル | 大きさ | 転送 |
|---|---|---|
| `assets/d3-geo.min.js`（d3-geo 3） | 36KB | 13KB |
| `assets/d3-array.min.js`（d3-array 3。d3-geo が中で使う） | 17KB | 6KB |
| `assets/topojson-client.min.js`（topojson-client 3） | 7KB | 2.6KB |
| `assets/countries-110m.json`（world-atlas 2 の粗い版。177か国） | 108KB | 39KB |
| `assets/world_countries.json`（1.3 の国の表） | 約18KB | 約7KB |

- **地図の画面を初めて開いたときに読みます**（筋肉の画面で three.js を読むのと同じ形）。アプリと同じ場所から来るので、アプリが開けるなら地図も開けます。
- 版は固定し、ファイルの頭に「どこの何版か」を1行書きます。

### 1.6 国の点（押す場所）の置き方

実際に全177か国で計算しました。
- 国全体の重心を使うと、13か国の点が国の外に落ちます（日本・フランス・ノルウェー・インドネシアなど）。
- **いちばん大きな島（多角形）の重心**を使うと、9か国は直ります。
- **それでも4か国は外に落ちます：イスラエル・ベトナム・クロアチア・ハイチ**（細長い・曲がった形）。これらは手で位置（経度・緯度）を持ちます。**イスラエルは実データの動き（米政権 → イスラエル政府）の行き先**なので、必ず直します。
- **粗い版の地図に無い小さな場所は、点だけを足します**（手で位置を持つ表）：シンガポール・香港・マカオ・ケイマン諸島・バミューダ・バーレーン・マルタ・ジャージー・ガーンジー・モーリシャス・リヒテンシュタイン・モナコ。

### 1.7 大きな地図の画面

- 世界の画面に、新しい画面（`view: 'map'`）を1つ足します。M5 までは、世界の画面の「お金の流れ」の見出しの横の「地図」から入ります。
- **図法**：Equal Earth（面積が正しく、形の歪みが小さい）。幅360なら高さは **178px** です（実測）。
- **地域に寄せるボタン**：全体・米州・欧州・中東・アジア。押すとその地域に合わせて拡大します。指でつまむ拡大は作りません。
- **点を押す**：押した所から22px以内にある一番近い国の点を選びます。**欧州の点どうしは、全体の地図で1.5px、「欧州」に寄せても7.2px しか離れていません**（ベルギーとルクセンブルク、実測）。指では押し分けられないので、**22px以内に国が2つ以上あるときは、「この辺りの国」を短い一覧で出して選ばせます**。
- **描く期間**：直近90日（回答書 10章-4）。端末に読み込んでいない月があれば、開いたときに読み込みます。
- **描く動き**：
  - 両端の国が決まった動きだけを線にします。同じ国の中の動きは線にせず、点の横に「国内 N件」と出します。
  - 確度3以下は出しません（既定の画面と同じ）。
  - v19.15 のまとめ方（同じ動きは1本）を先に当てます。
- **線**：
  - 出す側の点から受ける側の点へ、少し曲げた線を引き、受ける側に矢印を付けます。
  - 場所の無い相手は、下の3つの枠へ線を引きます。
  - M1 では太さは固定です（M3 で5段にする）。
  - 物・人の動きは細い点線（回答書 10章-5）。累計（span がある）は破線。
  - **同じ国の組に何本もあるときは、足さずに少しずつずらして並べます。太い順に5本まで描き、6本目からは「ほか◯本」と添えます**（回答書 10章-3）。
- **線を押す**：その動きの札へ行きます。まとめた行（2つの出典）なら、2枚を並べて出します。
- **場所不明**：地図の下に「場所不明 N件」。押すと、その動きの一覧を出します。

### 1.8 あわせて入れる直し（回答書4章）

**鎖に出すのは、まとめた後に2件以上ある塊だけにします。** 1件になった塊（今の「米国を中心に 1件」「金市場を中心に 1件」）は、「お金の動き（単発）」へ回します。

- **気をつける点**：いまの単発は「お金」の動きだけを並べています。報復関税・金の買い入れは［物］なので、そのまま回すと既定の画面から消えます。**鎖から回ってきたものは、物・人でも単発に出します**（［物］の印つき）。
- 鎖の本数は「2件以上の塊」の数になるので、9/18 の見直しの判断に使えます。

## 2. M2：初期投入（v20.1）

### 2.1 形
- **新しい取り込みの仕組みは作りません。** 今の取り込みの関数（`{"events":[…]}`）をそのまま通します。url の無い札・重複・未来の日付は、今までどおり落ちます。
- 取り込む画面に「初期投入」の欄を足し、地域ごとに4つの「プロンプトをコピー」を置きます：**米州／欧州・ロシア／中東・アフリカ／アジア・太平洋**。
- 返ってくる JSON の一番上に `"seed": "americas"` のような地域の印を書かせます。**取り込みは、この印がある JSON の札に `seed` を付けます。** コピーしたボタンを端末に覚えておく作りにしないのは、初期投入のプロンプトをコピーした後に、毎朝の JSON を貼る取り違えが起きうるためです。

### 2.2 プロンプトの中身
- **集めるもの**：直近90日に、国をまたいで大きなお金が動いた出来事。1回に12件まで。
- **主体**：政府・中央銀行・財務省・政府系ファンド・大企業・集まり。**個人は、公職として動いた人だけ**（私人は入れない）。
- **国**：主体に `country`（3文字コード）を必ず付けさせる。市場・国際機関・地域は MKT・INT・REG。
- それ以外の規則（探し方・確度・wants・追えた割合・下限の規則）は、毎朝のプロンプトと同じ文を使います。
- **字数**：毎朝のプロンプトから「今日の数字」「毎回必ず見るもの」「よく使う出典」を外すので、短くなる見込みです。**実装のときに4本とも測り、12,000字以内に収めます。**

### 2.3 初期投入の札の扱い（`seed`）
- `seed` の札は、**未読にも「今日読んだ札」にも数えません**（朝の一覧を埋めないため）。
- 地図・お金の一覧・探す・鎖には出します。
- 「最近のお金の動き」（毎朝のプロンプトの末尾30件）にも入れます。鎖づくりの材料が増えるのは狙いどおりです（回答書 10章-10）。
- どの地域をいつ流したかは、`world/index.json` に `seeds: { americas: '2026-09-12', … }` として残します（ソースごとの `pulls` と同じ合わせ方）。取り込む画面に「米州 9/12 済」のように出します。

## 3. M3：ドル換算と線の太さ（v20.2）

### 3.1 金額を読む
**いまの金額を読む関数は、英語の書き方を読めません**（実測）。

| 書き方 | いまの関数 |
|---|---|
| 276億ドル・15兆3993億円・7000億元 | 読める |
| €70 billion・EUR 90 billion・$3.3 billion・£12 billion・CNY 50 billion | **読めない** |
| 3,500百万ドル・100億ドル超 | **読めない** |

国をまたぐ4本のうち3本（ウクライナ支援の2本と、米政権 → イスラエル政府）が英語の書き方です。**このままでは太さがほとんど付きません。**

- **ドル換算の専用の読み方を足します**（`worldParseMoney`）。今の関数はお金の一覧の通貨分けで使っているので、変えずに残します。
- 読むもの：
  - 通貨の記号と3文字コード（$・€・£・¥・USD・EUR・GBP・JPY・CNY・RMB・CAD・CHF・KRW・INR・RUB・SAR など）
  - 英語の桁（thousand・million・billion・trillion、k・m・bn・tn）と日本語の桁（万・億・兆・百万）
  - 「超」「以上」「約」「over」「more than」は、読めるが**「以上」の印**を付けます。太さには使い、画面では「100億ドル超（推定）」と元の書き方を添えます。
- 読めないもの（オンス・バレル・トン・人）は、換算しません。

### 3.2 換算（端末がやる）
- **ECB の参照レート**（毎日・鍵なし・ブラウザから直接）で、動きの日（`eventDate`）の値を使います。その日が無ければ、7日前まで遡って一番近い日の値を使います。**円 → ドルは、ユーロを挟んで割ります**（9/10：179.09 ÷ 1.1616 ＝ 1ドル 154.2円）。
- ECB に無い通貨は、**米財務省の為替レート**（四半期ごと・約170通貨）の、動きの日以前で一番近い四半期末の値を使います。
- どちらにも無ければ換算しません（細い点線）。
- レートは端末に覚えておき（日付と通貨ごと）、同じ日のレートを何度も取りに行きません。

### 3.3 持ち方（札に保存する。回答書3章）
```
usd: { value: 3300000000, approx: false,
       rate: 1, rateDate: '2026-09-08', source: 'ECB 参照レート',
       url: 'https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html',
       by: '端末', at: '2026-09-12' }
```
- 元の金額（`amount`）は書き換えません。
- **換算するのは端末だけ**です。生成には書かせません。生成が書いた `usd` があっても、取り込みで捨てます。
- 米財務省のレートを使ったときの `url` は `https://fiscaldata.treasury.gov/datasets/treasury-reporting-rates-exchange/treasury-reporting-rates-of-exchange`（開けることを確かめた）。
- **過去の札も、地図を開いたときに端末が埋めます**（`usd` が無く、換算できる札だけ）。埋めたら札を保存して同期します。
- **換算したら、地図の下に1行出します**（指示書 2-A。黙って書き換えないため）：「12件を換算しました（ECB 9/10）」。換算できなかった札がある日は、その数も添えます：「12件を換算しました／6件は換算できません（オンス・バレル・人）」。ボタンは足しません。換算する札が0件の日は、この行を出しません。
- 画面では「約◯億ドル（推定・ECB 9/10）」とだけ出し、**合計には使いません**。

### 3.4 太さ（対数の5段。回答書のとおり）

| 段 | ドル換算（推定） | 太さ |
|---|---|---|
| 1 | 1億ドル未満 | 1px |
| 2 | 1〜10億ドル | 2px |
| 3 | 10〜100億ドル | 3.5px |
| 4 | 100〜1,000億ドル | 5px |
| 5 | 1,000億ドル以上 | 7px |

- 追えた割合（total・share）がある動きは、`amount`（行き先が分かった額）で決めます（回答書 10章-6）。
- 地図の隅に、5段の見本を小さく出します。

## 4. M4：国の網（v20.3）

- 大きな地図で国の点を押すと、その国の網の画面（`view: 'countryNet'`）が開きます。
- **点**：その国の主体のうち、直近90日のお金の動きに出たもの。**円の上に等間隔**で並べます。並び順は名前順で固定なので、毎回同じ場所に出ます。
- **矢印**：その国の中のお金の動き（出す側 → 受ける側）。太さは M3 の5段、物・人は点線です。
- **共起は描きません**（回答書 2章-6：矢印＝お金だけ）。
- **国の外への動き**：円の外側に「→ カナダ」「← 米国」「→ 市場」のような札を置き、矢印を向けます。国の札を押すと、その国の網へ移ります。
- 主体の点を押すと、主体の詳細へ行きます。矢印を押すと、その札へ行きます（2つの出典なら2枚）。
- 言葉の網の画面（`screen-graph`）の「拡大縮小と、押すと札が出る」作りを流用します。

## 5. M5：世界の画面の一番上に小さな地図（v20.4）

- 世界の画面の一番上（地層の1行の上）に、高さ178px の小さな地図を置きます。
- 描くのは、**直近7日の線だけ**です。国の点は押せません（押すと大きな地図へ）。
- 地図の部品が読めなかったとき（初めて開いた日にネットが無い等）は、小さな地図の場所に1行だけ出します。「地図を読み込めませんでした（理由）。お金の流れは下の一覧で見られます」
- その下は今のまま：お金の鎖 → お金の動き（単発）→ 今日動いた主体 → 背景の札 → 探す。
- 切替（タブ）にはしません。朝の画面は変えません。

## 7. 確かめ方

**M1**
1. 種の主体21件に 1.2 の表どおり国が付くこと。自分で直した国を、起動しても上書きしないこと。
2. 実データの13件と同じ形の札を localhost に入れ、次のとおりに分かれること。
   - 国をまたぐ4本が線になる。
