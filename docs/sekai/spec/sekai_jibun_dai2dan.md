## 0. 第2段で何ができるようになるか

1. お金の動きに**使い道の印**が付く：**設備／自社株／注入／買収／投資**の5つ
2. 地図の種類の絞りに「**自分に使う（N）**」が増える
3. お金の一覧を、使い道で絞れる。絞った一覧には**期間**と「**計画らしい／区別なし**」が必ず出る。**合計はしない**
4. 使い道が決まらなかった候補を、件数つきで出す
5. 「件数を必ず出す」「0件なら押せない」を守る**共通の道具**を作り、この段で触る所から使う

**札のデータは変えない。** 使い道も計画らしさも、描くときに毎回決める（「原油・石油」の絞りと同じやり方）。

## 1. 使い道の印

### 1.1 判定の表（1か所にまとめる）

上から順に当て、**最初に当たった1つ**をその動きの使い道にする。種類が「お金」の動きだけが対象。

| 順 | 使い道 | 見る所 | 言葉 |
|---|---|---|---|
| 1 | 設備 | 何の支払いか＋見出し | 設備投資・有形固定資産・property and equipment・設備増強 |
| 2 | 自社株 | 何の支払いか＋見出し | 自社株・自己株式 |
| 3 | 注入 | 何の支払いか＋見出し | 資本注入・資本を補う |
| 4 | 買収 | 何の支払いか＋見出し | 買収 |
| 5 | 投資 | **何の支払いかだけ** | 投資・出資（ただし 1.2 の言葉を除いてから当てる） |

- 「設備投資」は1で設備になり、5の投資には来ない
- **「投資だけ外す」は、この表から5の行を消すだけ**でできる形にする。絞りのボタンも一覧の印も、この表から作る

### 1.2 「投資」「出資」の広がりの見込み（回答書の問いへの答え）

**実測（全期間の札121枚）：**

- 判定に使う範囲（お金の動きの「何の支払いか」）で当たるのは**5本**。別の意味への誤りは**0本**
- ただし札の**本文**には、「投資信託」（3回）、「海外投資家」「債券投資家」「投資家に信じ…」などが出ている。**見出しや本文まで見ると、これらに当たる**
- 「投資家」は、お金の動きの**相手の名前**にも2本出ている（海外投資家 → 国債市場、国内外の債券投資家 → サウジ政府）
- 「投資|出資」を含む札は、月ごとに 6月2枚・7月4枚・8月7枚・9月5枚（13日まで）

**だから：**

- 投資だけは、**何の支払いかの欄だけ**を見る（見出し・本文・相手の名前は見ない）
- 当てる前に「**投資家・投資信託・投資適格・投資銀行・投資顧問・投資収益・投資判断**」を取り除く
- この先の見込みは**測れません**。今の割合（90日で5本／お金の動き63本）のままなら月2本前後だが、札の集め方で変わる。広がりすぎたかは、2.2 の件数と一覧で見て判断する

**失うもの：** 見出しにだけ「投資」とある動き（何の支払いかの欄が「融資」「支払い」など）は拾わない。今のデータには無い。

## 2. 使い道が決まらなかった候補

### 2.1 何を候補にするか

種類が「お金」で、**使い道の表のどれにも当たらず**、何の支払いか・相手の名前に次の言葉があるもの。

取得・増資・設備・工場・株主・資本・投資・出資

- 今のデータでは**0本**（前回の5本は「投資」として入った）

### 2.2 出す所

お金の一覧で「自分に使う」を選んだとき、一覧の一番下に：

```
使い道が決まらなかった候補 0本
```

- **0本でも行は出す**（押せない形）。1本以上なら押すと一覧が開く
- 回答書のとおり、これは「新しい言い方が来て黙って落ちる」ことへの手当て。**候補の言葉にも当たらない言い方は、やはり黙って落ちる**（完全には防げない）

## 3. 地図の絞り「自分に使う」

### 3.1 ボタン

種類の絞りの並びの最後に足す：`全部（N）お金（N）物・人（N）原油・石油（N）約束（N）自分に使う（N）`

- 件数の数え方は今の絞りと同じ（**いま選んでいる地域で**、線と国内を数える）。今のデータで**19**
- 0件なら押せない。選んでいる間に0件になったら「全部」に戻す（今の決まりのまま）

### 3.2 押したとき

- 自分に使う動きの線と国内だけを描く（今の絞りと同じ仕組み）
- 地図の下の数字の行に、次を足す：

```
自分に使う 20本のうち、場所不明で描けないもの 1本
```

「1本」は押すと一覧が開く。0本なら出さない。**ボタンの19と、全部の20が合わない理由をここで見せる**

### 3.3 根との関係

第2段では**根は描かない**。「自分に使う」を押すと横の線で描かれる。根に替えるのは第3段。

## 4. お金の一覧の絞り

### 4.1 並び

お金の一覧（探す欄の下）に、件数つきのボタンを1列：

```
全部（N）自分に使う（N）設備（N）自社株（N）注入（N）買収（N）投資（N）
```

- 件数は**端末に読み込んでいる月の札**で数える。一覧の上に「読み込んでいる月：N か月」と出す（地図は90日、一覧は読み込んだ月、と対象が違うため。数字が地図と合わない理由を見せる）
- 件数は、今の一覧と同じく**同じ動きを1行にまとめた後の行数**で数える
- 今のデータ（全期間）では自分に使う**21枚**（設備7・自社株5・注入3・買収1・投資5）、まとめた後は**20行**（トヨタの同じ日の2枚が1行になる）
- 0件のボタンは押せない
- 「買収だけ外す」「投資だけ外す」は、個別のボタンを選べば見分けられる

### 4.2 絞った一覧の行

今のお金の一覧の行（日付・金額・何の支払いか・ドル換算）に、次を**必ず**足す。

| 足すもの | 出し方 | 今のデータ |
|---|---|---|
| 使い道 | 「設備」などの小さな印 | 20行すべて |
| 期間 | 「期間：2026年4〜6月期」。無ければ「**期間なし**」 | 期間なし 5行 |
| 計画らしさ | 「**計画らしい**」か「**区別なし**」。「実績」とは書かない | 計画らしい 9行・区別なし 11行 |

- **期間は必ず出す。** 回答書の「1年と半年を同じ太さで読む」危険への補い
- 今の一覧は期間を「（〜の累計）」と出しているが、「2026年（計画）」のようなものまで累計と読めてしまう。**絞った一覧では「期間：」の書き方に揃える**（絞っていない一覧は今のまま）

### 4.3 計画らしさの見分け方

見出しと何の支払いかに、次のどれかがあれば「計画らしい」。生成が約束の印を付けていても「計画らしい」。

今の約束の言葉（配分・表明・約束・誓約・コミット・拠出を決め・支援を決め・計画を発表）＋ **上限・枠・決定・決めた・合意・予定・へ引き上げ・残している**

- **地図の「約束」の見分け方は変えない**（変えると約束の線が3本→17本になるため）。足した言葉は一覧の「計画らしい」にだけ使う
- 今のデータで「計画らしい」は9行。読んで確かめた範囲で、実績を計画と誤ったものは無い
- 読むと計画なのに「区別なし」になるもの：メキシコの「2027年のペメックス支援を縮小」など。「区別なし」は「実績」という意味ではない

### 4.4 合計しない

一覧の下の「合計は出しません」の注意書きは今のまま。絞っても合計・積み上げは出さない。

## 5. 共通の道具

### 5.1 件数つきの絞りボタン

- 受け取るもの：名前・件数・選んでいるか・押したときの動き
- **件数が無ければ作れない形にする**（件数を渡し忘れると、画面に「件数がありません」と出して押せないボタンにする。黙って件数なしのボタンを出さない）
- 件数0なら押せない
- 見た目は今の絞りボタンと同じ

### 5.2 一覧の行

- お金の一覧の1行（日付・金額・何の支払いか・ドル換算・期間・印）を作る道具
- 4.2 の「期間」「計画らしさ」「使い道」を出すかどうかを受け取る

### 5.3 使い始める所（この段で触る所だけ）

| 場所 | 道具 |
|---|---|
| 地図の種類の絞り（今の5つ＋自分に使う） | 件数つきの絞りボタン |
| お金の一覧の使い道の絞り（新しい） | 件数つきの絞りボタン |
| お金の一覧の行 | 一覧の行 |

**触らない所：** 地図の地域の絞り（全体・米州・欧州・中東・アジア）。**このボタンには今、件数が出ていない。** 回答書の「数字が見えないボタンは押しません」に反するので、別の段で件数を出すことを勧める（この段には入れない）。

**失うもの：** 同じファイルの中に、道具を使う書き方と今の書き方がしばらく並ぶ。

## 6. 消えないための決まり

| 危険 | 対策 |
|---|---|
| 使い道を札に書き込み、同期や整え直しで消える | **書き込まない。** 描くたびに決める |
| 新しい言い方が黙って落ちる | 候補の件数を、0本でも必ず出す |
| 「区別なし」を実績と読む | 「実績」とは書かない。「区別なし」と書く |
| 期間の違う額を同じに読む | 絞った一覧には期間を必ず出す。無ければ「期間なし」 |
| 地図と一覧の数が合わず、どちらかが間違って見える | 地図は「場所不明で描けないもの」、一覧は「読み込んでいる月」を出して、合わない理由を見せる |
| 件数なしのボタンが紛れ込む | 道具が件数を受け取らないと押せない形にする |
