- 段1だけ。段2（幹の地図）・段3（地図タブを奥へ）は、段1を公開して実機で確かめたあとに相談する
- 版：v20.56

## 0. 決まり

- 基準は「読む助けになるか」。見ごたえでは決めない
- 地図は押す物にしない（押しても何も起きない物を増やさない。指でなぞればページが動く）
- 空の枠を置かない。描く物が無ければ、枠ごと出さない
- データの欄とプロンプトは変えない（ドル換算を動かす時を足すだけ）
- 地図タブ（大きな地図・網・点検の一覧）は変えない

---

## 1. 置く場所と中身

札の画面（枝・葉・根はどれも同じ画面）の **「なぜ」の文のすぐ下、「動かした側」の前** に、上から次の2つを置く。

1. **その札の地図**（2章。描く物が無ければ出さない）
2. **誰から誰への1行**（3章。札に動きがあれば、地図が描けなくても出す）

```
9/8  米国が9月29日からカナダ産の酒と乳製品の輸入を禁止
幹：関税で相手の制度を動かす ▸
カナダが276億カナダドル分の報復関税を発動した当日に、…（なぜ）
┌───────────────────────────┐
│   （世界地図。カナダ → 米国 の線1本）      │
└───────────────────────────┘
カナダ → 米国　酒・乳製品 500億ドル
動かした側
…
```

- 札を1枚だけ描く。同じ幹のほかの枝は重ねない
- 前の動き（その札に記録された続きの前の札）も、段1では重ねない（相談の「足すなら」は段1に入れない。まず1枚で読む助けになるかを見る）

## 2. その札の地図

### 2.1 何を描くか（札1枚。期間の制限なし）

場所の決め方は、地図タブと同じ手順（両端の名前から国・枠を当てる／外国の持ち主への支払いを市場に寄せる／国の呼び名が2つ以上の名前は決めない）。

| 札の動き | 地図 | 地図の下の1行の後ろに添える理由 |
|---|---|---|
| 国 → 別の国 | 線1本（矢印つき） | なし |
| 国 → 枠（市場・国際機関・地域）、枠 → 国 | 線1本。地図の下に、その枠の箱だけを置いて、そこへ向かう | なし |
| 枠 → 別の枠 | 2つの枠の箱と、その間の線 | なし |
| 同じ枠どうし（市場 → 市場） | 枠の箱1つ（線なし） | 「（市場の中の動き）」 |
| 同じ国どうし | その国の点1つと「国内」の文字 | 「（国の中の動き）」 |
| 片方の場所だけ分かる | 分かる側の点（国なら国、枠なら枠の箱） | 「（相手の場所が決まらない：名前）」 |
| 両方とも場所が決まらない | 主体の国の点（2.3）。それも無ければ地図を出さない | 「（場所が決まらない）」 |
| 確度3以下 | 線は描かず、分かる場所の点（国・枠の箱） | 「（確度3以下なので線にしていません）」 |
| 動きが書かれていない | 主体の国の点（2.3）。それも無ければ地図を出さない | 3章の「動きなし」の1行 |

- 線の見分けは地図タブと同じ：太さ＝ドル換算の5段、点線＝物・人・換算できないもの、破線＝累計・期間あたり、薄い線＋白抜きの矢印＝約束
- **杭**：その動きが自分に使う金（設備・自社株・注入・買収・投資。地図タブと同じ見分け）なら、出す側の国の点の下に杭を描く（太さはドル換算の段、長さは地図タブと同じ）。線があれば線も描く
- 関わる国（点・線の両端）は、地図タブと同じく少し明るく塗る
- 国の名前は地図の上に書かない（誰から誰へは3章の1行で読む）

### 2.2 形と大きさ

- 世界全体（地図タブの「全体」と同じ図法）。幅は札の画面の幅いっぱい、高さは幅に合わせる（幅358なら約175px。推測）
- 枠の箱が要る札だけ、地図の下に高さ28pxの帯を足し、要る枠の箱だけ置く（地図タブのように3つ並べない）
- 拡大・押す・選ぶ はしない。指でなぞればページが動く
- 地図と「なぜ」の文の間、地図と下の1行の間は、ほかの欄の間と同じ空き

### 2.3 主体の国

動きが書かれていない札・場所が決まらない札は、「動かした側」の名前を地図タブと同じ当て方で国にし、国に当たったものを点で描く（最大3か国）。
- 点の意味は線と違う（起きた場所とは限らない）ので、1行に「点は主体の国」と添える（3章）

### 2.4 国の形の使い回し（**必須**）

相談の実測（PC）：開くたびに国の形を作り直すと、札を1枚開く時間が 4.9ms → 48ms（約10倍）。覚えれば 6.8ms。

- 国の形（177か国の輪郭）は、**幅ごとに1回だけ作り**、端末のメモリに覚える（アプリを閉じれば消える。保存はしない）
- 2回目からは、覚えた形を複製して置き、関わる国の塗りだけ変え、線・点・杭だけを描く
- 覚えるのは直近2つの幅まで（iPhone の縦・横など）
- 地図の部品（世界地図の形・国の表）の読み込みは、今の地図タブ・小さな地図と同じもの（そのタブで1回）

### 2.5 描く順番

- 札の中身の文字を先に出し、地図は後から入れる（部品の読み込みを待たない）
- 地図の高さの分は、はじめから空けておく（後から入って文がずれない）
- 読み込めなかったときは、地図の場所に「地図を読み込めませんでした」の1行（小さい字）。誰から誰への1行はそのまま出す
- 開いたまま別の札を開いたら、前の札の地図は描かない（取り消す）

## 3. 誰から誰への1行

札に動き（flow）があれば、**地図が描けても描けなくても**出す。

```
［物］ロシア → インド　原油　日量210万バレル
カナダ → 米国　酒・乳製品 500億ドル
欧州委員会 → ウクライナ政府　30億ユーロ　約34億ドル（推定・ECB 6/25）（国の中の動き）
```

- 中身は、今「詳しく」の中にある「お金の動き：…」の行と同じ（物・人の印、出す側 → 受け取る側、何、額、期間、ドル換算）。自分で作った札の「自分で入力」の注も同じ
- 後ろに 2.1 の理由を添える
- 動きが書かれていない札は、主体の国を点で描いたときだけ「誰から誰へは書かれていません（点は主体の国）」の1行。点も無ければ何も出さない
- **「詳しく」の中の同じ行は外す**（二重に出さない）
- **「動かした側」の下のドル換算の1行（「30億ユーロ ≒ 約34億ドル…」）も外す**（この1行に入るので二重になる）

## 4. ドル換算を動かす時を足す

いま換算（レートを取りに行き、札に書き込む）は、地図タブを開いたときにしか動かない。段1で次の時にも動かす。

- **朝の取り込み・候補から札を作ったあと**（札が1枚以上入ったとき）。裏で動かし、終わって換算した札があれば、開いている世界の画面を描き直す
- 札を開くたびには動かさない（開くたびに通信しない）
- 地図タブを開いたときの今の動きは変えない
- 通信できなかったときは何も出さない（次に取り込んだとき、または地図タブを開いたときにもう一度）

失うもの：取り込みのたびに ECB・米財務省へ通信する（換算の要る札があるときだけ。今は地図タブを開いたときにまとめて取っている）。

## 5. 変えないもの

- 地図タブ・小さな地図・網・点検の一覧
- 札の画面のほかの欄の並び（「なぜ」の下に2つ入るだけ）
- 札のデータ（ドル換算の書き込みは今と同じ欄）

## 6. 確かめ

### 手元（試しのページ・本物のデータの写し）

1. 実データの分類ごとに1枚ずつ開く：国→国／国→枠／枠→枠／同じ枠／国内／片方だけ／場所不明／確度3以下／動きなし（主体の国あり・なし）／杭／約束／物・人。地図と1行と理由が 2.1・3 のとおり。空の枠が出ない
2. 145枚すべてを中から開き、ページのエラー0、地図の有無の数が相談の実測（線52・国の点84・何も出さない9）と合う
3. 重さ：同じ幅で10枚続けて開いたときの1枚あたりの時間（覚えた後）、1枚目（覚える前）
4. 「詳しく」の中と「動かした側」の下に、同じ行が二重に出ていない
5. 朝の取り込みのあと、換算が動く（偽のレートで）。通信できないときに何も出ない
6. 狭い幅で見た目

### 公開の前に実機で確かめてほしいこと（触ると壊れる形を先に）

1. **iPhone で、幹の画面の枝の一覧から、枝を次々に開いたときに引っかからないか**（手元では iPhone の重さを測れていない）
2. **「なぜ」の文と地図の間が空きすぎないか**。地図が入って、読む流れが途切れないか（下へ流す量が 150〜240px 増える見込み）
3. 地図を指でなぞってページが動く（地図が指を取らない）
4. 誰から誰への1行が読める。「詳しく」の中に同じ行が残っていない
5. 朝の取り込みのあと、新しい札の1行にドル換算が付く（地図タブを開かなくても）
