## 1. 朝の取り込みのプロンプト

### 1.1 足す節

「■ 並べ方」の後、「■ 出力形式」の前に：

```
■ 今日見るべき件（today）
この JSON の出来事のうち、金融や世界情勢に詳しくない人が、今日まず見るべきものを 0〜3件選ぶ。
見るべきものが無い日は空の配列にする。数を合わせるために選ばない。
- ref：選んだ出来事の番号。"#番号"（上から1、2…と数える）。
- type：なぜ見るべきかの型。次のどれか。
    詰まり（運ぶ道・生産・在庫が詰まっている）
    逃げ（危ないものから安全なものへお金が移っている）
    囲い込み（国や陣営が、取引や供給網を分けている）
    無理（借金・利上げ・介入など、お金の限界に近づいている）
    つぎ込み（戦争や大きな投資に、先に大きくお金を張っている）
  どれにも当たらなければ、10字以内の自分の言葉で書く。
- why：なぜ今日これを見るべきかを1文・60字以内。専門用語を使わない。
```

出力形式の例に足す（`events` の後、`checked` の前）：

```
"today":[{"ref":"#1","type":"詰まり","why":"…"}],
```

末尾の決まりの行に足す：

```
今日見るべきものが無いとき： "today": []
```

- **初期投入の JSON（地域ごと）には付けない**（足5）
- 字数：**本物で数えて報告する**（回答書の確かめ方）。見込みは約600字増（足す節の文の長さからの見込み。今のプロンプト全体の字数はまだ測っていないので、実装のときに前後を実データで測る）

## 2. 取り込み

### 2.1 形

`today` が JSON に書かれていたときだけ、「今日の3件」の記録を1つ作る（書かれていなければ作らない。空の配列は「0件」として作る）。

| 欄 | 中身 |
|---|---|
| id | `pk_YYYYMMDD_` ＋ 乱数6桁 |
| date | 取り込んだ日（端末の日付） |
| at | 取り込んだ日時 |
| batchId | その取り込みの番号（札の batchId と同じ） |
| items | 選ばれた件の並び（下） |

1件：

| 欄 | 中身 |
|---|---|
| ref | 書かれていた指し方（"#2" など） |
| cardId | 取り込んだ札の番号（#番号を直したもの）。落ちたら空 |
| fact | 指した出来事の「何が起きたか」（落ちた札でも読めるように、書かれていた文を残す） |
| type | 5つの型のどれか、または10字以内の言葉（超えたら切って印） |
| why | 理由。120字まで（安全弁。超えたら切って印） |
| gone | 指した出来事が取り込まれなかった理由（重複・url なし・日付・本文なし・番号が無い） |

- 3件を超えて書いてきたら：**落とさず全部持つ**。結果の1行に「多かった」
- `ref` が「#番号」の形でない・範囲の外：`gone` に「番号が無い」を入れて残す
- type・why が空：残す（表示で「（理由が書かれていません）」）

### 2.2 取り込みの結果の1行（足3）

今の結果の文の後に：

- 「今日見るべき件：3件」
- 0件：「今日見るべき件：0件（チャットが選びませんでした）」

### 2.3 置き場所

- **自分で調べたことの月ファイル（`world/dig/YYYY-MM.json`）の中に、`picks` という並びで持つ。** 月は取り込んだ日の月
- 理由：印と記録は札とは別のファイルに置く決まり。世界の索引（`world/index.json`）に足すと、古い版の端末が知らない欄を落とす（9/14 の予告の日時で起きた）。調べたことの月ファイルと索引は、合わせ方・書き方・2台の同期がすでに確かめてあるので、それに乗せる
- 合わせ方：id ごとに足し合わせる（書き換えない記録なので、どちらでも同じ）
- 失うもの：ファイルの名前が「dig（掘った）」なのに、朝の3件も入る。**kotoba-data の説明ファイル（README）を書くときに、この中身を書く**

## 3. 画面

### 3.1 世界の画面の一番上

世界の画面の「予告」の行の上に：

```
今日見るべき件（9/14 の取り込み・チャットが選んだ）
 ┌──────────────────────────────
 │ ［詰まり］ ホルムズ海峡を通る船が1日7隻に減った
 │   なぜ：…（60字）
 ├──────────────────────────────
 │ ［無理］ 米政府の債務総額が40.07兆ドルになった
 │   なぜ：…
 ├──────────────────────────────
 │ ［囲い込み］ カナダが米国製品に15〜50%の報復関税を発動
 │   なぜ：…
 └──────────────────────────────
```

- 1件を押すと、その札を開く（今の札の一覧と同じ開き方。月が読み込まれていなければ読み込んでから）
- 型の印は小さな文字の枠。**型ごとに色を変えない**（色を増やすと、推定の黄色・警告の赤・自分で調べた白と混ざる）
- 理由が空：「なぜ：（理由が書かれていません）」
- 取り込まれなかった札を指していた件：文を薄い字で出し「（この札は取り込まれませんでした：重複）」。押せない
- **表示する記録の決め方**（足4）

| 状態 | 出すもの |
|---|---|
| 今日の取り込みの3件がある | 今日の、一番新しい取り込みの分 |
| 今日の取り込みで0件だった | 「今日の取り込みでは、見るべき件は選ばれませんでした（材料が少ない日）」の1行 |
| 今日の取り込みが無い・`today` が書かれていなかった | 直近の3件を「9/12 の取り込み」と日付つきで。7日より古ければ何も出さない |
| 3件の記録が一度も無い | 何も出さない |

- 1日に2回取り込んだら、一番新しい方を出す（前の分も記録には残る）

### 3.2 変えない所

- 3件の下の、今の並び（予告・小さな地図・今日動いた主体・お金の鎖・問い）は変えない
- 3件に入った札も、下の一覧に今までどおり出る（二重に見えるが、下の並びを変えない方を選ぶ）
- ホーム（朝）の世界の行は変えない
