## 0. この段で何ができるようになるか

1. 絞りのボタン（地図の種類・地域、お金の一覧の使い道）を選ぶと、**その絞りが何を拾うかが1行で出る**
2. 地図の下の件数などを押して開いた一覧の**頭に1行の説明**が出る。分かりにくい名前を変える
3. 地図とお金の一覧の一番下に「**数字の見方 ▸**」。押すと、その画面の数字の決まりが全部並ぶ
4. 画面の「**（〜の累計）**」を「**期間：〜**」に揃える（計画の額が実績に見える嘘をなくす）
5. **確度の理由**を、札を開いたら「詳しく」を押さなくても見えるようにする
6. 数字の後ろの言葉を8か所変える（「確7」→「確度7」など）

**データは変えない。** 判定の結果も変えない（6 の確かめで本物のデータの数が同じことを見る）。

## 1. 説明の文の決まり

- **1行に収める。幅320で26字以内。**（実測：幅320の説明の行は幅273pxで、「あ」なら27字入るが、句読点や括弧が混ざると27字で2行になった。幅360で「あ」31字、375で33字。390は測れていない）
- 2行になるなら、**文のほうを短くする**（回答書のとおり）
- 専門用語を使わない
- 「数字の見方 ▸」の中だけは、26字を超えてよい（押して開く場所なので）

## 2. 説明を判定の表と同じ場所に持つ

### 2.1 使い道の表を「言葉の並び」に持ち替える

今は拾う言葉を機械向けの書き方（正規表現）で持っている。これを**言葉の並び**に変え、拾う仕組みはその並びから作る。**表の各行に説明の一文を持たせる。**

| 使い道 | 説明の一文（26字以内） | 拾う言葉（今と同じ） | 見る所（今と同じ） |
|---|---|---|---|
| 設備 | 設備投資・有形固定資産などの支払い | 設備投資・有形固定資産・property and equipment・設備増強 | 何の支払いか＋見出し |
| 自社株 | 自社株買い・自己株式の取得 | 自社株・自己株式 | 何の支払いか＋見出し |
| 注入 | 資本注入・資本を補う支払い | 資本注入・資本を補う | 何の支払いか＋見出し |
| 買収 | 会社を買う支払い（買収） | 買収 | 何の支払いか＋見出し |
| 投資 | 何の支払いかに「投資」「出資」とあるもの | 投資・出資（投資家・投資信託などを除いてから） | 何の支払いかだけ |

- 英語の「property and equipment」は、大文字小文字を区別しない今の拾い方を**そのまま保つ**
- **確かめ（回答書のとおり、必ず報告に書く）：** 持ち替えた後、本物のデータで **自分に使う20行・設備7・自社株4・注入3・買収1・投資5・候補0本** が変わらないこと。あわせて「投資」の行を外すと候補5本、戻すと0本

### 2.2 地図の種類の絞りの表に一文を足す

| 種類 | 説明の一文 |
|---|---|
| 全部 | （出さない） |
| お金 | お金が動いたもの |
| 物・人 | 物か人が動いたもの（お金以外） |
| 原油・石油 | 物のうち原油・石油製品が動いたもの |
| 約束 | まだ動いていない約束の金（配分・表明など） |
| 自分に使う | 自分の側に積む金（設備・自社株・注入・買収・投資） |

「自分に使う」は、使い道の表の名前の並びから括弧の中を作る（使い道を足したり外したりすると、ここも変わる）。

### 2.3 地域の説明は、地域の名前から作る

`片端が{地域}の国にある線と、{地域}の国の中の動き`（例：「片端が米州の国にある線と、米州の国の中の動き」22字）。「全体」のときは出さない。地域を足しても、文を書き足す必要がない。

### 2.4 そのまま使える表

約束の8語・計画らしいの8語・外貨建ての4語・一般名の19語は、もともと言葉の並びなので、「数字の見方 ▸」にそのまま並べる。

## 4. 押すと開く件数：名前を変える＋開いた一覧の頭に1行

一覧の画面の見出しのすぐ下に、1行の説明を出す。

| 今の名前 | 新しい名前 | 開いた一覧の頭の1行（26字以内） |
|---|---|---|
| 場所不明 N件 | （そのまま） | どちらかの端の国が分からない動き |
| 「・」の前で場所を決めた相手 N件 | **名前の先頭で国を決めた相手 N件** | 名前の「・」の前だけを見て国を決めたもの |
| 相手の国をもう片方から推し量った動き N件 | **国をもう片方と同じとみなした動き N件** | 株主・取得先などを、もう片方と同じ国にしたもの |
| 外貨建てとして市場の枠に入れた動き N件 | **外国の持ち主への支払いとして市場に入れた動き N件** | 保有者への支払いに外貨建て・ドル債などとあるもの |

- 「・」の後にもほかの国が並ぶ名前の知らせ（第1段）は、今のまま見出しに出す
- 一覧が1枚だけのときも（札がそのまま開く形でも）、説明の1行は出す

**失うもの：** 開いた一覧の見出しの下に1行増える。地図の下の名前が長くなる（折り返して並ぶ。幅320・360で、はみ出さないことを実装時に確かめる）。

## 6. 「（〜の累計）」を「期間：〜」に揃える

**画面の6か所**を揃える（実測）：

| 画面 | 今 | 直した後 |
|---|---|---|
| お金の一覧（絞っていないとき） | （2026年の累計） | 期間：2026年 |
| 札の中のお金の行 | （2026年の累計） | 期間：2026年 |
| 主体の詳細のお金 | 同上 | 同上 |
| 地層の画面のお金 | 同上 | 同上 |
| 探すの結果のお金 | 同上 | 同上 |
| お金の鎖 | 同上 | 同上 |

- 期間が無い動きには、**絞っていない一覧では何も出さない**（今と同じ。絞った一覧だけ「期間なし」を出す第2段の形は変えない）
- **生成へのプロンプトの中の「累計」2か所は変えない。** プロンプトでは「span＝その金額が期間の累計・合計なら、その期間」と説明していて、生成への指示としては意味が通る。変えると生成の書き方が変わる恐れがあるので、この段では触らない

**失うもの：** 「累計」という言葉で「足し上げた額だ」と分かった動き（本当に累計のもの）も、「期間：」とだけ出る。累計か1回か計画かは、この表示だけでは分からない（今も正しくは分かっていない）。

## 7. 確度の理由を、開いた札で見えるようにする

### 7.1 今どうなっているか（実測）

- 札の行の「確7」には、理由が**指を置くと出る吹き出し**で入っている。**iPhone では出ない**
- ただし、札を開いて「**詳しく**」を押すと、「確度：7/10（理由）」の行で**理由は見える**。iPhone でも見える
- 本物のデータで、確度がある札113枚のうち、**理由が入っているのは88枚**（理由は確度7以下のときに書かせている）
- **前回の報告の「iPhone では見えていない」は言い過ぎだった。** 正しくは「札の行では見えない。開いて『詳しく』を押すと見える（2回押す必要がある）」

### 7.2 直し方

- 札を開いたとき、**「詳しく」を押さなくても見える所**に「確度 7/10：理由」の1行を出す（理由があるときだけ。理由の文は短く切らない）
- 「詳しく」の中の同じ行は、二重になるので外す
- 札の行の吹き出しは残す（パソコンでは便利。iPhone では何も起きないが、押せる形ではないので「押しても何も起きないもの」にはならない）

**かかる手間：** 小さい（行を1つ、隠れている所から見える所へ移すだけ）。**この段に入れる。**

**失うもの：** 開いた札の「詳しく」の外が1行（理由が長ければ2〜3行）長くなる。

### 7.3 同じ形（指を置くと出る吹き出し）が、ほかにいくつあるか

アプリ全体で **11か所**（実測）。

| 画面 | 何に付いているか | 吹き出しの中身 | 他で見られるか |
|---|---|---|---|
| 世界：札の行 | 「確7」 | 確度の理由 | 開いて「詳しく」で見える → **7.2 で直す** |
| 世界：地図の下の枠 | 市場・国際機関・地域の箱 | 箱に入っている相手の名前**全部**（箱には2行＋「ほかN」まで） | 箱を押すと一覧・網で見える |
| 世界：国の網の点 | 点の名前 | 切れる前の名前（8字で「…」） | 点を押すと主体の詳細・札で見える |
| 世界：国の網の外の札 | 外の札 | 切れる前の場所の名前 | 押すと網・一覧で見える |
| 世界：札の★ | 刺さったボタン | 「刺さった（もう一度押すと外す）」 | **見られない**（★の意味） |
| 言葉：★ | 刺さったボタン | 同上 | **見られない** |
| 言葉：一覧の◆◇ | 残したいボタン | 「残したい（押すと普通に戻す）」 | **見られない** |
| 記録：振り返りの日のボタン | 「1年前」など | その日の日付・「記録なし（一番近い日を開きます）」 | 押すと開いた日で分かる |
| 筋トレ：× | セットを消す | 「このセットを消す」 | × で意味は分かる |
| 筋トレ：↓ドロップ | ドロップを足す | 「休まず重量を落として続けた分を足す」 | **見られない**（ドロップの意味） |
| 筋トレ：× | 段を消す | 「この段を消す」 | × で意味は分かる |

- **世界タブで「書いたのに見えていない」のは確度の理由だけ**で、7.2 で直す。ほかの世界タブの3つは、押せば全文が見える
- 世界タブの外で、他の場所でも見られないのは **★（2か所）・◆◇・↓ドロップ** の4つ。どれもボタンの意味の短い説明で、この段（世界タブの数字）の外なので**触らない**。別の段で扱うかは判断をください
