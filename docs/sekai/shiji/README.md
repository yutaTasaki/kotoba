# 指示書の置き場

**ここに指示書を置く。** `C:\kotoba` の直下に置いても実行はできるが、溜まると探せなくなるのでここへ入れる。

## 中身は公開されない

この README だけが GitHub に送られ、**指示書そのものは送られない**（`.gitignore` で除外）。
だから、ここに置いた指示書は**この端末にしかない**。消えると戻せないので、端末ごと移るときは自分で持っていく。

## 名前

`<題>_shiji.md`　例：`chuu_200ji_shiji.md`、`yomu_dai1dan_shiji.md`

## 実行したら、どこに結果が残るか

| 元の指示書 | 実行結果の報告書 |
|---|---|
| `chuu_200ji_shiji.md` | `../houkoku/2026-09-12_chuu_200ji.md` |

**指示書1本＝報告書1本。** 名前は「日付＋指示書の名前から `_shiji` を取ったもの」。
報告書は公開側に残るので、端末が変わっても読める。決まりは `../houkoku/README.md`。
