## 先に要点

1. **壊れているもの（確度・高）が5つ。** 文章の言い方の問題ではなく、今、取り込みや読みが静かに外れている。
   - 読むの依頼文が「下げたときは **confidenceWhy** に理由を書く」と頼んでいる。一方、例と取り込みは `why` を読んでいる。文のとおりに返されると、確度の下げが黙って捨てられる。
   - 朝の依頼文が、v20.65 で消した「最近のお金の動き」の一覧から id を選べと、3か所で言っている。
   - 朝の決算書類（SEC）の節が「つながりを **read** に書く」と言っている。read は朝では書かない決まり（v20.18）で、形にも read が無い。
   - 撮るのサムネ・タイトルの依頼文が、v20.113 でやめた「最初の約200字の約束」を前提にしている。さらに「開始数秒でタイトルの約束を回収する」冒頭をもう1つ作らせていて、謎から入る構成の冒頭と逆向きになっている。
2. **API の5つの道は、JSON を守らせるための文言・ゆるい読み取り・読めなければもう一度払って呼び直す、の3段で身を守っている。** API の構造化出力（`output_config.format`）で形を保証すれば、3段とも要らなくなる。
3. **関連づけと投稿の要約・説明は、思考する型に替えると切れる。** 返事の上限が 2048・300 と小さく、切れたかどうかを見ていないため。前の版の設定の移し替えで、関連づけに Sonnet 5 が入ることもある。
4. **撮る・世界の依頼文に、太字と「必ず」「絶対に」「厳守」が積もっている。** 撮るで本人が見つけた「決まりを積むほど悪くなる」（v20.113）と同じ形。
