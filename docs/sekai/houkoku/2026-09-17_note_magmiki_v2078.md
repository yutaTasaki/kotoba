## 先に：結果

- **設定 → 世界 の「幹を立てる（割り直し）」に［マガジンを幹にする］を足した。** 押す（2回押し）と、今の幹11本を閉じ（記録は残る）、マガジン7個を幹にする。そのあと同じ欄の段B（チャットに2回）で、全部の札をマガジンに割り直す
- 切り替えたあとは、**マガジン＝幹**：
  - 朝の取り込みで、新しい札はマガジンに付く（決まりの文も「読者向けのテーマ」に替えた）
  - 幹に入らない札が積もると、「新しいマガジンの案」が出る
  - ［マガジンを足す］と幹も増える
  - 世界の画面は「マガジン 7個・葉 N枚 ▸」「今日動いたマガジン」、札の画面は「マガジン：〇〇 ▸」
- **幹の答えと根（出発点）を止めた。** 読む回の依頼文から答えの節が消え、朝の取り込みで出発点を探さない。前の答え12件・根3件は記録に残る
- **記事のマガジンは、札のマガジンを先に入れ、企画でチャットが「ほかにも入るマガジン」だけを足す**
- まだ本物のデータは切り替えていない（押すのは本人）

## 本人がやること（1回だけ）

1. 両方の端末で「版 v20.78」になってから
2. 設定 → 世界 →「幹を立てる（割り直し）」→［マガジンを幹にする］→［マガジンを幹にする（決める）］
3. 段B 1回目のプロンプトをコピー → **新しいチャット**に貼る → 返事を1回目の欄に貼って［読む］
4. 段B 2回目のプロンプトをコピー → **別の新しいチャット**に貼る → 返事を2回目の欄に貼って［読む］
5. 比べた結果を見て［この割り当てで入れる］

- 依頼文は1回 約25,000字（札154枚）。返事が途中で切れたら［返事の無かった札だけもう一度コピー］
