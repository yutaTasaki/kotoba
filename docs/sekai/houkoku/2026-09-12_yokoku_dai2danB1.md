# 予告 第2段B-1：読む枠の配分・朝タブを1行に・捨てるときに予告も捨てる

## 1. 何をしたか

1. **読む回の枠20枚を種類ごとに配分した。** これまで未読だけで埋まっていた枠に、
   「朝の浅い読みを書き直す札」を必ず5枚入れる。足りない種類の分は他へ回すので、枠は遊ばせない。
2. **朝タブの予告を1行にした。** 押すと予告の画面へ飛び、**戻ると朝に返る**。
3. **世界のデータを捨てるとき、予告も一緒に捨てる。** 捨てる前の確認に**本数**が出る。

## 2. 結果

### 2-1. 作ってあるのに一度も動いていなかった仕組みが、動いた

**これが今回いちばん効いた点です。**「朝の浅い読みを書き直す」は前回（v20.18）に作りましたが、
未読が尽きるまで動かない作りで、**一度も回っていませんでした**。未読75枚は4回ぶんあるので、当分先でした。

配分を入れたので、いまは毎回必ず5枚が回ります。

| 仕込んだ札 | 選ばれた内訳 |
|---|---|
| 未読75・浅い読み20 | **浅い読み5・未読15**（計20） |
| 未読75・浅い読み2（浅い読みが足りない） | 浅い読み2・**未読18**（余りは未読へ） |
| 未読3・浅い読み20（未読が足りない） | **浅い読み17**・未読3（余りは浅い読みへ） |
| 未読2・浅い読み1（全部少ない） | 未読2・浅い読み1（計3。無いものは作らない） |

**枠が余ることはなく、無い種類を待って止まることもありません。**

### 2-2. 読ませて取り込むところまで通した

20枚を選び、それに対する読みを実際に取り込みました。

```
15枚に思惑が入りました（15人ぶん）。　朝の浅い読みを書き直した5人ぶん（前の文は札に残しています）。
　読んだ内訳：浅い読み5・未読15。
```

- 取りこぼし・行方不明の札：**0**
- 書き直した5枚とも、**前の文が札に残っていた**（消えていない）
- **何が回ったかが必ず文に出る**ので、また「作ったのに動いていない」に戻ることはありません

### 2-3. 朝タブは1行になった

| 状態 | 出たもの |
|---|---|
| 期限が来たものがある | `待っている予告 5本・期限が来たもの 2本 ▸` |
| 期限が来たものが0本 | `待っている予告 5本 ▸`（余計な0を出さない） |
| 両方0本 | **行ごと出ない**（「ありません」の空行を作らない） |

押すと予告の画面へ飛び、戻るボタンが**「朝に戻る」**になって、押すと朝に返りました。
世界タブから入ったときは**「世界に戻る」**のままで、世界に返ります。迷子になりません。

### 2-4. 捨てる前に本数が出る

実際に出た確認の文（**押していません。キャンセルして中断しました**）：

```
札 3枚・概念 3件・用語 0件・問い 0件・予告 5本を捨てます。
主体・地層の値・ソースは残します。
元に戻すにはバックアップを手で戻す必要があります。
捨てますか？
```

中断後、札3枚・予告5本とも**そのまま残っていました**（間違って捨てていません）。

### 2-5. 狭い画面でも崩れない

**幅360・320のどちらでも、はみ出し0・横スクロールなし。** 朝の1行は折り返さず1行（27px）に収まりました。

### 2-6. 前に作ったものが壊れていない

- 読む回のプロンプト：組める（5,280字）。予告を書かせる指示・答え合わせ・書き直しの指定すべて健在
- 予告の画面（第2段A）：期限が来た2本に「当たり／外れ／確かめられない」が出て、
  「当たり1・外れ1・確かめられない0・まだ5（当たりと外れが10件そろうまで、割合は出しません）」も表示

## 3. 意味

**「作ったのに動いていない」は、壊れているより見つけにくい。**
書き直しの仕組みは黙って何もしておらず、画面にも何も出ないので、実際に数えるまで分かりませんでした。
今回は配分を入れて動かしたうえで、**毎回の取り込み結果に内訳を出す**ようにしました。
次に同じことが起きたら、内訳の数字が0のまま並ぶので、その回に気づけます。

捨てる処理は、足す順番を間違えると「消したのに次の同期で戻る」という切り分けの難しい壊れ方をします。
仕様書どおり**保存庫 → 端末の器 → 書き戻す器 → 受け取る側**の順に足し、
予告の上書きは**地層の後・月ファイルの前**に置きました（途中で止まっても器が中途半端に残らない位置）。

## 4. 残り

- **浅い読みの枠5枚は、変えやすい形にしてあります。** 何回か流して重い／軽いと感じたら、
  数字1つで変わります（外れた札の3枚も同じ場所に並べてあります）。
- **「読み込めなかった月が N か月あります」の警告行は、まだ出るところを見ていません。**
  試した環境では月が0件で、警告が要らない状態だったためです。ここは実際に保存庫へ繋いだときに確認します。
- **B-2（予告が外れたら、その札を読む回に戻す）は入っていません。** 枠3枚だけ先に確保してあります。
  いま入っている予告の期限が 10/04〜12/04 なので、**本当の確認は10月4日以降**になります。

## 5. 測り方について1つ

幅の確認を最初にやり損ねました。ウィンドウを360にしてもブラウザの最小幅に阻まれて、
中身は668のままでした。**そのまま「360で確認した」と書けば嘘になる**ので、
幅360の枠の中にアプリを読み込み直して測りました（狭い画面用の切り替えもちゃんと効く形）。
上の 2-5 はその測り直した値です。
