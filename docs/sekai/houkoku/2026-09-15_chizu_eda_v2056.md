## 先に：結果

- **段1の仕様書を書き、実装した。** 札の画面（枝・葉・根）の「なぜ」の文のすぐ下に、その札だけの地図と、誰から誰への1行を置いた
- **誰から誰への1行は、地図が描けない札にも出す**（指示書の「むしろこれが本体」のとおり）。「詳しく」の中の同じ行と、「動かした側」の下のドル換算の1行は外した（二重に出さない）
- **国の形の使い回しを入れた（必須のとおり）。** 形を覚えた後、枝を10枚続けて開くと、札の画面を開く時間込みで 1枚あたり約8〜11ms（PC）。覚える前の初回だけ、形を作るのに約56ms
- **ドル換算を、朝の取り込み・候補から札を作ったあとにも動かすようにした。** 地図タブを開かなくても、新しい札の1行にドルが付く
- 本物の写しの札145枚を全部開いて、ページのエラー0、地図の出方が相談の実測と一致

## 1. 作ったもの

### 1.1 札の画面の並び

```
（札の行）9/8 …
幹：… ▸
なぜ（文）
┌ その札の地図（世界全体。線1本・点・杭。枠への線なら下に枠の箱）┐
誰から誰への1行（物・人の印、出す側 → 受け取る側、何、額、期間、ドル換算、理由）
動かした側
…
```

### 1.2 札ごとの出方（本物の写し145枚で数えた）

| 札の動き | 枚数 | 地図 | 1行の後ろ |
|---|---|---|---|
| 国 → 別の国 | 24 | 線1本 | — |
| 国 ⇄ 枠（市場・国際機関・地域） | 28（うち杭4） | 線1本＋下に枠の箱1つ | — |
| 同じ枠どうし | 2 | 枠の箱1つ | （地域の中の動き）など |
| 同じ国どうし | 28（うち杭10） | 国の点＋「国内」 | （国の中の動き） |
| 片方の場所だけ分かる | 9（うち杭3・枠2） | 分かる側の点か枠の箱 | （相手の場所が決まらない：名前） |
| 確度3以下 | 8 | 分かる場所の点・枠の箱（線なし） | （確度3以下なので線にしていません） |
| 動きなし・主体の国が分かる | 38 | 主体の国の点（最大3） | 1行「誰から誰へは書かれていません（点は主体の国）」 |
| 動きなし・主体の国も分からない | 8 | **出さない**（空の枠を置かない） | **出さない** |

- **線が出る札52枚・地図が出る札137枚・何も出さない札8枚**。相談の実測（線52・国が分かる84・国なし9）と合う。国なし9枚のうち1枚（「世界の石油在庫→石油市場」）は、場所が枠（市場）なので枠の箱1つを出した
- 線の見分けは地図タブと同じ（太さ＝ドル換算の5段、点線＝物・人・換算できない、破線＝累計・期間、薄い線＋白抜きの矢印＝約束）
- 杭は、地図タブの「自分に使う」と同じ見分け・同じ形（下へ薄くなる棒）
- 地図は押す物にしていない（指でなぞればページが動く）

### 1.3 重さ

- 国の形（177か国）は、画面の幅ごとに1回だけ作って覚え、2回目からは複製して、関わる国の塗り・線・点・杭だけを描く。覚えるのは直近2つの幅まで（アプリを閉じれば消える）
- 文字を先に出し、地図は部品を読んでから入れる。地図の高さの分は、はじめから空けておく（後から文がずれない）

## 2. 手元で確かめたこと

偽の GitHub に本物の kotoba-data の写しを置いて動かした。**本物の保存庫には何も書いていない。** 画面の移動はページの中から押した（座標で押すとずれるため）。

| 確かめ | 結果 |
|---|---|
| 分類ごとに1枚ずつ開く（国→国・国→枠・枠＋杭・国内＋杭・確度3以下・動きなし・何も出さない・片方だけ・同じ枠） | 1.2 のとおり。地図は「なぜ」の直後、1行は地図の直後、その次が「動かした側」 |
| 「詳しく」の中のお金の動きの行・動かした側の下のドル換算の1行 | どの札でも出ていない（二重なし） |
| 145枚を全部開く | 地図が出る137・出ない8・線52・1行が出る137。地図と1行が2つ出た札0。ページのエラー0 |
| 10枚続けて開く（線の出る枝、PC、5回） | 1枚あたり 19.6（1回目）→ 10.8・8.0・7.7・11.0ms（札の画面を開く時間込み） |
| 国の形を作る（覚える前）／覚えた形を複製 | 55.9ms／0.2ms |
| 朝の取り込み（12億ユーロの札。ECB のレートを試しの値で端末に置いた） | 取り込んだ直後は換算なし → 裏で換算され、地図タブを開かずに「約14億ドル（推定・ECB 9/14）」が1行に付き、線の太さが 3.5px |
| 見た目（幅528px の窓） | 欧州委員会 → 地域（ウクライナ向け防衛調達）：線が地図の下の「地域」の箱へ伸び、下に1行 |

**測れていないもの**
- 色を塗る時間（測ったタブが裏になっていた）。上の ms は描く処理とレイアウトまで
- **iPhone の重さ**。推測で PC の2〜4倍
- 幅400px 前後の見た目（確かめの窓がそこまで狭くならなかった）。地図の高さは、幅358px なら約175px、枠の箱があると約211px（計算）
- 通信できないときに何も出ないこと：試しのページは外への通信を止めているので、実データの札の換算が失敗しても、エラー0・画面に何も出ないことは確かめた。ECB から実際に取る動きは確かめていない

## 3. 確かめの途中で気づいたこと（直していない）

- 誰から誰への1行は、今の「詳しく」の中の行と同じ書き方をそのまま使ったので、「日量66.2万バレル （期間：…）」のように括弧の前に空白が入る。前からの書き方
- 地図を出すかは部品を読んでから決まるので、動きも主体の国も無い8枚では、開いた一瞬だけ地図の場所が空き、すぐ閉じる（部品を読み込み済みなら、画面に出る前に閉じる見込み。推測）

## 4. 公開の前に実機で確かめてほしいこと（触ると壊れる形を先に）

1. **iPhone で、幹の画面の枝の一覧から、枝を次々に開いたときに引っかからないか**（手元では iPhone の重さを測れていない。最初の1枚だけは形を作る分遅い見込み）
2. **「なぜ」の文と地図の間が空きすぎないか**。地図が入って、読む流れが途切れないか（地図の高さは幅358px で約175px、枠の箱があると約211px）
3. 地図の上を指でなぞって、ページが動く（地図が指を取らない）
4. 誰から誰への1行が読める。「詳しく」を押しても同じ行が出ない。動かした側の下にドル換算の1行が残っていない
5. 次の朝の取り込みのあと、ドルで書かれていない新しい札の1行にドル換算が付く（地図タブを開かなくても）
