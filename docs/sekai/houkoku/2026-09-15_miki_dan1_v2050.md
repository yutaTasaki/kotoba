## 1. 作ったもの

### 1.1 記録（データ）

- 調べたことの月ファイル（`world/dig/YYYY-MM.json`）の `miki` に、一度書いたら変えない記録を足す
- 札・索引・主体・予告には何も書かない
- 段1で使う記録：幹を立てた（`open`：名前・1行・中心の札・見る地層）／名前を直した・外した（`rename`）／札を幹にぶら下げた（`attach`：幹0〜2本）／割り直し1回分（`split`）／同じ出来事の組（`sameGroup`）
- 今の姿（幹の一覧・札ごとの幹）は、記録を日時の順にたどって端末で組み立てる

### 1.2 割り直しの欄（設定 → 世界）

| 段 | 画面 | 決まり |
|---|---|---|
| 段A | ［段A のプロンプトをコピー］→ 貼る →［幹の案を読む］ | 前後の文や ``` で囲まれた返事も読む。知らない札の番号・一覧に無い地層は外して数える |
| 案 | 名前と1行を打って直せる・［外す／採る］・［この幹で決める］ | 採る幹が1本も無いと押せない。決める前なら［案を捨てて貼り直す］ |
| 段B 1回目 | コピー → 貼る →［読む］ | 「132枚中130枚に返事、2枚は返事なし」→［返事の無かった札だけもう一度コピー］。同じ欄に貼ると1回目に足す |
| 段B 2回目 | 札の並びを逆にしたプロンプト | 1回目が済むまで押せない |
| 比べる | 2回とも同じ・食い違い（共通の幹だけ付ける／付けない）・揺れた幹の組（押すと札の一覧）・同じ出来事の組 | 割り当ての1枚ずつの直しは作らない |
| 入れる | ［この割り当てで入れる］ | 押すと途中の欄が空になる |
| 直す | ［切り方を直す］→ 名前・1行を直す、外す、［＋ 幹を足す］→［この切り方で決める］ | 決めたあと段B を通すまで「まだ段B を通していません」と出す |

**割り直しの途中（案と2回分の返事）は、その端末に保存する。** iPhone で Claude に切り替えてアプリが読み込み直されても、続きから進められる。

### 1.3 幹の画面

- 世界の画面の一番上：「幹を立てる ▸」（押すと設定のその欄が開く）／「幹 9本 ▸」
- 幹の一覧：名前・1行・「枝 26　新しい枝 9/13　答えはまだ」
- 幹1本：1行／主な主体（押すと主体の画面）／見る地層（押すと地層）／予告（枝の札から出たもの。押すと予告の画面）／枝（新しい順に10枚、「ほか N枚 ▸」。押すとその札が開いた一覧）
- 札の画面：「幹：〇〇 ▸」
- 戻る：札の一覧・主体・地層から開いたものは幹1本へ、幹1本は幹の一覧へ、幹の一覧は世界の画面へ

## 3. 仕様書から変えたところ

| 仕様書 | 変えたこと | 理由 |
|---|---|---|
| 幹の一覧の「最後に枝 9/14」 | 「新しい枝 9/13」（枝の出来事の日付でいちばん新しいもの）。並びも同じ | 割り直しでは全部の札が同じ日に付くので、付けた日では並ばず、全部同じ日付になる |
| 予告を押すと「予告の画面のその予告」 | 予告の画面を開くだけ（その1本までは移らない） | 予告の画面に1本を指して開く作りが無い。段4で予告と幹をつなぐときに一緒に直す |
| 見る地層 | 段A でチャットが書いた地層のうち、一覧にあるものだけ | 仕様どおり。一覧に無い地層は外して数える |

## 4. 公開の前に（実機で確かめてほしいこと）

段0と同じく、iPhone は公開しないと新しい版が来ない。**順番は「公開 → 実機 → 問題があれば戻す」を想定している。**

**触ると壊れる形を先に並べる。**

1. 世界の画面の「幹を立てる ▸」を**指で押す** → 設定の割り直しの欄が開く
2. 段A のプロンプトをコピーして Claude に貼り、返事を貼って［幹の案を読む］
3. **iPhone で名前の欄を指で押して、日本語で打ち直す**（変換中に画面が描き直されて文字が消えないか）
4. ［外す］を押して薄くなる →［この幹で決める］
5. 段B 1回目をコピーして Claude に貼る → **Claude のアプリに切り替えて戻ってきても、決めた幹と1回目の欄が残っている**
6. 1回目の返事を貼って［読む］。返事の無い札が出たら［返事の無かった札だけもう一度コピー］
7. 段B 2回目は**別のチャット**に貼る → 返事を貼って［読む］
8. 比べた結果を読み、揺れた幹の組を押して札を見る →［この割り当てで入れる］
9. 世界の画面 →「幹 N本 ▸」→ 幹1本 → 枝 → 札の「幹：… ▸」→ 戻る
10. **もう片方の端末で同期して**、同じ幹が見える

見た目：iPhone の幅で、案の枠と比べた結果の表が崩れないか。

**戻すとき**：v20.50 のコミットを取り消して送り出す。幹の記録は調べたことの月ファイルに残り、v20.49 は読まないだけで消さない（2の古い版の確かめのとおり）。もう一度 v20.50 にすれば、そのまま見える。
