## 1. 作ったもの

### 1.1 本部の点（12）

国連安保理（ニューヨーク）・IMF・世界銀行（ワシントン）・NATO・EU（ブリュッセル）・ECB（フランクフルト）・WTO（ジュネーブ）・国際刑事裁判所・国際司法裁判所（ハーグ）・IAEA・OPEC（ウィーン）・BIS（バーゼル）。

- 呼び名と**丸ごと一致**したときだけ当てる（「欧州委員会」「欧州連合」は EU の点、「安保理」「国連」は国連安保理の点）
- **BRICS・G7・G20・湾岸の産油国のような集まりは点にしない**（本部が無い）。今までどおり枠のまま
- 国コードに置き換えないので、米国 → 国連安保理・ユーロクリア → 欧州委員会 も線のまま

### 1.2 本部の点だと分かるようにする（指示書 2.2 への答え）

枝の地図には使い方の説明が無いので、**点の名前に「（本部）」を付ける**。

| 種類 | 形 | 名前 |
|---|---|---|
| 国 | 丸 | 書かない |
| 海峡・運河 | ひし形 | ホルムズ海峡 |
| **本部** | **四角** | **IMF（本部）・国連安保理（本部）** |

- 地図タブの使い方にも節を足した：「ひし形は海峡・運河。四角は国際機関などの**本部の場所**で、金や手が本部から出入りしたという意味ではない。本部が無い集まり（BRICS・G7・湾岸の産油国）は点にせず、下の枠に置く」

### 1.3 効かせた線の場所を取り直す

効かせた線は、記録に入れたときの場所で持っている。**本部の点が表に足された後も古い場所のままだった**ので、画面に出すときに名前から取り直すようにした（「EU → ロシア」が地域の枠のままだった）。線にするかどうかの決まり（2回とも同じ組か）は、記録に入れたときのまま変えない。

## 3. 段2の矢印が「北東へ動いた」と読まれないか（指示書 2.1 への答え。段2では実装しない）

| 案 | 中身 | 失うもの |
|---|---|---|
| **A 矢印を描かず、点の横に文字だけ（推奨）** | 国の点のすぐ右に、小さい字で「→ 国債市場」。線は引かない | 形の目立ちは弱い。**方角の誤読は原理的に起きない** |
| B 点線の短い棒（6px ほど）＋名前 | 点から外へ短い点線 | 短くても向きはあるので、方角と読まれる余地が残る |
| C 地図の縁で止める矢印 | 点から縁へ | いちばん方角に見える。**反対** |

- 勧めは A。地図の中に「相手の名前」だけが増え、位置は主張しない。「→」は文字の一部として向き（出る・入る）だけを表す
- A でも紛れるようなら、**段2は入れず、今の下の箱のまま**にする
