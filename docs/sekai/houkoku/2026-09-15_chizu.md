## 先に：結論

1. **前の答えの「枝1件の地図は反対」を取り下げる。** 判断の軸を「見ごたえ」に置いていたのが誤りだった。加えて、前の答えは「線1本は本文にもう書いてある」を理由にしたが、**実際には「誰から誰へ」は札の画面の既定の表示には出ていない**（「詳しく」を押した中にしかない。3章）。枝の地図は、押さずに見えるようになる点で読む助けになる
2. **枝の地図は「なぜ」の文のすぐ下に置き、その枝だけを描く**（同じ幹のほかの枝は重ねない）。線が引ける枝は41枚／112枚、線が無い枝も大半は関わる国の点なら出せる
3. **国の形を覚えておくことが前提。** 開くたびに作り直すと札を開く時間が約10倍（PC 4.9→48ms）、覚えれば 6.8ms
4. 幹の地図は前の答え（根のすぐ下・90日の制限なし）のまま。葉は枝と同じ、根も枝と同じ
5. **地図タブはまだなくさない（反対）。** ドル換算が地図タブを開いたときにしか動かない。換算を移し、点検の一覧の置き場所を決めてから、奥へ下げる
6. **ふだんの日に押す回数は増えない。** 枝の場所を地図で確かめるのは、いま5〜7回 → 0回

### 問4 開くたびに作る重さ（実測・PC。5回の中央値。地図の幅358）

**測れていないもの**：色を塗る時間（測るタブを前に出せず、描画のフレームが来なかった）。数字は描く処理とレイアウトの計算まで。

| 何を | ms |
|---|---|
| 組み立て：札1枚だけ／全部の札から探す | 0.3／23.4 |
| 小さな地図の描き方で描く＋レイアウト | 38.4＋1.7（線0本でも31） |
| 大きな地図の描き方で描く＋レイアウト | 47.2＋2.7 |
| 描く時間の内訳：国の形／線1本 | 約30／0.1 |
| 覚えた国の形を置き直す（2回目以降を想定） | 0.9 |
| **10枚続けて開く：今の札の画面だけ** | **4.9／枚** |
| **同：開くたびに地図を作り直す** | **48.0／枚（約10倍）** |
| **同：国の形を覚えて、線だけ描く** | **6.8／枚** |
| 地図の部品を読み込む（そのタブで初回だけ） | 57 |

- 描く時間のほとんどは国の形を作る時間で、線はほぼ0
- **国の形を覚えないまま作ると、枝を次々に開く使い方で待ちが出る見込み**（推測：iPhone は PC の2〜4倍として 1枚 100〜200ms）
- 国の形を覚えれば、推測で iPhone 1枚 15〜30ms。**iPhone は測れません**
- 文字を先に出し、地図は後から入れる形にする（今の小さな地図と同じ）

### 問5 その枝だけか、その枝を濃く同じ幹のほかの枝を薄くか

同じ幹のほかの枝の線の本数（実測。その枝自身の線は除く。2本の幹に付いた枝は、2本の幹の枝をまとめて数えた）：

| 本数 | 0 | 1 | 2〜3 | 4〜6 | 7以上 |
|---|---|---|---|---|---|
| 枝112枚 | 15 | 11 | 17 | 33 | 36 |
| うち自分の線がある41枚 | 1 | 3 | 3 | 23 | 11 |

- 重ねると意味が加わる例：関税の幹の「カナダ→米国」。薄い線6本が重なり、同じ日の報復関税が逆向きで見え、日本は投資で払う側だと分かる
- 邪魔になる例：欧州＋制裁の幹の「凍結ロシア資産」。この札は線0本で、薄い線だけが14本並ぶ。この札の話に関わるのは1本だけ

| 案 | 失うもの |
|---|---|
| **A その枝だけ（推奨）** | 同じ幹の中での位置（関税の応酬のような形）は、枝の地図では見えない。幹の地図まで行く必要がある |
| B その枝を濃く・同じ幹のほかを薄く | 自分の線がある41枚のうち34枚で、薄い線が4本以上重なる。読んでいる枝の線が埋もれる。「薄い」は約束の線がもう使っているので、色で分ける必要がある。2本の幹に付いた枝は線がさらに増える |

**推奨：A。** 基準の「読んでいる枝を、その場で分かりやすくする」には、線1本と国の点が一番まっすぐ。同じ幹の中の形は、幹の地図の役目に分ける。
- 足すなら「前の動き（その札に記録された、同じ筋の1つ前の動き）」だけ。関税の例の逆向きの報復関税はこれに当たる（前の動きが記録されている枝は少ない。前回の数えで、足して2本になるのは7枚）
- 失うもの（足す場合）：線が2本になる枝と1本の枝が混ざる

## 2. 幹・葉・根の地図（問6〜8）

### 問6 幹の地図は前の答えのままでよいか

**よい。** 根のすぐ下（今のコードでは「根」の欄と「主な主体」の間）、90日の制限なし。付け足すこと：
- 幹の地図には、下の枠の箱（市場・国際機関・地域）と「国内N」の印が要る（無いと、欧州・外貨・国債の幹はほぼ空。前回の数え）
- 線を押したら、その枝を開く（枝の地図と行き来できる）
- 線が引けない幹（エネルギー高・紅海）は、前回の回答のとおり地図の枠を出さず、理由を1行

### 問7 葉を開いたときは何を出すか

**枝と同じ単独の地図（その葉だけ）。** 葉は画面も枝と同じ（札の一覧の中で開く）。
- 実測：線が出る葉は33枚中11枚（うち4枚は同じトヨタの自社株買い）。関わる国の点なら大半に出せる
- 「葉が集まっているときに、どこで起きているか」の地図は、**いまは反対**。葉を点で出すと15か国、2枚以上の葉に出る国は7か国で、米国11枚・日本9枚が大半。同じ国が出る葉の組は103組（全528組）で、「米国と日本」が集まって見えるだけで、新しい幹の手がかりにならない（推測）
- 置くなら、**芽**（葉から出た新しい幹の案）を開いた中に、その芽のもとの葉の地図を置く方が筋が通る。芽はまだ実データに無いので、芽が出てから考える

### 問8 根は枝と同じ扱いでよいか

**よい。** 根は枝の一種で、画面も同じ。
- 実測：根の記録は1件だけ（制裁の幹、2020-10-08「米財務省がイランの金融部門を制裁対象に指定」）。この札に動きは無いので、枝の地図では主体の国（米国）の点と1行になる
- 幹の地図の「根から今日の枝まで」は、根の札に動きが書かれるまで線にならない
- 気づいたこと：根の札の画面には「この幹の根」の印が無い（幹の行が出るだけ）。読むときに根だと分からない

## 3. 全体（問9〜12）

### 問9 各画面に地図を置いたあと、地図タブは何のために残るか

残る理由（コードで確かめた）：

| 地図タブにしか無いもの | 各画面の地図で代われるか |
|---|---|
| **ドル換算を動かす**（大きな地図を開いたときの1か所だけ。札の「≒ 約N億ドル」、お金の行、線の太さはこの結果を読む） | 代われない。**移さずに地図タブを消すと、新しい札からドルが消え、線が「換算できない点線」になる** |
| **点検の一覧**（場所不明・名前の先頭で国を決めた・確度3以下で外した ほか7種） | 代われない。場所の当て方を確かめる唯一の場所。枝の地図の線が正しいかも、ここで確かめる |
| 国の網・市場の網 | 入口は全部地図の中。幹の地図の国の点から開けるようにすれば代われる |
| 全部の動きを地域・種類で絞る | 各画面には要らない |
| どの幹にも入らない動きを含めた全体 | 葉1枚ずつなら枝の地図で見える。全体を一度に見る場所は無くなる |

| 案 | 失うもの |
|---|---|
| A なくす | 上の表の全部。ドル換算の置き場所、点検の一覧の置き場所、網の入口を先に作らないと壊れる。**いまは反対** |
| **B 残して奥へ下げる（推奨）** | 世界の画面の「地図」ボタンと小さな地図（7日）を外し、幹の地図から「全体の地図で見る ▸」だけにする。換算は取り込みの後と、枝・幹の地図を出すときにも動かす。失うもの：全体の地図へは押す回数が1回増える。今週どこで金が動いたかを世界の画面で一目で見る絵が無くなる（本人の話では、ほぼ見ていない） |
| C 点検専用にして設定の中へ | 普段の道から完全に消える。網もほぼ開かれなくなる。場所の間違いに気づくのが遅れる |

**推奨：B。** 地図タブの役目を「読む場所」から「点検と全体」に変える。なくすかは、B のあと実際に開いたかを見て決める（開いた回数を残していないので、**本人の感触で判断するしかない**）。

### 問10 地図タブにあって、各画面の地図では出せないもの。それは各画面に要るか

| もの | 枝・葉・根 | 幹 |
|---|---|---|
| 地域・種類の絞り込み | 要らない | 要らない |
| 90日の期間 | 要らない（かけると古い枝の地図が消える） | 要らない（前回のとおり、外貨の幹は10/28に空になる） |
| 下の枠の箱（市場・国際機関・地域） | 枠への線がある枝（23枚）だけ要る | 要る |
| 国内の印 | 要る（点＋「国内」） | 要る |
| 杭（自分に使う） | 要る（その札が自分に使う金なら杭で描く。17枚） | 要る |
| 線を押したときの動き | 要らない（開いているのがその枝） | 要る（押したら枝を開く） |
| 近い線の選び分け・拡大 | 要らない（線は1本） | 一部（線の多い幹だけ） |
| 太さの見本 | 要らない | 要らない（線の太さの意味は1行で足りる） |
| 国の網への入口 | 要らない | あると良い（国の点を押すと網） |
| 点検の一覧 | 要らない。代わりに「描けない理由」を1行 | 同じく1行 |

作る側の注意（コード）：
- 小さな地図の描き方は、置く場所を受け取るので、どこにでも置ける。ただし国をまたぐ線しか描かない（枠・国内・杭が無い）
- 大きな地図の描き方は、地図タブの場所に決め打ちで書き込むので、そのままでは他の画面に置けない（同じ画面に2つ置くと部品の名前がぶつかる）
- どちらを元にするにしても、**「札の集まり」を受け取って描く形に作り直す**のが本体の作業
- 同じ国の組は太い順に5本までの決まりがあり、幹の地図で額の小さい枝の線が「ほかN本」に隠れる。幹の地図では別の決まりが要る

### 問11 ふだんの日に押す回数

- **増えない。** 枝・葉・根・幹の地図は開いた画面に最初から出るので0回
- **減る**：いま枝を読んでいて「どこで起きたか」を地図で確かめるには、戻る3回 → 「地図」 → 目で探す → 線を押す（近くに線があれば選ぶ）で **5〜7回**、枝に戻るまで往復 **10〜12回**。これが **0回** になる
- 増えるもの：流す量。地図の高さの分だけ、枝を1枚読むのに下へ流す量が増える（推測 150〜240px）
- 90日より前・確度3以下・場所不明の枝は、今の地図タブでは線が出ず、出ない理由も書かれていない。枝の地図では理由の1行が出る

### 問12 何段に分けるか

| 段 | やること | 使えるようになること |
|---|---|---|
| **段1 枝の地図** | 札の画面（枝・葉・根）の「なぜ」の下に、その札だけの地図（線1本・点・杭、枠への線なら枠の箱）。地図の下に「誰から誰へ」の1行（「詳しく」の外に出す）。描けない理由の1行。国の形を覚える。ドル換算を取り込みの後にも動かす | 枝を読んだそばで場所と向きが分かる。枝を次々に開いても待たない |
| **段2 幹の地図** | 幹の画面の根の下に、枝の全部で描く地図（枠の箱・国内・杭、90日なし）。線を押すとその枝を開く。国の点で網。根の札の画面に「この幹の根」の印 | 幹の中で金がどこからどこへ回っているかが、幹を開いたそばで見える。枝と幹を行き来できる |
| **段3 地図タブを奥へ** | 世界の画面の「地図」ボタンと小さな地図を外す。幹の地図から「全体の地図で見る ▸」。点検の一覧と網は全体の地図に残す。札を足す画面の「地図（直近90日）に出ます」の文言を直す | 地図の入口が、読む場所（枝・幹）に移り切る |

- 段1を先にする理由：本人の目的（読んでいる枝を分かりやすくする）に一番近く、ふだん一番多く開く画面。1枚の地図なので作りも一番小さい
- 段2と段3を分ける理由：段3は地図タブの入口を消すので、段1・2の地図が実際に読まれているかを見てからにする
- 芽の地図（問7）は、芽が実データに出てから
- 名前（杭）は①-2で済んでいるので、どの段でも「根」と「杭」は混ざらない
