## 仕様を書く中で見つかったこと

1. **札の「何が起きたか」は40字まで。** 今の取り込みは黙って切る。JPモルガンの件の文（約40字超）はそのままでは札にできないので、札にする欄で字数を出し、超えたら作れないようにした
2. **地図は直近90日だけ。** JPモルガンの融資の日付を2025年9月にすると、札にはなるが地図には出ない。日付を入れたとき「地図に出る／出ない」を1行出す
3. **自分で作った札は、今のままだと読む回の未読に選ばれ、AI が推定を書き込む。** 自分で掘ったものと AI の読みが1枚に混ざるので、読む回の枠から除く
4. JPモルガンは主体の一覧に無い。札にすると主体は足されるが、国が分からないので**地図では「場所不明」に入る見込み**。主体の画面の「国」から直せる（今ある機能）

## url を開いて確かめる仕組み

- ［url を開く］を押すまで［書いてあった］を押せない。［書いてあった］を押すまで［札を作る］を押せない。url を書き換えたら開く前に戻る
- ［開けなかった・書いてなかった］は、その url を記録に残して欄を空にする（件は消さない）
- アプリは url を取りに行かない（ほかのサイトの中身は読めない。読めても「書いてあったか」は人が決める）
