# v20.88 記事づくりの「3. 図」を消す

2026-09-23 のチャットの依頼（指示書なし）：「図は文章から自分で作っているので、要るか。要らなければ消す」。

## 何をしたか

記事づくりの往復から「3. 図」を消した。流れは 1. 企画 → 2. 本文 → 3. 確かめ → できあがり の3往復になった。確かめは、本文を取り込めばすぐ進める。

## 結果

- チャットとの往復が1回減った（図の依頼文と、返ってきた JSON を貼る手間がなくなった）。
- できあがりから「図N をコピー」のボタンが消えた。サムネのコピーは残した。
- 本文の中の「［図N：型・何を見せるか］」の印は残した。どこに・何の図を作るかは、これまでどおり本文に出る（v20.87 の「先に見せる図」の決まりもそのまま）。
- 試しの記事で、本文 → 確かめ → 取り込む → できあがり まで押して通った。エラー0。

## 意味

図の往復は、画像生成AIに渡すプロンプトとグラフの数値を作らせるためのものだった。本人は本文の印を見て図を自分で作っているので、使われていなかった。確かめで「図の数値が本文と合っているか」を見る点検は、図の往復の返事が無いと働かないので一緒に外した。

## 残り

- すでに図を取り込んだ記事の図の記録は消していない（画面に出ないだけ）。
- 図の印の書き方（何を見せるか）が作るのに足りないと感じたら、本文の依頼文で印の中身を詳しくする。
