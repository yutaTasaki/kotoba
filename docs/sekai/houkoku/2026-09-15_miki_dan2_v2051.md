## 先に：結果

- **段2を実装した。** 本人が割り直した本物の幹（11本）が入った実データの写しで、取り込みから幹を立てるまで押して通した
- 公開したら使えるようになること

  - 世界の画面の一番上に「今日動いた幹」。今日見るべき件はその幹の下に入る

- **朝のプロンプトは約1,470字長くなる**（幹13本のとき。11本なら約1,330字。候補の節が入る日はさらに約560字、推測）

## 2. 作ったもの

### 2.1 朝の取り込みのプロンプト（初期投入には付けない）

| 足した節 | いつ | 字数（実測・幹13本） |
|---|---|---|
| ■ どの幹の枝か（miki） | 幹が1本以上あれば毎回 | 242 |
| ■ 出発点を探す幹（1本） | 出発点の記録（見つけた・見つからない）が無い幹があるとき | 297 |
| ■ 幹（末尾の一覧、名前と1行） | 毎回 | 846 |
| 出力形式の `"miki":[]`, `"mikiMore":null` と決まりの行 | 毎回 | 83 |
| ■ 新しい幹の候補（mikiNew）と札の一覧 | 幹に入らない札が3枚たまった日だけ | 約560（3枚のとき、推測） |

- 幹の今の答え・主な主体・枝の番号は渡さない（仕様どおり）
- 取り込む画面の［プロンプトをコピー］で実際にコピーした文にも、幹の規則・出発点・幹13本の一覧が入っていた

### 2.2 取り込み

| 返事 | どうするか |
|---|---|
| `miki`（幹の番号 0〜2） | 札ごとに「ぶら下げた」記録を書く。知らない番号は付けずに数える。3本目以降は外して数える |
| `miki` が書かれていない札 | 何も書かない（「入らない」とは数えない） |
| `mikiMore` | 数えるだけ |
| `startOf` | その幹の出発点として記録し、札をその幹に付ける。**出発点がもう決まっていた幹なら、その札はふつうの枝にする** |
| `startNone` | 「見つからない」と理由つきで記録（次から、その幹は探さない） |
| `mikiNew` | 候補として記録。`#番号` はこの取り込みの札に直す。知らない札・名前の無い候補は外して数える |
| 候補の節を載せたのに `mikiNew` が無い | 「候補の報告なし」と出し、たまった数は数え直す |
| 今日見るべき件が出発点の札を指す | 外して数える |

### 2.3 取り込みの結果の1行（例は手元の試しで実際に出たもの）

```
幹に付いた枝：ホルムズが詰まる +2・紅海の出口が握られる +1　／　どの幹にも入らない 2枚（たまった 2枚。あと 1枚で候補を聞きます）。
3本目を付けたかった 1枚。　※ 幹の番号が見つからない 1件（付けていません）。　※ 3本目以降 1件は外しました。
出発点が見つからない：紅海の出口が握られる（紅海の始まりが一つの出来事に絞れない）。
※ 出発点がもう決まっていた幹 1件（その札はふつうの枝にしました）。　※ 出発点の札 1件は今日見るべき件から外しました。
```

### 2.4 取り込む画面（結果の下）

- **新しい幹の候補 N件 ▸**：候補ごとに、理由・入る札・名前と1行の欄（チャットの文が入っていて打ち直せる）・［この幹を立てる］
- **この回の札から幹を立てる（9/15 の取り込み・N枚）▸**：札ごとに今の幹と［この札から幹を立てる］→ 名前と1行（空）→ 両方入るまで［立てる］は押せない
- どちらも、取り込みの結果の文が消えたあとも、取り込む画面を開けば出る（直近の取り込みの分）
- 立てた幹は、札にまだ2本付いていなければ枝として付ける。2本付いていた札には付けず、そう出す

### 2.5 世界の画面の一番上

```
今日動いた幹（今日の取り込み）
  ホルムズが詰まる　枝 +5
    今日見るべき件：［詰まり］オマーンが…　なぜ：…
  資源国が売り方を国が握る　枝 +3
  …
幹に入らない今日見るべき件
  今日見るべき件：［逃げ］トルコが…　なぜ：…
幹 13本 ▸
```

- 幹の行を押すと幹の画面、今日見るべき件の行を押すとその札が開く
- 取り込みが無い日は、最後に取り込んだ日の分を日付つきで出す
- 今日見るべき件が0件の回は「見るべき件は選ばれませんでした」
- 幹が1本も無いときは、今までの「今日見るべき件」の形のまま

### 2.6 読む回の切れた推定は12枚まで

- 余った枠を配る2回目で、切れた推定には回さないようにした
- 手元の実データで：切れた推定12・未読7（前は未読が少ないと切れた推定が20枚になった）
- 読む欄の説明に「切れた推定は12枚まで」と出す

| 確かめ | 結果 |

| 朝のプロンプト | 規則・出発点を探す幹1本・末尾の幹一覧・出力形式の行が入った。幹に入らない札が0枚のうちは候補の節が無い |
| 取り込み（**本物のクリック**）：幹1本・3本・入らない・知らない番号・書いていない・出発点（2回目）・見つからない | 2.3 の1行のとおり。3本は2本だけ付き、知らない番号は付かず、書いていない札には記録なし、2回目の出発点はふつうの枝 |
| 出発点が決まった幹 | 次のプロンプトから、まだ決まっていない幹に移った |
| 入らない札が3枚たまる | 次のプロンプトに候補の節（3枚の一覧）と出力形式の mikiNew が入った |
| 候補を返した取り込み（1件は壊れた候補） | 候補1件を記録、壊れた候補2件を外した、たまった数は0に戻った |

| ［この札から幹を立てる］→ 名前だけ**打つ** | ［立てる］は押せないまま。1行も打つと押せた |
| ［立てる］を**押す** | 幹が立ち、その札に2本目として付いた |
| 世界の画面の一番上 | 今日動いた幹、その下に今日見るべき件、幹に入らない件は下にまとめて出た |
| 今日見るべき件の行・幹の行を**押す** | 札が開いた（「幹：ホルムズが詰まる ▸」つき）・幹の画面に移った |
| 読む回の枠 | 切れた推定12・未読7 |
| **前の版（v20.50）の端末**で月ファイルを書き直す | 段2で足した記録（出発点・候補・候補を聞いた記録を含む186件）は全部残った |
| 2台目で同期 | 同じ幹13本、同じ「今日動いた幹」 |
| ページのエラー | 0件 |

**確かめの途中で見つけて直したもの**
- **割り直しで幹0本になった札まで「幹に入らない札」に数えていて、最初の取り込みの前から候補の節が載っていた（24枚）** → 朝の取り込みで「入らない」と返った札だけを数えるようにした
- 同じ札に何度も記録が書かれた日（候補から立てたあと、同じ札から別の幹を立てた）に、「枝 +4」と重ねて数えていた → 札を1枚ずつ、今の幹で数えるようにした
- 今日見るべき件が0件の回に何も出なかった → 「選ばれませんでした」と出すようにした

## 4. 仕様書から変えたところ

| 仕様書 | 変えたこと | 理由 |
|---|---|---|
| 出発点（4.1） | 段3 → **段2** に入れた（回答の3-1。すでに仕様書に書いた） | 切れた推定の直しと並行させるため |
| 幹に入らない札の数え方 | 朝の取り込みで「入らない」と返った札だけ（割り直しの幹0本は数えない） | 3の1つ目。数えると、最初から候補が出続ける |
| 候補を聞いた回の数え直し | 候補を返した取り込みの札も「聞いた」側に数える（その回の入らない札は、次のたまりに入らない） | 同じ取り込みの札を、次の回にもう一度候補へ出さないため |
| 出発点の数 | 「1日1本」ではなく「取り込み1回に1本」（すでに仕様書に書いた） | 1日に何回か取り込むと早く揃う |

## 5. 公開の前に（実機で確かめてほしいこと）

**触ると壊れる形を先に並べる。**

1. 朝の取り込みを1回流す → 結果の1行に「幹に付いた枝：…」が出る。Claude の返事に `"miki"` が入っているか（入っていなければ「幹の報告なし」と出る）
2. 世界の画面の一番上に「今日動いた幹」→ **幹の行を指で押す** → 幹の画面。**今日見るべき件の行を押す** → 札が開く
3. 取り込む画面の「この回の札から幹を立てる ▸」→［この札から幹を立てる］→ **iPhone で名前と1行を日本語で打つ**（変換中に消えないか）→［立てる］。試しに立てた幹は、そのまま残る（外すボタンは幹の画面にはまだ無い。消したい場合は設定の［切り方を直す］で［外す］→［この切り方で決める］。そのあと「まだ段B を通していません」と出るが、段B をやり直さなくても外した幹は一覧から消える）
4. 結果の1行に「出発点：…」が出る日、その札が今日見るべき件に出ていないこと
5. 入らない札が3枚たまった次の朝、Claude の返事に `"mikiNew"` が入り、取り込む画面に「新しい幹の候補 ▸」が出るか（出るまで数日かかる。**公開を止める理由にしない**）
6. 読む回の欄に「切れた推定は12枚まで」と出て、1回が12枚を超えない
7. **もう片方の端末で同期して**、同じ「今日動いた幹」が見える

見た目：iPhone の幅で、今日動いた幹の行と、その下の今日見るべき件の字下げが崩れないか。

**戻すとき**：v20.51 のコミットを取り消して送り出す。段2の記録（枝・出発点・候補）は調べたことの月ファイルに残り、v20.50 は読まないだけで消さない（3の古い版の確かめのとおり）。v20.50 に戻ると、朝のプロンプトから幹の節が消えるので、その間に取り込んだ札には幹が付かない。
