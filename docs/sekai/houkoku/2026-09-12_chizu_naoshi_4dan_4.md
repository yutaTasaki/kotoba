# 第4段：何が動いたかで分ける

## 0. 何をして、どうなったか

**したこと**：地図の地域ボタンの下に、**何が動いたかで絞るボタン**を足した。
全部・お金・物と人・原油と石油・約束の5つで、**押す前に何本あるかが見える**。

**結果**：あなたの札（第1段を入れた後、地図に出る64本）で数えると次のとおり。

| ボタン | 本数 |
|---|---|
| 全部 | 64 |
| お金 | 46 |
| 物・人 | 18 |
| **原油・石油** | **9** |
| 約束 | 2 |

品目の内訳は 原油・石油9・金貴金属8・半導体2・武器装備2・天然ガスLNG1・レアアース1 で、
**残る41本は品目なし**（お金の動きが大半なので当然）。

**意味**：地図が「お金の地図」から「**何が、どこへ動いたかの地図**」になる。
「原油・石油」を押せば、石油の流れだけが9本残る。

### 約束について、正直に

**この段でいちばん弱いのはここ。** いま約束と判定できたのは**2本だけ**で、しかも
きっかけだった **NATO の「100億ドル超を配分」は入っていない**（その札は場所不明に落ちているか、
90日の窓の外にある）。拾えたのは「国内投資に振り向ける資本の表明」と「軍事装備・支援・訓練」の2本。

つまり **NATO の配分と実際の35億ドルが地図の上で分かれるところは、まだ見られない。**
これは、これまでの札に約束の印が無く、文面から拾うしかないため。
**朝のプロンプトに1行足したので、これからの札は生成が直接書く。** そこから実際に効き始める。

**残り**：4段すべて完了。後回しにしたのは線の太さ（単位ごと）と国内の案内。

## 1. 決めたこと

| 決めたこと | 中身 | なぜ |
|---|---|---|
| 人のボタン | **作らない**。物と一緒にした（「物・人」） | 人は2本しかなく、独立させると空振りになる |
| 物の1本目 | **原油・石油** | 品目が付いた23本のうち9本で最多。ここだけで物の流れの大半が片付く（質問フェーズでは「物13本のうち9本」と書いたが、第1段で場所不明から10本が地図に乗ったため、いまは物・人18本・品目つき23本が正しい） |
| 武器・穀物 | **作らない**（語の表には持つが、ボタンにしない） | いまのデータに1件も無い |
| 約束の見せ方 | **薄い線＋白抜きの矢印**（相談のうえ） | 破線はすでに「累計・期間あたり」で使っている。重ねると見分けがつかなくなる |
| 0本のボタン | **押せなくする** | 押しても何も起きないものを作らない |

### 約束の印について

指示書は「破線にする」だったが、**破線はすでに使われていた**（累計・期間あたりの金額）。
そのまま重ねると、累計と約束が区別できなくなる。相談のうえ、**薄さと白抜きの矢印**で分けた。
この形なら「累計かつ約束」は薄い破線になり、**両方の意味が残る**。

## 2. これまでの札でも効くようにした

品目も約束も、これから生成が書く欄（`item`・`pledge`）だが、**すでにある札には入っていない**。
生成待ちにすると、ボタンを押しても0本という状態が当分続く。
そこで、**書かれていない札は文面から拾う**ようにした（`what` と `fact` を見る）。
これであなたの13本の物の動きと NATO の札に、その日から効く。

朝のプロンプトにも1行足したので、**新しい札は生成が直接書く**。書かれていればそちらを優先する。

## 3. 途中で見つけた自分の間違い

最初の語の表で、実データを通したら**3件が誤って分類された**。

| 文面 | 誤り | 原因 |
|---|---|---|
| 送金者の移動 | 金・貴金属 | 「金」1字が**送金**の中に当たった |
| 装備の購入資金 | 金・貴金属 | 同じく**資金**に当たった（正しくは武器・装備） |
| 半導体用ガスの輸出 | 天然ガス・LNG | 「ガス」が半導体より先に試されていた |

直し方：**1字の語をそのまま使うのをやめ**（「金地金」「金の買い入れ」「金市場」のような形でだけ当てる）、
**長くて具体的な語から先に試す**（半導体をガスより前に置く）。
直したあと、同じ11件で 送金・拠出は品目なし、装備は武器・装備、半導体用ガスは半導体、
「金の買い入れ」は金・貴金属、生成が書いた `item:原油` は原油・石油、と正しく出ることを確かめた。
