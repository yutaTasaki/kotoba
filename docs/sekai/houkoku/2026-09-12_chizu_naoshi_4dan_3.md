# 第3段：市場の中身を見えるようにする

## 0. 何をして、どうなったか

**したこと**：地図の下の「市場」の枠を押すと、これまでは札の一覧が出るだけだった。
**市場の網**が開くようにした。市場の名前が点になり、上の帯に「市場に入れる側」、下の帯に「市場から出す側」が並ぶ。

**結果**：これまで「市場」の一言に丸められて消えていた**誰と誰の取引か**が見えるようになった。
あなたの札では、市場の枠に**11種類**が入っていた（国債市場3・為替市場2・株式市場2・石油市場1・金市場1、
および海外の買い手・欧州アジアの買い手・株主・データセンターの買い手・海外投資家など）。

**意味**：「金市場」を押せば、その裏にいる中国人民銀行と金を売った相手が並ぶ。
枠に丸めても**元の名前は札に残っていた**ので、拾い直せた。

**残り**：第4段（何が動いたかで分ける）。

## 1. 決めたこと（相談のうえ）

**枠は3つのまま。市場を押して開く網の中で、本物の市場と受け皿を分ける。**

幅320のとき、枠を4つに増やすと1枠75px・名前7字までに潰れ、「データセンターの買い手」が読めなくなる
（いまは1枠101px・10字）。枠を増やさずに中身を分ける方が、狭い画面で名前が生き残る。

**分け方**：名前に「市場」が入っていれば本物の市場、入っていなければ受け皿（買い手・株主・投資家）。
あなたのデータにそのまま当てはまる素直な決め方で、語の一覧を新しく作らずに済む。
網では**本物の市場が先、受け皿が後ろ**に並ぶ。

## 2. 作りの要点

- 描くところは**国の網をそのまま使った**（点の並べ方・矢印・拡大縮小・押したときの動き）
- 国の網は「国の中の動き」を内側の矢印にするが、市場には「市場どうしの動き」が無いので内側の矢印は使わない。
  代わりに**上下の帯＝入れる側・出す側**が、そのまま「出し手 → 市場 → 受け手」になる
- 相手の国の札を押すと、**その国の網へ移る**（国の網と同じ動き）
- 市場の網から国の網へ移るとき、市場の状態を消している（消し忘れると、国の網が市場の見出しのまま出る）
