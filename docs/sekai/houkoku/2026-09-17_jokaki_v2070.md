# 報告：置き換わる数字を同じ札の中で上書きする（v20.70）の実装

- 指示：「取り込んだ情報が更新されている場合、同じ札を上書きし、過去の重要な情報は同じ札の中で比較できる形で残す仕組みを作ってほしい」
- 仕様書：`spec/sekai_jokaki.md`
- 版：v20.70（**手元の確かめまで。公開はまだ**。コミットは手元だけ）

---

## 1. 何ができたか

**`validTo`（v20.68）を持つ札に限り、上書きできるようになりました。**

- 朝のプロンプト末尾に「置き換わる数字」の一覧（`validTo` がある札）を渡す
- チャットが新しい回の値を見つけたら、新しい札にせず `"updates":"w_xxxxx"` でその札を指す
- 対象の札は**同じ id のまま**、事実・確度・出典・動き・`validTo` が新しい値に差し替わる
- **差し替える前の値は、その札の `history` に積まれて残ります。** 画面には「過去の値」として、なぜ の下・`validTo` の下に出ます

実際の事故（ガソリン補助）を模した試しで確認しました。

```
週1を取り込む：36.0円（〜9/16）
週2を取り込み、週1の番号を updates に指定：51.0円（〜9/30）

結果：新しい札は増えない。同じ札を開くと
　「試し9：ガソリン補助が1リットル51.0円になった」
　この数字は 9月30日までの分
　過去の値
　36.0円（〜9/16）
```

## 2. 分類（用語・アクター・地層・幹・見せ方）は書き換えない、と決めました

書き換えるのは**観測した値**（事実・理由・詳しく・出典・確度・動き・置き換わり期限）だけです。**用語・アクター・地層の値・幹の紐付け・効かせた相手・見せ方の印・非表示の状態・進んだ予告は、対象の札のものをそのまま残します。**

理由：新しい札を作るときと同じ深さの処理（用語・アクターの登録、地層への値の反映、幹の紐付け、見せ方の判定）を書き換えにも適用しようとすると、取り込みの本体（100行以上ある1件ずつのループ）に手を入れる範囲が大きくなり、ふだんの新規取り込みを壊す危険が増えます。**今回は「値の差し替え」に絞り、安全な範囲にとどめました。** 分類ごと更新したいケースが増えてきたら、改めて相談します。

## 3. `eventDate` は変えないと決めました

新しい回の値が来ても、**札の日付（世界タブでの並び順）は最初に分かった日のまま**です。日付を動かすと、月をまたいだときに月ファイルの引っ越し（削除して別の月に足す）が必要になり、作りが複雑になって壊れやすくなります。

**更新があったことは、日付ではなく「過去の値」を見れば分かります。**

## 4. 手元で確かめたこと

偽の GitHub に本物の kotoba-data の写しを置いて動かした。**本物の保存庫には何も書いていない。**

| 試した形 | 結果 |
|---|---|
| 週1（36.0円・`validTo`9/16）→ 週2（51.0円・`validTo`9/30・`updates`で週1を指定） | 新しい札は増えない。同じ id で内容が差し替わり、`history` に週1の内容が残る |
| `updates` が存在しない id を指す | 書き換えを諦め、**新しい札として入る**（内容を失わない） |
| `updates` が `validTo` の無い札を指す | 同上（新規の札になる） |
| 既存145枚 | 帯13・折れ線6・地図13・1行122/99/55・地図タブ51/28/9/47・エラー0、**すべて不変** |

途中、`history` を保存する normalize の処理が抜けていて、書き換え後に過去の値が消える不具合を見つけて直しました（`normalizeWorldEvent` が知らない欄は黙って捨てる作りだったため）。

## 5. 字数（実測）

候補（`validTo` を持つ札）が0件のとき、固定部分で**205字**。実データにはまだ `validTo` を持つ札が無いので、公開直後の増分はこの205字だけです。今後 `validTo` の札が増えるほど、1件あたり約60字ずつ伸びます。

## 6. 分かっている限界（正直に）

- 用語・アクター・地層・幹・見せ方の印は書き換えで更新しません（3節のとおり）
- `eventDate` は変わりません（4節のとおり）
- **すでに読んだ札は、書き換えても「未読」には戻りません。** 読む一覧の仕組みには触れていないので、気づかず読み逃す可能性があります。取り込みの結果の1行と「過去の値」が、いまのところの気づく手段です
