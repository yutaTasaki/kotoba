## 1. 流れ

1. 世界の画面で1つ選ぶ（段1）
2. ［語り方を集める依頼文をコピー］→「コピーしました。新しいチャットに貼ってください…」
3. 新しいチャットに貼る。返ってきた JSON を、選んだ枠の欄に貼る
   - **貼った文章は、取り込むまで端末に残る**（アプリを離れてページが読み直されても消えない。手元で読み直して確かめた）
4. ［語り方を取り込む］→ 結果の1行
   - 例：「取り込みました：媒体 6・動き 2・思惑 2（開けなかった媒体 2・見出しだけ 4）」
   - 立場が3つに足りない、持ち主や割れ方の書き方が決まりと違う、url の形が正しくない、切った欄、なども出る
5. 選んだ枠：問い・割れ方（芯の種類）・「語り方・思惑の全部は［札を開く］の中」
6. 札の画面（「自分で調べたこと」の上）：

```
語り方（9/17 に集めた・推測を含む）
問い　なぜ米国は「海峡は開いている」と言い続けるのか
割れ方　一部だけ（語りと動きのずれ） ─ 米国の媒体は長官の数字を見出しにし、カタールの媒体は…
芯　なる ─ …
┌媒体────┬国・持ち主──┬強調──┬書かなかった┬誰のせい┬言葉┐   ← 表だけ横に動く
動き　湾岸からの原油輸出は…［湾岸の産油国 → 世界の買い手 原油 日量約900万バレル］（出典）
思惑（推測）　← 推定と同じ黄色の点線
　米エネルギー省：…
　　根拠：… ／ 崩れる条件：… ／ 裏づける条件：…
仕組み　…
疑いの候補　① … ② … ③ …
```

## 2. 依頼文の中身（仕様書 2.2 のとおり）

- 渡すもの：札に元から書いてあったこと、ずれ、仕組みの1行、属する幹の名前と1行、同じ主体のほかの出来事での読み（主体ごとに新しい順で3つまで）
- 頼むこと：立場を3〜5つ・国と持ち主（右寄り左寄りは書かない）・開けなかった／見出しだけの印・強調／書かなかった／誰のせい／言葉・動き（語りの数字と一次資料を混ぜない）・割れ方と芯の3種類・思惑に根拠と崩れる条件と裏づける条件・問い・仕組み・疑い3つ・芯になりそうか
- 媒体の例として、9/17 の調査で開けた媒体の名前を並べた（TASS・新華社・IRNA・アルジャジーラ・Fox・NHK・産経・朝日など）
- 「今日は 2026-09-17 です。できるだけ新しい記事を」と日付を入れた

**気づいたこと**：同じ主体のほかの読みに、**60字で切れたままの古い読みが1件**混ざっていた（イラン政府の読み「…本国防空に回せる人と物を削ってで」）。依頼文の中では「前にチャットが推測したもの」として渡しているので害は小さいが、切れた推定を直す読む回が進めば消える。

## 3. 返事の試し（本物のチャットの代わり）

選んだ札「米エネルギー長官がホルムズ通過を日量1000万バレルとした」で、私が Web 検索を3回して返事の JSON を作った。

- 見つかった媒体：CNBC（米）・Bloomberg（米・中身は読めず）・アルジャジーラ（カタール）・The National（UAE）・Times of Israel（イスラエル）
- **イラン側の媒体（Tehran Times）は検索で出てこなかった**ので、開けなかったとして残した
- 記事の中まで開かず、検索結果の要約だけで作ったので、ほとんど「見出しだけ」
- 割れ方は「一部だけ・語りと動きのずれ」。米国の媒体は長官の数字を、カタールは追跡データとの食い違いを、イスラエルはイランの禁止区域を前に出していた

**これで分かったこと・分からないこと**
- 分かった：返事の形が取り込め、画面で読める。「米国は日量で語り、追跡データは隻数で4〜8隻」のように、語りと動きのずれは実際に拾える
- 分からない：**本物のチャット（Pro）が、対立する国の媒体まで実際に開けるか**。私の試しでは、検索でイランの媒体が上がってこなかった。次の実機で一番見てほしいところ
