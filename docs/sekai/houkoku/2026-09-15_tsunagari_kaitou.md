# 報告：3本目の記録が9枚→7件になった原因／①の仕様書

- 指示書：`shiji/sekai_tsunagari_kaitou.md`
- 書いた仕様書：`spec/sekai_tsunagari.md`（①だけ。②③は①の実機のあと）
- **コードもデータも変えていない。** 本物の kotoba-data は読むだけ（写しを最新にして、保存庫の履歴をさかのぼった）

---

## 先に：結論

1. **記録は消えていない。** 幹の記録は、保存庫の履歴23回分をさかのぼっても、一度書かれた167件が1件も消えず、1件も書き換わっていない（実測）
2. **「3本目を付けたかった 2件」は、たぶん別の数だった。** 結果の1行には、よく似た2つの数が並ぶ
   - 「3本目を付けたかった N**枚**」：チャットが3本目の欄に書いた幹。記録に残る
   - 「※ 3本目以降 N**件**は外しました」：チャットが幹の欄に3本以上書いたとき、3本目以降を**捨てた**数。**記録に残らない**
   - 控えの「2件」は後者の書き方で、データにも合う（下の1章）。**消えたのではなく、はじめから書いていない**。これは作りの穴
3. **同じ「数えるだけで捨てる」形は、ほかにもある**（2章）。ただし、いま表に出ている数字（枝112枚・葉33枚・またぐ枝13枚・3本目7件・根1件）は、書いた記録と一致していて信用してよい。信用できないのは「捨てた分がいくつあったか」だけ
4. 落ちた2件は、**アプリのデータからは戻せない**。その朝のチャットの返事が Claude のアプリの履歴に残っていれば、そこから分かる（3章）
5. 直し方と、3本目が付いた幹と同じ番号の穴の直し方は、①の仕様書に入れた（4章）
6. 線が引けない幹2本の1行案は5章

## 1. 原因

### 1.1 消えたかどうか（実測）

数えたもの：kotoba-data の `world/dig/2026-09.json`（幹の記録はこの1ファイルだけ）を、変更のあった23回のコミットすべてで開き、幹の記録を id ごとに前の回と比べた。

| 見たこと | 結果 |
|---|---|
| 一度あって、後の回で無くなった記録 | **0件** |
| 同じ id で中身が変わった記録 | **0件** |
| 朝の取り込みで書かれた「枝を付けた」記録 | 履歴全体で**6件**（すべて同じ1回の取り込み、9/15 に根が見つかった回）。6件とも3本目は空で、**書かれた最初から空** |
| いまの記録 | 167件（幹を立てた11・枝を付けた145・割り直し2・同じ出来事の組8・根1） |

→ 同期や上書きで消えたのではない。

### 1.2 その取り込みで何が起きたか

その回の6枚の記録（実測）

| 札 | 付いた幹 |
|---|---|
| 2020-10-08 米財務省がイランの金融部門を制裁対象に指定（根） | 制裁 |
| 米財務省が長期国債の買い戻しを3倍化 | **国債の買い手・政府の資金繰り（2本）** |
| 米エネルギー長官がホルムズ通過を日量1000万バレル | ホルムズ |
| カナダがウクライナに20億ドル超の支援 | なし（葉） |
| 8月の金ETFに180億ドル | **国債の買い手・制裁（2本）** |
| 米財務省がロシアのVTB銀行をイラン関連で制裁 | 制裁 |

コードを読んで確かめたこと
- 取り込みは、チャットの返事の札ごとに「幹の欄（miki）」と「3本目の欄（mikiMore）」を読む
- **3本目の欄**に書かれた幹は、数えて、記録にも書く。数えるのと書くのは同じ値なので、「数えたのに書かれない」は起きない
- **幹の欄**に3本以上書かれていたら、2本までを付け、残りを「3本目以降 N件は外しました」と数えて**捨てる**（記録に書かない）
- 手元の試しでも、幹の欄に3本書いた返事で「※ 3本目以降 1件は外しました」と出て、記録には2本しか残らないことを確かめている（段2の報告の手元の試し）

**見立て（推測。かなり強い）**
- 控えの「2件」は「件」で数えている。「3本目を付けたかった」は「枚」で出る。「件」で出るのは「3本目以降…外しました」の方
- 幹が2本の札がちょうど2枚ある（国債の買い戻し・金ETF）。チャットがこの2枚の幹の欄に3本ずつ書いた、と読むとぴったり合う
- 3本目の欄に書いてあったなら、記録に残っているはず（1.1 のとおり空）なので、こちらではない

**あわせて**：控えでは「国債の買い手 +1」だが、記録では国債の買い手に付いたのは2枚（+2）。結果の1行と記録は同じ一覧から作るので、画面には「+2」と出ていたはず。控えを書き写すときのずれと見ている（推測）。

**確定させる方法**：3章のとおり、その朝の返事の JSON を見れば分かる。

### 1.3 なぜ穴か

- 「3本目を付けたかった」と「3本目以降を外した」は、チャットの**同じ意図**（この札は3本目の幹にも掛かる）を、欄の書き間違いで分けているだけ
- 前者は残り、後者は数だけ出して捨てる。結果の1行も似た言葉で並ぶので、人が見て区別できない
- 仕様書（段1）は「3本目以降は外して数える」としていた。仕様どおりに作ったが、**仕様が捨てる側に倒れていた**

## 2. 同じ形で落ちうる記録（コードを全部の入口で読んだ）

「数えて結果の1行に出すだけで、記録に残さない」所を並べた。

| 記録 | 入口 | 捨てるもの | 結果の1行に出るか |
|---|---|---|---|
| 枝を付けた | 朝の取り込み | ① 幹の欄の3本目以降 | 出る（「3本目以降 N件は外しました」）← **今回の2件** |
| 〃 | 〃 | ② 知らない幹の番号（幹の欄・3本目の欄とも） | 出る（「幹の番号が見つからない N件」） |
| 〃 | 〃 | ③ 3本目の欄が文字でない（配列など） | **出ない**（黙って空） |
| 〃 | 〃 | ④ 3本目が、付けた幹と同じ番号 | 捨てずに**そのまま3本目として残り、数にも入る**（前回見つけた穴） |
| 〃 | 割り直し | ①②と同じ | 出る。3本目は1回目の分だけ枝の記録に写す（2回目の分は割り直しの記録に残っている） |
| 〃 | 読む回（幹がまだの札に付ける） | ⑤ 3本以上書かれた幹を**黙って2本に切る**／知らない幹を黙って落とす | **出ない** |
| 根 | 朝の取り込み | 知らない幹の番号、すでに根がある幹（その札はふつうの枝になる） | 出る |
| 芽（候補） | 朝の取り込み | 知らない札・名前の無い候補 | 出る |
| 答え | 読む回 | 出口・基準が決まりに無い答え、文が空の答え | 出る（「読めない答え N つ」）。**150字を超えて落とした文は記録に残る**（こちらは捨てない） |
| まだ分からないこと | 読む回 | 知らない幹・空の文・知らない番号を閉じる | 出る |

**いまの数字への影響（実測）**
- 答え・まだ分からないこと・芽の記録は、本物のデータにまだ1件も無い。捨てた分も0
- 根は1件。その回に根で捨てた分があったかは、控えに出ていないので**測れません**（捨てた分があっても、立っていない根が1本増えるだけで、今ある数字は変わらない）
- 読む回で幹を付けた記録（⑤）は0件。まだ起きていない
- 割り直しの①②：段2の実機の控えにその数は無い。割り直しの記録は切った後の値なので、切ったかどうかは**測れません**。ただし割り直しの枝は2回の返事の共通だけを付けるので、3本目以降が1回だけに出ていても枝の数には効かない
- ④に当たる記録は1件（サウジの保険プール。3本目が付けた幹と同じ「紅海」）

→ **分かっている範囲で捨てたのは、朝の取り込み1回の「3本目以降」2件**（割り直しの分は測れない）。枝・根・葉・またぐ枝の数は書いた記録どおり。

**同期で消える道**：記録の月ファイルは id ごとに足し合わせ、中身は丸ごと写す。23回分で消えた記録0件（1.1）。この道で消えた跡は無い。2台が同時に書いた時の抜けは、履歴に残らない端末の中の分だけは**測れません**。

## 3. 落ちた2件は戻せるか

- **アプリのデータからは戻せない。** チャットの返事の JSON は保存していない（札と記録にしてから捨てている）
- **戻せる道が1つある**：Claude のアプリで、その朝の取り込みの会話（根に「2020-10-08 米財務省のイラン金融部門への制裁指定」が入った回）が残っていれば、返事の JSON に、国債の買い戻しと金ETF の札の `"miki"` が3本ずつ書かれているかが見える
  - 3本あれば、見立てが確定し、3本目がどの幹かも分かる
  - 返事の JSON をここに貼ってもらえれば、読んで確かめる。**本物のデータに3本目を書き足すのは、その結果を見てから、改めて聞く**
- 戻さなくても、①の直しが入れば、次の取り込みからは残る

## 4. 直し方（①の仕様書に入れた）

詳しくは `spec/sekai_tsunagari.md` の2章。要点：

| 穴 | 直し方 | 失うもの |
|---|---|---|
| ① 幹の欄の3本目以降を捨てる | 3本目の欄が空なら、幹の欄の3本目を**3本目として残す**（「幹の欄から移した」印つき）。4本目以降と、3本目の欄にもう書いてあった分は、枝の記録に**控えとして残す**（付けはしない） | チャットの書き間違いと本当の3本目が、印でしか分けられない。記録が1件あたり数十字増える |
| ② 知らない幹の番号 | 枝の記録に控えとして残す（書かれた文字のまま、40字まで） | 同上 |
| ③ 3本目の欄が配列など | 最初の読める番号を3本目とし、読めなければ「読めない3本目」と数えて控えに残す | なし |
| ④ 3本目が付けた幹と同じ番号 | 3本目にしない・数えない。控えに「同じ番号」と残す。**すでにある1件（保険プール）も、読むときに同じ扱い**にする（記録は書き換えない） | なし |
| ⑤ 読む回で黙って切る | 朝の取り込みと同じ扱いにし、結果の1行に数を出す | なし |
| 結果の1行が紛らわしい | 「3本目を付けたかった N枚（うち幹の欄から移した M枚）」の1つにまとめ、「外しました」の言い方をやめる。4本目以降は「※ 4本目以降 N件は控えに残しました」 | なし |

**隣の幹（③）の材料について**：指示のとおり、この直しが入り、次の取り込みで数が合うことを見るまで、3本目の数を判断材料に使わない。

## 5. 線が引けない幹2本で、地図の代わりに何を出すか（1行案）

**地図の枠は出さず、同じ場所に「地図にならない理由」を1行だけ出す。**
- エネルギー高：「地図にできる動きがありません（枝8枚とも、誰から誰へのお金の動きが書かれていない）」
- 紅海：「線にできる動きがありません（動き6件：確度が低い2・場所が決まらない1・同じ地域の中1・国の中だけ2）」

失うもの：地図の画面の中で「この幹は動きが見えていない」ことに気づく場所が、1行の文字だけになる。紅海は国の中の点が2つ（イエメン・サウジ）あるので、点だけの小さな地図を出すかは②の相談で決める。
