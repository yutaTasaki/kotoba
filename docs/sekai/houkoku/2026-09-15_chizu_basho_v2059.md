## 1. 規則を直したあと、今ある145枚はどうなるか（指示書の3への答え）

| 問い | 答え |
|---|---|
| 埋め直すのか、新しい札からだけ効くのか | **新しく取り込む札からだけ効く。** 今ある145枚の記録は、埋め直さない限りそのまま |
| 埋め直すなら、29,995字を2回か | 全部を埋め直すなら、規則が110字長くなったので **約30,105字（計算）で30,000字を超える**。［前半だけ］［後半だけ］に分けて貼る形になる（2回×2つ） |
| 落ちた見込みの札だけ選べるか | **今の画面では選べない**（埋める札は「記録が無い札」だけ）。選ぶなら次の2つの決め方があるが、どちらも日銀の札を確実には拾えない。**「線が1本も無い札（約100枚、推測）を埋め直す」なら日銀も入り、約21,000字×2（推測）で分けずに貼れる** |
| 選び方の実測 | 「なぜ に、主体と今の線に無い国の名前が出る札」38枚＋「片方だけの組がある札」11枚＝重なりを除いて43枚（約9,300字×2）。**ただし日銀の札は入らない**（なぜ の文が「米財務長官」で、国の名前「米国」が出てこないため） |
| 埋め直したとき、今の記録はどうなるか | 札ごとに新しい記録を**足す**。画面は札ごとに一番新しい記録を使うので、見た目は**上書き**になる。前の記録は消さずに残る（月ファイルが札1枚あたり約250字増える、推測） |
| 場所の表の穴を塞げば、埋め直さなくても控えから線になる組はあるか | **ある。4組**（安保理の停戦決議に反対・決議2803 の「米国 → 国連安保理」各1、BRICS 宣言の「インド → BRICS」「中国 → BRICS」）。2回とも同じ組だったので、比べ直しで線になった（v20.59 を開いたときに入れた）。「米国 → 国際刑事裁判所」は、同じ札の「米国 → NATO」と同じ国際機関の箱になるので、2本目にはならなかった |

**勧め**：埋め直すなら「線が1本も無い札だけ」を選べる形を足してから（小さな直し）。数日、朝の取り込みで新しい規則の返事を見て、日銀のような手が書かれるようになったのを確かめてからでよい。

### 2.5 国の中の動きの1行

### 2.6 埋めた返事を残さない

- これから埋めるときは、返事2回分の記録を書かず、札ごとの記録にも返事の写しを書かない。朝の取り込みも、場所を決められたときは返事の写しを書かない
- すでにある返事の記録は、v20.59 を開いたときに1回だけ、今の場所の表で比べ直し → 線が変わった札の記録と比べた結果を足し → 返事の記録に消した印

## 4. 確かめの途中で気づいたこと

- **イラン → ホルムズ海峡のように、国と海峡がすぐ近いと、線がとても短く、手の言葉が国の点に重なる**（試しのページの見た目）。世界全体の地図の大きさのままでは、今は直していない。後の相談（関わる国だけが大きく見える範囲に切る）で扱える
- 「札を作る・読む」の言葉と、画面の文に入っているチャットが書いた文（確度の理由など）の中の「札」は、変えていない
