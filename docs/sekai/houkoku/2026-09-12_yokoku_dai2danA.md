# 予告 第2段A：答え合わせ（押せるようにするまで）

## 0. 何をして、どうなったか

**したこと**：期限が来た予告を朝のプロンプトに渡し、生成に**当たりらしさの候補と根拠1行**を書かせて取り込む。
世界タブに**予告の画面**を作り、そこで**あなたが押して結果を確定する**ようにした。

**結果**：取り込んだだけでは結果が変わらない。**押して初めて変わる**。

**意味**：「思惑 → 予告 → 答え合わせ」が一周した。外れた予告は、次の段で読む回に戻せる。

**残り**：第2段B（外れたら読む回に戻す・朝タブを1行に・捨てるときに予告も捨てる）。

## 1. いちばん守りたかった境目

**取り込みでは結果を動かさない。**

生成が「当たり」と書いてきても、入るのは次の4つだけ。

- 生成の見立て（当たり／外れ／確かめられない のどれを推すか）
- 根拠1行
- 判定に使った数字（系列・基準日・そのときの値・**読み取った日時**）
- 判定を取り込んだ日時

**結果は「まだ」のまま。** 人が押して初めて変わる。
生成の見立てと人の判断を**別の項目**にしたので、後から「これは誰が決めたのか」が辿れる。

読み取った日時は**端末が入れる**。生成に書かせると、生成が名乗った時刻になってしまうため。

## 2. 押す画面

世界タブに入口を1つ置いた。期限が来たものがあるときは「**予告 ・ 期限が来たもの 1本 ▸**」と本数を出し、色を変える。
0本でも入口は出す（出さないと、最初の1本が入るまで画面に辿り着けない）。

画面は4つに分かれる。

| 区分 | 押せるか |
|---|---|
| 期限が来た（押して確定してください） | **押せる** |
| 待っている | 押せない（期限前） |
| 押したもの | **押せる**（押し直して変えられる） |
| 畳んだもの | 押せない |

- **根拠1行は、ボタンより上**に出す（押す前に必ず読ませる）
- 「取り消し」は作らない。**別のボタンを押せば変わる**
- 「確かめられない」を**3回**押すと畳む。畳んだものは**消さない**が、当たり率の分母に入れない
- 畳んだものが5本を超えたら「印の立て方を見直す時期です」と1行出す

## 3. 当たり率

予告の画面の一番上。**分母は当たり＋外れだけ**（確かめられない・まだ・畳んだものは入れない）。

**10件そろうまで割合を出さない。** いまは「当たり 1・外れ 0・確かめられない 0・まだ 2（当たりと外れが10件そろうまで、割合は出しません）」と出る。

## 4. 読む回のプロンプトにも手を入れた

印に使える系列を名指しした。ただし**「この3つしか使うな」とは書いていない**。

```
数字で確かめられるのは、いまのところ次の3つだけ：
  米国の政府債務総額／米国 上位0.1%の富の割合／米国 下半分の富の割合
それ以外は「公表そのもの」を印にしてよい。公表を印にするのは有効。
```

実際に入った5本はほとんど公表を印にしており、それは有効な立て方だから。

## 5. 確かめたこと（実機・6項目）

| # | 見たもの | 結果 |
|---|---|---|
| 1 | 期限切れが朝のプロンプトに出るか | 0本なら**節ごと出ない**（16,654字）。2本で節と `verify` の書き方が出る（17,244字） |
| 2 | 取り込み直後、結果が「まだ」のままか | **「まだ」のまま**。候補・根拠・数字だけ入った |
| 3 | 押すと付き、別を押すと変わるか | 当たり→外れに変わり、押した日時も更新。確かめられない3回目で畳まれた |
| 4 | 根拠1行が押す前に見えるか | **ボタンより上**に出ている |
| 5 | 期限前のものも含めて全部出るか | 4区分すべて表示（期限が来た1・待っている1・押したもの1・畳んだもの1） |
| 6 | 当たり率が件数だけで出るか | 件数だけ。割合は出ない（10件未満） |

あわせて：

- **期限前と畳んだ行にはボタンが無い**（押せるのは2行だけ）＝押しても何も起きないものは無い
- 取り込みで落としたものは理由ごとに数が出る（端末に無い1本・3値でない判定1本）
- 幅360・320で**はみ出しなし**
- 第1段は壊れていない（ホームの「待っている予告」は従来どおり）

**字数の増え方**：期限切れ2本で590字（約3.5%）。見積もり（5本450字・3%）とほぼ一致。
