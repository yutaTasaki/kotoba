## 2. 読む回が「切れた推定20」になった件

### 2.1 作りどおりか

**作りどおり。** 読む回の20枚は2回に分けて配っている。

1. **1回目**：種類ごとの枠まで取る（外れた札3・切れた推定12・浅い読み5。未読は残り全部）
2. **2回目**：余った枠を「未読 → 浅い読み → 切れた推定 → 外れた札」の順に回す

未読が0枚で浅い読みも少ないと、2回目の余りが全部「切れた推定」に回り、20枚になる。段0で12枚にしたのは1回目の枠で、2回目の余りは止めていなかった。前の報告で「1回12枚」とだけ書いたのは言葉が足りなかった。

### 2.2 12枚を上限にできるか

**できる。**
- 直すところ：読む枠の配り方の2回目で、「切れた推定」には余りを回さないようにする
- 数字は今と同じ「読む枠の配分」の定数（`WORLD_READ_QUOTA` の cut：12）1か所。これを「枠」でなく「上限」として扱う
- 回ってこなかった余りは、そのまま空ける（その回は20枚より少なくなる）

### 2.3 失うもの

- **切れた推定を直し終えるまでの読む回が増える。** 残り90枚なら、1回20枚で約5回のところ、12枚で約8回（推測。新しい札が来なければ）
- 段3を始める条件（中心の札の切れた推定が0枚）までは、中心の札を先に直すので影響は小さい。段1の試しでは中心の札24枚 → 12枚ずつで2回（1回20枚でも2回）
- 読む回の文が短くなる（切れた推定1枚あたり約650字。20枚 → 12枚で約5,000字短い見込み）。これは得

### 2.4 いつ直すか

指示書のとおり**段2（v20.51）に混ぜる**。それまでは、未読が少ない日は20枚になる。重いときは、貼る前にそのまま閉じてよい（コピーしただけでは何も変わらない）。
