# 画面の数字に短い説明を足す（質問フェーズ）：置き場所・表から作れるか・説明のない数字の一覧

日付：2026-09-13　元の指示書：`shiji/shiji_setsumei_2026-09-13.md`　起点：v20.25
**実装なし・仕様書なし。** 質問への答えと推奨だけ。

## 何をしたか

- 世界タブ（朝の行・世界の画面・地図・網・お金の一覧・札・概念の一覧・予告・問い・取り込み）で、**数字を画面に出している所をコードから全部拾った**（63か所 → 画面に出る種類として47）
- それぞれ「何を数えているか」「ラベルの言葉だけで分かるか」「近くに説明があるか」を読んで分けた
- 説明の元になる判定の表（使い道・種類の絞り・約束・一般名・外貨建て）を読み、表から説明を作れるかを確かめた

## 結果（先に結論）

1. **置き場所：選んでいる絞りの説明を、ボタンの列のすぐ下に1行だけ出す**のが一番安い。押す場所を増やさず、画面が伸びるのは1行分。地図の下の件数（「・」の前で…など）は、**名前を変える＋押して開いた一覧の頭に説明**。0件で押せないものの説明は、画面の一番下の「数字の見方 ▸」に全部まとめる
2. **表から作れる。ただし半分だけ。** 「どの言葉で拾うか」は表から自動で作れる。「何を拾いたいのか」という定義の一文（「相手に払う金ではなく、自分の側に積む金」）は言葉の並びからは作れないので、**表の同じ行に1文を持たせる**。これで表を直すときに説明も目に入る
3. **説明のない数字：47種類のうち、言葉だけでは分からないものが15、名前を変えれば分かるものが8。** 一覧は下の表
4. **一度に全部やるのには反対。** 今日決めた決まりで数えている数字（第2段で作ったもの中心）の9つを先にやる。名前を変えるだけで済むものは、説明を足さずに名前を変える

## 1. どこに置くのが安いか

### 推奨

| 数字の種類 | 置き方 | 例 |
|---|---|---|
| **絞りのボタン**（地図の種類・地域、お金の一覧の使い道） | **いま選んでいるボタンの説明を、ボタンの列のすぐ下に1行**。選び直すと変わる。「全部」を選んでいる間は出さない | 「自分に使う」を選ぶと：`相手に払う金ではなく、自分の側に積む金。設備・自社株・注入・買収・投資の5つ。` |
| **押すと一覧が開く件数**（地図の下の場所不明・「・」・推し量った・外貨建て、候補） | **名前を分かる言葉に変える**＋**開いた一覧の見出しのすぐ下に1行の説明** | 押す → 一覧の頭に `「株主」「取得先」のように名前だけでは国が分からない側を、もう片方と同じ国とみなしたもの。` |
| 0件で押せないもの・上の2つに当てはまらないもの | 画面の一番下に「**数字の見方 ▸**」を1つ。押すと、その画面の数字の説明を全部並べる | 地図の画面・お金の一覧の画面にそれぞれ1つ |

### 理由

- 選んでいるボタンの説明なら、**押した瞬間に「何を選んだか」が目に入る**。押す場所は増えない（「押しても何も起きないもの」を作らない）
- 地図の下の件数は、押すと必ず一覧が開く作りなので、**開いた先に説明を置けば、押す理由と答えが同じ場所**になる
- 「数字の見方 ▸」は、0件で押せないボタンや、ボタンでない数字（「確7」など）の逃げ場。押すと必ず中身が開く

### 他の選択肢

| 案 | 失うもの・採らない理由 |
|---|---|
| ボタン1つずつに「ⓘ」を付けて押すと開く | 地図だけで種類6＋地域5、一覧で7。**小さい押す場所が18個増える**。iPhone で押し分けにくい |
| 全部の説明をいつも出す | 種類の説明6行＋使い道7行。**画面がボタンより説明で長くなる**。「短く」に反する |
| 指を置くと出る説明（パソコンの吹き出し） | **iPhone では出ない**。実際に今、札の「確7」の理由がこの形で入っていて、iPhone では見えていない |
| 説明を足さず、名前だけ変える | 「自分に使う」「約束」「計画らしい」は、**決まり（どの言葉で拾うか）を知らないと使えない**。名前だけでは足りない |

### やった場合に失うもの

- ボタンの列の下に**1行増える**。字の大きさは12pxで、幅360では1行に27字前後と見積もる（**測っていません**）。40字の説明なら2行
- 一覧の見出しの下に1行増える
- 「数字の見方 ▸」の1行が、地図とお金の一覧の一番下に増える
- 説明の文を書く手間が、表を直すたびに増える（下の 2）

## 2. 説明の言葉を判定の表から作れるか

**作れる。ただし2つに分けて考える必要がある。**

| 説明の部分 | 表から作れるか | どうする |
|---|---|---|
| **どの言葉で拾うか**（「設備投資・有形固定資産 などを含む支払い」） | **作れる** | 表の言葉の並びから自動で作る |
| **何を拾いたいのか**（「相手に払う金ではなく、自分の側に積む金」） | **作れない**。言葉の並びは「どう拾うか」で、「何のためか」は入っていない | 表の**同じ行**に定義の一文を持たせる。表を直す人の目に必ず入る |

**そのために要る直し（実装のときの話）：**

- **使い道の表**は、今は拾う言葉を「正規表現」という機械向けの書き方で持っている（`/設備投資|有形固定資産|property and equipment|設備増強/`）。これを**言葉の並び**に持ち替え、拾う仕組みはその並びから作る。すると説明にも同じ並びが使える
  - **失うもの：** 判定の表を書き換えるので、第2段と同じ確かめ（本物のデータで20行・設備7…が変わらないか）をやり直す必要がある
- **地図の種類の絞り**（全部・お金・物と人・原油と石油・約束・自分に使う）は、表の行に「判定の手順」が入っていて言葉が無い。**行に一文を足す**
- **約束**の言葉（配分・表明・約束・誓約・コミット・拠出を決め・支援を決め・計画を発表）、**計画らしい**の言葉（上限・枠・決定…）、**外貨建て**の4語は、もともと言葉の並びなので、そのまま使える
- **一般名**（「推し量った動き」の元）は19語ある。1行に並べると長いので、**先頭3語＋「など19語」**を1行に、全部は「数字の見方 ▸」に出す

**今の表の言葉の数（実測）：** 使い道 11語（設備4・自社株2・注入2・買収1・投資2）、約束 8語、計画らしい 8語、外貨建て 4語、一般名 19語（丸ごと一致6・含む13）

## 3. 説明のない数字の一覧

記号：**要** ＝言葉だけでは分からない（決まりを知らないと読めない）、**名** ＝名前を変えれば分かる、**可** ＝今の言葉で分かる、**済** ＝近くに説明がある

### 地図・網

| 画面 | 出ている数字 | 何を数えているか | 判定 |
|---|---|---|---|
| 地図 | 種類「自分に使う（18）」 | 使い道の表に当たったお金の動きの本数（線＋国内） | **要** |
| 地図 | 種類「約束（2）」 | 生成が約束と印を付けたか、約束の8語を含む動き | **要** |
| 地図 | 種類「お金・物と人・原油と石油（N）」 | その種類の動きの本数 | 可 |
| 地図 | 地域「米州（29）」など | その地域に片端がある、線＋国内の本数 | 済（両端で数える一言あり）。ただし「線と国内を数える」は書いていない |
| 地図 | 下の行「国をまたぐ線 N本・枠への線 N本・国内 N件」 | 描いた線・国内の件数 | 可 |
| 地図 | 「場所不明 N件」 | 両端のどちらかの国が決まらない動き | 可 |

| 地図 | **「相手の国をもう片方から推し量った動き N件」** | 「株主」「取得先」のような一般名の相手を、もう片方と同じ国とみなした動き | **要** |

### お金の一覧

| 出ている数字 | 何を数えているか | 判定 |
|---|---|---|
| **使い道「設備（7）」「投資（5）」など** | 使い道の表のその行に当たった動き | **要** |
| **「自分に使う（20）」** | 使い道の表のどれかに当たった動き | **要** |
| **「計画らしい」／「区別なし」** | 約束の8語か計画らしいの8語があるか | **要** |

| つながる札「ほか N件」 | — | 可 |
| **お金の鎖「〜を中心に N件」** | 鎖に入っている動きの数 | **名**（「動きN本」） |

| 出ている数字 | 何を数えているか | 判定 |

## 4. 一度に全部やるべきか

### 推奨：一度に全部はやらない（反対）。2つに分ける

**先にやる（この段）：今日決めた決まりで数えている数字、9つ**

1. 地図の種類「自分に使う」
2. 地図の種類「約束」
3. お金の一覧の使い道ボタン（設備・自社株・注入・買収・投資）
4. お金の一覧「自分に使う」
5. 「計画らしい」／「区別なし」
6. 「使い道が決まらなかった候補」
7. 地図の下「「・」の前で場所を決めた相手」
8. 地図の下「相手の国をもう片方から推し量った動き」
9. 地図の下「外貨建てとして市場の枠に入れた動き」

＋ 地図とお金の一覧に「数字の見方 ▸」を1つずつ

**理由：** この9つは**決まり（どの言葉で拾うか）を知らないと読めず、しかも決まりをこれからも直す**。表から説明を作る仕組みが一番効くのはここ。説明の元になる表も、ほぼ第2段で作ったものなので、触る範囲がまとまっている。

**名前を変えるだけで済むもの（説明を足さないほうが安い）：**

| 今 | 変える案 |
|---|---|
| 動いた主体の行「5件」 | 「札5枚」 |
| 札の行「確7」 | 「確度7」 |
| 「Nつの出典」 | 「同じ動きの札N枚」 |
| 国の網の外の札「（2）」 | 「（2本）」 |
| 概念・用語・主体の一覧「N件」 | 「札N枚」 |
| お金の鎖「N件」 | 「動きN本」 |
| 知りたいことから引く（N） | 「知りたいことから引く（問いN）」 |
| 記録「世界・N件」 | 「世界・読んだ札N枚」 |
| 地図の下の3つ（7〜9） | 「名前の先頭で国を決めた相手」「国をもう片方と同じとみなした動き」（払う側が「金融機関」のような一般名のこともあるので、「払う側と同じ」とは言えない）「外国の持ち主への支払いとして市場に入れた動き」など。**説明と合わせて**変える |

名前の変更は、説明の仕組みと関係なく1回で終わる。**これは先にやる9つと同じ段に入れてよい**と考える（数え方は変えず、言葉だけ）。

**後回し：** 残りの「要」（地層の「上に乗る」、前提の印の数字、つながる概念、当たり率の分母、「（〜のうち40%）」、絞っていない一覧の「累計」）。どれも第2段より前からある数字で、決まりを直す予定が無い。「数字の見方 ▸」ができた後、そこに1行ずつ足すのが安い

**「累計」だけは注意：** 絞っていないお金の一覧で、計画の額にも「（2026年の累計）」と出る。**言葉が誤解を招いている**ので、後回しにするより「期間：」に揃えるほうがよいかもしれない（判断をください）

### 失うもの

- 後回しにした「要」の6つは、しばらく分からないまま残る
- 名前を変えると、見慣れた言葉が変わる（「確7」→「確度7」で、札の行が少し長くなる）
