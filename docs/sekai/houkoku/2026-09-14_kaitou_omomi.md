## 回答書に無い小さい足し（賛成なので入れた）

1. 選ぶ数は「0〜3件」（見るべきものが無い日に数を合わせて選ばせない）
2. 3件は同じ JSON の出来事を「#番号」で指させる
3. 指した出来事が落ちても3件の中に「取り込まれなかった」と残す
4. 今日の取り込みが無い日は直近の3件を日付つきで出す（7日まで）
5. 初期投入の JSON には付けない

## 失うもの

- 朝のプロンプトが長くなる（実測して報告）
- チャットの選び方の癖が一番上になる（型と理由で気づけるようにする）
- 3件に入った札が上と下で2回見える（下の並びを変えない方を選んだ）
- ファイルの名前が「dig」なのに朝の3件も入る（README で説明する）
- **v20.46 以前の端末がその月ファイルを書き直すと、3件の記録が消える**（札は消えない）→ 両端末を v20.47 にしてから朝の取り込みを流してほしい
