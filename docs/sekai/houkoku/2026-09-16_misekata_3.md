## 2. 地層の11枚は、実は6枚だった

「3点以上」で数えると11枚ですが、**中身を見ると線が引けないものが混じっていました。**

### 外したもの① 値が数にならない並び

`日銀の資産の内訳`（3点）の中身はこうでした。

```
2026-09-10 | 519兆6287億円
2026-08-31 | 国債:519.927691026,貸付金:71.8577,ETF:36.9835
2026-03-31 | 485兆4280億円
```

2点目が**複合の文字列**で、数になりません。3点のうち2点しか使えないので線になりません（これで1枚減）。

**決まりにしたこと：1点でも数にできない並びは、線にしない。** 一部だけ使うと、抜けた点が無かったことになります。

### 外したもの② 期間が短すぎる並び

`日本の長期金利`は4点ありますが、**2026年9月1日〜9月10日の10日間**です。

この地層を使う札には「**長期金利が30年ぶりに3.005％を付けた**」があります。10日間の線を出すと、**「30年ぶり」という札の中身を支えないどころか、ただの上下に見せてしまいます。**

**決まりにしたこと：期間が90日に満たない並びは、線にしない。**（これで4枚減）

## 3. 見せ方（質問3・4・5）

### 3-1. 折れ線が合うか → **合います。ただし「札の数字の推移」ではありません**

これは**その札が乗っている地層の動き**です。「米財務省が買い戻し枠を倍増した」の下に出る線は、買い戻し枠の推移ではなく、**米国の政府債務総額**の33年です。

だから線の下に必ず **「地層：米国の政府債務総額（兆ドル・403点）」** と書きます。読む人が「これは地面の動きだ」と分かる形にしました。

**失うもの**：地層と札が近い2枚（債務総額）では強く効きますが、遠い2枚（ホルムズの船の数に対する世界貿易/GDP）では「関係あるような気がする」だけになります。私はここを弱いと見ていますが、**外すと6枚が4枚になる**ので残しました。実機で弱いと思われたら外せます。

### 3-2. 文の中に前の値がある札 → **段2の `cmp` をそのまま使えます**

段2-2 で作った `cmp` には、すでに **`rel:"prev"`＝同じ主体の前の額** があります。時間の札で必要なのは「前の値」なので、**同じ欄で足ります**。

- **新しい欄は要りません。字数の追加はゼロ**
- 変えるのは規則の1行だけ（「札の額が」→「札の数字が」）と、出す条件（印が `size` だけ → `size` と `time`）

**ただし、見せ方は棒2本ではない方がよいと考えます。** 金利 2.891% と 3.005% を0から伸ばす棒にすると、**ほとんど同じ長さ**になります。これは嘘ではありませんが、札が言いたい「0.11ポイント上がった」が消えます。

**勧め：時間の札では、数字2つと差だけを出す。** `2.891% → 3.005%（+0.114）`

これは質問9・10への答えでもあります（後述）。

### 3-3. 前の値がどこにも無い札（3枚） → **何もしない**

段2で「比べる相手が無い4枚は1行のまま」としたのと同じ判断です。「1998年以来の高さ」という文だけが残ります。

## 6. 軸に紛れ込む編集判断（質問9）── 先に洗い出した

段2の「比べる相手の選び方」と同じ危うさが、時間では**3か所**に出ます。

| どこに出るか | 何が起きるか | どうしたか |
|---|---|---|
| **どの期間を切り取るか** | 米国の債務を「直近1年」で切ると急増に見え、「33年」で見ると一貫した傾き。同じデータで正反対の印象 | **切り取らない。持っている点を全部出す。** 期間を両端の日付で必ず書く |
| **縦軸をどこから始めるか** | 0から始めると 2.891%→3.005% は真っ平らに見える。最小〜最大にすると同じ変化が画面いっぱいに見える | **最小〜最大にし、両端の値を数字で書く。** どちらを選んでも印象は作られるので、**数字を必ず添えて打ち消す** |
| **どの地層を選ぶか** | 1枚の札が複数の地層に乗っているとき、選び方で話が変わる | **点がいちばん多い地層**を機械的に選ぶ。人もチャットも選ばない |

**それでも残る危うさ**：縦軸を最小〜最大にしているので、**ほとんど動いていない並びでも、線は大きく上下して見えます**。いまの6枚はどれも大きく動いているので実害はありませんが、将来ほぼ平らな地層が3点以上たまったとき、その線は「動いた」ように見えます。ここは**測れていません**（そういう地層がまだ無いため）。

## 9. 反対すること（質問14）

**「時間の変化は文の数字を読めば足りる」という考えは、半分正しいと考えます。**

- **賛成する部分**：`2.891% → 3.005%` のような1回の変化は、文で読めば足ります。**だから段3-2 では棒を出さず、数字2つと差にしました**
- **賛成しない部分**：33年403点のような長い並びは、文では書けません。「4.25兆ドルから40.05兆ドルへ」と書いても、途中の形（いつから傾きが変わったか）は消えます。**線でしか出せない情報がここにあります**

なので、**線を出すのは長い並びだけ**、という今の形（90日以上・3点以上）が、ちょうど境目だと考えています。

そのうえで**1つ反対します**。地層が遠い2枚（ホルムズの船の数に世界貿易/GDPの線）は、**関係があるように見せてしまう危険**があります。実機で見て「関係ないのに線が出ている」と感じたら、**札と地層の近さで絞る**ことを勧めます（ただし近さを機械で測る方法は無いので、その場合はチャットに「この線を出すか」を書かせることになります）。
