# 予告の期限と、確かめられなかったものの聞き直し

日付：2026-09-14　元の指示書：`shiji/shiji_kigen_2026-09-14.md`（質問フェーズ）　起点：v20.39
**直していない。** コード（v20.39）と、kotoba-data の予告（2026-09-14 11:05 の版・読むだけ）を見て答えた。

---

## 結果（先に）

1. **期限が来たかどうかの判定は「端末の今日の日付（日本時間）が期限と同じか後か」。** 判定の関数は1つ（`index.html` 18038〜18041行）だが、**予告の画面にもう1か所、期限前かを直接比べている所がある**（22787行）。**2か所を一緒に直さないと、期限当日の予告が画面から消える**
2. **今この直しを入れて、すぐに答え合わせに載らなくなる予告は0本。** 期限が今日（9/14）の予告は米財務省の1本だけで、もう押してある。まだ押していない32本の期限は 9/18 以降
3. **1日待つと困ること：** 期限当日の夜に結果が出る予告（OPEC＋ 10/4 など）を、その夜には押せなくなる（今は期限が来るまで押せない作り）。**逆に、1日待っても足りない場合もある**：日本時間の翌日0時は米国東部の前日11時なので、米国の午後の発表は、翌日の朝早くに見るとまだ出ていない
4. **「確かめられない」を押した予告は、今の作りでは二度と答え合わせに戻らない。** 3回で畳む仕組み（`unverifiableCount`・畳んだもの）は前からあるが、回数が増えるのは「押したもの」の欄で同じボタンをもう一度押したときだけ。**続けて3回押すと、聞き直しをしないまま畳まれる**（見つけた穴）
5. **聞き直しの案：押した日から7日後に、答え合わせの対象に戻す。3回で打ち切る（今の決まりのまま）。** 結果（確かめられない）は機械が変えず、「もう一度確かめる予告」として載せ直す
6. **押していない見立ても、7日たったら聞き直す**案を入れた（今は、見立てがまだの予告がある間は後回し）
7. **1回10本の上限：** 全部が毎回「確かめられない」になる最悪の場合でも、毎日確かめれば1日の最大は11本（12/19）で、10本を超えるのは1日だけ。半分が確かめられないなら最大10本
8. **米財務省の1本：** 案の形（押した状態のまま、押した日から7日で戻す）なら、**直した後に自動で戻ってくる**（9/21）。kotoba-data への書き込みは要らない

## ア 期限の扱い

### 判定している所

| 所 | 行 | 中身 |
|---|---|---|
| 今日の日付 | 3098 | 端末の時計の日付（日本時間で使っていれば日本の日付） |
| **期限が来た予告** | **18038〜18041** | まだ押していない・畳んでいない予告のうち、**期限 ≦ 今日** |
| **予告の画面の「待っている」** | **22787** | まだ押していない予告のうち、**期限 ＞ 今日**（上の関数を使わず、直接比べている） |

「翌日以降」にするには、18040行を「期限 ＜ 今日」にし、22787行を「期限 ≧ 今日」にする（または両方を1つの関数で決める）。**18040行だけ直すと、期限当日の予告は「期限が来た」にも「待っている」にも入らず、画面から消える。**

### 期限の判定を使っている所（一緒に変わる所）

| 所 | 行 | 直すと |
|---|---|---|
| 答え合わせに載せる予告 | 18059 | 1日遅れて載る（直したい所） |
| 予告の画面の「期限が来た（押して確定してください）」 | 22774 | 1日遅れて出る。**押すボタンはこの欄だけに出るので、期限当日は押せない**（今の「期限前は押せない」決まり） |
| 答え合わせの塊を出すか | 22776 | 1日遅れて出る |
| ホームの「待っている予告 N本・期限が来たもの N本」 | 20235〜20236 | 「期限が来たもの」が1日遅れる |
| 世界の画面の「予告 ・ 期限が来たもの N本」 | 20396 | 同じ |
| 予告の画面の「待っている」 | 22787 | 上のとおり、一緒に直す |

**期限を使っているが、変わらない所：** 待っている予告の並び（期限の古い順）／同じ予告の見分け（主体・動き・期限が同じ）／読む回の「切れた推定」の枠の並び（予告の元の札を期限の近い順）／プロンプトに書く期限の文字。読む回そのものは期限の判定を使っていない。

### すぐに答え合わせに載らなくなる本数（実データ）

- 今（9/14）まだ押していない予告：32本。期限は 9/18 が最も早い
- 期限が今日の予告：米財務省の1本だけで、**すでに「確かめられない」を押してある**
- **→ 今直しても、すぐに載らなくなる予告は0本。** 直した後は、どの予告も期限の翌日に1日遅れて載る
- 同じ日に期限が来る最大：12月11日の9本（12月12日に載るようになる）

### 1日待つと困ること

- **その日の夜に結果が出る予告を、その夜に押せない。** 例：OPEC＋「10月4日の会合で11月分の必要生産量を据え置く」（期限 10/4、当たりの印：OPEC 声明）。会合の声明が日本時間の 10/4 のうちに出ても、答え合わせに載るのも押せるのも 10/5 から。**待つのは最大で1日**
- **期限より前に起きた予告も、今と同じく期限まで押せない**（今の作りのまま。変わらない）
- **1日待っても足りない場合：** 日本時間の翌日0時＝米国東部時間の前日11時（夏時間）。米国の役所の午後の発表は、日本時間の翌日の早朝（5〜6時ごろ）まで出ない。今回の米財務省は日本時間 9/14 11:04 に聞いて「米国時間で9/14未到来」だった。直した後は早くても 9/15 0時からだが、**0時〜6時に聞くと同じことが起きうる**。どの時間に答え合わせをするかは測れません
- 主体の国で時差を扱う案は、指示書どおり採らない

**反対はしない。** 1日待つ直しに賛成。困ることは「当日の夜に押せない（最大1日）」だけで、聞き直し（イ）があれば「早すぎて確かめられない」になっても戻ってくる。

## イ 聞き直し

### 今の作り（コードで確かめた）

- ［確かめられない］を押すと、結果が「確かめられない」になり「押したもの」の欄へ移る。**答え合わせの対象は「まだ押していない予告」だけなので、二度と載らない**
- 押すたびに「確かめられない の回数」が1つ増え、**3回で畳む**（「畳んだもの」の欄へ。畳んだものが5本を超えると「印の立て方を見直す時期です」の1行）。3回・5本は1か所の決まり
- **穴：** 「押したもの」の欄にも3つのボタンがあり、**同じ［確かめられない］をもう一度押すと回数が増える**。確かめ直していないのに、3回押すと畳まれる
- 取り込みは「まだ押していない予告」にしか入らない（押してある予告は「すでに押してある予告 N本は変えていません」）。聞き直しを作るなら、ここも聞き直しの予告を受け付ける必要がある

### 案

| 決めること | 案 | 理由 |
|---|---|---|
| 戻し方 | 結果（確かめられない）は**機械が変えない**。押した日から一定日数たった予告を「もう一度確かめる予告」として、答え合わせの塊と「期限が来た（押して確定してください）」の欄に載せ直す | 機械が結果を「まだ」に戻すと、人が押したことを機械が取り消すことになる。押した状態のまま載せれば、押した記録も残る |
| 何日後 | **押した日から7日後** | 当たりの印は、週ごとの発表（FRB H.4.1）・月ごとの発表（外貨準備）・四半期の決算・報道が混ざっている。7日なら週ごとの発表は必ず1回挟まる。3日だと週ごとの発表をまたがないことがある |
| 何回で打ち切る | **3回**（今の決まりのまま） | 7日×3回で、期限から約3週間。月ごとの発表（月の上旬に出る外貨準備など）も1回はまたぐ。2回だと2週間で、月ごとの発表を逃すことがある |
| 回数の数え方 | **確かめ直した後に押したときだけ**増やす（前に押した日時より後に、新しい見立てを取り込んでいるとき、または7日たって載り直した後） | 上の穴をふさぐ。続けて押しただけで畳まれないようにする |
| 打ち切ったものを出す所 | 今の「畳んだもの」の欄（予告の画面の一番下）に、回数と最後の見立ての理由（まだ発表されていない／公表されない数字）を添えて残す。当たり外れの割合の横にも「畳んだもの N本」 | 黙って消さない。今も欄はあるので、足すのは理由の1行だけ |
| 「公表されない数字だった」のとき | 聞き直しても変わらないので、**すぐに打ち切る案**も考えられる。ただし生成の見立てが間違っている可能性があるので、**今回は他と同じく7日で戻す**のを勧める | 何回か回して、「公表されない」が本当に変わらないかを見てから決める |

**失うもの：** 確かめられない予告が、7日ごとに最大2回戻ってくる（答え合わせのコピーと貼り付けが増える）。畳むまでに約3週間かかる。

### 「確かめられない」以外に戻すべきもの

| もの | 今 | 案 |
|---|---|---|
| **押さずに放っておいた予告**（見立てもない） | 期限が来たまま「期限が来た」の欄に残り、ホームにも「期限が来たもの N本」と出続ける。答え合わせにも毎回載る | **戻す仕組みは要らない**（消えていない）。今のままでよい |
| **見立ては取り込んだが押していない予告** | 「期限が来た」の欄に残る。**答え合わせには、見立てがまだの予告が1本でもある間は載らない**（v20.39 の決まり） | **見立てを取り込んでから7日たったら、見立てがまだの予告と同じ扱いで載せる**。見立てが「確かめられない・まだ発表されていない」なら、押していなくても7日で聞き直すのが自然 |
| 当たり・外れを押した予告 | 押したもの。戻らない | 戻さない（人が確定したもの） |
| 畳んだ予告 | 畳んだもの。戻らない | 戻さない。押し直せば戻る作りにするかは別に決める |

### 1回10本の上限にぶつかるか（実データで見込み）

今ある33本の期限で、「期限の翌日から載る・確かめられないは7日後に戻す・3回で打ち切る」として、**毎日答え合わせをする**と仮定して1日に載る本数を数えた。

| 場合 | 1日の最大 | 10本を超える日 |
|---|---|---|
| 聞き直しなし（今の決まりのまま、翌日から） | 9本（12/12） | 0日 |
| 半分が毎回「確かめられない」 | 10本（12/12） | 0日 |
| **全部が毎回「確かめられない」（最悪）** | **11本（12/19）** | **1日** |
| 全部が毎回「確かめられない」・3日後に戻す | 9本（12/12） | 0日 |

- 最悪でも、超えるのは1日だけで、残りは次のコピーに回る（今の「ほか N本は…」で足りる）
- **毎日ではなく週に1回まとめて答え合わせをすると**、12月7日〜13日の週は期限だけで12本になり、10本を超える（2回に分ける）
- 何割が「確かめられない」になるか、どのくらいの間隔で答え合わせをするかは、1本しか試していないので**測れません**

## 何を失うか（まとめ）

- 期限当日には押せなくなる（最大1日待つ）。米国の午後の発表は、日本時間の翌日の早朝までは出ていないことがある
- 確かめられない予告が7日ごとに最大2回戻り、コピーと貼り付けが増える
- 畳むまでに約3週間かかる
- 聞き直しの予告を受け付けるために、取り込みの「押してある予告は変えない」の決まりに例外ができる（**結果は変えず、見立てだけ入れ直す**）

## 質問

1. 期限の判定は「翌日以降」でよいか（2か所を1つの決まりにまとめて直す）
2. 期限当日の夜に結果が出た予告を、当日に自分で押せるようにするか（押すボタンは出すが、答え合わせのプロンプトには翌日から載せる、という形もできる）
3. 聞き直しは「押した状態のまま、7日後に載せ直す・3回で打ち切る」でよいか
4. 回数は「確かめ直した後に押したときだけ増やす」に直してよいか（続けて押すと畳まれる穴）
5. 「見立ては取り込んだが押していない予告」も、7日で聞き直すか
6. 「そもそも公表されない数字だった」も、他と同じく7日で戻すか（すぐ打ち切る案もある）

## 測れていないこと

- 答え合わせを何時ごろ・どのくらいの間隔でするか（1日待つ直しで足りるかは、見る時間による）
- 何割の予告が「確かめられない」になるか（まだ1本しか試していない）
