## 1. 世界タブの戻る（v20.53、手元）

**原因**：戻るは画面ごとに「ここから戻ったら、ここへ」の決まりを持っていて、決まりに無い組み合わせは全部、最初の画面に戻っていた（例：探す → 主体 → その主体の札 → 戻る で、主体を飛ばして最初へ）。

**直し方**：開いてきた画面の順番を覚えて、1つ前へ戻す。最初の画面まで戻ったら、探した語と見ていた位置も戻す。世界タブを離れる・入口から開き直すと順番を捨てる。

**手元の確かめ（実データの写し）**

| 流れ | 戻るの行き先 |
|---|---|
| 「財務省」で探す → 主体 → その主体の札 | 札 → 主体 → 最初の画面（探した語・結果・見ていた位置が戻る）→ 記録 |
| 幹の一覧 → 幹1本 → 枝の札 → 主体 | 主体 → 札 → 幹1本 → 幹の一覧 → 最初の画面 |
| 地図 → 国の網 | 網 → 地図 → 最初の画面 |

探す欄は本物のキーで打った。確かめ用のブラウザの窓の大きさが途中で変わり、指で押す位置が合わなくなったので、戻るボタンはボタンそのものを押す形で確かめた。**iPhone で指で押す確かめは公開後に必要**。

## 2. 一括入力

### 2.1 「自分の言葉が保存したら消える」

**保存はできていた。保存した直後の画面が、消えたように見える。**

- ブラウザで本物のキーを打って保存した（名言・本・読書メモ、読み込み直しの後）。どれも自分の言葉は保存されていた
- 保存した直後の画面：
  - 欄が空になり、赤字で「自分の言葉での一言を入力してください（必須）」が出る
  - 次の下書きのカードは画面の外にあって見えない
  - 「保存しました」の知らせが出ない
- 本物のデータ：一括入力から残った言葉16枚は、自分の言葉が全部埋まっていた（空で保存・保存したのに無い は0）。9/15 に、ほぼ同じ自分の言葉が28秒あけて別の2枚に入っていて、「消えたと思って次のカードに打ち直した」跡と読める

**本当に打った言葉が黙って捨てられる道もある**：「既存を置き換える」「こちらを残す」「あとで」、カードの横スワイプ。裏で読み込み直されて30分を過ぎると、2枚目以降で打っていた言葉は欄に戻らない。

**直し方（決まっている）**
1. 保存したら「保存しました：〈本文の頭〉（残り N 件）」を出し、次のカードが見える位置に戻す。まだ何も打っていないカードでは赤い必須を出さない
2. 自分の言葉の欄に文字があるときは、あとで・スワイプ・こちらを残す・置き換える の前に確かめる（2回押し）
3. 下書きの画面を開くとき、打ちかけの控えが残っている下書きから始める

### 2.2 分割ではなく、要約して少ない枚数で

**今**：AI への頼みは「分けよ／抜き出せ」。名言集は枚数の上限が実質無い（100）。

**実測（本物の一括入力3回）**
- 9/7 自分の話：下書き15枚（上限いっぱい）→ 12枚保存
- 9/9 読書メモ：3枚 → 1枚保存
- 9/15 名言集：13枚 → 3枚保存、10枚は捨てた（1つの章で主題も1つ。本人は手で2枚分を1枚の自分の言葉にまとめていた）

**案**

| | 1枚にするもの | 失うもの |
|---|---|---|
| A | 1回の一括入力で1枚 | 主題が2つ以上ある文章が1枚に詰め込まれ、2つ目以降は引く・相談に出なくなる |
| **B（推奨）** | **主題ごとに1枚、最大3枚**。言葉は核の一文（名言・本は原文のまま、自分の話は本人の言い回しで要約）、残りは「周辺のメモ」へ | 核に選ばれなかった一文は、単独では引けない（原文は周辺のメモに残る） |
| C | 出来事・問い・考え の型で分ける（自分の話向き） | 名言・本に合わない。考えが複数あっても1枚に潰れる |

- B なら4種類を同じ形にそろえられ、読書メモ（すでに1〜3か所＋周辺のメモ）とも合う
- **費用**：分解の呼び出しは1回約 $0.013。保存のたびに走る自動の関連づけが1枚約 $0.018 で、こちらが大きい（13枚全部保存で約 $0.24）。1〜3枚になれば関連づけの費用は 1/4〜1/13

## 3. 朝の相談の言葉が似ている

**選び方**：朝の「言葉を受け取る」（2件）も相談の「聞く」（3件）も、選ぶのは AI。言葉は今186件で、200件以下のあいだは全部を AI に渡し「今の状態に最も応える言葉」を選ばせている。**前に何を出したかは渡していない**。

**実際に出た言葉（日誌の朝10回・相談11回、実測）**
- 朝：18件のうち再登場3件（「朝起きたら考えること」が2日続けて）
- 相談：33件のうち再登場11件。うち10件は同じ質問の重ね聞き（「陰の波に、どうやって乗るのか」を同じ文で5回）
- **同じ言葉そのものの繰り返しは多くない**

**話題は偏っている（1人の読み）**
- 出た言葉の36%が「心を見張る・思考や感情の暴走を止める」（言葉全体では16%）。「試練・逆境」と合わせると53%（全体では24%）
- 数のいちばん多い「人付き合い」（32件）は1回、「仕事・勤勉」（19件）は0回しか出ていない

**言葉の側**
- 名言集3冊（ユダヤ58・ニーチェ51・ブッダ48）で84%。同じ話の言い換えの束が20束・53件（28%、1人の読み。例：「原因と結果の法則」はブッダとユダヤで見出しまで同じ）
- 一括入力で1つの文章から出た言葉が1回の相談に2〜3件並んだ回が、5回中4回

**原因の見立て**
1. 本人の一言がほぼ毎回「頭の靄・緊張・イライラ」などの内側の状態で、言葉の側に「心を見張る」系が多い。AI は頼まれたとおり一番合う言葉を選んでいる
2. 繰り返しを止める仕組みが無い
3. 相談の再登場のほとんどは、同じ質問の重ね聞き
4. **これから起きること（再現＋推測）**：言葉が200件を超えると（あと1〜2日の見込み）、端末が点数順に絞ってから渡す。点数に「最近出た回数」が入っているので、一言の無い朝では上位10件のうち8件がすでに出た言葉になる。「出る → 上に来る → また出る」の輪になる

**案と失うもの**
| | 中身 | 失うもの |
|---|---|---|
| A | 最近出した言葉を AI に渡し、同じ趣旨は避けてもらう | その日一番合う言葉が2回目は外されることがある。★の言葉にまた会う回数が減る |
| B | 2〜3件のうち1件は「違う話題・違う出典から」と頼む | 的外れに感じる日が増える |
| C | 言葉の側の似た束を知らせて束ねる。一括入力で同じ文章から出た同じ解釈は、保存前に1枚にまとめる | 本ごとの言い回しの違いが消える。束ねる手間 |
| A に付ける | 200件を超えた後の点数から「最近出た回数」を外す（★だけ残す） | 「最近よく効いた言葉が上に来る」ことだけ。400件くらいまでは差が小さい見込み |

2.2 の B（要約して最大3枚）は、C の「一括入力で似た言葉が並ぶ」も減らす。

## 4. 筋トレの種目を消す

**「種」は種目の候補**と見た（記録画面で部位ごとに並ぶ札。今は名前を変えられても消せない）。
- きっかけの見立て（推測）：今日、「Cable Side Raise」を**胸**に入れて2セット記録し、数分後に**肩**へ入れ直した跡がある。記録からは胸の分が消えたが、**胸の候補の札が残って消せない**
- 実データ：候補13枚。記録で使っていないのは2枚（胸の「Cable Side Raise」、有酸素の「Bike」）。書き間違いらしいのは足の「Hack Squad」

**今の作りの穴**：種目には消した印が無いので、片方で消しても同期で戻る。**名前を変えても古い名前が戻る**（写しで Hack Squad → Hack Squat にすると両方並んだ）。

**推奨：案A**
- 部位の枠の「種目の名前を変更」を「種目を直す」にし、各札に［消す］。1回目で「消す（記録は残る）」に変わり、2回目で消える。確認の窓は使わない
- 消すのは候補の一覧からだけ。過去の記録・筋肉の対応・ログ画像は残る。同じ名前を追加し直せば戻る
- 札に「消した」印と時刻を持たせ、同期では後に変えた方を採る（戻ってこない）。記録を保存したときの自動の入れ直しでは、消した札を戻さない
- 名前の変更も「古い名前を消す＋新しい名前を足す」にして、古い名前が戻る穴も一緒に直す
- 失うもの：ほぼ無い（消した行がファイルに残る。古い版の端末が同期すると札が戻る）

案B（札を記録から毎回作り、消すボタンは作らない）は、使ったことのある種目を片付けられないので次点。

## 6. 直したこと（v20.53）と確かめ

### 6.1 一括入力

| 直したこと | 使う人から見て |
|---|---|
| AI への頼みを「主題ごとにまとめる、最大3件」に | 1回の一括入力でできる下書きは最大3枚。各枚は核の一文（名言・本は原文のまま、自分の話は本人の言い回しで要約）＋周辺のメモ（同じ主題の残りの要旨） |
| 周辺のメモ | 名言・自分の話の下書きでも、メモがあれば欄が出て、保存すると言葉に付く（詳しい画面の「周辺のメモ」に出る。引く・網・相談には出ない） |
| ボタンの名前 | 「分解する」→「まとめる」 |
| 保存した直後 | 画面の上に「保存しました：「…」（次の下書き・残り N 件）」。次のカードが見える位置に戻る |
| 赤い「必須」 | 替わったばかりのカードでは出さない。そのカードで打ってから消したときだけ出す |
| 打った一言がある時の［あとで］ | 1回目は「打った一言を捨ててあとで」に変わるだけ。2回目で進む。打ち直すと元に戻る |
| スワイプ | 打った一言があるときは進まず、理由を出す |
| ［捨てる］［こちらを残す］［置き換える］ | 確認の文に「打った自分の言葉も消えます／使われません」を足した |
| 下書きの画面を開いたとき | 打ちかけの控えがある下書きから始める（2枚目以降で打っていた言葉も欄に戻る） |

手元の確かめ（偽の GitHub・AI の返事は偽物。本物の AI・保存庫には送っていない）
- まとめる → AI への頼みに「最大3件」、下書き2枚・それぞれ周辺のメモ付き、名言集でもメモ欄が出る
- 自分の言葉を**本物のキーで打って**保存 → 言葉に自分の言葉と周辺のメモが入り、「保存しました：「人生は思い通りにならない。だから委ねる。」（次の下書き・残り 1 件）」、欄は空で赤い必須は出ない、画面は先頭へ
- 一言を**本物のキーで打って**［あとで］1回 → 進まず文が変わる。スワイプ → 進まず理由。打ち直す → 元の文。2回 → 進む。打って消す → 赤い必須
- 読み込み直しから2時間たった控え（2枚目の下書き）→ 下書きの画面を開くと2枚目から、一言も欄に戻る

### 6.2 筋トレ

| 直したこと | 使う人から見て |
|---|---|
| 「種目の名前を変更」→「**種目を直す**」 | 各種目に［変更］と［消す］ |
| ［消す］ | 1回目で赤い「記録ごと消す（N日・Mセット）」（記録が無ければ「消す（記録なし）」）。2回目で消す。確認の窓は出さない |
| 消す範囲 | **その部位の、その種目の記録全部**。同じ名前がほかの部位にあれば、そちらの候補と記録は残る。記録が空になった日は日ごと消える |
| 同期 | 候補に「消した」印と時刻を持たせ、2台で後に変えた方を採る。消した種目は、もう片方の端末の古い一覧から戻らない |
| もう一度使う | 「種目を追加」で同じ名前を入れれば候補に戻る（消した記録は戻らない） |
| 名前の変更 | 古い名前に消した印を付けて新しい名前を足す形にした（前は、古い名前が同期で戻っていた） |

手元の確かめ（実データの写し）
- 胸の「Cable Side Raise」（記録なし）→「消す（記録なし）」→ 候補から消えた。**肩の Cable Side Raise と、その記録（9/11・9/15）は残った**
- 足の「Hack Squad」→「記録ごと消す（1日・4セット）」→ 9/11 の足から4セットが消え、同じ日の Leg Extension・肩は残った
- 消す前のデータと、どちらの順で合わせても、消した2つは戻らず、9/11 の記録も消えたまま
- 同期して2台目：同じ（候補に出ない、9/11 から消えている）
- 前の版（消した印を知らない版）が書いた形と合わせても、消した印は残る
- 名前の変更（Bent-over-Row → Bent-over Row）→ 消す前のデータと合わせても古い名前は戻らず、記録の名前も新しい名前
- 「種目を追加」で Hack Squad を足し直す → 候補に戻る

**確かめきれなかったこと**：確かめ用のブラウザの窓が途中で裏に回り、筋トレの欄に本物のキーで打つ確かめと、指で押す確かめができなかった（ボタンそのものを押して確かめた）。「種目を追加」の欄と［変更］の欄は今回変えていない。

### 6.3 公開の後、実機で確かめてほしいこと（触ると壊れる形を先に）

1. **一括入力**：名言集で1章ぶんを貼って［まとめる］→ 下書きが1〜3枚になる → **iPhone で自分の言葉を打って保存** → 「保存しました」が出て、次のカードが見える
2. 一言を打ってから［あとで］を**指で**1回 → 進まない。カードを**指でスワイプ** → 進まない
3. 保存した言葉の詳しい画面に、周辺のメモが出ている
4. **筋トレ**：部位の枠の［種目を直す］→ 胸の「Cable Side Raise」の［消す］を**指で2回** → 候補から消える。肩の同じ種目は残る
5. **もう片方の端末で同期**して、胸の Cable Side Raise が戻ってこない
6. **世界の戻る**：探す → 主体 → その主体の札 → ［← 戻る］を**指で** → 主体に戻り、もう一度で探した語が残った最初の画面

見た目：iPhone の幅で、［変更］［消す］が並んだ種目の行、赤い「記録ごと消す（…）」、「保存しました」の文が崩れないか。

**気をつけてほしいこと**：筋トレの［消す］は記録ごと消すので、2回目を押すと数字は戻らない。**2台とも v20.53 にしてから消す**（前の版の端末でその日を開いて直すと、その日の記録が戻ることがある）。
