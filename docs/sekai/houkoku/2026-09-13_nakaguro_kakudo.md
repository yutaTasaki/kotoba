# 「・」の決まりと、確度1〜10の定義を調べた（質問フェーズ）

日付：2026-09-13　元の指示書：`shiji/shiji_nakaguro_kakudo_2026-09-13.md`　起点：v20.26
**実装なし・仕様書なし。** 調べた事実と推奨だけ。

---

## 何をしたか

- kotoba-data の世界の札（全期間の121枚、非表示0枚）と主体の表（87件）を、読むだけで取り直した
- 名前（払う側・受け取る側・札の主体・主体の表の名前と別名）を全部集め、**「・」やほかの区切りを含むもの**を、今のアプリ（v20.26）の読み方で1つずつ読んだ
- 区切りに関係なく、**名前の中に国の呼び名が2つ以上入っているもの**を探した
- 生成への指示から、名前の書き方と確度の基準を**そのまま**抜き出した
- 確度の分布、理由の中身、確度で何かを外している箇所を全部数えた

## 結果（先に結論）

1. **「・」を含む名前は14個。「複数の国が並ぶ」型はすでに1つある。** ただし今の「・」の決まりで読まれているのではなく、**主体の表に生成が書いた国（中国）で読まれ、インドが黙って落ちている**（「ロシア産原油」のロシアは原油の産地で、製油業者の国ではない）。今の地図の線には出ていない
2. **本当の問題は「・」ではなく「1つの名前に国が2つ以上入ること」。** 「と」でも起きていて、「欧州の同盟国とカナダ」はカナダが地域の枠に吸い込まれている
3. **確度の基準は生成への指示に書いてある。ただし 10・7・4・1 の4つの目安だけ**で、2・3・5・6・8・9 の意味は書いていない
4. **確度3以下は14枚（12%）。** 地図・小さな地図・国の網・お金の鎖では**黙って外している**（直近90日の動き82枚のうち8枚）。お金の一覧は外していない（食い違い）。朝の画面は「背景の札 N件」に出すが、主体の無い札と混ざっている
5. **確度の1つの数字に、2つの違うものが混ざっている。** 「出典の確かさ」（報道だけ・一次資料に当たれず）と「出来事がまだ起きていない」（交渉段階・打診の段階）。後者の札も確度3で沈められ、地図から消えている

- **今の「・」の決まりで国が決まっているのは2つだけ（A・B）で、どちらも正しい**
- 一番多いのは **E（説明の言葉を「・」で並べただけ）の6つ**。国は「〜の」の前や一般名で決まり、「・」の決まりは使われていない
- **D（複数の国）は既に1つある。** 読んでいるのは「・」の決まりではなく、**主体の表の国**。この主体は、取り込みで生成が「中国」と書いた（手で決めた印は無い）。札は3枚（インドと中国のロシア産原油の荷揚げ・輸入の話）。**今は払う側・受け取る側の名前には出ていないので、地図の線には嘘は描かれていない**。ただし主体の詳細や「動いた主体」では「中国の主体」として扱われている

### 1-2. 「・」以外の区切り

| 区切り | 名前の数 | 中身 |
|---|---|---|
| 、 | 0 | — |
| ／ | 7 | 「財務省（MOF／日本の財務省）」など。**すべて主体の表の別名**（前の版で括弧つきの重複主体をまとめたときに残った書き方）。場所の読みには使われない |
| / ・and・＆・&・等・ほか・や・及び・，| 0 | — |
| など | 1 | 防衛装備・人件費などの支払い先（上の E） |
| **と** | **3** | **欧州の同盟国とカナダ**（払う側1。→ 地域の枠。**カナダが吸い込まれる**）、欧州とアジアの需要家（→ 地域の枠）、先端工程と海外工場（決まらない） |
| ＋ | 1 | OPEC＋ |

**区切りに関係なく「名前に国の呼び名が2つ以上入っている」もの：1つだけ**（上の D）。210個の名前を全部当てて、誤って引っかかったものは無かった。

**「欧州の同盟国とカナダ」**は国の呼び名が1つ（カナダ）＋地域の言葉（欧州の同盟国）で、上の探し方には引っかからないが、同じ種類の問題（カナダの分が地域に吸い込まれる）。「アンカラ首脳宣言で2026年の対ウクライナ支援700億ユーロを約束」の札の払う側。

### 1-3. 生成への名前の書き方の指示（そのまま引用）

毎朝のプロンプトの、お金の動きの説明：

```
  from／to は主体名（actors の name）か、国名で始まる相手（「米国の製油所」「ウクライナの防衛調達」）。
  市場なら「為替市場」「石油市場」のように書く。国の定まらない相手（「世界の海運会社」）に国名を付け足さない。
  買い手・出し手が複数の会社のときは、主導する1社を from に書き、ほかの会社は detail に書く。
```

主体（actors）の説明：

```
  - country：その主体の国の3文字コード（日本は JPN、米国は USA、中国は CHN）。市場は MKT、国際機関は INT、
    EU や国の集まりは REG。分からなければ空。
```

必ず守ること：

```
- actors の country を必ず書く（3文字コード。市場は MKT、国際機関は INT、EU や国の集まりは REG）。
```

既知の主体の一覧の見出し：

```
■ すでに知っているアクター（actors の name はここから探す。無ければ新しく書いてよい。name には先頭の名前だけを書き、［別名：…］は書かない。最大60件）
```

**「1つの名前に複数の国を並べない」という指示は無い。** 複数の会社については v20.24 で足したが、**複数の国については何も書いていない**。主体の country には1つの国しか書けないので、「インド・中国の製油業者」のような主体では、生成は**どちらか1つを選ぶしかない**。

### 1-4. 「米国・日本の製油所」が来たとき、どうするのが正しいか

| 案 | 今のデータで動くもの | 代償 |
|---|---|---|
| ア. 前だけ見る（今のまま） | なし | 1つ目の国だけの線が描かれる（嘘）。一覧の見出しに知らせは出る |
| **イ. 名前に国が2つ以上あったら場所不明にする**（区切りを問わない） | 払う側・受け取る側の名前では**0行**。主体の表の1件（インド・中国）が「国が並ぶ主体」になる | 描ける線が減る（今は0本）。国が2つある動きは、地図の下の場所不明の一覧で見る |
| ウ. 先頭・一番大きい国を採る | なし | アと同じ嘘 |
| エ. 生成に「1つの名前に国を並べない。国ごとに分ける」と指示 | これからの札だけ | プロンプトが約50字増える。過去の札には効かない |

**推奨：イ＋エ。そして、主体の表の国にも同じ決まりを当てる。**

- **理由1：「0件だから大丈夫」ではなかった。** 国が2つ並ぶ名前は既に1つあり、**「・」の決まりではなく主体の国の欄を通って**嘘が入っている。「・」だけを直しても防げない
- **理由2：イの代償は、今のデータでは0本。** 嘘を描かない側に倒しても、今の地図は1本も減らない
- **理由3：エだけでは足りない。** 主体の country は1つしか書けない作りなので、指示を足しても「インドと中国」のような主体はまた来る。見る側で止める必要がある
- **主体の表の国への当て方：** 主体の名前に国が2つ以上入っていて、国を手で決めた印が無いときは、**その主体の国を使わない**（場所を読むときに「決まらない」扱い）。主体の詳細の国の行に「名前に国が2つ（インド・中国）。取り込みで入った国は使っていません」と出す。**データは変えない**
- 「欧州の同盟国とカナダ」（地域の言葉＋国）も同じ扱いにするかは、**判断をください**。するなら、この1本が「地域への線」から「場所不明」に移る（約束の700億ユーロ）。しないなら、地域の枠に入れたまま、地図の下の一覧（「国をもう片方と同じとみなした動き」と同じ形）に「国と地域が並ぶ名前 N件」を出して黙らない

**反対するもの：** ウ（先頭を採る）。今と同じ嘘を、決まりとして固めることになる。

**「今のままで十分」には反対。** 理由1のとおり、既に1つある。

**別に見つかったもの（この件とは別の種類）：** 「ロシア軍・軍需産業」が場所不明。「〜軍」を国として読む決まりが無い。直すなら国の後ろの言葉（政府・議会・国防省など）に「軍」を足す案がある。今のデータで動くのは1本（ロシア国内になる）。**【訂正 2026-09-13】** 払う側「ロシア政府予算」も決まらないため、受け取る側がロシアになっても行は場所不明のまま。分類は変わらない（[2026-09-13_kaitou_nakaguro_kakudo.md](2026-09-13_kaitou_nakaguro_kakudo.md)）。

## 2つ目：確度1〜10の定義

### 2-1. 生成への指示に基準はあるか → **ある。ただし4つの目安だけ**

毎朝のプロンプトの、項目の説明（そのまま引用）：

```
- confidence：この札の確かさを 1〜10 の整数で。
  10＝一次資料の本文で、数字・日付・主体まで確かめた。7＝一次資料だが一部を確かめきれていない。
  4＝報道だけ。1＝噂・未確認。
- confidenceWhy：confidence が7以下なら、理由を1行。8以上なら空。
```

必ず守ること（そのまま引用）：

```
- 確認しきれなかった出来事も、捨てずに返す。confidence を下げ、confidenceWhy に理由を書く
  （一次資料に当たれず報道のみ、URL が開けなかった、数字が本文になく図から読んだ、など）。
```

```
- 一次資料が見つからず、報道・解説しか無いときも返してよい。そのときは source に媒体名を書き、
  confidence を下げ、confidenceWhy に「一次資料に当たれず報道のみ」と書く。
```

読む回のプロンプト（そのまま引用）：

```
- confidence：**下げるときだけ**書く。読んだ結果「これは確かでない」と分かったとき。
  - **上げてはいけません**（出典を開いていないので、確かさを上げる根拠がありません）。
  - 下げたときは confidenceWhy に理由を必ず書く。下げないなら両方とも省く。
```

決算を読む回（そのまま引用）：

```
- なぜ動いたかは検索で確かめる。確かめられなければ why と read に推定として書き、confidence を下げる。
```

### 2-2. 目安の無い数字は、何を見て決めていることになるか

**書かれていないので、生成が4つの目安の間を自分で埋めている。** 実データから分かること：

- 「一次資料に当たれず報道のみ」と理由に書いた札 **35枚**の確度は、**4が16枚、5が19枚**。指示の目安は「4＝報道だけ」なのに、**半分以上が5**になっている。**同じ理由で4と5が分かれている**
- 8以上で理由がある札が3枚（指示は「8以上なら空」）。例：「確9｜金額は本文で確かめたが、公表日がページに書かれていない」
- **確度3の理由に、出典の確かさとは別の話が混ざっている：**
  - 「金額はロイターの試算で確定額でなく、**交渉段階の案件にとどまる**」（エジプトの LNG）
  - 「協調融資は銀行団への**打診の段階**で、金額も条件も成立していない」（サウジの協調融資）
  - これは「出典が怪しい」ではなく「**まだ起きていない**」。指示の目安（10〜1）は出典の確かさだけを説明しているが、生成は「起きたかどうか」も確度に入れている

### 2-6. どうするのが安いか

| 案 | 効くこと | 代償 |
|---|---|---|
| a. プロンプトに1〜10の目安を全部書く | 4と5の揺れが減る（これからの札） | 約150字増える。過去の113枚は今の数字のまま。**「出典の確かさ」と「まだ起きていない」が混ざる問題は直らない** |
| b. 段を減らす（例：確か／報道だけ／未確認の3段） | 揺れが小さくなる | 今の113枚の数字を読み替える決まりが要る。指示・画面・切り捨ての決まりを全部直す。**混ざる問題は直らない** |
| c. 今のまま（数字に意味は無いと割り切る） | 何もしない | 切り捨ては今の数字で続く。地図で外れた8枚は見えないまま |
| **d. 切り捨てを見えるようにする** | 地図の下に「確度3以下で外した動き N件」（押すと一覧と理由）。お金の一覧と地図の決まりを揃える | 地図の下の件数が1つ増える。お金の一覧を地図に揃えるなら、一覧の件数が変わる |
| **e. 「まだ起きていない」を確度から外す** | プロンプトに「交渉・打診・約束の段階であることは確度では表さない。pledge（約束）で表す」と書く | 約60字増える。これからの札だけ。今の2〜3枚（エジプト LNG・サウジ協調融資・イランの追加供与）は確度3のまま |

**推奨：d ＋ e。段の数と目安（a・b）は今は触らない（反対）。**

- **理由1：一番大きな問題は「基準の細かさ」ではなく「黙って外していること」。** 地図は直近90日で8枚を外していて、画面のどこにも出ない。これは説明の段（v20.26）で「数が合わない理由は必ず見せる」と決めた決まりに反している。d はそれを直す
- **理由2：「まだ起きていない」ものが確度で沈むと、約束の絞り（地図の「約束」）に出るはずのものが消える。** エジプトの LNG 交渉やサウジの協調融資の打診は、出典の確かさの問題ではない。e はこれを分ける
- **理由3：a・b は代償に比べて効き目が小さい。** 4と5の揺れは、切り捨ての線（3以下）に関係しない。**揺れで地図から消えている札は無い**（4と5はどちらも残る）
- **お金の一覧を地図に揃えるか（一覧でも確度3以下を外すか）は、判断をください。** 揃えるなら一覧の件数が減り、揃えないなら一覧の「数字の見方」に「地図は確度3以下を外している」と1行足す

**失うもの：**

- d：地図の下の件数の並びが1つ増える
- e：プロンプトが長くなる。これからの札で、交渉・打診の札が今より高い確度で入り、地図に残る（約束の線として薄く描かれる）
- a・b をやらないので、4と5の揺れは残る
