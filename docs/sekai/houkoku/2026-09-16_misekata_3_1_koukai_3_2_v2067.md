## 2. 段3-2（v20.67）を実装した

時間の札に **「前の値 → 今の値（差）」** を出すようにしました。

```
前の回の長期金利 2.891% → 3.005%（+0.114）
前年同期の設備投資 396億ドル → 806億ドル（+410億ドル）
```

棒にはしていません（0から伸ばすと金利がほぼ同じ長さになるため）。

### 2-1. 「字数0」にできませんでした（+92字）

**ここは指示と違う判断をしたので、先に書きます。**

「今の値」は `flow` の額から取れると考えていましたが、**取れませんでした。**

時間の札27枚を1枚ずつ照らした結果：

| `flow` の額と、札が言っている数字の関係 | 枚数 |
|---|---|
| 合う | 8 |
| **違う数字** | **12** |
| そもそも額が無い | 7 |

- 「米政府の債務総額が40.07兆ドルになった」 → `flow` の額は **35億8000万ドル**（その日の個人納税）
- 「8月末の外貨準備が795億ドル減」 → `flow` の額は **15兆3993億円**（介入額）
- 「ECBが預金金利を2.50%に引き上げた」 → `flow` そのものが無い

`flow` の額を「今の値」として出すと、**27枚のうち19枚で、札が言っていない数字が並びます。**

そこで `cmp` に **`now`（この札の数字）** を1つ足しました。費用は実測 **+92字**（26,040 → 26,132字）。3万字までの余裕は約3,850字あります。

**失うもの**：チャットに書かせる項目が1つ増えます。書き忘れたら、その札には何も出ません（間違った数字は出ません）。

### 2-2. 差の出し方

- **単位がぴったり同じときだけ差を出す。** 「4億1540万バレル → 2億8540万バレル」のような複合の単位では、差を出しません（間違った引き算をしない）
- 単位が `%` のときは、差に単位を付けません（ポイントと％の取り違えを避ける）

## 4. 公開の前に実機で確かめてほしいこと
