## 2. 見せ方（質問3・4・5）

### 2-1. 横棒2本でよいか → **よいです。ただし2つの形になります**

- **全体の中の一部（24枚）**：帯を1本描き、その中を占める分を塗る
  `900億ユーロ ▓░░░░░░░░░ うち30億（3%）`
- **比べる（A・C・E 26枚）**：同じ物差しの上に2本並べる
  `今回 806億 ████████　前年同期 396億 ████`

どちらも「同じ物差しの上の長さ」という同じ部品です。**中に入るか、横に並ぶか**の違いだけです。

**失うもの**
- 高さを使う（1本18px＋名前で、2本なら約60px）。文が下に押される。地図が出ない札に出すので、地図と重なることはありません
- 通貨が違うとき、ドルに直さないと長さを比べられません。**ドルに直せない札では出さない**決まりが要ります（54枚中44枚はドル換算済み）

### 2-2. 比べる相手が無いとき（4枚） → **何も出さない**

額だけを大きな字にするのは**反対**です。大きな字は「重要だ」という合図になり、比べた結果ではありません。目盛りに当てはめるのも反対で、その目盛りをどこから持ってくるかが、また編集判断になります。

**4枚は1行のまま**にしてください。

### 2-3. 位置 → **地図と同じ、「なぜ」の直下**

印が `size` の札には地図が出ないので、場所は空いています。1行（お金：）はその下のまま。

## 3. データ（質問6・7・8・9）

### 3-1. 文の中の数字を機械で取れるか → **取れません（実測）**

「前年同期は」「前期は」などを拾う正規表現を書いて54枚に当てました。

| | 結果 |
|---|---|
| 取れた | **4枚**（Alphabet・Microsoft・Amazon・Oracle） |
| 型A（同じ主体の前の額）13枚のうち取りこぼし | **9枚** |

取れた4枚はどれも決算書の定型文（「前年同期は396億4300万ドル」）でした。取れなかったのは「2026年度の概算要求額は8兆8454億円だった」「前年同期の出荷は509隻分」のように、書き方が毎回違うものです。

さらに、**取れても「何と何を比べているか」は分かりません**。「前期は645億5100万ドル」という文字列だけでは、それが設備投資なのか自社株買いなのか配当なのか決まりません（Microsoft の詳しくには、その3つが並んでいます）。

**チャットに書かせるべきです。** 札を書いている時点なら、どの数字がどれかを分かっています。

### 3-2. 同じ主体の過去の札から額を拾えるか → **拾えません**

主体の記録（`actors.json`）が持っているのは、**名前・別名・種類・国と、その主体が出てくる札の id の一覧**だけです。「したこと」の時系列も、額も持っていません（99人すべて0件）。

札の id をたどれば額にはたどり着きます。54枚中29枚で、同じ主体の別の札に額がありました。**ただし中身が使えません。**

実例（トヨタ自動車の札の一覧、そのまま）

| 札 | 日 | 額 |
|---|---|---|
| トヨタが4〜6月に3兆6569億円の自社株買いを実施 | 2026-08-04 | 3兆6569億円 |
| トヨタが上限1兆円の自社株買いを決定 | 2026-08-04 | 1兆円（上限） |
| トヨタが1兆円の自社株買いと2億株の消却を決めた | 2026-08-04 | 1兆円 |
| トヨタが1兆円の自社株買いと通期見通しの引き上げを発表 | 2026-08-04 | 1兆円 |
| トヨタの自社株買いが1年で3兆6569億円 | 2026-08-04 | 3兆6569億円 |

**5枚とも同じ日の、同じ自社株買いです。**「前の額」は1つもありません。これは重複札の問題（別の相談）がそのまま出ています。

デッキが育てば前の額は貯まりますが、**いまは無い**、が答えです。

### 3-3. 地層の値と機械的に対応づけられるか → **できません**

大きさの札に付いている地層は6つでした。

| 地層 | 単位 | 貯まっている値 | 札 |
|---|---|---|---|
| 世界の軍事費 | 億ドル | **1点** | 7枚 |
| 各国中銀の金保有 | トン | 2点 | 2枚 |
| 世界貿易/GDP | % | 55点 | 2枚 |
| 日本の政府債務/GDP | % | 1点 | 2枚 |
| 日本の長期金利 | % | 4点 | 1枚 |
| 米国の政府債務/GDP | % | **0点** | 1枚 |

**額と比べられる単位を持つのは「世界の軍事費」だけで、値が1点しかありません。** 残りは % か トン で、円やドルの額とは比べられません。

規則を作っても無理です。「防衛省の8兆8908億円」と「日本の政府債務/GDP 260%」は、単位が違うので同じ物差しに乗りません。

### 3-4. 朝のプロンプトに欄を足すか → **足します**

- 足すもの：比べる相手（`cmp`）＝ 相手の名前・値・関係（「前の額」「全体」「他者」「稼ぎ」）。**推測で約400字**（効かせた相手の節が実測395字なので、同じ規模）
- **同時に「最近のお金の動き」の節（実測2,053字）を外します**（前回の約束どおり。鎖は8本中2本しか効いていません）
- 差し引き：27,698字 → **推測で約26,045字**（上限3万字）

**規則に必ず入れるべき1行**：比べる相手は、**その出典の中にある数字だけ**にする。外から探してこない。理由は5節。

## 4. 見た目（質問10・11）

### 4-1. 長さは線形か対数か → **線形です。対数には反対します**

地図の線の太さが対数5段（1億ドル→1px、1兆ドル→7px）なのは、**太さは5倍までしか使えない**からです。棒は画面の幅いっぱいまで使えるので、その制約がありません。

そして**棒の長さは量そのものです。** 対数にすると、2倍の額が1.1倍の長さに見えます。これは読む人を欺きます。

### 4-2. 桁が大きく違うとき → **100倍を超えたら棒をやめて、言葉にする**

実データで比の大きさを測りました。

| | 比 |
|---|---|
| 全体の中の一部24枚 | 3%〜83%（いちばん小さいのがEUの初回送金3%） |
| 比べる26枚 | ほとんど1.0〜3.4倍。いちばん大きいのが**トヨタ 3兆6569億 対 399億＝92倍**、いちばん小さいのがカタール 18隻 対 509隻＝**1:28** |

**100倍を超える札は、いまのデータには1枚もありません。** それでも決まりは要ります。100倍を超えたら、棒（1px以下になる）をやめて「政府債務の0.1%」と書く。

もう1つの端：**防衛省の8兆8908億 対 8兆8454億は1.005倍**で、棒2本が同じ長さに見えます。これは「ほとんど変わっていない」という読みなので、そのままで正しいと考えます。ただし差（454億円増）を数字で添えます。

## 5. 反対すること（質問15）

### 5-1. いちばん大きな危なさ：比べる相手の選び方は編集判断です

トヨタの1兆円の自社株買いを

- 前回の自社株買い（399億円）と並べると → **92倍。異常な規模に見える**
- 同じ四半期の営業利益（1兆634億円）と並べると → **ほぼ同じ。稼ぎの範囲内に見える**
- 通期の設備投資（2兆3000億円）と並べると → **その半分以下。控えめに見える**

**どれも本当の数字ですが、受ける印象は正反対です。** 棒にすると、これが「事実」の顔をします。文の中の数字なら、読む人が自分で選べます。

**防ぐ決まりを3つ勧めます。**
1. 比べる相手は、**その札の出典の中にある数字だけ**。外から探してこない
2. 相手の**名前と値を必ず棒の横に書く**（「前年同期 396億ドル」）。棒だけにしない
3. 相手は**1つだけ**。2つ3つ並べると、選び方の影響がさらに増える

### 5-2. 「文の額を読めば足りる」という考えについて

**一部はそのとおりだと思います。**

- **全体の中の一部（24枚）には賛成です。**「143兆のうち36.6兆」を「4分の1」と読み替えるのは、頭の中でやると手間で、帯なら一目です
- **同じ主体の前の額（13枚）にも賛成です。** 2倍か1.05倍かは、並べれば一目です
- **同じ種類の他者（9枚）には反対します。** 「信越99.2% 対 デナル80.8%」は棒にしても分かりませんし、対日と対米のレアアースは母数が違うので、並べると誤読を生みます。ここは文のままがよいと考えます
- **稼ぎと比べる（4枚）は、5-1 の危なさがいちばん出る型です。** 後回しを勧めます

つまり、**私が賛成するのは54枚のうち37枚**（全体の中の一部24＋前の額13）です。

### 5-3. 145枚の埋め直しには反対します

前回の埋め直し（効かせた相手）は1回3万字の壁で2回に分けました。**新しい札から効かせれば十分**です。古い札は文のまま読めます。

## 7. 測れないこと

## 8. 勧め（まとめ）

1. **段2-1 から始める**（欄に総額がある13枚の帯。新しいデータ0）
