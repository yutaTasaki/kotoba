## 何をしたか

2. 仕様書を第3版に直した（3.3〜3.5 を9px固定に書き直し、長さを探す仕組みを外した）

## 結果（先に）

- **9px固定に賛成。** 今の iPhone の地図の幅（343〜398px）では、9pxの根はどの国の点にも触れない。触れるのは画面320ptの初代 iPhone SE（地図の幅288px）の日本だけ
- **「全部」の画面は v20.29.1 と同じ。** 5地域×6種類＝30通りの画面の文字・線の本数・点の数を比べ、変わったのは「自分に使う」のボタンの件数（18→20、アジア 8→10）だけ
- **「自分に使う」を押すと、根14本（6か国）・線6本・「根だけ描いたもの 2本」。** 根は全部9px、太さは米国7px・日本／中国／台湾／カナダ5px・メキシコ3.5px
- **切り替えを出さない側にすると、30通りすべてで v20.29.1 と差が0**（網の⊥も0本、数字の見方の根の説明も出ない）
- **網の⊥は9本**（米国4・中国2・カナダ1・メキシコ1・日本1）
- 確かめの中で出たエラーは0
- **仕様どおりでなかった所が1つ：** 根を押すと、**必ず**「この辺りの線・国」の一覧が出る（根だけが直接開く所は無い）。一覧の中の「〇〇の根（N本）」を押すと開く（2.3）

## 1. 聞かれたことへの答え

### 1-1. 9px固定に賛成か → **賛成**

長さが状況で変わらないので、「日によって額が減ったように見える」「拡大で長さが変わる」が丸ごと消える。**根を出さない国の条件は第2版と同じ**（第2版でも9pxまで短くして触れる国は出さなかった）なので、固定にしても出さない国は増えない。

### 1-2. 3.3 の仕組みはどれだけ簡単になったか

- 第2版：国ごとに14pxから1pxずつ短くして触れない長さを探し、画面の中で一番短い長さを出し、全部の根をそれに揃える（拡大のたびにやり直す）
- 第3版：**国ごとに9pxで1回だけ触れるかを測り、触れたら出さない。** 画面全体で長さを揃える処理が無くなった
- 実装では、根の描き方と触れるかの判定を合わせて **約20行**。第2版の形なら、長さを探す繰り返しと揃える処理がさらに要った

### 1-3. 9px固定で、今のデータでほかの点に触れる国はあるか

「自分に使う」の画面で描く点（根の6か国＋線の端のベネズエラ・サウジ・シリア）で測った。**地図の幅＝画面の幅から左右の余白16pxずつを引いた幅。**

| 地図の幅（画面の幅） | 全体図 | 米州・中東・アジアの図 |
|---|---|---|
| 288（320pt・初代 iPhone SE） | **日本→台湾の点に0.7px食い込む → 日本の根を出さない** | 触れない |
| 320（352pt） | 触れない（日本と台湾のすき間0.8px） | 触れない |
| 343（375pt・iPhone SE 第2・3世代など） | 触れない（すき間1.9px） | 触れない |
| 358（390pt）・361（393pt） | 触れない（すき間2.7px） | 触れない |
| 398（430pt・Pro Max など） | 触れない（すき間4.7px） | 触れない |

**何を含めて測ったか：** 国の点は半径3.5px＋縁の線0.5px。根の縦棒は点の中心から下へ4pxの所から先まで、太さはドル換算の段。⊥の横棒は幅＝根の太さ＋4px・太さ1.5px。線と字は含めていない。上の表は、アプリと同じ地図の部品で位置を出した計算と、実装した画面で描いた根と点の位置で測った値の両方で同じ結果になった。

**前の報告の訂正：** 前の報告の表の「幅320／360／390」は、**地図の幅**の数字だった。画面の幅ではない。

### 1-4. 実機で9pxが短すぎたとき、それでも固定のほうが良いか → **固定のほうが良い**

値を上げたときに全体図で日本の根が出なくなる地図の幅：

| 固定の値 | 日本の根を出さない地図の幅 | 当たる端末（画面の幅） |
|---|---|---|
| 9px | 288 | 320pt（初代 SE） |
| 10px | 288・320 | 〜352pt |
| 11px | 288・320（343 はすき間0.3px） | 〜352pt |
| 12px | 288・320・343 | 375pt（SE 第2・3世代）まで |
| 13px | 358・361 まで | 390・393pt まで |
| 14px | 390未満のすべて | 430pt 未満のほぼ全部 |

**見立て：**

- 上げるなら **11pxまでなら、今の iPhone（375pt以上）では日本の根は消えない**。12pxにすると 375pt の端末で消える
- 消えても、地図の下に「アジアの図で見られる根 N本（日本）」が出て、押すとアジアの図で日本の根が出る（2.3 の13で確かめた）。黙って消えはしない
- 変える所は1か所（長さの値）。**お使いの端末の画面の幅が分かれば、どこまで上げられるかが決まる**

## 2. 実装

### 2.1 何が変わったか（使う側から見て）

- 地図の種類で「**自分に使う**」を押すと、主体の国の点から**下へ9pxの根**（先は⊥、矢印なし、いつも実線）。太さは線と同じドル換算の段で、1つの国に1本（太さはその国の一番大きい1本の段）
- 相手が別の国の自分に使う金（6本）は**横の線のまま**
- 相手の場所が分からない TSMC の2本も、台湾の根として描く
- ボタンは「自分に使う（20）」（地域：全体20・米州11・欧州1・中東2・アジア10）
- 地図の下の行：「自分に使う 20本：根 14本（6か国）・相手が別の国の線 6本」「相手の場所が分からず、主体の国に根だけ描いたもの 2本」。点に触れて出さない根があれば「〇〇の図で見られる根 N本（国名）」
- 選んだときの1行：「根＝自分の側に積んだ金、線＝行き先が別の国」
- 数字の見方に「根（自分に使う）」の節を足した
- 約束の金の根は薄い（今はカナダ・モントリオール銀行の1本）
- 国の網で、国の中の自分に使う金の矢印の先を⊥にした
- **「全部」の画面・小さな地図は変えていない**
- やめるときは、アプリの中の1か所（根を出すかどうか）を変えるだけ。長さも同じ場所の1つの値

## 3. 実機で見るもの（仕様書 11. の11項目）

1. 「自分に使う」を押したとき、根が根に見えるか（点から下に出た棒として、線と見分けられるか）。特に米国（7px）とメキシコ（3.5px）
2. ⊥の横棒が、5px・7pxの根の先で⊥に見えるか
3. **9pxの根が根に見えるか。** 見えなければ長さの値を上げる（上げたときに日本の根が消える幅は 1-4 の表）
4. 日本の根が台湾の点に触れていないか。台湾の根が台湾の点から出ているのが見えるか
5. 全体図と地域の図、拡大したときで、根の長さが変わらないか
6. 横に残した6本の線が、根と別のものに見え、「行き先が別の国」と読めるか
7. カナダの根を、米国→カナダの線（幅によっては日本→米国の7px破線も）が横切る所が読めるか
8. 約束の根（カナダ・モントリオール銀行）が薄く見えるか
9. 米国の網で、⊥の矢印が「自分に使った」と読めるか
10. お使いの端末で 1〜9（地図の幅＝画面の幅−32px。1-3 の表のどれに当たるか）
11. 「全部」の画面が v20.29.1 から変わっていないこと

**読めなければやめる：** アプリの中の1か所（根を出すかどうか）を変えれば、v20.29.1 と同じ画面に戻る（2.2 の5で確かめた）。
