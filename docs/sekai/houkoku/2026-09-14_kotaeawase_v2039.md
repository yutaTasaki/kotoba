## 何をしたか

- 予告の画面（世界 → 予告）に「答え合わせ」の塊を置いた：［答え合わせのプロンプトをコピー］・貼る欄・［答え合わせを取り込む］。期限が来た予告が0本のときは出ない
- プロンプトは押したときに組み立てる。1回10本。まだ見立てが付いていない予告を期限の古い順に載せ、全部に見立てが付いていたら聞き直す
- 生成に聞くもの：結果と根拠の url・事実の種類（期限の後に起きた／逆の動き／動きが見当たらない／数字が届かなかった）・確かめられなかった理由（まだ発表されていない／公表されない数字）・当たりの印で確かめたか・実際の数字
- 取り込み：当たり・外れは url 必須。組み合わせが合わないもの・押してある予告・端末に無い予告は取り込まず、理由ごとの本数を1行出す。**結果（当たり・外れ・確かめられない）は変えない**
- 画面：見立ての下に根拠1行・事実・根拠の url（押すと別のタブ）・印で確かめたか・実際の数字・確かめられなかった理由。**url の無い見立てには「URLなし」の印**（推定と同じ色）
- 外れを押した予告に「思惑の読み違いか：［読み違い］［読みは合っていた］［分からない］」。人が選ぶ。もう一度押すと外す
- 朝の取り込む回のプロンプトから答え合わせの節を外した。古い形の答え合わせが貼られたら取り込まず1行出す

**仕様書から変えたこと（実装中に見つけた）：** 返事の形の例に、載せた予告の本物の番号を入れていた。生成が例の中身（「外れ・期限の後に起きた・指定は2行」）をその予告の答えとして写すおそれがあるので、例の番号を架空のもの（`fc_20260101_000000`）にし、「例の中身は形を示すための架空のもの」と1行足した。

## 結果

### 回答書の確かめ

**1. 米財務省の1本で、本当にボタンを押してプロンプトを作った**
- 予告の画面で［答え合わせのプロンプトをコピー］を本物のクリックで押した → 「1本ぶんをコピーしました（1,392字）」
- コピーした文：今日の日付、必ず守ること（検索する・当たり外れは url 必須・動きが見当たらないときの url・思惑は書かない）、米財務省の予告（期限・当たりの印 CNBC・元の推定・元の札「米財務長官が9月14日に大手銀行を制裁すると予告」）、返事の形と各欄の説明が入っていた
- 仕様書の試作（約1,440字）より少し短いのは、文面を整えたため

**2. 期限が重なった日（10本）**
- 期限切れを12本にした → 塊の見出し「期限が来た予告 12本・見立てがまだの 12本」
- コピー → 「10本ぶんをコピーしました（3,625字）。ほか 2本は、取り込んだ後にもう一度コピーすると出ます。」コピーした文に載った予告は10本
- 10本に見立てを取り込んだ（本物のクリック）→「答え合わせの候補が10本つきました」。10本とも結果は「まだ」のまま。見出しは「見立てがまだの 2本」
- もう一度コピー → 「2本ぶんをコピーしました（1,621字）」。載ったのは残りの2本だけ

**3. url が無い結果を貼ったとき**（11本の試しの返事を1回で貼った）

| 貼ったもの | 結果 |
|---|---|
| 外れ・url なし | **取り込まれない** |
| 当たり・url が `javascript:` | **取り込まれない** |
| 確かめられない・url なし・理由「まだ発表されていない」 | 取り込まれ、**「URLなし」の印** |
| 確かめられない・url なし・事実「動きが見当たらない」 | 取り込まれ、「URLなし」の印 |
| 外れ・url あり・事実「期限の後に起きた」・別の出典「ロイター」・実際の数字「指定は2行」 | 取り込まれ、印なし。根拠の url・事実・別の出典・実際の数字が出た |
| 外れ・url あり・事実「動きが見当たらない」（発表一覧のページ） | 取り込まれた |
| 外れ・url あり・事実なし | 取り込まれない（組み合わせ） |
| 確かめられない・理由も事実もなし | 取り込まれない（組み合わせ） |
| 判定が「maybe」 | 取り込まれない |
| 押してある予告 | **変わらない** |
| 端末に無い予告 | 無視 |

結果の1行：「答え合わせの候補が4本つきました。見て、押して確定してください。うち url なし（確かめられない）2本には「URLなし」の印を付けました。前の見立てを置き換えた3本。※ url が無い当たり・外れ 2本を取り込んでいません。※ 事実の種類・理由が合わない 2本を取り込んでいません。※ 当たり／外れ／確かめられない のどれでもない 1本を取り込んでいません。※ すでに押してある予告 1本は変えていません。※ 端末に無い予告 1本は無視しました。」

取り込まれなかった予告に前からあった見立ては、そのまま残った。

## 意味

- 期限が来た予告は、予告の画面で「コピー → Claude に貼る → 返事を貼る」で、根拠の url つきの見立てが並ぶ。当たり外れは自分で押す
- url の無い見立ては印で分かる。url の無い当たり・外れは入らない

## やった場合に失うもの

- 朝の取り込む回のついでに答え合わせが付かなくなった（コピーと貼り付けが1回増える）
- 予告1本に欄が8つ増えた。**v20.38 までの端末は予告を整えるときに落とす**
- 見立てを入れ直すと、前の見立ては残らない（置き換えた本数は出す）
- 予告1本の表示が長くなった
