## 先に：結果

- 語り方を取り込んだ後に**［記事にする ▸］**が出るようになった（選んだ枠と、札の画面の語り方の欄。「芯になりにくい」語り方には出さない）
- 押すと**記事づくりの画面**が開き、4つの往復を上から順に進める
  1. 企画：依頼文をコピー → 返事（JSON）を貼る → サムネ案・タイトル案・冒頭案を**1つずつ押して選ぶ**
  2. 本文：依頼文をコピー → 返事の本文をそのまま貼る → **アプリが字数・図の印・出典の行・出典の無い区切り・アプリの言葉・言い切りを数えて1行で出す**
  3. 図：依頼文をコピー → 返事（JSON）を貼る → 図ごとの型・数値・絵の中の文字
  4. 確かめ：依頼文をコピー → 「直した点：N … ---本文--- …」を貼る
- 最後に**できあがり**：タイトル／サムネの文字／サムネのプロンプト／本文（タイトルの行を除く）／図ごとのプロンプトを、それぞれ1回押してコピー。グラフは「Claude に貼る」、ほかは「画像生成AIに貼る」と書き分けた。［note に出した］で出した日が残る
- **アプリを離れて戻っても、記事づくりの画面に戻る**（チャットと行き来するため）。貼った返事も取り込むまで残る
- 語り方の依頼文に、**開けなかったときに当たる近い立場の媒体の一覧**（国・持ち主ごと15行）を入れた。持ち主の選択肢に「軍系」「党系」を足した
- 依頼文の長さ（手元の試し）：企画 約4,400字・本文 約4,400字・図 約2,300字・確かめ 約5,600字

## 2. 気づいたこと

- **試作の本文は、アプリの数え方で約1,070字だった**（出典の行・見出し・図の印を除く）。仕様の目安 2,000字より短い。試作の報告で「約1,950字」と書いたのは url を含めた長さで、誤りだった（試作の報告は直した）。→ 本人の判断で、目安の1点ではなく**下限1,500字・上限2,500字の幅**にした（依頼文と、取り込みの1行の知らせの両方）
- 「出典の行が無い見出しの区切り」は目安。試作では「計算してみると」（一般の目安だけ）と「次のニュースで見ておきたいこと」（まとめ）が数えられた。出典が要らない区切りもあるので、赤い警告にはしていない
- 画面を離れていた間に語り方の記録が別の端末から届いていないと、「元の出来事か語り方がまだ端末に届いていません」と出る
