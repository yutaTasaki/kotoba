## 先に：結論

1. **日銀の札は、2回とも何も書かれていなかった**（片方だけではない。控えにも無い）。規則の「自分の国の中だけの手（利上げ…）は []」と「なぜの背景に出るだけの国は書かない」の2つに引っかかったと見ている（推測）。**規則が本当の手を落としている**。揺れた11枚のうち5枚も「米国 → イラン」を背景と見るかどうかの揺れ
2. 調べる途中で、**線が出ない理由がほかに2つ**見つかった
   - 返事に「国連安保理」「国際刑事裁判所」「BRICS」と書かれた組が、場所に当たらず控えになっている（**規則の例に「国連安保理」と書いたのに、アプリがそれを場所にできない**）
   - 効かせた線を「確度3以下の札には描かない」にしたため、線がある7枚が地図に出ていない（米財務長官 → 日本「リフレの終了」など）
3. 残っている「札」は、ほとんどが「札そのもの」（札にする・作る・まだ読んでいない札）。見出しと、別の札を指す言葉（「9/14 の札（1）」「つながる札」「続報の前の札」）は **「出来事」** にするのを勧める
4. **地図にならない札に「2つの箱と矢印」の図を置くのは反対。** 箱に書く名前は、すぐ下の1行とまったく同じで、読む助けが増えない。代わりに1行に国を足す（「日本の中：トヨタ自動車 → 株主」）。数字の1行も反対（前の値は、札の文にもう書いてあるか、取れないか）
5. **③（海峡の点）を先に。** その中に、場所の表の穴（安保理など）、規則の直し（日銀）、確度3以下の決め直し、埋めた返事を残さない直しを入れる

## 2. 日銀の札に線が出ていない（確かめた）

### 2.1 記録（実測）

| | 中身 |
|---|---|
| 札 | 日銀が9月会合で政策金利を1.25%にする方針 |
| なぜ | …米財務長官からも利上げを求められている。… |
| 動かした側 | 日本銀行だけ（米財務省はいない） |
| 1回目の返事 | [] |
| 2回目の返事 | [] |
| 札ごとの記録 | 線なし・控えなし |

→ **両方とも書かなかった**。片方だけではないので、控えにも「米国 → 日本」は無い。

**なぜ書かれなかったか（推測）**
- 規則の「自分の国の中だけの手（**利上げ**・統計・保有高・自国の予算）は []」に、日銀の利上げがそのまま当たる
- 米国 → 日本の要求は「なぜ」の中にしか無く、「なぜの背景に出てくるだけの国は書かない」にも当たる
- 同じ中身の札「米財務長官が日本に『リフレの終了』を求めた」には、2回とも「米国 → 日本（要求）」が付いている。主体が米国の札なら書かれ、主体が日銀の札では書かれない

### 2.2 「背景の国は書かない」は、本当の手を落としていないか（揺れた11枚・片方だけ11組を見た）

| 揺れの形 | 枚数 | 札 |
|---|---|---|
| **狙いの国（米国 → イラン）を、書くか背景と見るか** | **5** | トルコの銀行を制裁（狙いはイラン）、ヒズボラ支援網の制裁2枚、大手銀行の制裁予告、長官のホルムズ発言（イラン → 米国） |
| お金の動きがある投資・買収を、効かせた手としても書くか | 2 | サウジの EA 買収（サウジ → 米国）、サウジ企業のシリア太陽光（サウジ → シリア） |
| 2つ目の相手を書くか | 3 | 米国 → グアテマラ（送還）、ウクライナ → 米国（契約）、カタール → 欧州・アジア |
| 相手が主体の中にいない | 1 | オマーン → イラン（協議延期） |

- **5枚は、制裁の本当の狙い（イラン）を「背景」と見るかどうかで揺れている**。なぜに「イランの資金の通り道を塞ぐ」と書いてある札で、1回は書き、1回は書かなかった。規則が手を落としている側に効いている（推測だが、5枚とも同じ形）
- 46枚で◎だった23枚のうち、線の記録ができたのは19枚。できなかった4枚は：日銀（2回とも書かない・上の規則）、欧州議会（片方だけ）、安保理2枚（場所に当たらない・3章）。ヒズボラはレバノンは線、イランは片方だけ
- 線の記録ができた19枚のうち4枚（NATO・サウジの原油生産・ドイツ・リフレ）は、確度3以下のため地図には描かれていない（3.2）

### 2.3 規則の直し方（案）

| 案 | 中身 | 失うもの |
|---|---|---|
| **A 手の定義を足す（推奨）** | 「自分の国の中だけの手は []。**ただし、他の国から求められた・他の国に向けた手は書く**（例：米国が日本に利上げを求めた → 米国→日本 要求）」「**なぜに書いてある狙いの相手（制裁で断とうとしている国など）は書く。**なぜに名前が出るだけの国は書かない」 | 揺れは今より増えるかもしれない（測れません）。規則が約80字長くなる（推測） |
| B 背景の規則を消す | 「なぜの背景に出てくるだけの国は書かない」を消す | 46枚の相談で自動で拾ったときの誤り（背景の国を相手と読む）が、チャットの側で起きる |
| C 今のまま | — | 日銀のような札と、制裁の狙いの国が落ち続ける |

- 直したあと、今ある145枚を埋め直すかは、朝の取り込みで数日見てから決めればよい（日銀の札1枚のために2回×30,000字は重い）

## 3. 線が出ない理由がほかに2つ（調べる途中で見つけた）

### 3.1 場所に当たらない名前（実測。控え5件のうち）

| 札 | 返事の組 | なぜ当たらないか |
|---|---|---|
| 決議2803を採択させた | 米国 → **国連安保理** | 国際機関の枠の名前の表に「国連」「国際連合」はあるが「国連安保理」「安保理」が無い（丸ごと一致だけ） |
| 安保理の停戦決議案に反対 | 米国 → **国連安保理** | 同じ |
| NATO 加盟国に ICC 脱退を要求 | 米国 → **国際刑事裁判所** | 表に無い（NATO の方は線になっている） |
| BRICS 新デリー宣言 | インド・中国 → **BRICS** | 表に無い |

- **規則の例に「国連安保理」と書いたのに、アプリがそれを場所にできない**。仕様書を書いたときの見落とし
- 直し：枠の名前の表に「国連安保理・安保理・国連総会・国際刑事裁判所・ICC・BRICS」などを足す（③に入れる）

### 3.2 確度3以下の札の効かせた線（実測）

効かせた線の記録があるのに、確度3以下のため地図に出ていない札が **7枚**：米国 → 日本（リフレの終了、確度3）、ドイツ ⇄ ロシア（無人機、確度3）、米国 → NATO（ICC、確度3）、カナダ ⇄ 米国（報復関税、確度3）、イエメン → サウジ（施設攻撃、確度2）、米国 → レバノン（確度3）、イラン → サウジ（確度2）。

- お金の線と同じく「確度3以下は描かない」にしたが、確度3は「報道で、要人の発言を伝えている」札に多い（推測）。効かせた手はそもそも発言や発表が多く、この決まりで落ちる割合がお金の線より大きい
- 案：(ア) 今のまま（1行は出る）／(イ) 確度3以下の効かせた線は薄く描く（失うもの：薄さは約束の線がもう使っている。橙の薄い線と緑の約束の線が似る）／(ウ) 効かせた線には確度の決まりをかけない（失うもの：噂の手が線になる）。**本人に決めてほしい**（私は(ア)のまま1行で読む形を勧める。地図は確かな物だけ、を崩さないため）

## 4. 「札」という言葉が残っている（問3）

### 4.1 洗い出し（画面の文字列を、入っている画面ごとに数えた。プロンプトの文は除く）

| 画面 | 残っている「札」の例 | 意味 |
|---|---|---|
| **札の一覧の見出し** | 「9/14 の札（1）」「続報の札（N枚）」「同じ動きの札（N枚）」「『〇〇』の札」（探す）「この国の札を一覧で見る」（網） | **出来事の並び** |
| **札の画面の中** | 「つながる札」「続報の前の札：」「自分で調べて作った札（元の札：）」「同じと判断した札：」「この主体が動かした札（時系列）」「札を開く」 | **別の出来事を指す** |
| 札を作る・取り込む操作 | 札にする・書いてあった・札を作る・似た札がもうあります・入れた札を見る・この札に取り込む・札の候補 | 札そのもの（アプリが作る物） |
| 数・状態 | まだ読んでいない札・背景の札・読んだ札・読む札・端末に無い札・外れた札 | 札そのもの（枝も葉も入る） |
| 設定・幹の割り直し・埋める画面・説明文 | 段B で札を2回割らせます・効かせた相手の記録が無い札・渡していない札 | 札そのもの |

（数えた範囲：アプリ本体の画面に出る文字列で「札」を含むもの 約140か所。うち見出しと別の出来事を指す言葉が約15か所）

### 4.2 枝・葉に置き換えられるか

- **置き換えられるものは、ほぼ無い**。「つながる札」「続報の前の札」は、相手の札が枝のことも葉のこともある（1枚ずつ幹の記録を見て「続報の前の枝」「続報の前の葉」と出し分けることはできるが、見出しの言葉が札ごとに変わり、読む側が「枝と葉で何が違うのか」を考える場面を増やす。**反対**）
- 札を作る操作・数・状態は「札そのもの」なので残す

### 4.3 見出しと、別の出来事を指す言葉の案

| 案 | 例 | 失うもの |
|---|---|---|
| **A 「出来事」にする（推奨）** | 「9/14 の出来事（1件）」「つながる出来事」「続報の前の出来事：」「同じ動きの出来事（3件）」「この国の出来事を一覧で見る」 | 「札」（作る・読む）と「出来事」（並び・つながり）の2つの言葉が並ぶ。字が少し長くなる |
| B 見出しから「札」を外す | 「9/14（1件）」「つながり」「続報の前：」 | 何の並びか分からない見出しがある（「9/14（1件）」は、探すや網から来たときに何の1件か読めない） |
| C 今のまま | — | 本人の気になる所がそのまま |

- 数える単位は「枚」から「件」に揃える（出来事は「件」で数える方が自然）
- 失うもの（案A 全体）：これまでの報告・仕様書の「札の一覧」「つながる札」の呼び名とずれる

## 5. 世界地図にならない札に、別の図を置けないか（問4）

### 5.1 地図が出ない札は何枚か（実測、埋めた後の本物の写し145枚）

- 地図が出る札：**72枚**（直し①のときの52枚から、効かせた線で20枚増えた）
- 地図が出ない札：**73枚**

| 種類（指示書の3つ＋その他） | 枚数 | 中身 |
|---|---|---|
| **国の中の動き** | **26** | 国内25（トヨタ → 株主、米財務省 → 金融機関、Microsoft → 取得先 など）＋同じ枠どうし1（日銀の国債保有比率） |
| **相手の場所が決まらない** | **9** | 欧州の投資家 → 金ETF、米国防総省 → ボーイング、日本 → 原油の輸出国、サウジ政府 → 紅海のヤンブー港 など |
| 確度3以下の動き | 8 | カナダ → 米国（報復関税）、イラン → フーシ派 など。1行は出る |
| **数字の動き** | **16** | 政策金利（ECB 4枚・日銀・FRB・ロシア中銀）、長期金利・英国債利回り、米消費者物価、家計の金融資産2枚、富裕層、上位0.1%、ロシアの基金、サウジの原油生産 |
| 手はあるが線にならない | 14 | 海峡・港（フーシ派 3枚）・場所に当たらない（安保理2・BRICS）・確度3以下（ICC・ドイツ・リフレ）・片方だけ（欧州議会・オマーン・長官発言）・OPEC 据え置き・保険プール |

### 5.2 「2つの箱と矢印」は今のデータから作れるか（問2）

- **作れる**。国の中の動き26枚・相手の場所が決まらない9枚・確度3以下8枚の計43枚は、全部、出す側と受け取る側の名前を持っている（誰から誰への1行に使っている名前そのもの）
- **ただし反対**：
  - 箱に書く名前は、図のすぐ下の1行（「トヨタ自動車 → 株主　自社株買い 3兆6569億円」）と**まったく同じ**。世界地図は「どこからどこへ」という文に無い物（場所と向き）を足していたが、2つの箱は文を図に描き直すだけで、足す物が無い
  - 「読んでいる場所に、その動きが見える」は、今の1行ですでに満たしている（地図の無い札でも、なぜの直下に出ている）
  - 43枚の画面に図が増え、下へ流す量が増える（推測で1枚あたり60〜80px）
- 代わりの小さな直し（推奨）：**国の中の動きの1行に、国の名前を前に付ける**
  - 「日本の中：トヨタ自動車 → 株主　自社株買い 3兆6569億円」
  - 世界地図の点1つが伝えようとしていた「どこの国の中の話か」だけを、文で足す。失うもの：1行が数字長くなる

### 5.3 数字の動きの「前の値」はどこから取れるか（問3、実測）

数字の動き16枚について：

| 取れる場所 | 枚数 | 例 |
|---|---|---|
| **その数字と同じ地層**（値の並びが2つ以上） | **2** | 長期金利 → 地層「日本の長期金利」（値4つ）、上位0.1% → 地層「米国 上位0.1%の富の割合」（値147） |
| 札に付いている地層はあるが、別の数字 | 4 | 日銀の政策金利 → 地層は「日本の長期金利」、米消費者物価 → 「米国の長期金利」 |
| 同じ主体の前の札に同じ数字 | 0 | サウジの原油生産は、同じ主体の前の札が2枚あるが原油生産の数字ではない |
| **札の文そのもの**に前の値か変わり方が書いてある | 多い（推測で16枚中10枚前後） | 日銀「1.0%から1.25%へ」、サウジ「前月から約190万バレル減った」、ECB「0.25%引き上げ」、長期金利「30年ぶり」 |

→ 「前の値 → 今の値」を別の欄として作れるのは2枚だけ。残りは、札の文にもう書いてあるか、取れない。

### 5.4 3種類の見た目で混乱しないか（問4）

- 世界地図・箱と矢印・数字の1行の3つにすると、「この図は場所を表しているのか、ただの向きか」を札ごとに読み分けることになる。**混乱する見込み**（推測）
- 混乱しないために要る決まり（入れる場合）：図の上に「地図」「動き」「数字」の小さな見出しを付ける、色（緑・橙）の意味を3つの図で揃える、1枚の札に図は1つだけ
- ただし 5.2・5.3 のとおり、箱と数字の図は足す物が少ないので、決まりを作ってまで入れる値打ちは低いと見ている

### 5.5 押す回数（問5）

- どの案も増えない（開いた画面に出るだけ）
- 流す量は、箱と矢印を入れると43枚で増える。国の名前を1行に足す案は増えない

### 5.6 ③とどちらを先にやるか（問6）

**③を先に。** ③の中で、この相談で見つかった直しをまとめて入れる。

| ③に入れるもの | 地図に出る札が増える見込み（推測） |
|---|---|
| 海峡・運河の場所の点 | フーシ派の3枚、長官のホルムズ発言 など（効かせた線の相手が海峡の札） |
| 枠の名前の表に「国連安保理・安保理・国際刑事裁判所・ICC・BRICS」などを足す | 3枚（安保理2・BRICS） |
| 朝の取り込みの規則の直し（2.3 の案A） | 日銀のような札（次の取り込みから） |
| 確度3以下の効かせた線をどうするか（3.2、本人が決めたもの） | (イ)(ウ)なら7枚 |
| 埋めた返事を残さない直し（月ファイル85KB） | — |
| 国の中の動きの1行に国の名前を足す（5.2） | —（地図は増えない） |

- 理由：地図にならない73枚のうち14枚は、図の種類ではなく**線を引く材料の穴**（場所の表・規則・確度・海峡）で出ていない。先に穴を塞ぐと、地図が出る札が増え、残った「本当に地図にならない札」がはっきりする
- 「出来事」への言い換え（4章）は画面の言葉だけなので、③と別の小さな版で出せる

### 5.7 「地図が出ない札は文だけでよい」か（問7）

**文だけでよい、と考える（箱と矢印・数字の1行は反対）。** 理由：
- 地図にならない札で伝えたいのは「誰から誰へ」と「いくら」「どう変わったか」で、**それは札の文と、なぜの直下の1行にすでにある**。図にしても同じ言葉を並べ直すだけ
- 世界地図が読む助けになるのは、文に無い「場所の位置関係」を足すからで、同じ理由が箱や数字の図には無い
- 数字の「前の値」は、別の欄として取れるのが16枚中2枚。残りは札の文に書いてある
- 足すなら、文に無いものだけを文で足す：国の中の動きの「どこの国の中か」（5.2）
- 失うもの：図が無いので、ぱっと見て「動きがある札」だと目に入りにくい（1行の頭の色付きの「お金：」「効かせた：」で補う）

## 6. 本人に決めてほしいこと

1. **規則の直し**（2.3）：案A（他国から求められた手・なぜに書いてある狙いの相手は書く）でよいか
2. **確度3以下の効かせた線**（3.2）：(ア) 今のまま1行だけ／(イ) 薄く描く／(ウ) 決まりをかけない
3. **見出しと別の出来事を指す言葉**（4.3）：案A「出来事」でよいか
4. **地図にならない札の図**（5章）：箱と矢印・数字の1行は入れず、国の中の動きの1行に国の名前を足す、でよいか
5. **順番**（5.6）：③を先にし、場所の表・規則・確度・返事を残さない直しを③に入れる、でよいか
