# 相談：枠が相手のとき、地図からはみ出す線をどうするか（質問と推奨案）

- 指示書：`shiji/sekai_chizu_waku_shiji.md`（質問フェーズ）
- **実装もコードの変更もしていない。** 本物の kotoba-data は読むだけ（最新の写しを試しのページに載せ、アプリの場所の当て方と地図の組み立てで数えた）

---

## 先に：結論

1. **案3に賛成。ただし「本部のある国に置く」のではなく、海峡と同じ「場所の点」として置く。** 本部の国に置くと、**米国 → 国連安保理 が「米国 → 米国」になって線が消える**（実データで3組。1章の6）
2. 置ける枠は **国際機関と、EU・欧州委員会**。実データでは、枠が絡む札36枚のうち **14枚**が置ける枠（IMF・NATO・国連安保理・EU・欧州委員会）
3. 残るのは **市場（国債市場・株式市場・株主…）と、国の集まりの言い方（湾岸の産油国・欧州の投資家・BRICS）**。ここは案1（箱と矢印）も案4（地図を出さない）も勧めない。**点のそばに短い矢印と相手の名前を出す案（案6）**を勧める。案4だと地図が出る札が 75枚 → 54枚に減る
4. EU を国の集まりとして塗る案（問4）は作れるが、**段を分けて後に**（加盟国の一覧を自分で持つことになる）
5. お金の線の本数は変わらない見込み（端が下の箱から地図の中の点に移るだけ。**実装したら実測で確かめる**）

### 問6 お金の線は変わるか

- 置ける枠を点にすると、**線の端が下の箱から地図の中の点に移るだけ**で、線の本数は変わらない見込み（推測）。移るのは お金の端7つ（IMF 3・欧州委員会 4）と 効かせた端9つ（国連安保理2・NATO1・IMF1・EU5）
- **ただし「本部のある国」に置き換えると、3組が線でなくなる**（実測）
  - 米国 → 国連安保理（決議2803・停戦決議の反対）→ どちらも「米国 → 米国」
  - ユーロクリア → 欧州委員会 → 「ベルギー → ベルギー」
  - だから、国コードに置き換えるのではなく、海峡と同じ**独立した場所の点**にする
- 実装したときは、海峡のときと同じく「今の線の本数（地図タブ51・枝の地図52・国内28・場所不明9）が変わらない」を数で確かめる

## 2. 案ごとの答え

### 問3 案3で置ける枠と、置き方

**置き方：本部の場所を、海峡と同じ「場所の点」として持つ**（国コードにはしない。1章の6の理由）。

| 名前 | 点を置く場所 |
|---|---|
| 国連安保理・国連・国連総会 | ニューヨーク |
| IMF・世界銀行 | ワシントン |
| NATO・EU・欧州委員会・ECB(※) | ブリュッセル（ECB はフランクフルト） |
| WTO・国際司法裁判所(※ハーグ)・IAEA(※ウィーン)・OPEC(※ウィーン)・BIS(※バーゼル) | ジュネーブほか |
| 国際刑事裁判所 | ハーグ |

- 今のデータに出るのは IMF・国連安保理・NATO・EU・欧州委員会の5つ。残りは、これから出たときのために一緒に入れておく
- 失うもの：本部の場所は「決まっている場所」ではあるが、**その機関が動いている場所とは限らない**（IMF の金はワシントンから出るわけではない）。読み手が「ワシントンから金が出た」と読む危険がある。地図の使い方の説明に1行要る
- **BRICS のような国の集まりは、点にしない**（首都も本部も無い）。3の案（下の「置けない枠」）で扱う

### 問4 「地域」の枠（EU・欧州）を塗れるか

**作れる。ただし段を分けて後に。**
- 作り方：EU の加盟国27の国コードの一覧をアプリの中に持ち、その国を別の色で塗る。線の端は、塗った国の重心（ブリュッセル付近）に置く
- 失うもの
  - 加盟国の一覧を自分で持つことになる（変わったら直す。今の地図の部品には「どの国がEUか」のデータが無い）
  - 「欧州の投資家」「欧州の同盟国とカナダ」のような言い方まで塗ると、塗る範囲が話ごとに変わって読めなくなる。塗るのは「EU」「欧州委員会」だけにする
  - 塗りは「関わる国」の明るい塗りとぶつかる（同じ札に EU と別の国が出ると、2種類の塗りが並ぶ）

### 問5 場所の無い枠（市場・株主）が相手の札

| 案 | 中身 | 失うもの |
|---|---|---|
| 1 箱と矢印 | 出す側と相手を2つの箱にして矢印 | 箱の名前がすぐ下の1行と同じ（前の相談で取り下げた理由と同じ）。**反対** |
| 4 地図を出さない | 「相手の場所が決まらない」札と同じ扱い | **地図が出る札が 75枚 → 54枚（実測）**。トヨタ → 株主、米財務省 → 国債市場 のように「どこの国から出た金か」まで消える |
| **6 点のそばに短い矢印と名前（推奨）** | 出す側の国の点から、外向きに短い矢印を1本引き、その先に相手の名前（「国債市場」「株主」）を小さく書く。地図の下の箱は出さない | 相手の位置は分からないまま（そこは正しい）。矢印の向きは「外へ」だけで、方角に意味は無いと分かるように、いつも同じ向き（右上）にする。線の太さ・色の決まりは今のまま |

- 6を勧める理由：**地図の外に箱を置かない**（不自然さの元を消す）、**国から外へ出た／外から入った**という形は残る、1行と同じ言葉を2つの箱に書き直さない
- 失うもの（6全体）：同じ札に外向きの矢印が2本以上あると、どれがどれか分かりにくい（今のデータでは最大1本）

### 問7 地図タブ（大きな地図）

- いま：地図の下に「市場」「国際機関」「地域」の3つの箱を置き、中に相手の名前と本数を書く。枠へ向かう線は、地図の上端から箱の上端までの間に描く。箱を押すと、市場は網、ほかは札の一覧
- 案3を入れると：**IMF・国連安保理・NATO・EU・欧州委員会 が箱から地図の中の点に移る**（今のデータでは お金の端7・効かせた端9）。国際機関の箱はほぼ空になり、地域の箱は「湾岸の産油国」などの集まりだけになる
- 案6（点のそばの矢印）は枝の地図だけにする。大きな地図は線が多いので、外向きの矢印を全部の点に出すと読めなくなる（推測）。大きな地図では今の箱のままにする
- 失うもの：同じ「国連安保理」が、枝の地図では点、大きな地図では点（案3を両方に効かせるため）になり、箱の中身が減る。箱を押して一覧を見る道が、その名前については無くなる（点を押す道は大きな地図にある）

### 問8 反対の立場（今の下の箱で十分）

- 十分だと言える理由：市場・株主は本当に場所が無いので、**地図の外に置くのは正直な描き方**。線が外に伸びるのは「地図の外の相手だ」という印でもある
- それでも直す理由：**置ける枠（国際機関・EU）まで外に出している**のが今の形の弱み。まず案3で「外に出す必要が無いもの」を地図の中に入れ、本当に場所の無いものだけを外の扱いにする。その上で、外の扱いを箱のままにするか案6にするかは、実機で見て決めてよい
- つまり **案3は入れる、案6は試す価値がある、案1は反対、案4は損が大きい**

### 問9 段

| 段 | やること | 実データでの効き |
|---|---|---|
| **段1** | 国際機関・EU・欧州委員会などを「場所の点」にする（本部の場所。国コードにはしない）。地図の使い方に「点は本部の場所」の1行 | 14枚の札で、線が地図の中で完結する。お金の線の本数は変わらない（実装後に数で確かめる） |
| **段2** | 場所の無い枠（市場・株主・国の集まり）は、枝の地図で「点のそばの短い矢印＋名前」にし、下の箱を出さない | 22枚の札の見え方が変わる。地図が出る札の数は変わらない |
| 段3（後で） | EU を加盟国の塗りにする。大きな地図の箱の中身の整理 | 見た目の話。データの持ち方（加盟国の一覧）が増える |

## 3. 参考（指示書の4）

「大きさ・順序・時間」は、**描く道具ではなくデータが足りない**という見方に賛成。実測だけ置いておく。

- **大きさ**：ドル換算がある札は72件中68件。比べる相手（同じ主体の前の額・同じ地層の値）は、今は札に持っていない
- **順序**：前の動き（after）でつながる札は132枚中6枚。続報（follows）は別に数えて8本
- **時間**：数字の札16枚のうち、前の値が地層から取れるのは2枚（9/15 の調べ）

どれも、地図の描き方を変えるより先に、**朝の取り込みか読む回でその欄を書かせるか**を決める話になる。

## 4. 本人に決めてほしいこと

1. **案3を「場所の点」として入れる**（本部の国コードにはしない）でよいか
2. 場所の無い枠は **案6（点のそばに短い矢印と名前・下の箱は出さない）** でよいか。案4（地図を出さない）は、地図が出る札が75→54枚に減るので勧めない
3. 大きな地図は、点の扱いだけ案3に合わせ、**箱は今のまま**でよいか
4. EU の塗り（問4）は段3に回してよいか
5. 段1 → 段2 の順でよいか
