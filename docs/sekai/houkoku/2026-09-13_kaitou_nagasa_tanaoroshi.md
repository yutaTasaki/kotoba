## 1. 「関連を探し直す」の直し（v20.29.1）

### 何をしたか

押したら、**結果をボタンのすぐ下に必ず1行出す**ようにした。上限越えのときだけでなく、何も出ずに終わる道を全部ふさいだ。

| 押したときの状態 | 出る1行 |
|---|---|
| 今月の使用額が上限を越えている | 今月の API 使用額（$2.87）が上限（$2.00）を越えているので、探しませんでした。上限は 設定 → Claude API の「月の上限（USD）」で変えられます。 |
| 設定の「保存時に自動で関連づける」が切ってある | 設定の「保存時に自動で関連づける」が切ってあるので、探しませんでした（設定 → Claude API）。 |
| API キーが無い | Claude API キーが無いので、探しませんでした（設定 → Claude API）。 |
| 探して、足した | 関連を N件 足しました。 |
| 探したが、新しいものが無かった | 新しい関連は見つかりませんでした。 |
| 探す途中で失敗した | 探せませんでした（失敗の中身）。 |

- 額は、上限の注意（朝の画面の「上限の100%」）と同じ計算で出している
- 画面を描き直しても1行は残る。**別の言葉を開いたとき、同じ言葉を開き直したときは消える**（前の日の結果が残って見えないように）
- 押したときの動き（探すかどうか）は**変えていない**。変えたのは「結果を出す」ことだけ
- 言葉を保存したときの自動の関連づけ・一括の関連づけは、今までどおり（何も出さない）

### 確かめたこと

**本物のデータの写しで、4つの状態を作って押した：**

| 状態 | 出た1行 | エラー |
|---|---|---|
| API キーなし | キーが無いので、探しませんでした | なし |
| キーあり・上限が初期値（$2.00）・今月 $2.87 | 使用額（$2.87）が上限（$2.00）を越えているので… | なし |
| キーあり・上限 $100・自動の関連づけを切る | 「保存時に自動で関連づける」が切ってあるので… | なし |
| キーあり・上限 $100・自動の関連づけあり | 探せませんでした（通信を止めてあるため） | なし |

- 上限越えの状態は、**本物のクリック**で押して、ボタンの下に1行出るのを画面で見た
- 同じ言葉を開き直すと1行が消えることを確かめた
- 「探して足した／見つからなかった」は、本物の API を呼ばないと出せないので**確かめていない**（通信を止めた試験のため）
- ほかの呼び出し元（保存時・一括）は、戻り値に理由が1つ増えただけで、使い方は変わらないことを確かめた

## 2. 根の長さ：同じ画面で揃える（仕様書を直した）

### 聞かれたことへの答え

**「幅によって長さが変わっても、同じ画面の中で揃っていれば問題ない」で合っている。** ただし、1つだけ知っておいてほしい場面がある。

| 場面 | 何が起きるか | 読み違えの恐れ |
|---|---|---|
| 端末によって地図の幅が違う | 320で9px、360で12px、390で14px | 無い。1台の端末では地図の幅は変わらない（向きを変えたときを除く） |
| **同じ端末で、日によって** | 日本や台湾の近くに別の国の点が出る日は、**全部の根が短くなる** | **ある。** 前の日と見比べると、全部の額が減ったように見える。ただし全部が同じだけ短くなるので、国どうしの見比べは崩れない |
| 二本指で拡大したとき | 点の間が広がって触れなくなり、根が14pxに戻っていく | 小さい。点と線の見え方も一緒に変わる |
| 全体図と地域の図 | 地域の図は20pxから始まる | 無い。別の画面 |

**対策として、** 「数字の見方」に「根の長さはどの国も同じ。点に触れないよう、画面ごとに短くすることがある。額は太さで見る」を足した。

**9pxで根に見えるか**は実機で見てもらう（仕様書 11. の5）。下限は「根を出すかどうか」と同じ1か所で変えられる。

### 仕様書で直したこと

- 0. の決まったことの表に「同じ画面の根は全部同じ長さに揃える」を足した
- 3.5 を「勧めること」から「決まったこと」にした。下限まで短くしても触れる国は、その国だけ出さず、**残りの国の中で一番短い長さ**で揃える、と書き直した（前の版は「下限で揃える」と読めた）
- 長さが変わる場面の表（上の表）と、数字の見方の一文を足した
- 実装のときの確かめに「二本指で拡大したとき、触れない範囲で14pxに戻っていくか」を足した
- 実機で見るものの5を「幅320で全部の根が9pxになったとき、根に見えるか」にした

**仕様書 第2版（直し）を見てください。** 読んでもらったら実装（v20.30）に進む。
