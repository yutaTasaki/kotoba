# 相談：地図に描く「動き」を広げる（質問と推奨案）

- 指示書：`shiji/sekai_chizu_ugoki_shiji.md`（質問フェーズ）
- **実装もコードの変更もしていない。** 本物の kotoba-data は読むだけ（写しを試しのページに載せ、アプリの場所の当て方で数え、46枚は1枚ずつ読んだ）
- 詳しい記録：`chousa/2026-09-15_chizu_ugoki_46mai.md`（46枚の1枚ずつの判定）

## 先に：結論

1. **見立てに賛成。** 動きの無い46枚のうち **23枚は「誰が、どの国・国際機関・地域に向けて手を打ったか」が今の文から読める**（米国 → イラン：制裁、アルジェリア → UAE：断交 など）。お金の欄に入らないので地図に出ていないだけ
2. **ただし、今のデータから自動で拾うのは反対。** アプリの国の当て方で文から相手の国を拾うと、人の判定と比べて当たり15・誤り7・見落とし8。なぜに出てくる背景の国を相手と読む（概念のときと同じ壊れ方）、国際機関・地域が相手の手（NATO・安保理・EU）を落とす
3. **朝の取り込みのプロンプトに、札ごとの「効かせた相手」の欄を足すのを勧める。** 規則が約230字、出力は1件約40字。今ある145枚は、割り直しと同じ形の1回きりのプロンプトで埋める
4. **効かせた線は、お金の線と色と先の形で分ける**（お金＝緑の矢印、効かせた＝別の色の「⊣」の先＋手の言葉）
5. **点だけの地図はやめる。** 動きの無い札だけでなく、動きのある札の「国内・片方だけ・確度3以下」の点だけの地図（47枚）も、線が無ければ出さない。誰から誰への1行は残す。「書かれていません（点は主体の国）」の1行はやめる
6. 段は3つ：①点だけの地図をやめる（すぐ）→ ②効かせた線（プロンプトの欄・今の札を埋める・描く）→ ③海峡などの場所の点は様子を見て
7. ふだんの日に押す回数は増えない（今の札を埋める1回だけ、コピーと貼り付けが増える）

## 1. どこから取るか（問1〜3）

### 問1 「誰が誰に効かせたか」は今のデータのどこから取れるか

**数えたもの**
- 1枚ずつ読んだのは、線が出ない動きの無い札46枚（点だけ38枚＋何も出ない8枚）
- 判定：◎＝相手が地図に置ける（国か、国際機関・地域の枠）手が読める／△＝手はあるが相手が地図に置けない（海峡・「名前を伏せた銀行」など）か背景だけ／×＝手が無い（統計・自国の中の政策・保有高）

| 取る場所 | ◎23枚のうち、そこに相手が書いてあった枚数 | 自動で拾えるか |
|---|---|---|
| **札の文と、動かした側の「したこと」** | **22** | 国の呼び名なら拾える。国際機関・地域・英字の呼び名（UAE）は落ちる |
| なぜの文 | 1（#14 日銀：米国 → 日本の利上げ要求。主体に米国がいない） | 拾えるが、背景の国も拾う（誤りの4件はこれ） |
| 主体の推定・述べた理由 | 0（相手は「したこと」の方に先に出る） | 推定は読みなので、線の元にするのは反対 |
| 用語・概念・前提 | 0（「域外適用」「ハイブリッド戦」など、向きが無い） | 使えない |
| 幹の答え②（誰に向けた手か） | まだ1本も無い | 使えない。育っても幹1本に1つで、札1枚ずつの相手にはならない |
| 2人目の主体 | 2（#10 フーシ派 → サウジ、#24 イラン → 米国）。「したこと」に入っている | 主体の国どうしを組むだけだと、向きが分からない |

**自動で拾った場合（アプリの国の当て方で、主体の国と別の国が文に出るか）**：46枚中22枚。1枚ずつの判定と比べると

| | 枚数 | 例 |
|---|---|---|
| 当たり | 15 | 米国 → ブラジル（関税）、米国 → ロシア（VTB 制裁） |
| 誤り | 7 | なぜの背景の国（フーシ派のモカ制圧で「サウジ・イラン・米国」）、BRICS 宣言（手ではない）、サウジの保険プールで「ペルシャ湾」をペルーと読んだ |
| 見落とし | 8 | NATO・安保理・EU が相手か主体、「UAE」、主体にいない米国（#14） |

→ **自動で拾うのは反対。** 3割が誤りで、誤り方が「文に出てくる国を全部つなぐ」形（概念の共起と同じ壊れ方）。

### 問2 点1つ・2つしか出ない38枚のうち、何枚に線が引けそうか

**38枚のうち20枚**（1枚ずつ読んで）。何も出ない8枚からも3枚（欧州委・欧州議会・EU が主体で、相手がロシア）。

| | 46枚 | 点だけ38枚 | 何も出ない8枚 |
|---|---|---|---|
| ◎ 線が引ける | **23** | **20** | 3 |
| △ 手はあるが相手が置けない | 9 | 8 | 1 |
| × 手が無い | 14 | 10 | 4 |

- 指示書の例：VTB の札は ◎（米国 → ロシア：制裁、狙いはイラン）。ホルムズの札は △（イラン → ホルムズ海峡：通航の管理。海峡は地図の部品に点が無い）
- △のうち3枚は相手が海峡（ホルムズ・バブエルマンデブ）
- 動きのある札で点だけ出る47枚は、1枚ずつは見ていない。自動で拾うと11枚に相手の国が出る（手として正しいのは7割前後と推測）

### 問3 プロンプトに新しい欄を足す必要があるか

**足すのを勧める。** 今のデータだけで引く方法（自動で拾う）は問1のとおり3割誤る。人が1枚ずつ付ける方法は続かない（毎日の世話になる）。

**朝の取り込みに足す欄（案）**
```
"aims":[{"from":"米国","to":"ロシア","how":"制裁"}]
```
- 規則（案、約230字）：
  - 札ごとに、主体が誰に向けて何を効かせたかを0〜2件。お金・物・人が動いていなくてよい（制裁・関税・攻撃・要求・合意・名指し・投票 など）
  - from・to は国・国際機関・地域の名前。場所が決まらない相手（「第三国の銀行」「市場」）は書かない
  - how は短い言葉1つ
  - 自国の中だけの手（利上げ・統計・保有高）は []。flow と同じ向きの同じ話は書かない。なぜの背景に出るだけの国は書かない
- 出力：1件約40字。1回の取り込み（札10枚前後）で約200〜400字増える（推測）
- 失うもの：朝のプロンプトが約230字長くなる。チャットが「背景の国」を書く誤りは、規則で減らせても0にはならない（測れません）。欄を読むアプリの側の作り（場所の当て方は今のまま使える）

**今ある145枚を埋める**
- 割り直しと同じ形：札を並べた1回きりのプロンプトをコピーし、返事を貼る。札145枚で約15,000字（推測。割り直しの段B が139枚で約18,000字）
- 失うもの：コピーと貼り付けが1回増える（1回きり）

**反対する案**
- 読む回に書かせる：読む回は1回20枚まで・切れた推定の直しが先。全部の札に行き渡るまで何週間もかかる
- なぜ・推定から自動で：問1の誤り

## 2. 見た目（問4〜6）

### 問4 お金の線と効かせた線をどう分けるか

今の線は、太さ（ドル換算）・点線（物・人・換算できない）・破線（累計・期間）・薄さ＋白抜きの矢印（約束）・色は1色（緑）を使っている。

| 案 | 見え方 | 失うもの |
|---|---|---|
| **A 色と先の形を変え、手の言葉を添える（推奨）** | お金＝今の緑の曲線と矢印。効かせた＝別の色（例：橙）の曲線で、先を「⊣」（押し当てる形）。線の中ほどに「制裁」「関税」の短い言葉 | 色が2色になる（地図タブの「1色」の決まりが崩れる）。色を見分けにくい人には、先の形と言葉が頼り。言葉が線と重なって読みにくい札が出うる（線は1枚に1〜2本なので少ないと推測） |
| B 線の種類だけで分ける（例：二重線） | 色は1色のまま、効かせた線だけ二重線 | 点線・破線・薄さはもう使っていて、4つ目の種類を覚える必要がある。細い地図では二重線が1本に見える（推測） |
| C 効かせた線は地図に描かず、国を塗るだけ | 相手の国を別の色で塗る | 向きが出ない（誰が誰に、が消える）。塗りは「関わる国」でもう使っている |

**推奨：A。** お金と圧力が混ざらないことが一番大事なので、色・先の形・言葉の3つで重ねて分ける。

### 問5 1枚の札に、お金の線と効かせた線が両方あるとき

- 両方描く。同じ2つの国の間なら、お金の線は今の向き（中ほどが片側へ膨らむ）、効かせた線は反対側へ膨らませて重ならないようにする
- 下の1行は2行にする：
  ```
  お金：イラン → 中国　原油代金 …
  効かせた：米国 → 中国　制裁
  ```
- 同じ向きの同じ話（例：関税をかけた国 → かけられた国 で、お金も同じ向き）は、規則でチャットに書かせない（二重の線を作らない）
- 失うもの：線が2本になる札は、1本の札より地図が込み合う

### 問6 効かせた線の「強さ」

**太さは変えない（推奨）。**
- 額のような共通の物差しが無い。「攻撃 ＞ 制裁 ＞ 関税 ＞ 要求」のように手の種類で太さを決めると、読み（誰かの判断）が線に入る。**反対**
- 同じ組（米国 → イラン）の手が何枚にもわたるときの「重なり」は、札1枚の地図では出ない（段2の幹の地図で考える）
- 失うもの：大きな手も小さな手も同じ太さに見える。手の言葉（制裁・攻撃）で読む

## 3. それでも描けない札（問7〜9）

### 問7 効かせた線も引けない札は何枚残るか

- 動きの無い46枚のうち：**23枚**（×14枚・△9枚）
- 動きのある札で点だけ出る47枚のうち：1枚ずつは見ていないので**測れていない**。自動で拾うと相手の国が出るのは11枚で、残りは36枚前後（推測）

### 問8 描けない札は地図を出さないでよいか

**よい（賛成）。** 点1つ・2つは、札の文に書いてある国を示すだけで、読む助けにならない（本人の実機のとおり）。
- 同じ理由で、**動きのある札の点だけの地図（国内28・片方だけ9・確度3以下8・同じ枠どうし2＝47枚）も出さない**のを勧める。例：トヨタの自社株買い（日本の点＋杭）は、1行の「トヨタ自動車 → 株主 自社株買い」で足りる
- 失うもの：国内の動きの「どこの国の中か」が地図で見えなくなる（1行と札の文で読む）。杭（自分に使う金）が枝の地図に出る札は、相手が別の国の線を持つ札だけになる
- 誰から誰への1行（お金・物・人の動き）は、地図が無くても今のまま出す

### 問9 「誰から誰へは書かれていません（点は主体の国）」の1行はやめてよいか

**やめてよい（賛成）。** 点をやめれば、この1行は説明する物が無くなる。効かせた線が入った札は「効かせた：米国 → ロシア　制裁」の1行になる。

## 4. 全体（問10〜12）

### 問10 地図タブはどうなるか

**段2では、効かせた線は枝の地図だけに出す（地図タブには出さない）。**
- 地図タブは、お金の動きの全体と、場所の当て方の点検の場所。効かせた線を足すと、90日分で線が倍近くになり、点検の一覧の数も変わる（推測）
- 幹の地図（地図の段2）を作るときに、効かせた線を幹の地図に重ねるかを一緒に決める（幹の中で「米国がイラン周辺にどれだけ手を打っているか」が見える形は、幹の地図の方が合う）
- 失うもの：全体の地図で、制裁や関税の向きを一度に見る場所は無いまま

### 問11 何段に分けるか

| 段 | やること | 使えるようになること |
|---|---|---|
| **① 点だけの地図をやめる**（すぐ・データもプロンプトも触らない） | 線（お金・物・人）が無い札は地図を出さない。「書かれていません（点は主体の国）」の1行をやめる。誰から誰への1行は残す | 読む助けにならない地図が消える。地図が出る札＝線のある52枚だけになる |
| **② 効かせた線** | 朝の取り込みのプロンプトに「効かせた相手」の欄。今ある145枚を1回きりのプロンプトで埋める。枝の地図に別の色・⊣・手の言葉で描く。1行「効かせた：…」 | 動きの無い札でも、制裁・関税・攻撃の向きが地図に出る（46枚のうち23枚の見込み） |
| ③ 海峡などの場所の点（様子を見て） | ホルムズ・バブエルマンデブ・紅海・スエズなど数か所を、地図の部品に場所の点として足す | イラン → ホルムズ海峡 のような手が線になる（今の145枚で、札の文か主体のしたことに海峡が出るのは10枚） |

- ①を先に出す理由：データにもプロンプトにも触らず、本人が実機で見た「読む助けにならない」をすぐ消せる。②は欄を足すので、仕様書と取り込みの確かめが要る
- ③を後にする理由：場所の点を増やすと、お金の線の場所の当て方（「紅海のヤンブー港」など）にも効くかを決める必要がある

### 問12 ふだんの日に押す回数

- **増えない。** ①②とも、地図は札を開いた画面にそのまま出る。朝の取り込みは今と同じ1回のコピーと貼り付け（プロンプトが約230字長くなるだけ）
- ②で1回だけ、今ある145枚を埋めるコピーと貼り付けが増える

## 5. 本人に決めてほしいこと

1. **①点だけの地図をやめる**：動きの無い札だけでなく、動きのある札の点だけの地図（国内・片方だけ・確度3以下・同じ枠どうし）もやめてよいか
2. **②効かせた線は、朝の取り込みのプロンプトに欄を足して取る**（自動で拾うのは反対）でよいか。今ある145枚は1回きりのプロンプトで埋める、でよいか
3. **見分け方は案A**（別の色・⊣の先・手の言葉。太さは変えない）でよいか
4. 効かせた線は**枝の地図だけ**（地図タブには出さない）でよいか
5. 段の順（①すぐ → ② → ③は様子を見て）でよいか
