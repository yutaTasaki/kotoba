## 1. 画面

```
今日、深く見るなら（1つ選ぶ）
［今日見るべき件］サウジが紅海側のヤンブー港で原油の積み出しを止めた
  なぜ：ホルムズに続き紅海側の出口も止まり、サウジの原油が外へ出にくくなった
［ずれあり］米エネルギー長官がホルムズ通過を日量1000万バレルとした
  ずれ：米側は通過が日量1000万バレルに戻ったとするが、実際の通過は1日一桁台に…
…
今日はなし
```

- 選んだ後：「今日深く見る」＋選んだ出来事＋［札を開く］［選び直す］
- 「今日はなし」を押した後：「今日は選ばない（戻す）」の1行
- 候補の決まり（仕様書どおり）
  - 今日見るべき件から最大2つ、ずれのある札（出来事が14日以内・新しい順）から最大2つ。足りなければ片方で埋めて最大4つ
  - 前に選んだ札は出さない。選び直した札はまた出る
  - 同じ札が両方にあれば1つにまとめ「今日見るべき件・ずれあり」
  - 候補が0なら枠ごと出さない
- 置いた場所：「幹 N本・葉 N枚」の入口の下、「今日動いた幹」の上

## 2. 記録

- 調べたことの月ファイル（`world/dig/2026-09.json`）に、新しい並び `choices` として残る
- 1件に残すもの：選んだ日・札・出どころ（今日見るべき件／ずれ／両方）・並んでいた候補の札・選んだ時の文
- 「今日はなし」も1件として残す（あとで「選ばなかった日」を数えるため）
- 選び直しは消さずに「取り消した」の印を付ける（何を選んでやめたかが残る）

## 3. 確かめたこと

偽の GitHub に本物のデータの写し（読むだけ。本物には何も書いていない）を置き、試しのページで実際に押した。

| 確かめ | 結果 |
|---|---|
| 文の書き方（構文） | 誤りなし |
| 候補が本物のデータで出るか | 4つ出た（上の通り） |
| 候補を指で押す（マウスで押した） | 「今日深く見る」に変わった |
| ［選び直す］ | 候補に戻り、押した記録に取り消しの印 |
| 「今日はなし」→「戻す」 | 1行になり、戻すと候補4つに戻った |
| ［札を開く］ | 札の画面が開き「9/17 に深く見るものとして選んだ」が出た |
| 選んだ札が次の候補から外れるか | 外れた |
| 同期：1台目で選ぶ → 送る | GitHub のファイルに `choices` 3件。ほかの並び（幹・効かせた相手・見せ方・比べる相手）も残っていた |
| 2台目で開く | 同じ選んだ札が出た。2台目で［選び直す］→ 送る → 1台目で受けると、1台目も候補に戻った |
| 狭い幅（358px） | 候補の枠からはみ出す行0 |
| エラー | 0件（両方の端末） |

- 日付が変わった次の日に、新しい候補が出ること（端末の日付を動かしていない。決まりは「今日の日付の記録があるか」だけで見ている）
