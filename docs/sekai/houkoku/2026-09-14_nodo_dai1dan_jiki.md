## 第2段の仕様書の前に決めてほしいこと

1. **url の扱い：** 次のどれにするか
   - ア：依頼文を「この会話の中で出典として示された url は書く（開いて確かめていなくても）。示されていなければ空」に緩める。**失うもの：** 開けない url・作り話の url が入る可能性が上がる（札にする前に人が開いて確かめる手順が要る）
   - イ：依頼文はそのまま。第2段で、札にしたい件に**人が url を貼る欄**を付ける（仕様書の「url を足す欄」を中心にする）。**失うもの：** 札にするたびに url を探す手間が人に残る
   - ウ：アとイの両方（チャットが示した url は入れる。無ければ人が足す）
2. **札に元から書いてあったことを戻さない：** 依頼文に「札に書いてあったことは書かない。この会話で新しく分かったことだけ」を足してよいか（小さい変更。賛成なら第2段と一緒に入れる）
