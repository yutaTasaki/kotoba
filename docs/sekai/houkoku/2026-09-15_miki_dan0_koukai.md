## 1. 確かめる順番

## 2. 戻したとき、データはどうなるか（コードで確かめた）

### 2.1 世界貿易/GDP の55点

| 問い | 答え | 理由 |
|---|---|---|
| 消えるか | **消えない** | v20.48 も「出どころ csv」の値と「刻み：年」を正しい値として読む（csv は v20.8 から、年は前から使っている） |
| v20.48 の端末が書き戻すか | **書き戻す（持ち続ける）** | 地層の値は、2台で合わせるとき「日付ごとに足し合わせる」。片方にしか無い値も、もう片方に足される |
| 消す操作はあるか | **無い** | 地層の値を1点消す画面は、どの版にも無い。同じ日付に手で値を入れると置き換わるだけ |
| 刻み「年」と確認先（世界銀行） | 残る | 地層1本の欄は、更新日時の新しい方が勝つ。v20.48 はこの地層を書き換えないので、v20.49 が書いたものが残る |

**もし55点を消したくなったら**：v20.48 に戻すのでは消えない。「この地層の csv の値を捨てる」新しい版（v20.50 など）を出し、**2台とも**その版にしてから同期する必要がある。片方だけだと、もう片方の値が足し合わせで戻ってくる。
- 失うもの：数字そのものは世界銀行の公表値なので、消す必要が出る見込みは低い（推測）

**戻したあと、また v20.49 以上にしたとき**：55点が残っていれば、足し直さない（csv の値が1点でもあれば入れない決まり）。重なりは出ない。

### 2.2 日付が逆の「前の動き」

| 問い | 答え |
|---|---|
| 鎖に戻るか | **戻る。** v20.49 は表示で外しているだけで、札の「前の動き」の欄は消していない。v20.48 は今までどおり鎖にする（実データでは2本） |
| v20.49 のあいだに取り込んだ札 | 日付が後の相手を指していた前の動きは、**最初から付けずに保存している**。v20.48 に戻しても付かない（元の返事の JSON を貼り直せば付く） |

### 2.3 切れた推定の直し

- v20.49 で直した推定（1回12枚）は、札の中で「直した」印と前の文つきで保存される。v20.48 もこの形を読むので、**戻しても直した分は残る**
- 戻すと、枠が5枚に戻るだけ

### 2.4 2台のうち片方だけ古い版のとき

| もの | どちらが勝つか |
|---|---|
| 世界貿易/GDP の値 | **勝ち負けは無く、足し合わせ**。v20.49 の端末が1回でも同期すれば、55点は v20.48 の端末にも入る |
| 世界貿易/GDP の刻み・確認先 | 更新日時の新しい方。v20.48 はこの地層を書き換えないので、v20.49 の書いたもの |
| お金の鎖 | データの勝ち負けは無い。**端末ごとの表示**で、v20.48 の端末では日付が逆の2本が見え、v20.49 では見えない |
| 読む回の枠・朝の1行・設定の残り枚数 | 端末ごと。データには効かない |
| 読む回で直した推定 | どちらの版で直しても同じ形で保存され、札ごとに更新日時の新しい方が勝つ（前と同じ） |

### 2.5 戻す手順

1. 手元で `git revert 57e6ebb` を作り、master に送り出す（履歴を消さずに v20.48 の中身に戻す。設定の版の表示も「v20.48」に戻る）
2. 公開された版が戻ったかを、前と同じく中身の一致で確かめる
3. **端末側**（公開の知らせから10分ほど待ってから）
   - PC：設定 → 世界 の一番下の［最新の版を読み込む］、または Ctrl＋Shift＋R
   - iPhone：アプリを上へはじいて閉じてから開き直す。出なければ［最新の版を読み込む］
   - 両方で、設定 → 世界 の一番下が「版 v20.48」になったことを見る
4. データの側で必要な作業は無い（2.1〜2.3 のとおり、戻しても壊れるものは無い）。55点を消したい場合だけ、2.1 の新しい版が要る

## 3. 実機で確かめてほしいこと（再掲）

公開の知らせから10分ほど待ち、PC と iPhone の両方で、設定 → 世界 の一番下が「版 v20.49」になっていることを確かめてから：

1. 朝の画面の「途中で切れた推定 N枚 ▸」を**指で押す** → 読む欄に移ってコピーされる → Claude に貼る → 返事を貼って［読んだ結果を取り込む］
2. 設定 → 世界 を**開き直して**、「切れた推定：残り」が12枚ほど減っている
3. iPhone で、**今日の取り込みが無い日に**朝の1行が出る
4. 世界 → 地層 → 世界貿易/GDP を**押す** → 値と［確認先を開く］→ 世界銀行のページが開く
5. 両方が v20.49 になってから朝の取り込みを流す
6. 取り込みの結果に「前の動きの日付が後だった」が出たら、その札に前の動きが付いていないこと
