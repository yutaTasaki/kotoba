## 3. 作ったもの

### 3.1 読む回のプロンプト

| 足した節 | いつ |
|---|---|
| ■ 幹と、いまの答え（文に番号と裏の日つき・まだ分からないこと） | この回の札が掛かる幹のうち、答えがある幹 |
| ■ 答えがまだの幹（出発点と中心の札の全文、枝の何が起きたかを30枚まで） | 条件を満たし、答えがまだの幹を1回に3本まで |
| ■ 幹の答えを見る（書き直しの基準4つ・足す・変えなかったと backs・事実の食い違いは unknown・150字） | 上のどちらかがあるとき |
| 札ごとに「幹：〇〇（mk_…）」、幹がまだの札には「幹：まだ」 | 毎回 |
| ■ 幹がまだの札（mikiCards）と末尾の幹の一覧 | 幹がまだの札があるときだけ |
| 出力形式の miki・unknown・unknownClose（・mikiCards） | 上のどれかがあるとき |

### 3.2 取り込み

| 返事 | どうするか |
|---|---|
| first | 最初の答え。文ごとに番号と裏の日（読んだ日）。150字を超える文は前から入るところまで入れ、残りを落とす |
| rewrite（basis つき） | 書き直し。**前と一字一句同じ文は、前の番号と裏の日を引き継ぐ**。basis が決まりに無ければ入れずに数える |
| add | 足す。150字を超えたら、**裏が取れた日の古い文から**落とす（同じ日なら前の文から。足した文は最後まで残す） |
| keep（why・backs） | 変えなかった。backs の番号の文だけ裏の日を今日にする |
| 事実の食い違い | 答えに入れず、まだ分からないこと（食い違い）へ |
| unknownClose | まだ分からないことを閉じる（理由つき）。知らない番号は入れずに数える |
| mikiCards | 幹がまだの札にだけ付ける（すでに幹がある札・渡していない札は外して数える） |
| 渡した幹に返事が無い | 「返事の無い幹」として名前を出す |
| 渡していない幹への返事 | 無視して数える |

### 3.4 画面

- **幹の一覧**：「枝 8　新しい枝 9/14　最後に確かめた 9/15」。答えがまだなら「答えはまだ（出発点まだ・中心の切れた推定 2）」
- **幹の画面**（上から）：今の答え ①②③（見出しに「書き直した／足した／最初の答え 9/15・最後に確かめた 9/15」、文ごとに（裏 9/10）、［履歴 N回］で出口・基準・理由・落とした文）→ まだ分からないこと（分かったものは畳む）→ 出発点 → 主な主体・見る地層・予告・枝 → **［この幹を外す］**
- **［この幹を外す］**：押すと「枝 N枚がこの幹から外れます（札は消えません…）。外した幹は戻せません」と［外す］［やめる］。確認の窓は使わない
- **朝の誘い**：最後の読む回より後に幹へ新しい枝が付いたら、枚数に関わらず「幹に新しい枝：制裁が武器になる +3・…（まだ読んでいない札 14枚・途中で切れた推定 90枚）▸」
- **［切り方を直す］**：外しただけのとき、候補や1枚の札から幹を立てたときは「まだ段B を通していません」を出さない。出すのは割り直しの案で幹を足した・名前か1行を直したときだけ

## 5. 仕様書から変えたところ

| 仕様書 | 変えたこと | 理由 |
|---|---|---|
| 最初の答えの出口 | 答えがまだの幹に first 以外（add・rewrite）が返っても、最初の答えとして受ける | 出口の書き間違いで最初の答えを捨てないため |
| 返事の無い答え | 答えがある幹で①②③のどれかが省かれたら「返事の無い答え N つ」と数える（最初の答えでは数えない） | 仕様は「返事の無い幹」だけだったが、答えの一部だけ黙って止まるのも見えるようにした |
| 朝の誘い | 「最後の読む回」＝札に付いた読んだ印の一番新しい日時。割り直しと読む回で付けた枝は数えない | 朝の取り込みと手で立てた幹で来た枝だけを「新しい枝」とするため |

## 6. 公開の前に（実機で確かめてほしいこと）

**触ると壊れる形を先に並べる。**

1. 朝の画面の「幹に新しい枝：…▸」を**指で押す** → 読む欄に移ってコピーされる → Claude に貼る → 返事を貼って［読んだ結果を取り込む］→ 結果に「幹の答え：…」が出る。**条件が揃った幹がまだ無いので、はじめは答えの行は出ず、読む回の今までの結果だけになる**（それで正しい）
2. 幹の一覧で、各幹の「答えはまだ（出発点まだ・中心の切れた推定 N）」の N が、読む回のたびに減っていく
3. 幹の画面の一番下まで送り、**［この幹を外す］を指で押す → ［やめる］** で元に戻る（外さない）
4. 設定 → 世界 の割り直しの欄に「まだ段B を通していません」が出ていない
5. **もう片方の端末で同期して**、幹の一覧の「最後に確かめた日」や理由が同じに見える
6. 条件が揃った幹が出たあとの読む回（数日後。**公開を止める理由にしない**）：結果の1行に「最初の答え：…」が出て、幹の画面に①②③と（裏 日付）が出る。変えなかった回も1行に出る
