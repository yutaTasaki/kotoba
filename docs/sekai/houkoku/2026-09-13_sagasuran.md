### 3. 原因（確かめた）

打ったときの出来事を、ページの中で順番に記録した：

```
blur（入力欄から離れた合図）：打っている入力欄　まだページにつながっている　「戻る印」＝ money
入力欄の打った処理の後：「戻る印」＝ 空
描き直した後：新しい入力欄はあるが、フォーカスは戻っていない（BODY にある）
```

つまり：

1. 探す欄に1文字打つと、**画面をまるごと描き直す**
2. 描き直しで、**打っている最中の入力欄が消える**。このときブラウザが「入力欄から離れた」合図を出す
3. その合図を受けて、**「描き直した後にこの欄へ戻る」印を消していた**
4. 描き直した新しい入力欄は、印が無いのでフォーカスを受け取らない → 2文字目から打てない

**iPhone では、さらに悪い：** この作りのままだと、たとえ印を残しても、描き直しのたびに入力欄が作り直されてキーボードが閉じ、**日本語の変換も途中で切れる**。印を直すだけでは足りない。

### 4. 直し方

**打っている間は、入力欄を作り直さない。探す欄より下の結果だけを描き直す。**

- お金の一覧・世界の画面の探す・概念とアクターの一覧の3か所で、探す欄より下を1つの入れ物にまとめ、打ったときはその入れ物だけを描き直す
- 「あとからフォーカスを戻す」仕掛けは要らなくなったので外した
- ボタン（使い道・種類など）を押したときは今までどおり画面をまるごと描き直す（探す言葉は残る）

## なぜ気づけなかったのか

**答え：確かめの項目に「入力欄に実際に打つ」ものが1つも無かった。**

今日の4回（v20.24〜v20.27）の「実装のときに確かめること」を振り返ると：

- 数の確かめは、**本物のデータを node で流す**か、**ブラウザの中で状態を直接書き換えて画面を描かせる**（「探す言葉を空にする」「使い道を『自社株』にする」を、ボタンを押さずに中身から設定する）形だった
- ボタンは一部 `click()` で押したが、**入力欄に文字を打つ手順はどれにも無かった**
- 探す欄を使う画面（お金の一覧）を毎回確かめていたのに、**探す欄は見た目（はみ出さないか）しか見ていなかった**
- **中身から状態を書き換える確かめは、「押す」「打つ」の処理を通らない。** だから「画面は出るが、触ると動かない」壊れ方を、仕組みとして見つけられなかった

**私の確かめ方の穴です。** 見た目と数だけを確かめて、「動いた」と報告していました。

## これからの確かめの案

### 推奨：3つの層に分ける

| 層 | いつ | 中身 | 手間の見積もり |
|---|---|---|---|
| **A. 触る確かめ（毎回）** | 公開するたび | 下の「基本の触る表」を**ブラウザで本当に押す・打つ**。状態を中身から書き換えない | 1回あたり10分前後（見積もり。測っていません） |
| **B. 触った画面を触る（毎回）** | その版で触った画面 | その画面の**入力欄に2文字以上打って結果が変わるか**、**ボタンを1つずつ押して画面が変わるか**、「戻る」で戻るか | 画面の数による |
| **C. 全部触る（部品を変えたときだけ）** | 探す欄・ボタンの道具・一覧の行など、**複数の画面で使う部品**を変えたとき | その部品を使う画面を全部 | 大きい |

**基本の触る表（A）の案：**

1. お金の一覧の探す欄に2文字以上打つ → 行が絞れる、フォーカスが残る
2. 世界の画面の探す欄に2文字以上打つ → 種類ごとの件数が出る
3. 概念の一覧の探す欄に2文字以上打つ
4. 言葉の一覧の探す欄に2文字以上打つ
5. 知りたいことから引く欄に打つ
6. 地図の種類・地域のボタンを押す → 数が変わる
7. 地図の下の件数を1つ押す → 一覧が開き、戻ると地図に戻る
8. 札を1枚開いて「詳しく」を押す

### 反対するもの

- **「毎回アプリ全部を触る」には反対。** 画面と入力欄が多く（入力欄だけで数十）、毎回全部を触ると確かめの手間が実装を上回る。部品を変えたときだけ（C）にする
- **「数と見た目の確かめをやめて、触る確かめだけにする」にも反対。** 今日見つけた誤り（シリア・米連邦政府・判定の変化0の確認など）は、数の確かめでしか見つからなかった。**両方要る**

### 限界（正直に）

- **iPhone のキーボード・日本語の変換・指で押す感触は、ここでは確かめられない。** A〜C はパソコンのブラウザでの確かめ。iPhone でしか起きない壊れ方は、今までどおり実機で見てもらう必要がある
- 報告の「実機で見るもの」に、**入力欄に打つ項目を必ず1つ入れる**ようにする
