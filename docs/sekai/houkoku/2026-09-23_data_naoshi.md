# データの直し（v20.106〜v20.109）

日付：2026-09-23　元の依頼：チャット（[調査 データは1万日もつか](../chousa/2026-09-23_data_minaoshi.md) の「決めてほしいこと」1〜3に「はい」）
**公開済み（v20.109）。** 本物のデータの写しと偽の GitHub で、2〜3台の端末に見立てて確かめた。

---

## 何をしたか

調査の「直す順」の1〜5、7、8をやった。

| 版 | 使う側から見て変わったこと |
|---|---|
| v20.106 | 同期と保存が軽くなった。端末にある月は、別の端末で変わっていなければ GitHub に取りに行かない。幹の立て直しの依頼文が大きくなりすぎない |
| v20.107 | 取り込む・読む画面は、読む札がある月だけ読み込む。設定を開いただけでは全部の月を読まない |
| v20.108 | 撮るの動画が1本1ファイルになった。**古い動画が一覧から消えなくなった**（10月末に9月の動画が消えて見える件） |
| v20.109 | 設定 → 同期 → くわしく に［全部を書き出す］。GitHub の全部のファイルを1つのファイルに保存する |

## 結果（数字）

**同期と画面を開くときの通信**（本物のデータの写しで数えた）

| | 前（v20.105） | 後（v20.109） |
|---|---|---|
| ふだんの同期1回（何も直していない） | 取りに行く 13回 | **8回**・書き込み 0回 |
| 起動 ＋ 設定を開く | 39回 | **12回** |
| 設定を開くだけ | 13回（世界の全部の月） | **0回** |
| 取り込む・読む画面を開く | 全部の月（今は13か月、1万日で約330か月） | **読む札がある月だけ**（試しでは1か月・1回） |

- 前は、同期のたびに端末にある記録の全部の月を「直した」ことにしていた（古い版の端末から来た記録を拾うための仕掛けが、毎回全部に当たっていた）。これを、その同期で新しく来た記録の月だけにした。13回のうち5回はこれだった
- 別の端末で直した札・記録は、数が同じでも必ず届く（前は数が変わらないと月の日時が進まず、届くのは「開くたびに全部取り直す」のおかげだった）。2台で確かめた：8月・7月・2020年10月の札の直し、9月の記録の直し、言葉の直し、どれも届いた。変わっていない月は1回も取りに行かなかった

**保存**
- 言葉を1回保存するときの重さ：5万枚で約1.1秒 → **約0.3秒**（PC で測定。iPhone はこの数倍）。月の数だけ全部の言葉を見直していたのを、1回で分けるようにした

**依頼文**
- 幹の立て直し：段A は新しい300枚まで、段B は150枚ずつに分けてコピーする（今の186枚だと、1回目150枚・約2.4万字、続き36枚）。同じボタンを押すと続きがコピーされる
- 撮るの学び：すでにある決まり（口調・足すこと・避けること）は新しい順に60件まで

**撮る（v20.108）**
- 次の同期で自動で移る。本物のデータの写しでは、動画2本が toru/ に1本ずつ入り、**記録の9月のファイルは 222KB → 37KB** になった
- 一覧は索引（1本1行の要約）から出すので、端末に無い古い動画も並ぶ。押すと読み込んで開く（試し：15本のうち端末に10本、残り5本は押して開けた）
- 端末に置くのは新しい10本と、開いた動画だけ
- 古い版の端末が記録の中に動画を書いても、新しい版の端末が取り込んで移す（試しで確かめた）
- 設定 → 同期 → くわしく に「撮るの保存方式」。［撮るを記録の月ファイルに戻す］で戻せる（戻す → もう一度移す、を試して、2台とも合った）

**全部を書き出す（v20.109）**
- 試しでは45ファイル・4.6MB が1つのファイルになった。中身は GitHub のものと1文字も違わなかった
- 押すと、先に同期してから取る

## 意味

- 困る順の1（10月末に9月の動画が消える）は無くなった
- 困る順の2（幹の立て直しが大きすぎて使えない）は、札が何千枚になっても1回150枚で回る
- 困る順の3（取り込む画面と設定が全部の月を取りに行く）は、月が何百になっても、読む札のある月だけになった
- 困る順の5（言葉の保存が重い）は約4分の1になった。ただし全部の言葉を書き出して比べる重さは残る（5万枚で約0.3秒）
- GitHub 以外に全部の控えを持てるようになった

## 残り

**端末で確かめてほしいこと**
1. **両方の端末（iPhone と PC）を v20.109 にする。** 古い版のままの端末で札・記録の文を直すと、新しい版の端末に届かないことがある（古い版は数が変わらないと月の日時を進めないため）。設定 → 世界 の一番下に版が出る
2. 新しい版で最初に開いたときだけ、全部の月を一度取り直す（少し時間がかかる）
3. 撮る：設定 → 同期 → くわしく の「撮るの保存方式」が「1本1ファイル（2本…）」になっていれば移っている。撮るの一覧に9/18と9/23の動画が出るか
4. ［全部を書き出す］を一度押して、iPhone の「ファイル」に保存できるか

**まだやっていないこと（調査の直す順から）**
- 6：調べたこと（note の記事・語り・幹の記録）を、起動のたびに全部の月読む。1日約80KB 増えるので、1〜2年で重くなる
- 9：大きさの知らせ（リポジトリ 800MB・1GB、1ファイル50MB）
- 10：概念・主体の番号の一覧、言葉のつながりを開いたときに読む、リポジトリ名を設定に
- 書き出したファイルから戻す（読み込む）機能は無い。いまは GitHub に入れなくなったときの控えとして持つだけ

**気づいたこと**
- 設定の「幹を立てる（割り直し）」と「効かせた相手を埋める」は、全部の札が要るので［全部の月を読み込む］を押してから使う（前は設定を開くと勝手に読んでいた）
