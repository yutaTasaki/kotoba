記録の保存方式

「月ファイル」は記録（朝・相談・引く・問い）を kotoba-data の journal/YYYY-MM.json に月ごとに分けて置く方式です。移行の前に kotoba-data のバックアップを取ってください。戻すこともできます。

言葉の保存方式

「月ファイル」は言葉（ノート）を作成月ごとに kotoba-data の notes/YYYY-MM.json に分けて置く方式です。端末には全件を持つので網・相談は変わりません。同期で送るのは触った月の分だけになります。

瞑想の保存方式

瞑想の記録は最初から kotoba-data の meditation/YYYY.json（年ごと）＋ meditation/index.json に置きます。端末には全年分を持ちます。

v6 からデータは端末の IndexedDB に保存されます。localStorage に残った古いコピーは旧バージョンへ戻すときの保険です。容量が気になるときだけ消してください。

2. Claude API

console.anthropic.com で発行したAPIキーを入力してください。キーは端末のlocalStorageにのみ保存され、data.jsonには含まれません。

自動関連づけのモデル 朝の言葉・相談のモデル 問いのモデル

「問いを引く」に使うモデルです。空欄にすると「朝の言葉・相談のモデル」と同じになります。

月の上限（USD）

今月の概算費用がこの割合（50% / 80% / 100%）に達すると朝タブに知らせます。100%を超えると自動関連づけと朝の言葉を自動で止めます（相談は確認のうえ続行できます）。

この端末の名前

使用量の内訳で、この端末を区別するための表示名です（例: PC、iPhone）。

出典ごとの種類

出典（本・名言集・人名）ごとに、その言葉の種類（名言／本／自分）をまとめて設定します。押すとその出典の言葉すべてに反映されます。

候補の言葉の上限

言葉がこの数以下なら全件を（キャッシュして）モデルに渡します。超えたら、相談・関連づけのたびに「入力に近い言葉」をこの数だけ端末側で選んで渡します。
