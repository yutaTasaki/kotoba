2. Claude API

console.anthropic.com で発行したAPIキーを入力してください。キーは端末のlocalStorageにのみ保存され、data.jsonには含まれません。

自動関連づけのモデル 朝の言葉・相談のモデル 問いのモデル

「問いを引く」に使うモデルです。空欄にすると「朝の言葉・相談のモデル」と同じになります。

月の上限（USD）

今月の概算費用がこの割合（50% / 80% / 100%）に達すると朝タブに知らせます。100%を超えると自動関連づけと朝の言葉を自動で止めます（相談は確認のうえ続行できます）。

この端末の名前

使用量の内訳で、この端末を区別するための表示名です（例: PC、iPhone）。

最長連続の手動設定
